::: problem id=t1 type=choice
"I think the test is tomorrow":
- [x] テストは あしただと おもいます。
- [ ] テストは あしたと おもいます。
- [ ] テストは あしたですと おもいます。
solution: Nouns keep plain だ before と おもいます.
Hear it: !say[テストは あしただと おもいます。]
:::

::: problem id=t2 type=choice
"The hotel was clean and quiet" (きれい, しずか):
- [x] ホテルは きれいで、しずかでした。
- [ ] ホテルは きれくて、しずかでした。
- [ ] ホテルは きれいでした、しずかで。
solution: きれい is a な-adjective: きれいで; the past goes on the last one.
Hear it: !say[ホテルは きれいで、しずかでした。]
:::

::: problem id=t5 type=choice
"Which is bigger, Tokyo or Osaka?":
- [x] とうきょうと おおさかと どちらが おおきいですか。
- [ ] とうきょうは おおさかより どちらですか。
- [ ] とうきょうと おおさかの いちばん おおきいですか。
solution: A と B と どちらが ~ですか.
Hear it: !say[とうきょうと おおさかと どちらが おおきいですか。]
:::

::: problem id=t7 type=choice
Listen: !listen[かぜですか。きょうは はやく かえった ほうが いいですよ。]
What advice does the speaker give?
- [ ] Come in early tomorrow.
- [x] Go home early today.
- [ ] Don't go home today.
solution: はやく かえった ほうが いい: you'd better go home early.

::: problem id=t8 type=choice
Listen: !listen[m|ふゆは なつより すきですが、さむすぎるのは いやです。]
What does the speaker say?
- [x] They like winter more than summer, but hate it being too cold.
- [ ] They like summer more than winter.
- [ ] They like the cold very much.
solution: ふゆは なつより すき (like winter more than summer), さむすぎるのは いや (too cold is unpleasant).
