::: problem id=t1 type=choice
"When I was young" (young = わかい):
- [x] わかい とき
- [ ] わかいな とき
- [ ] わかいの とき
solution: い-adjectives go straight before とき.
Hear it: !say[わかい とき]
:::

::: problem id=t2 type=choice
"I bought a ticket before going to Osaka" (bought it before leaving):
- [x] おおさかに いく とき、きっぷを かいました。
- [ ] おおさかに いった とき、きっぷを かいました。
- [ ] おおさかに いったら、きっぷを かいました。
solution: The going hadn't happened yet: いく とき.
Hear it: !say[おおさかに いく とき、きっぷを かいました。]
:::

::: problem id=t3 type=text answers="たべたら"
Type the たら form of たべる.
hint: tabetara

:::

::: problem id=t4 type=text answers="ひまだったらきてください"

::: problem id=t5 type=choice
"I'm busy, so I can't go" (polite reason):
- [x] いそがしいので、いけません。
- [ ] いそがしいなので、いけません。
- [ ] いそがしいたら、いけません。
solution: い-adjectives take ので directly.
Hear it: !say[いそがしいので、いけません。]
:::

::: problem id=t6 type=choice
Someone asks どうして にほんごを べんきょうして いるんですか. A natural answer is:
- [x] にほんの アニメが すきなんです。
- [ ] にほんの アニメが すきなです。
- [ ] にほんの アニメが すきだんです。
solution: な-adjective + なんです: すきなんです.
Hear it: !say[にほんの アニメが すきなんです。]
:::

::: problem id=t7 type=choice
Listen: !listen[m|うちに ついたら、メールを おくります。]
When will the speaker send an email?
- [x] when he gets home
- [ ] before he leaves
- [ ] if he can't get home
solution: うちに ついたら: when (once) he arrives home.
:::
