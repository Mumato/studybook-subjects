::: problem id=t1 type=choice
"Japanese is more difficult than English" is:
- [x] にほんごは えいごより むずかしいです。
- [ ] えいごは にほんごより むずかしいです。
- [ ] にほんごの ほうが えいごより やさしいです。
solution: A は B より ~.
Hear it: !say[にほんごは えいごより むずかしいです。]
:::

::: problem id=t2 type=text answers="なつのほうがすきです"
Type "I like summer better." (summer = なつ)
hint: natsu no hou ga suki desu
solution: なつの ほうが すきです。
Hear it: !say[なつの ほうが すきです。]
:::

::: problem id=t3 type=choice
"Which season do you like best?" is:
- [x] きせつの なかで いつが いちばん すきですか。
- [ ] きせつと どちらが すきですか。
- [ ] きせつより なにが すきですか。
solution: group の なかで ~ が いちばん; for seasons, いつ (when) is the natural question word.
Hear it: !say[きせつの なかで いつが いちばん すきですか。]
:::

::: problem id=t4 type=text answers="のみすぎました"

:::

::: problem id=t5 type=choice
"You'd better ask the teacher" (ask = きく):
- [x] せんせいに きいた ほうが いいです。
- [ ] せんせいに きく ほうが いけません。
- [ ] せんせいに きかない ほうが いいです。
solution: Plain past + ほうが いい.
Hear it: !say[せんせいに きいた ほうが いいです。]
:::

::: problem id=t6 type=choice
"This bag is too small" (ちいさい):
- [ ] ちいさいすぎます
- [x] ちいさすぎます
- [ ] ちいさくすぎます
solution: Drop い: ちいさ + すぎます.
Hear it: !say[ちいさすぎます]
:::

::: problem id=t7 type=choice
Listen: !listen[m|でんしゃは バスより はやいですが、たかいです。]
What does the speaker say about the train?
- [x] faster than the bus, but expensive
- [ ] slower than the bus, but cheap
- [ ] faster and cheaper than the bus
solution: バスより はやい (faster than the bus), でも たかい (but expensive).
:::

::: problem id=t8 type=choice
Listen: !listen[あしたは しけんですから、こんばんは あそばない ほうが いいですよ。]
What advice is given?
- [ ] Have fun tonight.
- [x] Don't go out and play tonight, there's an exam tomorrow.
- [ ] Take the exam tonight.
solution: あそばない ほうが いい: you'd better not go out/play.
:::
