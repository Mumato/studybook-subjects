::: problem id=t1 type=text answers="ひろくてあかるいです"
Type "It's spacious and bright." (spacious = ひろい, bright = あかるい)
hint: hirokute akarui desu
solution: ひろくて、あかるいです。
Hear it: !say[ひろくて、あかるいです。]
:::

::: problem id=t2 type=choice
"He is kind and funny" (しんせつ, おもしろい):
- [x] かれは しんせつで、おもしろいです。
- [ ] かれは しんせつくて、おもしろいです。
- [ ] かれは しんせつだて、おもしろいです。
solution: しんせつ is a な-adjective: しんせつで.
Hear it: !say[かれは しんせつで、おもしろいです。]
:::

::: problem id=t3 type=choice
せんしゅう かった くつ means:
- [x] the shoes (I) bought last week
- [ ] (I) bought shoes last week
- [ ] the shoes (I'll) buy next week
solution: せんしゅう かった describes くつ.
Hear it: !say[せんしゅう かった くつ]
:::
