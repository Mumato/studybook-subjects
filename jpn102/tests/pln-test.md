::: problem id=t1 type=text answers="はなさない"
Type the ない form of はなす (speak).
hint: su → sa + nai
solution: はなさない.
Hear it: !say[はなさない]
:::

::: problem id=t2 type=text answers="しない"
Type the ない form of する.
hint: shinai
solution: しない.
Hear it: !say[しない]
:::

::: problem id=t3 type=text answers="まった"
Type the plain past of まつ (wait).
hint: まって → まった
solution: まった.
Hear it: !say[まった]
:::

::: problem id=t4 type=choice
"It wasn't fun" (たのしい, plain) is:
- [x] たのしくなかった
- [ ] たのしいじゃなかった
- [ ] たのしなかった
solution: い-adjectives: く + なかった.
Hear it: !say[たのしくなかった]
:::

::: problem id=t5 type=choice
In casual speech, "yes" is usually:
- [x] うん
- [ ] ううん
- [ ] いいえ
solution: うん is yes; ううん is no.
:::

::: problem id=t6 type=text answers="かのじょはこないとおもいます"
Type "I don't think she'll come." (she = かのじょ)
hint: kanojo wa konai to omoimasu
solution: かのじょは こないと おもいます。
Hear it: !say[かのじょは こないと おもいます。]
:::

::: problem id=t7 type=choice
Listen: !listen[m|きのう、ともだちと カラオケに いった。]
