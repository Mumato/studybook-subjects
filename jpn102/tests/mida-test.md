::: problem id=t1 type=text answers="およいで"

::: problem id=t2 type=text answers="かえってください"

solution: かえって ください。 かえる is Group 1: かえって.
Hear it: !say[かえって ください。]
:::

::: problem id=t3 type=choice
"You may not use a dictionary" (dictionary = じしょ, use = つかう):
- [x] じしょを つかっては いけません。

- [ ] じしょを つかって ください。

Hear it: !say[じしょを つかっては いけません。]
:::
