::: problem id=t2 type=choice
"What were you doing yesterday at 8?" is:
- [x] きのう はちじに なにを して いましたか。
- [ ] きのう はちじに なにを して いますか。
- [ ] きのう はちじに なにを しましょうか。
solution: Past progressive: ～て いました.
Hear it: !say[きのう はちじに なにを して いましたか。]
:::
