::: problem id=t1 type=text answers="よんで"
Type the て-form of よむ (read).
hint: yonde
solution: よんで: む → んで.
Hear it: !say[よんで]
:::

::: problem id=t2 type=text answers="きいて"
Type the て-form of きく (listen).
hint: kiite
solution: きいて: く → いて.
Hear it: !say[きいて]
:::

::: problem id=t3 type=choice
The て-form of する is:
- [x] して
- [ ] すって
- [ ] しって
solution: する is irregular: して.
Hear it: !say[して]
:::

::: problem id=t4 type=text answers="ドアをしめてください"
Type "Please close the door." (close = しめる)
hint: doa o shimete kudasai
solution: ドアを しめて ください。
Hear it: !say[ドアを しめて ください。]
:::

::: problem id=t5 type=choice
"May I go home?" is:
- [ ] かえっては いけませんか。
- [x] かえっても いいですか。
- [ ] かえって くださいか。
solution: て-form + も いいですか asks permission.
Hear it: !say[かえっても いいですか。]
:::

::: problem id=t6 type=choice
ばんごはんを たべてから、べんきょうします means:
- [x] I'll study after eating dinner.
- [ ] I'll eat dinner after studying.
- [ ] I study because I eat dinner.
solution: たべてから: after eating.
Hear it: !say[ばんごはんを たべてから、べんきょうします。]
:::

::: problem id=t7 type=choice
Listen: !listen[m|びじゅつかんで しゃしんを とっては いけません。]
What's the rule at the art museum?
- [ ] Photos are allowed.
- [x] Photos are not allowed.
- [ ] Please take photos.
solution: とっては いけません: must not take (photos).
:::

::: problem id=t8 type=choice
Listen: !listen[あさ はやく おきて、さんぽして、あさごはんを たべました。]
What did the speaker do second?
- [ ] got up early
- [x] took a walk
- [ ] had breakfast
solution: おきて (got up), さんぽして (took a walk), たべました (ate breakfast).
:::
