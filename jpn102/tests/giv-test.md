::: problem id=t1 type=choice
Fill in: たなかさんが わたしに おみやげを ＿。
- [ ] あげました
- [x] くれました
- [ ] もらいました
solution: Towards me: くれる.
Hear it: !say[たなかさんが わたしに おみやげを くれました。]
:::

::: problem id=t2 type=choice
Fill in: わたしは あねに ネックレスを ＿。 (I got a necklace from my sister.)
- [ ] くれました
- [x] もらいました
- [ ] あげました
solution: I received: もらいました.
Hear it: !say[わたしは あねに ネックレスを もらいました。]
:::

:::

::: problem id=t4 type=choice
"My mother made me lunch" (as a kindness):
- [x] ははが おべんとうを つくって くれました。
- [ ] ははが おべんとうを つくって あげました。
- [ ] ははに おべんとうを つくって あげました。
solution: Done for me: ～て くれる.
Hear it: !say[ははが おべんとうを つくって くれました。]
:::

::: problem id=t5 type=text answers="しゃしんをとってもらえませんか"
Type "Could you take a photo for me?" (polite, with もらう)
hint: shashin o totte moraemasen ka
solution: しゃしんを とって もらえませんか。
Hear it: !say[しゃしんを とって もらえませんか。]
:::

::: problem id=t6 type=choice
Which sounds condescending to a teacher?
- [x] せんせい、てつだって あげます。
- [ ] せんせい、てつだいましょうか。
- [ ] せんせい、なにか てつだいましょうか。
solution: ～て あげる to a superior sounds like doing them a favour. Offer with ～ましょうか.
:::

::: problem id=t7 type=choice
Listen: !listen[m|おとうとに ゲームを かして あげました。]
What did the speaker do?
- [x] lent his younger brother a game
- [ ] borrowed a game from his brother
- [ ] bought his brother a game
solution: かして あげました: lent (as a favour).
:::

::: problem id=t8 type=choice
Listen: !listen[ともだちに えきまで むかえに きて もらいました。]
What happened?
- [ ] The speaker picked up a friend at the station.
- [x] A friend came to pick the speaker up at the station.
- [ ] The speaker and a friend met at the station by chance.
solution: むかえに きて もらいました: had a friend come to pick (me) up.
:::
