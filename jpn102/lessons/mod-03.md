---
id: mod-03
title: Things like: ～たり～たり, and have you ever: ～ことがある
---
Two patterns built on the plain past (た form): one lists example activities, the other talks about experiences.

::: rule
- **Doing things like A and B**: た form + り, twice, then **する**: !say[しゅうまつは そうじを したり、せんたくを したり します。] *At weekends I do things like cleaning and laundry.*
- Tense goes on the final する: !say[きのうは ほんを よんだり、おんがくを きいたり しました。] *Yesterday I read and listened to music (among other things).*
- **Have done before**: た form + **ことが あります**: !say[すしを たべた ことが あります。] *I've eaten sushi (before).*
- **Have never**: た form + ことが **ありません**: !say[ふじさんに のぼった ことが ありません。] *I've never climbed Mt Fuji.*
- **Have you ever...?**: !say[にほんに いった ことが ありますか。] *Have you ever been to Japan?*
:::

::: example
Getting to know someone:

- A: !say[にほんに いった ことが ありますか。] *Have you ever been to Japan?*
- B: !say[m|はい、いちど あります。きょうとで おてらを みたり、きものを きたり しました。] *Yes, once. In Kyoto I did things like seeing temples and wearing a kimono.*
- A: !say[いいですね。わたしは まだ いった ことが ありません。] *Nice. I've never been yet.*
:::

::: problem id=p1 type=text answers="すしをたべたことがあります"
Type "I've eaten sushi before."
hint: sushi o tabeta koto ga arimasu
solution: すしを たべた ことが あります。
Hear it: !say[すしを たべた ことが あります。]
:::

::: problem id=p2 type=choice
"Have you ever seen a Japanese movie?" is:
- [x] にほんの えいがを みた ことが ありますか。
- [ ] にほんの えいがを みる ことが ありますか。
- [ ] にほんの えいがを みましたか ことが ありますか。
solution: Experience uses the た form: みた ことが ありますか.
Hear it: !say[にほんの えいがを みた ことが ありますか。]
:::

::: problem id=p3 type=text answers="いったことがありません"
Type "I've never been (there)."
hint: itta koto ga arimasen
solution: いった ことが ありません。
Hear it: !say[いった ことが ありません。]
:::

::: problem id=p4 type=choice
"On Sundays I do things like shopping and watching movies" is:
- [x] にちようびは かいものを したり、えいがを みたり します。
- [ ] にちようびは かいものを して、えいがを みたり です。
- [ ] にちようびは かいものを したり、えいがを みます。
solution: ～たり ～たり します, with the final する.
Hear it: !say[にちようびは かいものを したり、えいがを みたり します。]
:::

::: problem id=p5 type=choice
What's the difference between ～て and ～たり?
- [x] ～て lists actions in order (all of them); ～たり gives examples, in no particular order.
- [ ] ～たり is only for the past.
- [ ] There's no difference.
solution: ～て: "I did A, then B." ～たり: "I did things like A and B."
:::

::: problem id=p6 type=text answers="うたをうたったりおどったりしました"
Type "I did things like singing and dancing." (sing = うたを うたう, dance = おどる)
hint: uta o utattari odottari shimashita
solution: うたを うたったり、おどったり しました。
Hear it: !say[うたを うたったり、おどったり しました。]
:::

::: problem id=p7 type=choice
Listen: !listen[m|わたしは ひこうきに のった ことが ありません。]
What does the speaker say?
- [ ] They often fly.
- [x] They've never been on a plane.
- [ ] They flew last week.
solution: のった ことが ありません: have never ridden (a plane).
:::

::: problem id=p8 type=open
Talk about a trip or a day out: say where you've been, and two things you did there with ～たり～たり.
!speak[my trip]
solution: For example: とうきょうに いった ことが あります。とうきょうで ラーメンを たべたり、かいものを したり しました。
:::
