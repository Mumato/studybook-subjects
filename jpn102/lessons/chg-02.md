---
id: chg-02
title: Becoming: ～なる, ～ようになる
---
**なる** (become) describes change: getting colder, becoming a doctor, being able to do something you couldn't before.

::: rule
- **い-adjectives**: drop い, add **くなる**: さむい → !say[さむく なりました] *it's got cold*. いい → !say[よく なりました] *it got better*.
- **な-adjectives and nouns**: add **になる**: しずか → !say[しずかに なりました]; いしゃ → !say[いしゃに なりたいです] *I want to become a doctor*.
- **Starting to be able to**: potential (or dictionary) form + **ように なる**: !say[かんじが よめるように なりました。] *I've become able to read kanji.*
- **Not anymore**: ない form + ように なる / なく なる: !say[たばこを すわなく なりました。] *I've stopped smoking.*
- なる is a Group 1 verb: なります, なった, なって.
:::

::: example
Looking back on the year:

- A: !say[にほんごが じょうずに なりましたね！] *Your Japanese has got really good!*
- B: !say[m|ありがとうございます。まいにち れんしゅうしたので、かんたんな ほんが よめるように なりました。] *Thank you. I practised every day, so I've become able to read simple books.*
- A: !say[らいねんは なにを したいですか。] *What do you want to do next year?*
- B: !say[m|にほんで つうやくに なりたいです。] *I want to become an interpreter in Japan.*
:::

::: problem id=p1 type=text answers="さむくなりました"
Type "It's got cold."
hint: samuku narimashita
solution: さむく なりました。
Hear it: !say[さむく なりました。]
:::

::: problem id=p2 type=choice
"It got quiet" (しずか):
- [x] しずかに なりました。
- [ ] しずかく なりました。
- [ ] しずかな なりました。
solution: な-adjectives: に なる.
Hear it: !say[しずかに なりました。]
:::

::: problem id=p3 type=text answers="せんせいになりたいです"
Type "I want to become a teacher."
hint: sensei ni naritai desu
solution: せんせいに なりたいです。
Hear it: !say[せんせいに なりたいです。]
:::

::: problem id=p4 type=choice
"My cold got better" (かぜ, いい):
- [x] かぜが よく なりました。
- [ ] かぜが いく なりました。
- [ ] かぜが いいに なりました。
solution: いい → よく なる.
Hear it: !say[かぜが よく なりました。]
:::

::: problem id=p5 type=text answers="およげるようになりました"
Type "I've become able to swim."
hint: oyogeru you ni narimashita
solution: およげるように なりました。
Hear it: !say[およげるように なりました。]
:::

::: problem id=p6 type=choice
あには おさけを のまなく なりました means:
- [x] My brother has stopped drinking.
- [ ] My brother became able to drink.
- [ ] My brother wants to drink.
solution: のまなく なる: come to not drink.
Hear it: !say[あには おさけを のまなく なりました。]
:::

::: problem id=p7 type=choice
Listen: !listen[m|さいきん にほんごの ニュースが わかるように なりました。]
What has changed for the speaker?
- [x] They can now understand the news in Japanese.
- [ ] They started reading the news in English.
- [ ] They stopped watching the news.
solution: わかるように なりました: has become able to understand.
:::

::: problem id=p8 type=choice creative=true
Japanese often says にほんごが じょうずに なりましたね even after a few words. How should a learner take this?
- [x] As friendly encouragement; a modest reply like いいえ、まだまだです ("no, I've a long way to go") is the usual response.
- [ ] As proof they're fluent.
- [ ] As sarcasm.
solution: The compliment is kind but common. Responding modestly (いいえ、まだまだです) is the expected social move, and when people stop complimenting you, it often means you really have improved!
:::
