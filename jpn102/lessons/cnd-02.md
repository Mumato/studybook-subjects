---
id: cnd-02
title: If and when: ～たら
---
**たら** is the most useful "if" in Japanese, and it can also mean "when (after)". Make it by adding ら to the plain past.

::: rule
- **Form**: plain past + **ら**: いった → !say[いったら], たべた → !say[たべたら], たかかった → !say[たかかったら], ひまだった → !say[ひまだったら], あめだった → !say[あめだったら]. Negative: なかった → !say[なかったら].
- **If**: !say[あめが ふったら、いきません。] *If it rains, I won't go.* !say[やすかったら、かいます。] *If it's cheap, I'll buy it.*
- **When / once** (something sure to happen): !say[うちに かえったら、でんわします。] *When I get home, I'll call you.*
- **Discovery** (past): !say[ドアを あけたら、ねこが いました。] *When I opened the door, there was a cat.*
- **Advice question**: !say[どう したら いいですか。] *What should I do?*
- The たら part is always completed **before** the main action happens.
:::

::: example
Planning a weekend:

- A: !say[あした ひまだったら、いっしょに えいがを みませんか。] *If you're free tomorrow, would you like to see a movie together?*
- B: !say[m|いいですね。しごとが はやく おわったら、れんらくします。] *Sounds good. If work finishes early, I'll let you know.*
:::

::: problem id=p4 type=choice
えきに ついたら、でんわして ください means:
- [x] Please call when you arrive at the station.
- [ ] Please call before you get to the station.
- [ ] If you call, go to the station.
solution: ～たら here: when/once you've arrived.
Hear it: !say[えきに ついたら、でんわして ください。]
:::

::: problem id=p5 type=choice
"If I had money, I'd buy a car" (money = おかね):
- [x] おかねが あったら、くるまを かいます。
- [ ] おかねが あるから、くるまを かいます。
- [ ] おかねが あったから、くるまを かいました。
solution: あった + ら: if (I) had money.
Hear it: !say[おかねが あったら、くるまを かいます。]
:::

::: problem id=p6 type=choice
You lost your passport and ask a police officer for advice. You say:
- [x] パスポートを なくしました。どう したら いいですか。
- [ ] パスポートを なくしました。どう しても いいですか。
- [ ] パスポートを なくしました。どうして いいですか。
solution: どう したら いいですか means "what should I do?".
Hear it: !say[パスポートを なくしました。どう したら いいですか。]
:::

::: problem id=p7 type=choice
Listen: !listen[m|そつぎょうしたら、にほんで はたらきたいです。]
What does the speaker want to do?
- [x] work in Japan after graduating
- [ ] graduate in Japan
- [ ] work while studying
solution: そつぎょうしたら (after graduating) にほんで はたらきたい (want to work in Japan).
:::

::: problem id=p8 type=choice creative=true
English separates "if" (uncertain) and "when" (certain), but Japanese たら covers both. How do you think listeners tell them apart?
- [x] From context and common sense: うちに かえったら is surely going to happen (when), あめが ふったら might not (if).
- [ ] They can't, it's always ambiguous.
- [ ] たら always means "if".
solution: たら marks "once A is true, then B". Whether A is certain comes from what A is. Japanese has other "if" forms (ば, と, なら) for specific shades of meaning, which you'll meet in JPN201.
:::
