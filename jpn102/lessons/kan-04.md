id: kan-04
title: Kanji: everyday verbs
---
More verb kanji. With these and JPN101's eight, you can write most of the verbs you use every day the way Japanese people do: kanji for the meaning, kana for the ending.

::: rule
- Speaking and thinking: **言** !say[いう] say, **話** !say[はなす] speak (わ in 電話 !say[でんわ] telephone), **書** !say[かく] write, **思** !say[おもう] think, **知** !say[しる] know.
- Living and moving: **住** !say[すむ] live, **立** !say[たつ] stand, **起** !say[おきる] get up, **帰** !say[かえる] return home, **出** !say[でる] leave, go out, **入** !say[はいる] enter.
- Having and trading: **持** !say[もつ] hold, have, **売** !say[うる] sell, **買** !say[かう] buy.
- Signs: **出口** !say[でぐち] exit, **入口** !say[いりぐち] entrance. 売り場 !say[うりば] (sales floor) is on every department store map.
:::

::: example
A short diary:

{朝|あさ}六{時|じ}に{起|お}きて、{友|とも}だちに{電話|でんわ}しました。それから{本|ほん}を{買|か}いに{行|い}きました。{家|いえ}に{帰|かえ}ってから、{日本語|にほんご}で{日記|にっき}を{書|か}きました。

!say[あさ ろくじに おきて、ともだちに でんわしました。それから ほんを かいに いきました。いえに かえってから、にほんごで にっきを かきました。]

*I got up at six and phoned a friend. Then I went to buy a book. After getting home, I wrote my diary in Japanese.*
:::

::: problem id=p3 type=choice
Which is "entrance"?
- [ ] 出口
- [x] 入口
- [ ] 南口
solution: 入口 (いりぐち): entrance. 出口 is the exit.
Hear it: !say[いりぐち]
:::

::: problem id=p6 type=choice
What's the difference between 売る and 買う?
- [x] 売る is sell, 買う is buy.
- [ ] 売る is buy, 買う is sell.
- [ ] They both mean buy.
solution: 売る (うる) sell; 買う (かう) buy. 買 has a shell 貝 (old money) at the bottom.
:::

::: problem id=p7 type=choice
知っていますか means:
- [x] Do you know?
- [ ] Do you have it?
- [ ] Are you standing?
solution: 知る (しる): know.
Hear it: !say[しって いますか]
:::

::: problem id=p8 type=choice

Which kanji is in the verb you heard?
- [x] 持
- [ ] 待
- [ ] 特
solution: もって います: 持って います. 待 (まつ, wait) looks similar.
:::
