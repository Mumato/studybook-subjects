---
id: obl-01
title: Must and don't have to: ～なければいけない, ～なくてもいい
---
Both patterns start from the ない form. Japanese "must" literally says "if (I) don't do it, it's no good": a double negative.

::: rule
- **Must / have to**: ない form, drop い, add **ければ いけません**: いく → いかない → !say[いかなければ いけません] *(I) have to go*, たべる → !say[たべなければ いけません].
- **ければ なりません** means the same, a bit more formal: !say[かえらなければ なりません].
- In speech, なければ is often shortened to **なきゃ**: !say[もう いかなきゃ。] *I have to go now.*
- **Don't have to**: ない form, drop い, add **くても いいです**: !say[いかなくても いいです] *(you) don't have to go*, !say[はらわなくても いいです] *(you) don't have to pay*.
- Compare: ～ても いい (may) / ～ては いけない (must not) / ～なければ いけない (must) / ～なくても いい (don't need to).
:::

::: example
The night before a trip:

- A: !say[あした なんじに おきなければ いけませんか。] *What time do you have to get up tomorrow?*
- B: !say[m|ごじに おきなければ いけません。ひこうきが しちじですから。] *I have to get up at five. The flight is at seven.*
- A: !say[パスポートを わすれないで くださいね。] *Don't forget your passport, OK?*
- B: !say[m|はい。でも、ビザは もって いかなくても いいです。] *Right. But I don't need to take a visa.*

(～ないで ください means "please don't".)
:::

::: problem id=p1 type=text answers="べんきょうしなければいけません"
Type "I have to study."
hint: benkyou shinakereba ikemasen
solution: べんきょうしなければ いけません。
Hear it: !say[べんきょうしなければ いけません。]
:::

::: problem id=p2 type=text answers="またなくてもいいです"
Type "You don't have to wait" in Japanese.
hint: matanakute mo ii desu
solution: またなくても いいです。
Hear it: !say[またなくても いいです。]
:::

::: problem id=p3 type=choice
Which means "You must not eat"?
- [ ] たべなければ いけません。
- [x] たべては いけません。
- [ ] たべなくても いいです。
solution: ～ては いけません is "must not". たべなければ いけません is "must eat".
Hear it: !say[たべては いけません。]
:::

::: problem id=p4 type=choice
もう いかなきゃ means:
- [x] I have to go now.
- [ ] I don't want to go.
- [ ] Let's not go.
solution: なきゃ is the casual short form of なければ (いけない).
Hear it: !say[もう いかなきゃ。]
:::

::: problem id=p5 type=text answers="くすりをのまなければいけません"
Type "I have to take medicine." (medicine = くすり; "take" medicine uses のむ)
hint: kusuri o nomanakereba ikemasen
solution: くすりを のまなければ いけません。
Hear it: !say[くすりを のまなければ いけません。]
:::

::: problem id=p6 type=choice
"You don't have to come tomorrow" is:
- [x] あした こなくても いいです。
- [ ] あした きては いけません。
- [ ] あした こなければ いけません。
solution: くる → こない → こなくても いいです.
Hear it: !say[あした こなくても いいです。]
:::

::: problem id=p7 type=choice
Listen: !listen[m|きょうは しゅくだいを しなくても いいです。]
What does the teacher say?
- [x] There's no need to do homework today.
- [ ] You must do your homework today.
- [ ] You must not do homework today.
solution: しなくても いいです: don't have to do.
:::

::: problem id=p8 type=choice
Listen: !listen[あしたは はやく おきなければ いけません。]
What does the speaker have to do?
- [ ] go to bed early
- [x] get up early tomorrow
- [ ] sleep in tomorrow
solution: はやく おきなければ いけません: must get up early.
:::
