---
id: cnd-01
title: When: ～とき
---
**とき** means "time" or "when". Put a plain-form clause before it, like any noun description, to say when something happens.

::: rule
- Plain form + **とき**: !say[ひまな とき、ほんを よみます。] *When I'm free, I read.* !say[こどもの とき、ロンドンに すんで いました。] *When I was a child, I lived in London.*
- Joining: verbs and い-adjectives as is (!say[さむい とき]), な-adjectives + **な** (!say[しずかな とき]), nouns + **の** (!say[がくせいの とき]).
- **Tense before とき matters** with movement verbs:
  - Dictionary form = the action **hasn't happened yet** at that time: !say[にほんに いく とき、かばんを かいました。] *I bought a bag when (= before) going to Japan.* (bought it at home, on the way)
  - た form = the action **has already happened**: !say[にほんに いった とき、かばんを かいました。] *I bought a bag when I went to Japan.* (bought it in Japan)
- The main sentence at the end shows the overall tense.
:::

::: example
- A: !say[さびしい とき、どう しますか。] *What do you do when you're lonely?*
- B: !say[m|かぞくに でんわします。こどもの ときから、そう して います。] *I call my family. I've done that since I was a child.*
:::

::: problem id=p1 type=text answers="ひまなときえいがをみます"
Type "When I'm free, I watch movies."
hint: hima na toki eiga o mimasu
solution: ひまな とき、えいがを みます。 な-adjectives take な before とき.
Hear it: !say[ひまな とき、えいがを みます。]
:::

::: problem id=p2 type=choice
"When I was a student" is:
- [x] がくせいの とき
- [ ] がくせいな とき
- [ ] がくせい とき
solution: Nouns take の before とき.
Hear it: !say[がくせいの とき]
:::

::: problem id=p3 type=choice
"I bought a souvenir when I went to Kyoto (bought it in Kyoto)":
- [x] きょうとに いった とき、おみやげを かいました。
- [ ] きょうとに いく とき、おみやげを かいました。
- [ ] きょうとに いきます とき、おみやげを かいました。
solution: The going had already happened (you were in Kyoto): いった とき.
Hear it: !say[きょうとに いった とき、おみやげを かいました。]
:::

::: problem id=p4 type=choice
うちを でる とき、「いってきます」と いいます means:
- [x] When leaving home, I say "ittekimasu".
- [ ] After I've left home, I say "ittekimasu".
- [ ] I say "ittekimasu" instead of leaving.
solution: でる とき: at the moment of leaving (before you're out).
Hear it: !say[うちを でる とき、いってきますと いいます。]
:::

::: problem id=p5 type=text answers="さむいときこうちゃをのみます"
Type "When it's cold, I drink black tea." (black tea = こうちゃ)
hint: samui toki koucha o nomimasu
solution: さむい とき、こうちゃを のみます。
Hear it: !say[さむい とき、こうちゃを のみます。]
:::

::: problem id=p6 type=choice
"When I was sick, my friend came" (sick = びょうき, a noun):
- [ ] びょうきな とき、ともだちが きました。
- [x] びょうきの とき、ともだちが きました。
- [ ] びょうき とき、ともだちが きました。
solution: びょうき is a noun: の とき.
Hear it: !say[びょうきの とき、ともだちが きました。]
:::

::: problem id=p7 type=choice
Listen: !listen[m|こどもの とき、まいにち こうえんで あそびました。]
What did the speaker do as a child?
- [x] played in the park every day
- [ ] went to school by bus
- [ ] lived near a park
solution: まいにち こうえんで あそびました: played in the park every day.
:::

::: problem id=p8 type=choice
Listen: !listen[ねる とき、でんきを けして ください。]
What should you do?
- [ ] Turn on the light when you wake up.
- [x] Turn off the light when you go to bed.
- [ ] Sleep with the light on.
solution: ねる とき (when going to bed) でんきを けして (turn off the light).
:::
