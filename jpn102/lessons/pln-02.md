---
id: pln-02
title: Plain past: た and なかった
---
The plain past is easy if you know the て-form: just change て to **た** (and で to **だ**). The negative past changes ない to **なかった**.

::: rule
- **Past affirmative (た form)**: like the て-form with た: たべて → !say[たべた], のんで → !say[のんだ], いって → !say[いった], して → !say[した], きて → !say[きた].
- **Past negative**: ない → **なかった**: たべない → !say[たべなかった], いかない → !say[いかなかった].
- **い-adjectives**: !say[たかかった] (was expensive), !say[たかくなかった] (wasn't). いい → !say[よかった].
- **Nouns and な-adjectives**: !say[あめだった] (was rain), !say[ひまじゃなかった] (wasn't free).
- Casual past question: !say[きのう なに した？] *What did you do yesterday?*
:::

::: example
Two friends on Monday:

- A: !say[しゅうまつ、なに した？] *What did you do at the weekend?*
- B: !say[m|ともだちと うみに いった。すごく たのしかった！] *I went to the beach with friends. It was really fun!*
- A: !say[いいな。わたしは どこにも いかなかった。] *Lucky. I didn't go anywhere.*
:::

::: problem id=p1 type=text answers="のんだ"
Type the plain past of のむ.
hint: のんで → のんだ
solution: のんだ.
Hear it: !say[のんだ]
:::

::: problem id=p2 type=text answers="かいた"

hint: かいて → かいた
solution: かいた.

:::

::: problem id=p3 type=text answers="たべなかった"

hint: tabenakatta

:::

::: problem id=p4 type=choice
The plain past of いい (good) is:
- [ ] いかった
- [x] よかった
- [ ] いいだった
solution: いい uses よ: よかった.
Hear it: !say[よかった]
:::

::: problem id=p5 type=choice
"It wasn't quiet" (しずか, plain) is:
- [x] しずかじゃなかった
- [ ] しずかくなかった
- [ ] しずかなかった
solution: な-adjectives: じゃなかった.
Hear it: !say[しずかじゃなかった]
:::

::: problem id=p6 type=choice
The plain past of くる is:
- [ ] くった
- [x] きた
- [ ] こた
solution: くる → きて → きた.
Hear it: !say[きた]
:::

::: problem id=p7 type=choice
Listen: !listen[m|きのう ぜんぜん ねなかった。]
How did the speaker sleep last night?
- [ ] very well
- [x] not at all
- [ ] a little
solution: ぜんぜん ねなかった: didn't sleep at all.
:::

::: problem id=p8 type=open
In casual Japanese, tell a friend three things you did last weekend and one thing you didn't do.
!speak[my weekend, casually]
solution: For example: どようびに えいがを みた。にちようびに ともだちと ごはんを たべた。それから かいものを した。でも、しゅくだいは しなかった。
:::
