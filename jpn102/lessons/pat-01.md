---
id: pat-01
title: Please don't, before, after and while: ～ないで, ～まえに, ～あとで, ～ながら
---
Four patterns for time and requests that come up in every conversation. Each attaches to a verb form you already know.

::: rule
- **Please don't**: ない form + **で ください**: !say[ここで しゃしんを とらないで ください。] *Please don't take photos here.* Casual: !say[しんぱいしないで。] *Don't worry.*
- **Before doing**: dictionary form + **まえに**: !say[ねる まえに、はを みがきます。] *I brush my teeth before going to bed.* Nouns: noun + の まえに: !say[しょくじの まえに] *before the meal*.
- **After doing**: た form + **あとで**: !say[しゅくだいを した あとで、あそびます。] *I'll play after doing my homework.* Nouns: !say[じゅぎょうの あとで] *after class*.
- **While doing**: ます-stem + **ながら**: !say[おんがくを ききながら、べんきょうします。] *I study while listening to music.* The main action comes last; both actions are by the same person.
- Tense comes from the last verb, as always: ねる まえに is dictionary form even in a past sentence: !say[ねる まえに シャワーを あびました。]
:::

::: example
House rules from a host family:

!say[m|へやの なかで くつを はかないで ください。でかける まえに、でんきを けして ください。ばんごはんの あとで、いっしょに テレビを みましょう。でも、たべながら スマホを みないで くださいね。]

*Please don't wear shoes inside. Turn off the lights before going out. After dinner, let's watch TV together. But please don't look at your phone while eating.*
:::

::: problem id=p1 type=text answers="わすれないでください"
Type "Please don't forget." (forget = わすれる)
hint: wasurenaide kudasai
solution: わすれないで ください。
Hear it: !say[わすれないで ください。]
:::

::: problem id=p2 type=choice
"Before eating, I wash my hands" is:
- [x] たべる まえに、てを あらいます。
- [ ] たべた まえに、てを あらいます。
- [ ] たべて まえに、てを あらいます。
solution: Dictionary form + まえに.
Hear it: !say[たべる まえに、てを あらいます。]
:::

::: problem id=p3 type=choice
"After work, I'll go shopping" (work = しごと, a noun):
- [x] しごとの あとで、かいものに いきます。
- [ ] しごとを あとで、かいものに いきます。
- [ ] しごとする あとで、かいものに いきます。
solution: noun + の あとで.
Hear it: !say[しごとの あとで、かいものに いきます。]
:::

::: problem id=p4 type=text answers="テレビをみながらたべます"
Type "I eat while watching TV."
hint: terebi o minagara tabemasu
solution: テレビを みながら たべます。 み (stem of みる) + ながら.
Hear it: !say[テレビを みながら たべます。]
:::

::: problem id=p5 type=choice
"After I graduated, I got a job" (graduate = そつぎょうする, get a job = しゅうしょくする):
- [x] そつぎょうした あとで、しゅうしょくしました。
- [ ] そつぎょうする あとで、しゅうしょくしました。
- [ ] そつぎょうしながら、しゅうしょくしました。
solution: た form + あとで.
Hear it: !say[そつぎょうした あとで、しゅうしょくしました。]
:::

::: problem id=p6 type=choice
Which sentence is wrong?
- [ ] あるきながら はなします。
- [x] ははが りょうりしながら、わたしは テレビを みます。
- [ ] コーヒーを のみながら ほんを よみます。
solution: ながら needs the same person doing both actions. For two different people, use あいだ or とき.
:::

::: problem id=p7 type=choice
Listen: !listen[m|しけんの まえに、きょうかしょを よく よんで ください。]
What should students do before the exam?
- [x] read the textbook carefully
- [ ] not read the textbook
- [ ] buy the textbook
solution: しけんの まえに (before the exam) よく よんで (read carefully).
:::

::: problem id=p8 type=choice
Listen: !listen[しんぱいしないで。だいじょうぶだよ。]
What is the speaker saying?
- [x] Don't worry, it's fine.
- [ ] I'm worried, is it OK?
- [ ] Don't be late.
solution: しんぱいしないで: don't worry. だいじょうぶ: it's fine.
:::
