id: kan-06
title: Kanji: school, culture and health
---
The last kanji lesson of the semester: words for school, films and songs, and visiting the doctor. With these you know about 140 kanji, the usual first-year total.

::: rule
- School: **校** (!say[がっこう] 学校 school), **語** language (!say[にほんご] 日本語), **文** writing (!say[さくぶん] 作文 essay, !say[ぶんか] 文化 culture), **紙** !say[かみ] paper (!say[てがみ] 手紙 letter), **勉** and **強** (!say[べんきょう] 勉強 study; 強い !say[つよい] strong).
- Question word: **何** !say[なに] / !say[なん] what (!say[なんじ] 何時 what time).
- Culture: **映** and **画** (!say[えいが] 映画 movie), **歌** !say[うた] song (歌う !say[うたう] sing), **有** (!say[ゆうめい] 有名 famous).
- Health: **病** and **院** (!say[びょういん] 病院 hospital; !say[びょうき] 病気 illness).
:::

::: example
A note from a classmate:

きのうは{病気|びょうき}で{学校|がっこう}を{休|やす}みました。{今日|きょう}は{元気|げんき}です。{日本語|にほんご}の{作文|さくぶん}は{何|なん}ページですか。

!say[きのうは びょうきで がっこうを やすみました。きょうは げんきです。にほんごの さくぶんは なんページですか。]

*I was off school sick yesterday. I'm fine today. How many pages is the Japanese essay?*
:::

::: problem id=p4 type=choice

::: problem id=p5 type=choice
有名 means:
- [x] famous
- [ ] name

Hear it: !say[ゆうめい]
:::

- [ ] 作文
- [x] 文化

::: problem id=p8 type=choice

Which kanji is in the word you heard?
- [x] 歌
- [ ] 語
- [ ] 画
solution: うた / うたう: 歌, song, sing.
:::

::: problem id=p9 type=draw answer="文"
Write 文 **writing**.
solution: 文 has 4 strokes. The dot, the horizontal, then the sweep left and the sweep right.
:::

::: problem id=p10 type=draw answer="何"
Write 何 **what**.
solution: 何 has 7 strokes. The person 亻 on the left (two strokes), then 可 on the right.
:::

::: problem id=p11 type=draw answer="有"
Write 有 **have, exist**.
solution: 有 has 6 strokes. The sweep left and the horizontal (in that order, like 右 and unlike 左), then 月 underneath.
:::

::: problem id=p12 type=draw answer="画"
Write 画 **picture**.
solution: 画 has 8 strokes. The top bar, then 田 in the middle, then the open box around it: the left side, then the bottom and right side.
:::

::: problem id=p13 type=draw answer="紙"
Write 紙 **paper**.
solution: 紙 has 10 strokes. 糸 on the left (six strokes), then 氏 on the right.
:::
