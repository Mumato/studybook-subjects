---
id: mod-01
title: Joining descriptions: ～くて and ～で
---
To say "cheap and tasty" or "quiet and pretty", adjectives and nouns have their own て-forms. The last word in the chain shows the tense, just like with verbs.

::: rule
- **い-adjectives**: drop い, add **くて**: やすい → !say[やすくて], おいしい → !say[おいしくて]. いい → !say[よくて].
- **な-adjectives and nouns**: add **で**: しずか → !say[しずかで], がくせい → !say[がくせいで].
- Chains: !say[この みせは やすくて、おいしいです。] *This shop is cheap and tasty.* !say[わたしの へやは ひろくて、きれいで、あかるいです。] *My room is big, clean and bright.*
- Tense goes on the last one: !say[りょこうは たのしくて、おもしろかったです。] *The trip was fun and interesting.*
- People: !say[やまださんは にほんじんで、だいがくの せんせいです。] *Yamada is Japanese and a university teacher.*
- Only join descriptions that point the same way (both good or both bad). For contrast, use でも or が: !say[やすいですが、おいしくないです。] *It's cheap, but not tasty.*
:::

::: example
Describing your town to a new friend:

!say[m|わたしの まちは ちいさくて、しずかです。ひとが しんせつで、たべものも おいしいです。でも、ふゆは さむくて、ゆきが おおいです。]

*My town is small and quiet. The people are kind, and the food is good too. But winters are cold, with lots of snow.*
:::

::: problem id=p1 type=text answers="やすくておいしいです"
Type "It's cheap and tasty."
hint: yasukute oishii desu
solution: やすくて、おいしいです。
Hear it: !say[やすくて、おいしいです。]
:::

::: problem id=p2 type=text answers="しずかできれいです"
Type "It's quiet and pretty."
hint: shizuka de kirei desu
solution: しずかで、きれいです。 Both are な-adjectives: しずか + で.
Hear it: !say[しずかで、きれいです。]
:::

::: problem id=p3 type=choice
The て-form of いい is:
- [ ] いくて
- [x] よくて
- [ ] いいで
solution: いい uses よ: よくて.
Hear it: !say[よくて]
:::

::: problem id=p4 type=choice
"The hotel was old and dirty" (old = ふるい, dirty = きたない):
- [x] ホテルは ふるくて、きたなかったです。
- [ ] ホテルは ふるかったて、きたないです。
- [ ] ホテルは ふるいで、きたなかったです。
solution: ふるい → ふるくて; the past goes on the last adjective.
Hear it: !say[ホテルは ふるくて、きたなかったです。]
:::

::: problem id=p5 type=choice
Which sounds unnatural?
- [ ] たかくて、おいしくないです。
- [ ] やすくて、おいしいです。
- [x] Neither, both are fine.
solution: Trick question: たかくて、おいしくない (expensive and not tasty) is natural because both are bad points. The rule is to join things that point the same way; to contrast, use が or でも.
:::

::: problem id=p6 type=choice
"She is American and a student" is:
- [x] かのじょは アメリカじんで、がくせいです。
- [ ] かのじょは アメリカじんくて、がくせいです。
- [ ] かのじょは アメリカじんだて、がくせいです。
solution: Nouns join with で.
Hear it: !say[かのじょは アメリカじんで、がくせいです。]
:::

::: problem id=p7 type=choice
Listen: !listen[m|この へやは ひろくて、あかるいです。]
How is the room?
- [x] big and bright
- [ ] small and dark
- [ ] big but dark
solution: ひろくて (big/spacious) あかるい (bright).
:::

::: problem id=p8 type=choice creative=true
Why might Japanese ask you to join only descriptions that point "the same way", while English "and" happily joins "cheap and nasty"?
- [x] The て-link implies the qualities fit together naturally; mixing good and bad sounds like a non sequitur, so Japanese marks contrast explicitly with が or でも.
- [ ] Japanese adjectives can't be negative.
- [ ] English never joins opposite qualities.
solution: The て-link suggests a smooth flow. Contrast gets its own signal (が, でも, けど), which makes the speaker's evaluation clear.
:::
