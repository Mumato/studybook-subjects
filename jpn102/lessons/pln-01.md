---
id: pln-01
title: Plain forms: dictionary and ない forms
---
Every polite verb (ます) has a **plain** partner. Friends and family talk in plain forms, and plain forms are also the building blocks for many grammar patterns this semester. Start with the present: the dictionary form (affirmative) and the ない form (negative).

::: rule
- **Present affirmative** = dictionary form: のみます → !say[のむ], たべます → !say[たべる].
- **Present negative (ない form)**:
  - Group 2: replace る with **ない**: !say[たべない], !say[みない].
  - Group 1: change the last **u** sound to **a**, add ない: のむ → !say[のまない], かく → !say[かかない], はなす → !say[はなさない], まつ → !say[またない]. Verbs ending in **う** use **わ**: かう → !say[かわない].
  - Group 3: する → !say[しない], くる → !say[こない].
  - Special: ある → !say[ない] (there isn't).
- **Nouns and な-adjectives**: です → **だ**: !say[がくせいだ]; negative じゃない: !say[がくせいじゃない].
- **い-adjectives**: drop です: !say[たかい], !say[たかくない].
:::

::: example
Polite → plain:

- !say[あした いきますか。] → !say[あした いく？] *Are you going tomorrow?*
- !say[m|いいえ、いきません。] → !say[m|ううん、いかない。] *No, I'm not.*
- !say[ひまですか。] → !say[ひま？] *Are you free?* (In casual questions, だ usually drops.)

In casual speech, はい becomes **うん** and いいえ becomes **ううん**.
:::

::: problem id=p1 type=text answers="のまない"
Type the ない form of のむ.
hint: mu → ma + nai
solution: のまない.
Hear it: !say[のまない]
:::

::: problem id=p2 type=text answers="かわない"
Type the ない form of かう (buy).
hint: Verbs ending in う use わ.
solution: かわない, not かあない.
Hear it: !say[かわない]
:::

::: problem id=p3 type=text answers="こない"
Type the ない form of くる.
hint: It's irregular.
solution: こない.
Hear it: !say[こない]
:::

::: problem id=p4 type=choice

solution: ある is special: its negative is just ない.
Hear it: !say[ない]
:::

::: problem id=p5 type=text answers="みない"

:::

::: problem id=p6 type=choice
The plain form of せんせいです is:
- [x] せんせいだ
- [ ] せんせいる
- [ ] せんせいない
solution: です → だ for nouns.
Hear it: !say[せんせいだ]
:::

::: problem id=p7 type=choice
Listen: !listen[m|きょうは がっこうに いかない。]
What does the speaker say?
- [ ] I'm going to school today.
- [x] I'm not going to school today.
- [ ] I didn't go to school today.
solution: いかない: plain present negative of いく.
:::

::: problem id=p8 type=choice creative=true
Japanese has polite and plain forms of the same sentence. Using plain forms with your teacher or boss would sound rude, and polite forms with close friends would sound cold. How might this change the way you make friends in Japanese?
- [x] Switching from polite to plain forms is a signal of growing closeness; people often agree, explicitly or not, to "drop the です・ます".
- [ ] Friends must always use polite forms.
- [ ] Plain forms are only for children.
solution: Moving to plain speech (タメ語, *tamego*) is a social step. Some people ask directly: タメ語で いい？ "Can we talk casually?"
:::
