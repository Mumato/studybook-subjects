---
id: obl-03
title: Probably and maybe: ～でしょう, ～かもしれません
---
To talk about things you're not sure of, add **でしょう** (probably) or **かもしれません** (might, maybe) to a plain form.

::: rule
- **Probably**: plain form + **でしょう**: !say[あしたは はれるでしょう。] *It'll probably be sunny tomorrow.* (Weather forecasts love this.) With nouns and な-adjectives, drop だ: !say[あしたは あめでしょう。]
- Casual: **だろう** (or rising **でしょ？** for "right?"): !say[おいしいでしょ？] *It's good, right?*
- **Might / maybe**: plain form + **かもしれません**: !say[かぜを ひいたかもしれません。] *I might have caught a cold.* !say[あしたは ゆきかもしれません。] *It might snow tomorrow.* (Again, no だ.)
- Casual: **かもしれない** or just **かも**: !say[いけないかも。] *I might not be able to go.*
- でしょう is more confident than かもしれません: probably vs maybe.
:::

::: example
Planning a picnic:

- A: !say[あしたの てんきは どうでしょうか。] *What will the weather be like tomorrow?*
- B: !say[m|ごぜんは はれるでしょう。でも、ごごは あめが ふるかもしれません。] *It'll probably be sunny in the morning. But it might rain in the afternoon.*
- A: !say[じゃあ、かさを もって いった ほうが いいですね。] *Then we'd better take umbrellas.*
:::

::: problem id=p1 type=text answers="あしたはさむいでしょう"
Type "It'll probably be cold tomorrow."
hint: ashita wa samui deshou
solution: あしたは さむいでしょう。
Hear it: !say[あしたは さむいでしょう。]
:::

::: problem id=p2 type=text answers="たなかさんはこないかもしれません"
Type "Tanaka might not come."
hint: Tanaka-san wa konai kamoshiremasen
solution: たなかさんは こないかもしれません。
Hear it: !say[たなかさんは こないかもしれません。]
:::

::: problem id=p3 type=choice
"It might be a lie" (lie = うそ):
- [ ] うそだかもしれません。
- [x] うそかもしれません。
- [ ] うそですかもしれません。
solution: Nouns drop だ before かもしれません.
Hear it: !say[うそかもしれません。]
:::

::: problem id=p4 type=choice
Which is most confident?
- [x] ふるでしょう。
- [ ] ふるかもしれません。
- [ ] ふるかも。
solution: でしょう (probably) is more confident than かもしれません/かも (maybe).
:::

::: problem id=p5 type=choice
おいしいでしょ？ (rising) means:
- [x] It's tasty, right?
- [ ] It might not be tasty.
- [ ] Is it tasty, I wonder?
solution: Rising でしょ asks for agreement: "right?"
Hear it: !say[おいしいでしょ？]
:::

::: problem id=p6 type=text answers="かぜをひいたかもしれません"
Type "I might have caught a cold."
hint: kaze o hiita kamoshiremasen
solution: かぜを ひいたかもしれません。
Hear it: !say[かぜを ひいたかもしれません。]
:::

::: problem id=p7 type=choice
Listen: !listen[m|あしたは たぶん ゆきが ふるでしょう。]
What's the forecast?
- [x] It'll probably snow tomorrow.
- [ ] It might rain tomorrow.
- [ ] It snowed yesterday.
solution: ゆきが ふるでしょう: it'll probably snow. (たぶん = probably.)
:::

::: problem id=p8 type=choice creative=true
Japanese speakers often add かもしれません or でしょう even when they're fairly sure. Why might that be?
- [x] Sounding less absolute is polite: it leaves room for the listener's view and avoids seeming overconfident.
- [ ] Japanese people are never sure about anything.
- [ ] It's required by grammar.
solution: Hedging is a politeness strategy in many languages, and especially common in Japanese, where direct assertions can feel pushy.
:::
