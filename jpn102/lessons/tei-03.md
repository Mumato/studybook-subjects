id: tei-03
title: Reading: a letter from Japan
---
A letter from an exchange student to her old teacher, packed with ～ている (what she's doing these days, where she lives, what people are wearing in a photo) and the て-form.

::: rule
Reading tips for this letter:
- **～ています** in this letter means three different things: an action going on now, a habit these days, or a state (lives, is married). Decide which one from the verb.
- **Linked sentences**: a て-form in the middle means "and"; the tense is on the last verb.
- Letters start with a **season greeting** and end with a wish for the reader's health: set phrases you can reuse.
:::

::: example
{先生|せんせい}、お{元気|げんき}ですか。

わたしは いま おおさかに すんで います。まいにち だいがくで にほんごを べんきょうして います。ホストファミリーの おかあさんは とても しんせつで、まいばん おいしい ばんごはんを つくって くれます。

しゃしんを おくります。まんなかで あかい セーターを きて いる ひとが ホストファミリーの おかあさんです。めがねを かけて いる ひとは おとうさんです。おとうさんは ぎんこうで はたらいて います。

いま、まどの そとでは ゆきが ふって います。さむいですが、げんきです。

先生も おからだに 気を つけて ください。

!say[せんせい、おげんきですか。わたしは いま おおさかに すんで います。まいにち だいがくで にほんごを べんきょうして います。ホストファミリーの おかあさんは とても しんせつで、まいばん おいしい ばんごはんを つくって くれます。しゃしんを おくります。まんなかで あかい セーターを きて いる ひとが ホストファミリーの おかあさんです。めがねを かけて いる ひとは おとうさんです。おとうさんは ぎんこうで はたらいて います。いま、まどの そとでは ゆきが ふって います。さむいですが、げんきです。せんせいも おからだに きを つけて ください。]

New words: まいばん every evening, おくる send, まんなか in the middle, おからだに 気を つけて please take care of yourself.
:::

::: problem id=p1 type=choice
Where does the writer live now?
- [x] Osaka
- [ ] Tokyo
- [ ] Kyoto
solution: おおさかに すんで います.
:::

::: problem id=p2 type=choice
What does the host mother do every evening?
- [ ] teaches Japanese
- [x] cooks dinner for the writer
- [ ] works at a bank
solution: まいばん ばんごはんを つくって くれます: makes dinner (for me).
:::

::: problem id=p3 type=choice
In the photo, who is wearing a red sweater?
- [x] the host mother
- [ ] the host father
- [ ] the writer
solution: あかい セーターを きて いる ひとが ホストファミリーの おかあさんです.
:::

::: problem id=p4 type=choice
How can you recognize the host father in the photo?
- [ ] He's wearing a hat.
- [x] He's wearing glasses.
- [ ] He's in the middle.
solution: めがねを かけて いる ひとは おとうさんです.
:::

::: problem id=p5 type=choice
What is the weather like as she writes?
- [ ] It's raining.
- [x] It's snowing.
- [ ] It's sunny.
solution: ゆきが ふって います: it's snowing (right now).
:::

::: problem id=p6 type=choice
In おとうさんは ぎんこうで はたらいて います, what does ～て います express?
- [ ] an action happening right this second
- [x] his job: what he does these days
- [ ] a finished action
solution: An ongoing activity (his job), not "is working at this moment".
:::

::: problem id=p7 type=open

:::
