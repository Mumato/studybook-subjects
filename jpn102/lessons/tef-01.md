id: tef-01
title: Verb groups and the て-form
---
Until now you've used verbs in their polite ます form. Japanese verbs also have a **dictionary form** (the plain form you'd look up), and from it you build the **て-form**, the most useful verb form in the language. First you need to know which of three groups a verb belongs to.

::: rule
- **Dictionary form**: たべます → !say[たべる], のみます → !say[のむ], いきます → !say[いく].
- **Group 2 (る-verbs)**: dictionary form ends in **-iru** or **-eru**, and the ます form drops just る: たべる → たべます. て-form: replace る with **て**: !say[たべて], !say[みて], !say[ねて], !say[おきて].
- **Group 1 (う-verbs)**: everything else. The て-form depends on the last sound:
  - う, つ, る → **って**: !say[かって] (かう), !say[まって] (まつ), !say[かえって] (かえる)
  - む, ぶ, ぬ → **んで**: !say[のんで] (のむ), !say[あそんで] (あそぶ), !say[しんで] (しぬ)
  - く → **いて**: !say[かいて] (かく). Exception: いく → !say[いって].
  - ぐ → **いで**: !say[およいで] (およぐ)
  - す → **して**: !say[はなして] (はなす)
- **Group 3 (irregular)**: する → !say[して], くる → !say[きて].
- Watch out: some -iru/-eru verbs are Group 1: かえる (go home) → かえります, かえって; はいる (enter) → はいって; しる (know) → しって.
:::

::: example
Turning ます forms into て-forms:

- よみます → dictionary よむ (む) → !say[よんで]
- ききます → きく (く) → !say[きいて]
- たべます → たべる (Group 2) → !say[たべて]
- べんきょうします → べんきょうする (Group 3) → !say[べんきょうして]

A trick: if the sound just before ます is an **e** sound (たべます, ねます, みせます), the verb is Group 2. If it is an **i** sound, it is usually Group 1 (のみます → のむ, かえります → かえる), but a few common ones are Group 2: みます (みる), おきます (おきる), います (いる), かります (かりる). When in doubt, learn the dictionary form with the verb.
:::

::: problem id=p1 type=text answers="のんで"
Type the て-form of のむ (drink).
hint: む → んで
solution: のんで (nonde).
Hear it: !say[のんで]
:::

::: problem id=p2 type=text answers="かいて"
Type the て-form of かく (write).
hint: く → いて

Hear it: !say[かいて]
:::

::: problem id=p3 type=text answers="いって"
Type the て-form of いく (go).
hint: The one exception among く verbs.
solution: いって (itte), not いいて.
Hear it: !say[いって]
:::

::: problem id=p4 type=text answers="まって"

hint: つ → って
solution: まって (matte).
Hear it: !say[まって]
:::

::: problem id=p5 type=choice
Which group is かえる (go home)?
- [x] Group 1 (う-verb), so かえって
- [ ] Group 2 (る-verb), so かえて
- [ ] Group 3 (irregular)
solution: かえる looks like an -eru verb, but it's Group 1: かえります, かえって.
Hear it: !say[かえって]
:::

::: problem id=p6 type=text answers="はなして"
Type the て-form of はなす (speak).
hint: す → して
solution: はなして (hanashite).
Hear it: !say[はなして]
:::

::: problem id=p7 type=choice
What's the て-form of くる (come)?
- [ ] くって
- [x] きて
- [ ] こって
solution: くる is irregular: きて.
Hear it: !say[きて]
:::

::: problem id=p8 type=choice
Listen: !listen[あそんで]
Which verb is this the て-form of?
- [x] あそぶ (play)
- [ ] あそむ
- [ ] あそる
solution: あそんで comes from あそぶ: ぶ → んで. (There's no verb あそむ.)
:::
