---
id: pat-02
title: Something, nothing, and so on: なにか, なにも, や, ～のが好き
---
Small words with big uses: "something" and "nothing", listing examples with や, and turning a verb into a noun with の so you can say what you like **doing**.

::: rule
- **Something / someone / somewhere**: question word + **か**: !say[なにか たべましたか。] *Did you eat something?* !say[だれか きました。] *Someone came.* !say[どこかに いきたいです。] *I want to go somewhere.*
- **Nothing / no one / nowhere**: question word + **も** + negative verb: !say[なにも たべませんでした。] *I ate nothing.* !say[だれも いません。] *There's no one.* With places, keep the particle: !say[どこにも いきませんでした。] *I went nowhere.*
- **A, B and so on**: **や** lists examples (と lists everything): !say[かばんの なかに ほんや ペンが あります。] *There are books, pens and so on in my bag.*
- **Doing as a noun**: plain verb + **の**: !say[りょうりを するのが すきです。] *I like cooking.* !say[およぐのが じょうずです。] *(She)'s good at swimming.* Also with へた (bad at), きらい.
:::

::: example
- A: !say[しゅうまつ、どこかに いきましたか。] *Did you go anywhere at the weekend?*
- B: !say[m|いいえ、どこにも いきませんでした。うちで ほんを よむのが すきですから。] *No, I didn't go anywhere. I like reading at home.*
- A: !say[どんな ほんを よみますか。] *What kind of books do you read?*
- B: !say[m|しょうせつや まんがを よみます。] *Novels, manga and so on.*
:::

::: problem id=p1 type=text answers="なにかのみますか"
Type "Will you drink something?"
hint: nanika nomimasu ka
solution: なにか のみますか。
Hear it: !say[なにか のみますか。]
:::

::: problem id=p2 type=text answers="なにもかいませんでした"
Type "I didn't buy anything."
hint: nanimo kaimasen deshita
solution: なにも かいませんでした。
Hear it: !say[なにも かいませんでした。]
:::

::: problem id=p3 type=choice
"There's no one in the room" is:
- [x] へやに だれも いません。
- [ ] へやに だれか いません。
- [ ] へやに だれも います。
solution: だれも + negative.
Hear it: !say[へやに だれも いません。]
:::

::: problem id=p4 type=choice
"I didn't go anywhere" is:
- [x] どこにも いきませんでした。
- [ ] どこも いきませんでした。
- [ ] どこかに いきませんでした。
solution: Places keep their particle: どこにも.
Hear it: !say[どこにも いきませんでした。]
:::

::: problem id=p5 type=choice
What's the difference between すしと てんぷら and すしや てんぷら?
- [x] と lists everything (just those two); や gives examples (and other things).
- [ ] や is more polite.
- [ ] There's no difference.
solution: と: a complete list. や: examples from a longer list.
:::

::: problem id=p6 type=text answers="うたをうたうのがすきです"
Type "I like singing." (sing a song = うたを うたう)
hint: uta o utau no ga suki desu
solution: うたを うたうのが すきです。
Hear it: !say[うたを うたうのが すきです。]
:::

::: problem id=p7 type=choice
"My brother is bad at cooking":
- [x] あには りょうりを するのが へたです。
- [ ] あには りょうりを するが へたです。
- [ ] あには りょうりを しての へたです。
solution: Plain verb + の が へた.
Hear it: !say[あには りょうりを するのが へたです。]
:::

::: problem id=p8 type=choice
Listen: !listen[m|けさは なにも たべませんでした。]
What did the speaker eat this morning?
- [ ] something light
- [x] nothing
- [ ] toast and coffee
solution: なにも たべませんでした: ate nothing.
