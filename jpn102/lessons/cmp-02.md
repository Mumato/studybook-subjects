---
id: cmp-02
title: Too much and should: ～すぎる, ～ほうがいい
---
Two very common patterns: saying something is **too** much, and giving **advice**.

::: rule
- **Too ~ / overdo it**: verb ます-stem + **すぎる**: たべすぎる (eat too much): !say[たべすぎました。] *I ate too much.*
- With adjectives: drop い / な, add すぎる: !say[たかすぎます] *too expensive*, !say[しずかすぎます] *too quiet*. いい → !say[よすぎる].
- すぎる is a Group 2 verb: すぎます, すぎた, すぎて.
- **You'd better / you should**: plain past + **ほうが いいです**: !say[はやく ねた ほうが いいですよ。] *You'd better go to bed early.*
- **You'd better not**: ない form + ほうが いいです: !say[むりを しない ほうが いいです。] *You shouldn't overdo it.*
- Advice with よ sounds friendly; without it, it can sound blunt.
:::

::: example
At the doctor's:

- Patient: !say[ゆうべ のみすぎて、あたまが いたいです。] *I drank too much last night and have a headache.*
- Doctor: !say[m|みずを たくさん のんだ ほうが いいですよ。きょうは おさけを のまない ほうが いいです。] *You'd better drink a lot of water. You shouldn't drink alcohol today.*
:::

::: problem id=p1 type=text answers="たべすぎました"
Type "I ate too much."
hint: tabesugimashita
solution: たべすぎました。
Hear it: !say[たべすぎました。]
:::

::: problem id=p2 type=text answers="たかすぎます"
Type "It's too expensive."
hint: takasugimasu
solution: たかすぎます: たかい → たか + すぎます.
Hear it: !say[たかすぎます。]
:::

::: problem id=p3 type=choice
"This room is too quiet" (しずか):
- [x] この へやは しずかすぎます。
- [ ] この へやは しずかなすぎます。
- [ ] この へやは しずかくすぎます。
solution: な-adjectives drop な: しずか + すぎます.
Hear it: !say[この へやは しずかすぎます。]
:::

::: problem id=p4 type=text answers="やすんだほうがいいです"
Type "You'd better rest."
hint: yasunda hou ga ii desu
solution: やすんだ ほうが いいです。 Advice uses the plain past.
Hear it: !say[やすんだ ほうが いいです。]
:::

::: problem id=p5 type=choice
"You shouldn't go" is:
- [ ] いった ほうが いいです。
- [x] いかない ほうが いいです。
- [ ] いかなかった ほうが いいです。
solution: Negative advice uses the ない form: いかない ほうが いい.
Hear it: !say[いかない ほうが いいです。]
:::

::: problem id=p6 type=choice
Your friend coughs a lot and smokes. Which advice is natural?
- [x] たばこを やめた ほうが いいですよ。
- [ ] たばこを やめすぎた ほうが いいですよ。
- [ ] たばこを やめる ほうが いけません。
solution: やめた ほうが いい: you'd better quit.
Hear it: !say[たばこを やめた ほうが いいですよ。]
:::

::: problem id=p7 type=choice
Listen: !listen[m|この ズボンは ちょっと ながすぎます。]
What's wrong with the trousers?
- [ ] too short
- [x] a bit too long
- [ ] too expensive
solution: ながすぎます: too long.
:::

::: problem id=p8 type=choice creative=true
A Japanese friend says この レストランは ちょっと たかすぎますね rather than "This place is overpriced". What does the softener ちょっと do here?
- [x] It makes a criticism gentler and keeps the conversation friendly, even when the meaning is clearly "too expensive".
- [ ] It means the price is only slightly high.
- [ ] It's a mistake.
solution: ちょっと ("a little") is a classic softener in Japanese: it tones down complaints, refusals and requests without changing the message.
:::
