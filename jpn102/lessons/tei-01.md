---
id: tei-01
title: ～ている: what's happening now
---
て-form + **いる** (polite **います**) describes an action that is going on, like English "-ing". It's also used for habits: things you're doing these days.

::: rule
- **In progress**: て-form + います: !say[いま なにを して いますか。] *What are you doing now?* !say[テレビを みて います。] *I'm watching TV.*
- Negative: て-form + **いません**: !say[いま あめは ふって いません。] *It isn't raining now.*
- Past: て-form + **いました**: !say[きのうの よる しちじに なにを して いましたか。] *What were you doing at 7 last night?*
- **Habits and ongoing activities**: !say[まいにち ジムで うんどうして います。] *I'm working out at the gym every day (these days).* !say[だいがくで にほんごを べんきょうして います。] *I'm studying Japanese at university.*
- **Jobs**: !say[あには ぎんこうで はたらいて います。] *My older brother works at a bank.*
- In casual speech, い often drops: みてる, してる (you'll hear this a lot).
:::

::: example
A phone call:

- A: !say[もしもし、いま なにを して いますか。] *Hello, what are you doing now?*
- B: !say[m|ともだちと カフェで しゅくだいを して います。] *I'm doing homework with a friend at a café.*
- A: !say[そうですか。わたしは いえで ごはんを つくって います。] *I see. I'm cooking at home.*
:::

::: problem id=p1 type=text answers="ほんをよんでいます"
Type "I'm reading a book."
hint: hon o yonde imasu
solution: ほんを よんで います。
Hear it: !say[ほんを よんで います。]
:::

::: problem id=p2 type=text answers="なにをしていますか"
Type "What are you doing?"
hint: nani o shite imasu ka
solution: なにを して いますか。
Hear it: !say[なにを して いますか。]
:::

::: problem id=p3 type=choice
あめが ふって います means:
- [x] It's raining.
- [ ] It rained.
- [ ] It will rain.
solution: ふって います: is falling, it's raining now.
Hear it: !say[あめが ふって います。]
:::

::: problem id=p4 type=choice
"My mother works at a hospital" (hospital = びょういん) is:
- [ ] ははは びょういんで はたらきました。
- [x] ははは びょういんで はたらいて います。
- [ ] ははは びょういんに はたらいて います。
solution: An ongoing job uses ～て います, and the place of work takes で.
Hear it: !say[ははは びょういんで はたらいて います。]
:::

::: problem id=p5 type=choice
"I wasn't sleeping" is:
- [x] ねて いませんでした。
- [ ] ねませんで います。
- [ ] ねて いません。
solution: Past negative of ～て いる: ～て いませんでした.
Hear it: !say[ねて いませんでした。]
:::

::: problem id=p6 type=choice
In casual speech, みて いる often becomes:
- [ ] みいる
- [x] みてる
- [ ] みって
solution: The い drops: みてる, してる, たべてる.
Hear it: !say[みてる]
:::

::: problem id=p7 type=choice
Listen: !listen[m|いま おとうとは へやで ゲームを して います。]
What is the younger brother doing?
- [ ] studying in his room
- [x] playing a game in his room
- [ ] sleeping in his room
solution: ゲームを して います: playing a game.
:::

::: problem id=p8 type=choice
Listen: !listen[さいきん まいあさ はしって います。]
What is the speaker saying?
- [x] They run every morning these days.
- [ ] They are running right now.
- [ ] They ran this morning.
solution: さいきん (recently) まいあさ (every morning) はしって います: a current habit.
:::
