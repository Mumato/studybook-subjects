---
id: pln-03
title: I think and they said: ～と思います, ～と言っていました
---
Plain forms let you report thoughts and other people's words. Put a plain-form sentence before **と** (the "quotation" particle), then add the verb for thinking or saying.

::: rule
- **I think that...**: plain form + **と おもいます**: !say[あしたは あめが ふると おもいます。] *I think it will rain tomorrow.* !say[たなかさんは こないと おもいます。] *I don't think Tanaka will come.*
- With nouns and な-adjectives, plain だ stays: !say[あの ひとは せんせいだと おもいます。] *I think that person is a teacher.*
- **(Someone) said that...**: plain form + **と いって いました**: !say[やまださんは いそがしいと いって いました。] *Yamada said she was busy.*
- **Why do you think so?**: !say[どうして そう おもいますか。]
- **What do you think about X?**: X **に ついて** どう おもいますか: !say[にほんの たべものに ついて どう おもいますか。]
:::

::: example
A discussion in class:

- Teacher: !say[m|にほんごの テストは どうだったと おもいますか。] *How do you think the Japanese test went?*
- Student: !say[ちょっと むずかしかったと おもいます。でも、ぜんぶ かいたと おもいます。] *I think it was a bit hard. But I think I answered everything.*
- Teacher: !say[m|リーさんは かんたんだったと いって いましたよ。] *Lee said it was easy, you know.*
:::

::: problem id=p1 type=text answers="あしたははれるとおもいます"
Type "I think it'll be sunny tomorrow." (become sunny = はれる)
hint: ashita wa hareru to omoimasu
solution: あしたは はれると おもいます。
Hear it: !say[あしたは はれると おもいます。]
:::

::: problem id=p2 type=choice
"I think he's a student" is:
- [x] かれは がくせいだと おもいます。
- [ ] かれは がくせいと おもいます。
- [ ] かれは がくせいですと おもいます。
solution: Nouns keep plain だ before と おもいます.
Hear it: !say[かれは がくせいだと おもいます。]
:::

::: problem id=p3 type=choice
"I don't think it's expensive" is usually said:
- [x] たかくないと おもいます。
- [ ] たかいと おもいません。
- [ ] たかくないです おもいます。
solution: Japanese puts the negative inside the thought: たかくないと おもいます. (たかいと おもいません sounds stronger, like disagreeing.)
Hear it: !say[たかくないと おもいます。]
:::

::: problem id=p4 type=text answers="すずきさんはあしたこないといっていました"
Type "Suzuki said she won't come tomorrow."
hint: Suzuki-san wa ashita konai to itte imashita
solution: すずきさんは あした こないと いって いました。
Hear it: !say[すずきさんは あした こないと いって いました。]
:::

::: problem id=p5 type=choice
How do you ask "What do you think about this movie?"
- [ ] この えいがは なんと おもいますか。
- [x] この えいがに ついて どう おもいますか。
- [ ] この えいがを どう いって いましたか。
solution: X に ついて どう おもいますか.
Hear it: !say[この えいがに ついて どう おもいますか。]
:::

::: problem id=p6 type=choice
Which sentence uses the right form before と?
- [ ] たなかさんは きますと おもいます。
- [x] たなかさんは くると おもいます。
- [ ] たなかさんは きてと おもいます。
solution: Use the plain form before と: くると おもいます.
Hear it: !say[たなかさんは くると おもいます。]
:::

::: problem id=p7 type=choice
Listen: !listen[m|せんせいは らいしゅう テストが あると いって いました。]
What did the teacher say?
- [x] There will be a test next week.
- [ ] There was a test last week.
- [ ] There's no test next week.
solution: らいしゅう テストが あると: that there's a test next week.
:::

::: problem id=p8 type=choice
Listen: !listen[あの レストランは たかいと おもいます。]
What does the speaker think?
- [ ] The restaurant is cheap.
- [x] The restaurant is expensive.
- [ ] The restaurant is closed.
solution: たかいと おもいます: I think it's expensive.
:::
