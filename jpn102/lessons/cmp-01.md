---
id: cmp-01
title: Comparisons: より, のほう and いちばん
---
Which is bigger, faster, more fun? Japanese comparisons don't change the adjective (no "-er" or "more"): the particles do all the work.

::: rule
- **A is more ~ than B**: A は B **より** ~: !say[とうきょうは おおさかより おおきいです。] *Tokyo is bigger than Osaka.*
- **Which is more ~, A or B?**: A と B と **どちらが** ~ですか: !say[いぬと ねこと どちらが すきですか。] *Which do you like better, dogs or cats?*
- **Answer**: A の **ほうが** ~: !say[ねこの ほうが すきです。] *I like cats better.* Or both: !say[どちらも すきです。]
- **The most ~ (in a group)**: group の なかで X が **いちばん** ~: !say[くだものの なかで りんごが いちばん すきです。] *Of all fruit, I like apples best.*
- Asking: !say[スポーツの なかで なにが いちばん すきですか。] For people use だれ, for places どこ, for times いつ.
:::

::: example
Choosing a travel destination:

- A: !say[きょうとと ほっかいどうと どちらに いきたいですか。] *Which do you want to go to, Kyoto or Hokkaido?*
- B: !say[m|ほっかいどうの ほうが いいです。きょうとより すずしいですから。] *Hokkaido's better. It's cooler than Kyoto.*
- A: !say[にほんで どこが いちばん すきですか。] *Where in Japan do you like best?*
- B: !say[m|おきなわが いちばん すきです。] *I like Okinawa best.*
:::

::: problem id=p1 type=choice
ふじさんは たかおさんより たかいです means:
- [x] Mt Fuji is higher than Mt Takao.
- [ ] Mt Takao is higher than Mt Fuji.
- [ ] Mt Fuji and Mt Takao are the same height.
solution: A は B より ~: A is more ~ than B. (たかい here means high/tall.)
Hear it: !say[ふじさんは たかおさんより たかいです。]
:::

::: problem id=p2 type=text answers="コーヒーのほうがすきです"

solution: コーヒーの ほうが すきです。
Hear it: !say[コーヒーの ほうが すきです。]
:::

::: problem id=p3 type=choice
How do you ask "Which is cheaper, the bus or the train?"
- [x] バスと でんしゃと どちらが やすいですか。
- [ ] バスは でんしゃより やすいですか どちら。
- [ ] バスと でんしゃの いちばん やすいですか。
solution: A と B と どちらが ~ですか.
Hear it: !say[バスと でんしゃと どちらが やすいですか。]
:::

::: problem id=p4 type=choice
Fill in: クラスの なかで だれが ＿ せが たかいですか。 (Who's the tallest in the class?)
- [ ] より
- [ ] ほうが
- [x] いちばん
solution: いちばん: most, -est.
Hear it: !say[クラスの なかで だれが いちばん せが たかいですか。]
:::

::: problem id=p5 type=text answers="あにはわたしよりせがたかいです"

Hear it: !say[あには わたしより せが たかいです。]
:::

::: problem id=p6 type=choice
Someone asks なつと ふゆと どちらが すきですか. You like both. You say:
- [ ] どちらが すきです。
- [x] どちらも すきです。
- [ ] いちばん すきです。
solution: どちらも: both.
Hear it: !say[どちらも すきです。]
:::

::: problem id=p7 type=choice
Listen: !listen[m|にほんの たべものの なかで ラーメンが いちばん すきです。]
What's the speaker's favourite Japanese food?
- [ ] sushi
- [x] ramen
- [ ] tempura
solution: ラーメンが いちばん すきです.
:::

::: problem id=p8 type=choice
Listen: !listen[しんかんせんは ひこうきより おそいですが、べんりです。]
What does the speaker say about the bullet train?
- [x] It's slower than a plane, but convenient.
- [ ] It's faster than a plane.
- [ ] It's more expensive than a plane.
solution: ひこうきより おそい: slower than a plane; でも/が べんり: but convenient.
:::
