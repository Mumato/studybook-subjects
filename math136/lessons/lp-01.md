title: Lines in space
---
A line is a starting point plus any multiple of a direction. That description works the same in 2D, 3D or any $\mathbb{R}^n$. (Nicholson ch. 4)

::: rule
The line through point $P$ with direction $\vec{d} \ne \vec{0}$:
$$\vec{x} = P + t\vec{d}, \quad t \in \mathbb{R}$$
- Component by component this gives the **parametric equations**: $x = p_1 + td_1$, $y = p_2 + td_2$, $z = p_3 + td_3$.
- Through two points $A$ and $B$: use $P = A$ and $\vec{d} = B - A$.
- A point lies on the line when **one** value of $t$ works in **every** component.
- Two lines are **parallel** when their directions are multiples of each other.
:::

::: example
The line through $(1, 2, 3)$ with direction $(2, -1, 4)$: $x = 1 + 2t$, $y = 2 - t$, $z = 3 + 4t$.
At $t = 2$ it passes through $(5, 0, 11)$. Is $(7, -1, 15)$ on it? $1 + 2t = 7$ gives $t = 3$; then $y = -1$ and $z = 15$. ✓ Yes.
:::

::: problem id=p1 type=numeric answer="-1"
For the line $x = 1 + 2t$, $y = 2 - t$, $z = 3 + 4t$, what is $z$ when $t = -1$?
solution: $3 + 4(-1) = -1$. The point is $(-1, 3, -1)$.
:::

::: problem id=p2 type=numeric answer="4"
A line passes through $A = (1, 0, 2)$ and $B = (3, 4, -1)$. Using $\vec{d} = B - A$, what is the second component of $\vec{d}$?
solution: $\vec{d} = (2, 4, -3)$: second component 4.
:::

::: problem id=p3 type=numeric answer="0.5"
Same line, $\vec{x} = (1, 0, 2) + t(2, 4, -3)$. For which $t$ does it reach $x = 2$?
solution: $1 + 2t = 2$, so $t = 0.5$. (The point is $(2, 2, 0.5)$, halfway from $A$ to $B$.)
:::

::: problem id=p4 type=choice
Is $(3, 1, 6)$ on the line $\vec{x} = (1, 2, 3) + t(2, -1, 4)$?
- [ ] Yes, with $t = 1$
- [x] No
solution: $x$: $1 + 2t = 3$ gives $t = 1$. Then $y = 1$ ✓ but $z = 7 \ne 6$. No single $t$ works.
:::

::: problem id=p5 type=choice
Which line is parallel to $\vec{x} = (0, 1, 5) + t(2, -1, 4)$?
- [x] $\vec{x} = (3, 3, 3) + s(-4, 2, -8)$
- [ ] $\vec{x} = (0, 1, 5) + s(1, 2, 0)$
- [ ] $\vec{x} = (2, -1, 4) + s(1, 1, 1)$
solution: $(-4, 2, -8) = -2(2, -1, 4)$: same direction up to a multiple.
:::

::: problem id=p6 type=numeric answer="7"
The line $\vec{x} = (1, -1) + t(3, 4)$ in the plane: what is $y$ when $x = 7$?
solution: $1 + 3t = 7$ gives $t = 2$; $y = -1 + 4(2) = 7$.
:::

::: problem id=p7 type=numeric answer="2"
The lines $\vec{x} = (1, 0) + t(1, 1)$ and $\vec{x} = (5, 0) + s(-1, 1)$ cross. What is the $y$-coordinate of the crossing point?
hint: Set $1 + t = 5 - s$ and $t = s$.
solution: $1 + t = 5 - t$ gives $t = 2$. The point is $(3, 2)$: $y = 2$.
:::
