title: Planes
---
A plane in $\mathbb{R}^3$ is fixed by one point and a **normal vector**: a vector perpendicular to the whole plane. (Nicholson ch. 4)

::: rule
- The plane through $P$ with normal $\vec{n} = (a, b, c)$: $\vec{n} \cdot (\vec{x} - P) = 0$, which expands to the **scalar equation**
$$ax + by + cz = d$$
where $d = \vec{n} \cdot P$.
- The coefficients of $x, y, z$ form a normal vector.
- Through three points $A, B, C$: $\vec{n} = (B - A) \times (C - A)$.
- Distance from point $Q$ to the plane: $\frac{|ax_0 + by_0 + cz_0 - d|}{\|\vec{n}\|}$.
:::

::: example
The plane through $(1, 2, 3)$ with normal $(2, -1, 4)$: $2x - y + 4z = 2 - 2 + 12 = 12$.
Distance from $(1, 1, 1)$ to $2x - y + 2z = 9$: $\frac{|2 - 1 + 2 - 9|}{\sqrt{4 + 1 + 4}} = \frac{6}{3} = 2$.
:::

::: problem id=p1 type=numeric answer="12"
The plane through $(1, 2, 3)$ with normal $(2, -1, 4)$ is $2x - y + 4z = d$. What is $d$?
solution: $2(1) - 2 + 4(3) = 12$.
:::

::: problem id=p2 type=numeric answer="3"
A plane passes through $(1, 0, 0)$, $(0, 2, 0)$ and $(0, 0, 3)$. Its normal is $(6, b, 2)$. What is $b$?
solution: $B - A = (-1, 2, 0)$ and $C - A = (-1, 0, 3)$. Their cross product is $(6, 3, 2)$.
:::

::: problem id=p3 type=numeric answer="6"
Same plane, $6x + 3y + 2z = d$. What is $d$?
solution: Put in $(1, 0, 0)$: $d = 6$. Check $(0, 2, 0)$: $6$ ✓.
:::

::: problem id=p4 type=numeric answer="1/3" tolerance=0.001
Find the distance from $(3, 0, 1)$ to the plane $x + 2y + 2z = 4$. (A fraction, or 3 decimals.)
solution: $\frac{|3 + 0 + 2 - 4|}{\sqrt{1 + 4 + 4}} = \frac{1}{3} \approx 0.333$.
:::

::: problem id=p5 type=numeric answer="2.6"
The line $\vec{x} = (1, 2, 3) + t(2, -1, 4)$ meets the plane $x + y + z = 10$. What is the $x$-coordinate of the meeting point?
solution: $(1 + 2t) + (2 - t) + (3 + 4t) = 10$ gives $6 + 5t = 10$, $t = 0.8$. So $x = 1 + 1.6 = 2.6$.
:::

::: problem id=p6 type=choice
Are the planes $2x - y + 3z = 4$ and $-4x + 2y - 6z = 1$ parallel?
- [x] Yes: their normals are multiples of each other
- [ ] No: their right sides differ
- [ ] No: they meet in a line
solution: $(-4, 2, -6) = -2(2, -1, 3)$. Different right sides (after scaling) mean they're parallel and distinct.
:::

::: problem id=p7 type=numeric answer="16"
The plane through $(2, 1, -1)$, $(0, 3, 1)$ and $(1, 0, 2)$ has normal $(8, 4, 4)$. Write it as $8x + 4y + 4z = d$. What is $d$?
solution: Use $(2, 1, -1)$: $16 + 4 - 4 = 16$.
:::

::: problem id=p8 type=choice creative=true
A line's direction $\vec{d}$ is orthogonal to a plane's normal $\vec{n}$ ($\vec{d} \cdot \vec{n} = 0$). The line:
- [x] is parallel to the plane (or lies in it)
- [ ] is perpendicular to the plane
- [ ] must cross the plane at one point
solution: Moving along $\vec{d}$ never changes $\vec{n} \cdot \vec{x}$, so the line stays at a constant "height" above the plane.
:::
