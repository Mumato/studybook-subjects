title: Linear transformations and their matrices
---
A function that sends vectors to vectors and respects addition and scaling is a **linear transformation**. Every one of them is just multiplication by a matrix. (Nicholson ch. 2)

::: rule
- $T: \mathbb{R}^n \to \mathbb{R}^m$ is **linear** if $T(\vec{u} + \vec{v}) = T(\vec{u}) + T(\vec{v})$ and $T(c\vec{v}) = cT(\vec{v})$. In particular $T(\vec{0}) = \vec{0}$.
- Its **standard matrix** has the images of the standard basis vectors as columns:
$$A = [\,T(\vec{e}_1) \ \cdots \ T(\vec{e}_n)\,]$$
Then $T(\vec{x}) = A\vec{x}$ for every $\vec{x}$.
- A formula like $T(x, y) = (2x + y, \ x - 3y)$ is linear when every output is a combination of the inputs with no constants, powers or products.
:::

::: example
$T(x, y) = (2x + y, \ x - 3y)$. Then $T(\vec{e}_1) = (2, 1)$ and $T(\vec{e}_2) = (1, -3)$, so
$$A = \begin{bmatrix} 2 & 1 \\ 1 & -3 \end{bmatrix}$$
and $T(3, 1) = A(3, 1) = (7, 0)$.
:::

::: problem id=p1 type=numeric answer="-1"
$T(x, y, z) = (x + 2z, \ y - z)$. What is the second component of $T(1, 2, 3)$?
solution: $2 - 3 = -1$. (The first is $1 + 6 = 7$.)
:::

::: problem id=p2 type=numeric answer="2"
Same $T$. Its standard matrix is $2 \times 3$. What is entry (1, 3)?
solution: $T(\vec{e}_3) = T(0, 0, 1) = (2, -1)$ is column 3, so entry (1, 3) is 2.
:::

::: problem id=p3 type=numeric answer="17"
A linear $T$ has $T(\vec{e}_1) = (1, 2)$ and $T(\vec{e}_2) = (3, -1)$. What is the first component of $T(2, 5)$?
solution: $T(2, 5) = 2(1, 2) + 5(3, -1)$, which is $(17, -1)$.
:::

::: problem id=p4 type=choice
Which map is linear?
- [ ] $T(x, y) = (x + 1, y)$
- [ ] $T(x, y) = (xy, x)$
- [x] $T(x, y) = (3y, x - y)$
- [ ] $T(x, y) = (x^2, y)$
solution: Only combinations of $x$ and $y$ with no constants, products or powers. The first fails $T(\vec{0}) = \vec{0}$.
:::

::: problem id=p5 type=numeric answer="10"
$T$ is linear with $T(\vec{v}) = (2, 5)$. What is the second component of $T(2\vec{v})$?
solution: $T(2\vec{v}) = 2T(\vec{v}) = (4, 10)$.
:::

::: problem id=p6 type=numeric answer="3"
A linear $T: \mathbb{R}^3 \to \mathbb{R}^2$. How many columns does its standard matrix have?
solution: One column per input basis vector: 3. (It's $2 \times 3$.)
:::

::: problem id=p7 type=numeric answer="-1"
$T(\vec{u}) = (1, 4)$ and $T(\vec{v}) = (2, -1)$. What is the first component of $T(3\vec{u} - 2\vec{v})$?
solution: $T(3\vec{u} - 2\vec{v}) = 3(1, 4) - 2(2, -1)$. First component: $3 - 4 = -1$ (the second is $12 + 2 = 14$).
:::
