::: problem id=t1 type=numeric answer="3"
Solve $x + y = 5$ and $2x - y = 4$. What is $x$?
solution: Adding: $3x = 9$, so $x = 3$ (and $y = 2$).
:::

::: problem id=t2 type=numeric answer="2"
What is the rank of the matrix with rows $(1, 2, 3)$, $(2, 4, 6)$, $(1, 0, 1)$?
solution: Row 2 is twice row 1. Rows 1 and 3 are independent: rank 2.
:::

::: problem id=t3 type=numeric answer="11"
Find $(1, -2, 2) \cdot (3, 0, 4)$.
solution: $3 + 0 + 8 = 11$.
:::

::: problem id=t4 type=numeric answer="7"
Find $\|(2, 3, 6)\|$.
solution: $\sqrt{4 + 9 + 36} = \sqrt{49} = 7$.
:::

::: problem id=t5 type=numeric answer="7"
$A$ has rows $(2, 1)$ and $(0, 3)$; $B$ has rows $(1, 4)$ and $(2, -1)$. What is entry (1, 2) of $AB$?
solution: $(2, 1) \cdot (4, -1) = 8 - 1 = 7$.
:::

::: problem id=t6 type=numeric answer="-9"
Find the determinant of the matrix with rows $(2, 1, 3)$, $(0, -1, 4)$, $(1, 2, 0)$.
solution: Down column 1: $2(0 - 8) + 1(4 + 3)$, which is $-16 + 7 = -9$.
:::

::: problem id=t7 type=numeric answer="2"
The plane through $(1, 1, 1)$ with normal $(1, 2, -1)$ is $x + 2y - z = d$. What is $d$?
solution: $1 + 2 - 1 = 2$.
:::

::: problem id=t8 type=numeric answer="-1"
Find the entry (1, 2) of the inverse of $\begin{bmatrix} 3 & 1 \\ 5 & 2 \end{bmatrix}$.
solution: $ad - bc = 6 - 5 = 1$. The inverse has rows $(2, -1)$ and $(-5, 3)$.
:::
