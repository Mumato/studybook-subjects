id: expr-01
title: Variables and writing expressions
---
::: rule
A **variable** is a letter that stands for a number we don't know yet. An **expression** combines numbers and variables with operations.

$3n$ means $3 \times n$. Common phrases:
- "5 more than n": $n + 5$
- "twice n": $2n$
- "3 less than n": $n - 3$ (careful with the order!)
- "n divided by 4": $\frac{n}{4}$
:::

::: example
"7 less than 3 times a number n" is $3n - 7$.
:::

::: example
Tickets cost 8 dollars. The cost of n tickets is $8n$ dollars.
:::

Use the letter n in your answers, like 3n-7.

::: problem id=x18 type=expression answer="3n+3" vars="n" set=extra
n is an integer. Write the sum of n and the next two integers.
hint: The next two integers are $n + 1$ and $n + 2$.
solution: $n + (n + 1) + (n + 2) = 3n + 3$.
:::

::: problem id=x19 type=expression answer="6n+6" vars="n" set=extra
A rectangle is n wide, and its length is 3 more than twice its width. Write its perimeter.
hint: Length is $2n + 3$. Add all four sides.
solution: $n + (2n + 3) + n + (2n + 3) = 6n + 6$.
:::

::: problem id=x20 type=expression answer="9n" vars="n" set=extra creative=true
Pens cost 3 dollars each, but in every group of 4 pens one is free. Write the cost, in dollars, of $4n$ pens.
hint: How much does one group of 4 cost?
solution: One group of 4: pay for 3, so 9 dollars. $4n$ pens are n groups: $9n$ dollars.
:::
