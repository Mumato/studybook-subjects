---
id: expr-01
title: Variables and writing expressions
---
::: rule
A **variable** is a letter that stands for a number we don't know yet. An **expression** combines numbers and variables with operations.

$3n$ means $3 \times n$. Common phrases:
- "5 more than n": $n + 5$
- "twice n": $2n$
- "3 less than n": $n - 3$ (careful with the order!)
- "n divided by 4": $\frac{n}{4}$
:::

::: example
"7 less than 3 times a number n" is $3n - 7$.
:::

::: example
Tickets cost 8 dollars. The cost of n tickets is $8n$ dollars.
:::

Use the letter n in your answers, like 3n-7.

::: problem id=p1 type=expression answer="n+5" vars="n"
Write "5 more than n".
solution: $n + 5$.
:::

::: problem id=p2 type=expression answer="2n" vars="n"
Write "twice n".
solution: $2n$.
:::

::: problem id=p3 type=expression answer="n/4" vars="n"
Write "n divided by 4".
solution: $\frac{n}{4}$, typed n/4.
:::

::: problem id=p4 type=expression answer="n-3" vars="n"
Write "3 less than n".
hint: Start with n, then take 3 away.
solution: $n - 3$.
:::

::: problem id=p5 type=expression answer="6n+1" vars="n"
Write "the product of 6 and n, plus 1".
solution: $6n + 1$.
:::

::: problem id=p6 type=choice
Which expression means "10 less than n"?
- [x] $n - 10$
- [ ] $10 - n$
hint: "Less than" flips the order.
solution: Start with n and take 10 away: $n - 10$.
:::

::: problem id=p7 type=expression answer="8n" vars="n"
Tickets cost 8 dollars each. Write the cost of n tickets.
solution: $8n$.
:::

::: problem id=p8 type=expression answer="n^2-2" vars="n"
Write "the square of n, minus 2".
solution: $n^2 - 2$, typed n^2-2.
:::
