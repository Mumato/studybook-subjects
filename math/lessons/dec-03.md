---
id: dec-03
title: Multiplying decimals
---
::: rule
Multiply as if there were no decimal points. Then count the digits after the decimal point in **both** numbers: the answer gets that many.

Multiplying by 10, 100, 1000 moves the decimal point 1, 2, 3 places to the **right**.
:::

::: example
$2.3 \times 0.4$

$23 \times 4 = 92$. There are 2 decimal digits in total (one in 2.3, one in 0.4), so the answer is **0.92**.
:::

::: example
$1.25 \times 100 = 125$ (the point moves two places right).
:::

::: problem id=p1 type=numeric answer="4.2"
$0.6 \times 7 = ?$
solution: $6 \times 7 = 42$, one decimal digit: **4.2**.
:::

::: problem id=p2 type=numeric answer="2.25"
$1.5 \times 1.5 = ?$
hint: $15 \times 15 = 225$.
solution: $15 \times 15 = 225$, two decimal digits: **2.25**.
:::

::: problem id=p3 type=numeric answer="31.4"
$3.14 \times 10 = ?$
solution: Move the point one place right: **31.4**.
:::

::: problem id=p4 type=numeric answer="0.06"
$0.2 \times 0.3 = ?$
hint: $2 \times 3 = 6$, and there are two decimal digits.
solution: $2 \times 3 = 6$, two decimal digits: **0.06**.
:::

::: problem id=p5 type=numeric answer="24.3"
$4.05 \times 6 = ?$
solution: $405 \times 6 = 2430$, two decimal digits: 24.30 = **24.3**.
:::

::: problem id=p6 type=numeric answer="8"
Apples cost 3.20 dollars per kg. How much for 2.5 kg?
solution: 3.20 is the same as 3.2. $32 \times 25 = 800$, and 3.2 and 2.5 have two decimal digits together: 8.00 = **8** dollars.
:::

::: problem id=p7 type=numeric answer="1"
$0.125 \times 8 = ?$
solution: $125 \times 8 = 1000$, three decimal digits: 1.000 = **1**.
:::

::: problem id=p8 type=numeric answer="0.5"
$12.5 \times 0.04 = ?$
hint: $125 \times 4 = 500$.
solution: $125 \times 4 = 500$, three decimal digits: 0.500 = **0.5**.
:::
