---
id: wn-03
title: Subtracting whole numbers
---
::: rule
To subtract, line the numbers up by place value and subtract one column at a time, starting with the **ones**.

If the top digit is smaller, **borrow** 1 from the next column: the top digit gets 10 more and the next column gets 1 less.

**Check** your answer by adding: answer + number you took away = number you started with.
:::

::: example
Subtract $524 - 268$.

Ones: 4 is less than 8, so borrow. $14 - 8 = 6$. The tens digit 2 becomes 1.
Tens: 1 is less than 6, so borrow. $11 - 6 = 5$. The hundreds digit 5 becomes 4.
Hundreds: $4 - 2 = 2$.

The answer is **256**. Check: $256 + 268 = 524$.
:::

::: example
$1000 - 357 = 643$. Check: $643 + 357 = 1000$.
:::

::: problem id=p2 type=numeric answer="362"

::: problem id=c1 type=numeric answer="7" creative=true

hint: The tens digits should be next to each other, like 2_ and 3_.
solution: Put 2 and 3 in the tens places. Make the smaller number as big as possible (24) and the bigger as small as possible (31): $31 - 24 = 7$. Other choices give 9 or more, so the answer is **7**.

::: problem id=x10 type=choice set=extra
