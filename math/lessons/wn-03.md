---
id: wn-03
title: Subtracting whole numbers
---
::: rule
To subtract, line the numbers up by place value and subtract one column at a time, starting with the **ones**.

If the top digit is smaller, **borrow** 1 from the next column: the top digit gets 10 more and the next column gets 1 less.

**Check** your answer by adding: answer + number you took away = number you started with.
:::

::: example
Subtract $524 - 268$.

Ones: 4 is less than 8, so borrow. $14 - 8 = 6$. The tens digit 2 becomes 1.
Tens: 1 is less than 6, so borrow. $11 - 6 = 5$. The hundreds digit 5 becomes 4.
Hundreds: $4 - 2 = 2$.

The answer is **256**. Check: $256 + 268 = 524$.
:::

::: example
$1000 - 357 = 643$. Check: $643 + 357 = 1000$.
:::

::: problem id=p1 type=numeric answer="45"
$92 - 47 = ?$
hint: 2 is less than 7, so borrow from the 9.
solution: Ones: $12 - 7 = 5$. Tens: $8 - 4 = 4$. Answer: **45**. Check: $45 + 47 = 92$.
:::

::: problem id=p2 type=numeric answer="362"
$600 - 238 = ?$
hint: You have to borrow across the zeros.
solution: Think of 600 as 5 hundreds, 9 tens and 10 ones. Ones: $10 - 8 = 2$. Tens: $9 - 3 = 6$. Hundreds: $5 - 2 = 3$. Answer: **362**.
:::

::: problem id=p3 type=numeric answer="2137"
$5013 - 2876 = ?$
solution: $5013 - 2876 = 2137$. Check: $2137 + 2876 = 5013$.
:::

::: problem id=p4 type=numeric answer="650"
A trail is 2,400 m long. You have walked 1,750 m. How many metres are left?
solution: $2400 - 1750 = 650$ m.
:::

::: problem id=p5 type=numeric answer="1105"
How much greater is 8,104 than 6,999?
hint: "How much greater" means subtract.
solution: $8104 - 6999 = 1105$. Check: $1105 + 6999 = 8104$.
:::

::: problem id=p6 type=numeric answer="5679"
$10000 - 4321 = ?$
solution: $10000 - 4321 = 5679$. Check: $5679 + 4321 = 10000$.
:::

::: problem id=p7 type=numeric answer="36"
A game costs 59 dollars. You have 23 dollars. How many more dollars do you need?
solution: $59 - 23 = 36$, so you need **36 dollars** more.
:::

::: problem id=p8 type=numeric answer="450"
Start with 500. Subtract 125, then add 75. What do you get?
hint: Do the steps in order.
solution: $500 - 125 = 375$, then $375 + 75 = 450$.
:::

::: problem id=c1 type=numeric answer="7" creative=true
Use each of the digits 1, 2, 3 and 4 exactly once to make two 2-digit numbers. Make their difference as small as possible. What is that smallest difference?
hint: The tens digits should be next to each other, like 2_ and 3_.
solution: Put 2 and 3 in the tens places. Make the smaller number as big as possible (24) and the bigger as small as possible (31): $31 - 24 = 7$. Other choices give 9 or more, so the answer is **7**.
:::
