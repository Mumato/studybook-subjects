---
id: expr-03
title: Combining like terms
---
::: rule
**Like terms** have the same variable to the same power: $3x$ and $5x$ are like terms, $3x$ and $3x^2$ are not. Numbers on their own are like terms with each other.

To **simplify**, add or subtract the numbers in front (the **coefficients**) of like terms:
$3x + 5x = 8x$
:::

::: example
$4a + 2 - a + 6$

Group like terms: $(4a - a) + (2 + 6) = 3a + 8$.
:::

::: example
$2x^2 + 3x + x^2 = 3x^2 + 3x$ (the $x^2$ terms combine; $3x$ stays on its own).
:::

::: problem id=p1 type=numeric answer="8"
Simplify $3x + 5x$. What number goes in front of x?
solution: $3 + 5 = 8$, so $8x$.
:::

::: problem id=p2 type=numeric answer="5"
Simplify $7y - 2y$. What number goes in front of y?
solution: $7 - 2 = 5$, so $5y$.
:::

::: problem id=p3 type=choice
Simplify $4a + 2 - a + 6$.
- [x] $3a + 8$
- [ ] $5a + 8$
- [ ] $3a + 4$
hint: $-a$ means $-1a$.
solution: $4a - a = 3a$ and $2 + 6 = 8$: $3a + 8$.
:::

::: problem id=p4 type=numeric answer="2"
Simplify $2x + 3 + 5x - 1$. What is the number without an x?
solution: $3 - 1 = 2$. (The whole answer is $7x + 2$.)
:::

::: problem id=p5 type=numeric answer="3"
Simplify $x + x + x$. What number goes in front of x?
solution: Each x is $1x$: $1 + 1 + 1 = 3$, so $3x$.
:::

::: problem id=p6 type=choice
Simplify $6m - 6m + 2$.
- [x] $2$
- [ ] $12m + 2$
- [ ] $2m$
solution: $6m - 6m = 0$, leaving **2**.
:::

::: problem id=p7 type=numeric answer="-3"
Simplify $5n - 8n$. What number goes in front of n?
solution: $5 - 8 = -3$, so $-3n$.
:::

::: problem id=p8 type=numeric answer="4"
Simplify $3x^2 + 2x + x^2$. What number goes in front of $x^2$?
hint: Only the $x^2$ terms combine.
solution: $3x^2 + x^2 = 4x^2$. (The whole answer is $4x^2 + 2x$.)
:::
