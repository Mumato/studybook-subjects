---
id: expr-03
title: Combining like terms
---
::: rule
**Like terms** have the same variable to the same power: $3x$ and $5x$ are like terms, $3x$ and $3x^2$ are not. Numbers on their own are like terms with each other.

To **simplify**, add or subtract the numbers in front (the **coefficients**) of like terms:
$3x + 5x = 8x$
:::

::: example
$4a + 2 - a + 6$

Group like terms: $(4a - a) + (2 + 6) = 3a + 8$.
:::

::: example
$2x^2 + 3x + x^2 = 3x^2 + 3x$ (the $x^2$ terms combine; $3x$ stays on its own).
:::

::: problem id=p1 type=numeric answer="8"
Simplify $3x + 5x$. What number goes in front of x?
solution: $3 + 5 = 8$, so $8x$.
:::

::: problem id=p2 type=numeric answer="5"
Simplify $7y - 2y$. What number goes in front of y?
solution: $7 - 2 = 5$, so $5y$.
:::

::: problem id=p3 type=choice
Simplify $4a + 2 - a + 6$.
- [x] $3a + 8$
- [ ] $5a + 8$
- [ ] $3a + 4$
hint: $-a$ means $-1a$.
solution: $4a - a = 3a$ and $2 + 6 = 8$: $3a + 8$.
:::

::: problem id=p4 type=numeric answer="2"
Simplify $2x + 3 + 5x - 1$. What is the number without an x?
solution: $3 - 1 = 2$. (The whole answer is $7x + 2$.)
:::

::: problem id=p5 type=numeric answer="3"
Simplify $x + x + x$. What number goes in front of x?
solution: Each x is $1x$: $1 + 1 + 1 = 3$, so $3x$.
:::

::: problem id=p6 type=choice
Simplify $6m - 6m + 2$.
- [x] $2$
- [ ] $12m + 2$
- [ ] $2m$
solution: $6m - 6m = 0$, leaving **2**.
:::

::: problem id=p7 type=numeric answer="-3"
Simplify $5n - 8n$. What number goes in front of n?
solution: $5 - 8 = -3$, so $-3n$.
:::

::: problem id=p8 type=numeric answer="4"
Simplify $3x^2 + 2x + x^2$. What number goes in front of $x^2$?
hint: Only the $x^2$ terms combine.
solution: $3x^2 + x^2 = 4x^2$. (The whole answer is $4x^2 + 2x$.)
:::

::: problem id=x1 type=numeric answer="13" set=extra
Simplify $9x + 4x$. What number goes in front of x?
solution: $9 + 4 = 13$, so $13x$.
:::

::: problem id=x2 type=numeric answer="-3" set=extra
Simplify $12y - 15y$. What number goes in front of y?
solution: $12 - 15 = -3$, so $-3y$.
:::

::: problem id=x3 type=numeric answer="5" set=extra
Simplify $a + 6a - 2a$. What number goes in front of a?
solution: $1 + 6 - 2 = 5$, so $5a$.
:::

::: problem id=x4 type=numeric answer="3" set=extra
Simplify $4x - 7 + 2x + 10$. What is the number without an x?
solution: $-7 + 10 = 3$. (The whole answer is $6x + 3$.)
:::

::: problem id=x5 type=choice set=extra
Simplify $5m + 3 - 2m - 8$.
- [x] $3m - 5$
- [ ] $3m + 5$
- [ ] $7m - 5$
- [ ] $-2m$
solution: $5m - 2m = 3m$ and $3 - 8 = -5$: $3m - 5$.
:::

::: problem id=x6 type=choice set=extra
Which pair are like terms?
- [x] $4x^2$ and $-x^2$
- [ ] $3x$ and $3y$
- [ ] $2x$ and $2x^2$
- [ ] $5$ and $5x$
solution: Same variable to the same power: $4x^2$ and $-x^2$.
:::

::: problem id=x7 type=numeric answer="-3" set=extra
Simplify $-x + 4x - 6x$. What number goes in front of x?
solution: $-1 + 4 - 6 = -3$, so $-3x$.
:::

::: problem id=x8 type=numeric answer="1.75" set=extra
Simplify $0.5y + 1.25y$. What number goes in front of y?
solution: $0.5 + 1.25 = 1.75$.
:::

::: problem id=x9 type=numeric answer="5/6" set=extra
Simplify $\frac{1}{2}x + \frac{1}{3}x$. What number goes in front of x?
solution: $\frac{3}{6} + \frac{2}{6} = \frac{5}{6}$.
:::

::: problem id=x10 type=expression answer="6x+5" set=extra
A triangle has sides $2x$, $3x + 1$ and $x + 4$. Write its perimeter.
solution: $2x + 3x + x = 6x$ and $1 + 4 = 5$: $6x + 5$.
:::

::: problem id=x11 type=choice set=extra
Zoe simplifies $3x + 2y$ to $5xy$. What is right?
- [ ] $5xy$ is right.
- [ ] $5x$
- [x] They are not like terms, so it stays $3x + 2y$.
- [ ] $6xy$
solution: x and y are different variables, so $3x$ and $2y$ can't be combined.
:::

::: problem id=x12 type=numeric answer="7" set=extra
Simplify $3a + 2b - a + 5b$. What number goes in front of b?
solution: $2b + 5b = 7b$. (The whole answer is $2a + 7b$.)
:::

::: problem id=x13 type=numeric answer="4" set=extra
Simplify $5x^2 - 3x + 2x^2 + 7x$. What number goes in front of x (not $x^2$)?
solution: $-3x + 7x = 4x$. (The whole answer is $7x^2 + 4x$.)
:::

::: problem id=x14 type=numeric answer="20" set=extra
Simplify $4x + 3 - x + 2$, then evaluate it when $x = 5$.
solution: $3x + 5$. Then $3(5) + 5 = 20$.
:::

::: problem id=x15 type=expression answer="6n+4" vars="n" set=extra
Ella has $3n$ coins, Max has $n + 5$ coins and Lia has $2n - 1$ coins. Write the total.
solution: $3n + n + 2n = 6n$ and $5 - 1 = 4$: $6n + 4$.
:::

::: problem id=x16 type=choice set=extra
Which expression is equal to $7x - 2$?
- [x] $4x - 5 + 3x + 3$
- [ ] $4x - 5 + 3x - 3$
- [ ] $9x - 2x + 2$
solution: $4x + 3x = 7x$ and $-5 + 3 = -2$. The others give $7x - 8$ and $7x + 2$.
:::

::: problem id=x17 type=choice set=extra
Simplify $2x^2 + 3x - 5 - x^2 + 4 - 3x$.
- [x] $x^2 - 1$
- [ ] $x^2 + 6x - 1$
- [ ] $3x^2 - 1$
- [ ] $x^2 - 9$
hint: Group the $x^2$ terms, the x terms and the numbers.
solution: $2x^2 - x^2 = x^2$, $3x - 3x = 0$, $-5 + 4 = -1$: $x^2 - 1$.
:::

::: problem id=x18 type=numeric answer="-2" set=extra
Simplify $-3a - 4 + 7a - (-2)$. What is the number without an a?
hint: Subtracting $-2$ is adding 2.
solution: $-4 + 2 = -2$. (The whole answer is $4a - 2$.)
:::

::: problem id=x19 type=numeric answer="8" set=extra
A rectangle has sides $3x + 2$, $x - 1$, $3x + 2$ and $x - 1$. Add the four sides. What number goes in front of x?
hint: Add the x terms: $3x + x + 3x + x$.
solution: $8x$ and $2 - 1 + 2 - 1 = 2$: perimeter $8x + 2$. The coefficient is **8**.
:::

::: problem id=x20 type=numeric answer="6" set=extra creative=true
Three even numbers in a row are $2n$, $2n + 2$ and $2n + 4$. Simplify their sum. What is the biggest whole number that always divides the sum, whatever n is?
hint: Write the sum as a number times a bracket.
solution: Sum $= 6n + 6 = 6(n + 1)$. Since $n + 1$ can be any whole number, the biggest number that always works is **6**.
:::
