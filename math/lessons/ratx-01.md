---
id: ratx-01
title: Simplifying rational expressions
---
::: rule
A **rational expression** is a fraction with polynomials, like $\frac{x + 2}{x - 5}$.

- It isn't defined where the **denominator is 0** (those x values are **excluded**).
- To simplify, **factor** the top and bottom, then cancel common **factors**. You can only cancel things that multiply the whole top and the whole bottom, never single terms of a sum.
:::

::: example
$\frac{x^2 - 9}{x - 3} = \frac{(x + 3)(x - 3)}{x - 3} = x + 3$, for $x \ne 3$.
:::

::: problem id=p1 type=choice
Simplify $\frac{x^2 - 9}{x - 3}$.
- [x] $x + 3$
- [ ] $x - 3$
- [ ] $x^2 - 3$
solution: $\frac{(x + 3)(x - 3)}{x - 3} = x + 3$.
:::

::: problem id=p2 type=numeric answer="5"
Which value of x is excluded from $\frac{x + 2}{x - 5}$?
solution: The denominator is 0 when $x = 5$.
:::

::: problem id=p3 type=choice
Simplify $\frac{2x + 4}{x + 2}$.
- [x] $2$
- [ ] $2x$
- [ ] $x + 2$
solution: $\frac{2(x + 2)}{x + 2} = 2$.
:::

::: problem id=p4 type=numeric answer="2"
$\frac{x^2 - 4}{x + 2}$ simplifies to $x - \square$. What goes in the box?
solution: $\frac{(x + 2)(x - 2)}{x + 2} = x - 2$.
:::

::: problem id=p5 type=multi answers="1;-1"
Which values of x are excluded from $\frac{1}{x^2 - 1}$? Type both.
hint: Solve $x^2 - 1 = 0$.
solution: $x^2 = 1$: $x = 1$ and $x = -1$.
:::

::: problem id=p6 type=choice
Simplify $\frac{x^2 + 3x + 2}{x + 1}$.
- [x] $x + 2$
- [ ] $x + 3$
- [ ] $x^2 + 2$
solution: $\frac{(x + 1)(x + 2)}{x + 1} = x + 2$.
:::

::: problem id=p7 type=numeric answer="5"
Evaluate $\frac{x^2 - 1}{x - 1}$ at $x = 4$.
solution: $\frac{15}{3} = 5$. (Or simplify first to $x + 1 = 5$.)
:::

::: problem id=p8 type=text answers="no"
Can you cancel the x's in $\frac{x + 3}{x}$? Type yes or no.
solution: **No**: the x on top is only part of a sum, not a factor of the whole top.
:::
