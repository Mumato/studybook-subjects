---
id: ratx-01
title: Simplifying rational expressions
---
::: rule
A **rational expression** is a fraction with polynomials, like $\frac{x + 2}{x - 5}$.

- It isn't defined where the **denominator is 0** (those x values are **excluded**).
- To simplify, **factor** the top and bottom, then cancel common **factors**. You can only cancel things that multiply the whole top and the whole bottom, never single terms of a sum.
:::

::: example
$\frac{x^2 - 9}{x - 3} = \frac{(x + 3)(x - 3)}{x - 3} = x + 3$, for $x \ne 3$.
:::

::: problem id=p1 type=choice
Simplify $\frac{x^2 - 9}{x - 3}$.
- [x] $x + 3$
- [ ] $x - 3$
- [ ] $x^2 - 3$
solution: $\frac{(x + 3)(x - 3)}{x - 3} = x + 3$.
:::

::: problem id=p2 type=numeric answer="5"
Which value of x is excluded from $\frac{x + 2}{x - 5}$?
solution: The denominator is 0 when $x = 5$.
:::

::: problem id=p3 type=choice
Simplify $\frac{2x + 4}{x + 2}$.
- [x] $2$
- [ ] $2x$
- [ ] $x + 2$
solution: $\frac{2(x + 2)}{x + 2} = 2$.
:::

::: problem id=p4 type=numeric answer="2"
$\frac{x^2 - 4}{x + 2}$ simplifies to $x - \square$. What goes in the box?
solution: $\frac{(x + 2)(x - 2)}{x + 2} = x - 2$.
:::

::: problem id=p5 type=multi answers="1;-1"
Which values of x are excluded from $\frac{1}{x^2 - 1}$? Type both.
hint: Solve $x^2 - 1 = 0$.
solution: $x^2 = 1$: $x = 1$ and $x = -1$.
:::

::: problem id=p6 type=choice
Simplify $\frac{x^2 + 3x + 2}{x + 1}$.
- [x] $x + 2$
- [ ] $x + 3$
- [ ] $x^2 + 2$
solution: $\frac{(x + 1)(x + 2)}{x + 1} = x + 2$.
:::

::: problem id=p7 type=numeric answer="5"
Evaluate $\frac{x^2 - 1}{x - 1}$ at $x = 4$.
solution: $\frac{15}{3} = 5$. (Or simplify first to $x + 1 = 5$.)
:::

::: problem id=p8 type=text answers="no"
Can you cancel the x's in $\frac{x + 3}{x}$? Type yes or no.
solution: **No**: the x on top is only part of a sum, not a factor of the whole top.
:::

::: problem id=x1 type=numeric answer="-7" set=extra
Which value of x is excluded from $\frac{x - 1}{x + 7}$?
solution: $x + 7 = 0$ at $x = -7$.
:::

::: problem id=x2 type=multi answers="2;3" set=extra
Which values of x are excluded from $\frac{x + 1}{x^2 - 5x + 6}$?
solution: $x^2 - 5x + 6 = (x - 2)(x - 3) = 0$: 2 and 3.
:::

::: problem id=x3 type=choice set=extra
Simplify $\frac{5x - 10}{x - 2}$.
- [x] $5$
- [ ] $5x$
- [ ] $-5$
- [ ] $x - 2$
solution: $\frac{5(x - 2)}{x - 2} = 5$.
:::

::: problem id=x4 type=choice set=extra
Simplify $\frac{x^2 - 16}{x - 4}$.
- [x] $x + 4$
- [ ] $x - 4$
- [ ] $x + 2$
- [ ] $x^2 + 4$
solution: $\frac{(x + 4)(x - 4)}{x - 4} = x + 4$.
:::

::: problem id=x5 type=choice set=extra
Simplify $\frac{x^2 + 5x + 6}{x + 3}$.
- [x] $x + 2$
- [ ] $x + 3$
- [ ] $x + 5$
- [ ] $x^2 + 2$
solution: $\frac{(x + 2)(x + 3)}{x + 3} = x + 2$.
:::

::: problem id=x6 type=numeric answer="2" set=extra
$\frac{x^2 - 2x}{x}$ simplifies to $x - \square$. What goes in the box?
solution: $\frac{x(x - 2)}{x} = x - 2$.
:::

::: problem id=x7 type=choice set=extra
Simplify $\frac{x^2 - 1}{x^2 + 2x + 1}$.
- [x] $\frac{x - 1}{x + 1}$
- [ ] $\frac{x + 1}{x - 1}$
- [ ] $-1$
- [ ] $\frac{-1}{2x + 1}$
solution: $\frac{(x + 1)(x - 1)}{(x + 1)^2} = \frac{x - 1}{x + 1}$.
:::

::: problem id=x8 type=choice set=extra
Simplify $\frac{x - 3}{3 - x}$.
- [x] $-1$
- [ ] $1$
- [ ] $0$
- [ ] $x - 3$
solution: $3 - x = -(x - 3)$, so the fraction is $-1$.
:::

::: problem id=x9 type=choice set=extra
Zoe writes $\frac{x + 6}{6} = x + 1$. Is she right?
- [x] No: 6 is not a factor of the whole top
- [ ] Yes: the 6s cancel
- [ ] No: the answer is $x$
- [ ] No: the answer is $x + 6$
solution: Only factors cancel. Test $x = 6$: $\frac{12}{6} = 2$, but $x + 1 = 7$.
:::

::: problem id=x10 type=numeric answer="7" set=extra
Evaluate $\frac{x^2 - 9}{x + 3}$ at $x = 10$.
solution: It simplifies to $x - 3 = 7$. (Check: $\frac{91}{13} = 7$.)
:::

::: problem id=x11 type=multi answers="0;4" set=extra
Which values of x are excluded from $\frac{2x}{x^2 - 4x}$?
solution: $x^2 - 4x = x(x - 4) = 0$: 0 and 4. (Even after cancelling, 0 stays excluded.)
:::

::: problem id=x12 type=choice set=extra
Simplify $\frac{4x^2}{2x}$.
- [x] $2x$
- [ ] $2x^2$
- [ ] $2$
- [ ] $\frac{x}{2}$
solution: $\frac{4}{2} = 2$ and $\frac{x^2}{x} = x$: $2x$ (for $x \ne 0$).
:::

::: problem id=x13 type=choice set=extra
Simplify $\frac{x^2 - 6x + 9}{x^2 - 9}$.
- [x] $\frac{x - 3}{x + 3}$
- [ ] $\frac{x + 3}{x - 3}$
- [ ] $-6x$
- [ ] $1$
solution: $\frac{(x - 3)^2}{(x - 3)(x + 3)} = \frac{x - 3}{x + 3}$.
:::

::: problem id=x14 type=numeric answer="3" set=extra
$\frac{2x^2 + 6x}{2x}$ simplifies to $x + \square$. What goes in the box?
solution: $\frac{2x(x + 3)}{2x} = x + 3$.
:::

::: problem id=x15 type=choice set=extra
Which value of x is **allowed** in $\frac{x + 2}{(x - 1)(x + 5)}$?
- [ ] $x = 1$
- [ ] $x = -5$
- [x] $x = -2$
solution: Only the denominator matters: 1 and $-5$ make it 0. At $x = -2$ the fraction is just 0.
:::

::: problem id=x16 type=choice set=extra
Simplify $\frac{x^2 + x - 12}{x^2 - 9}$.
- [x] $\frac{x + 4}{x + 3}$
- [ ] $\frac{x - 4}{x - 3}$
- [ ] $\frac{x + 4}{x - 3}$
- [ ] $\frac{x + 12}{9}$
solution: $\frac{(x + 4)(x - 3)}{(x + 3)(x - 3)} = \frac{x + 4}{x + 3}$.
:::

::: problem id=x17 type=choice set=extra
Simplify $\frac{2x^2 - 8}{x^2 + 4x + 4}$.
- [x] $\frac{2(x - 2)}{x + 2}$
- [ ] $\frac{2(x + 2)}{x - 2}$
- [ ] $\frac{2x - 8}{4x + 4}$
- [ ] $2$
hint: Take out the 2 first.
solution: $\frac{2(x - 2)(x + 2)}{(x + 2)^2} = \frac{2(x - 2)}{x + 2}$.
:::

::: problem id=x18 type=numeric answer="6" set=extra
A rectangle has area $x^2 + 7x + 12$ and width $x + 3$. How long is it when $x = 2$?
hint: Length = area ÷ width.
solution: $\frac{(x + 3)(x + 4)}{x + 3} = x + 4$. At $x = 2$: 6.
:::

::: problem id=x19 type=choice set=extra
Simplify $\frac{x^3 - x}{x^2 - x}$.
- [x] $x + 1$
- [ ] $x - 1$
- [ ] $x$
- [ ] $x^2$
hint: Factor x out of both first.
solution: $\frac{x(x - 1)(x + 1)}{x(x - 1)} = x + 1$.
:::

::: problem id=x20 type=numeric answer="5" set=extra creative=true
For which k does $\frac{x^2 + kx + 6}{x + 2}$ simplify to a polynomial (no fraction left)?
hint: $x + 2$ must be a factor of the top, so the top is 0 at $x = -2$.
solution: $4 - 2k + 6 = 0$, so $k = 5$. Then $\frac{(x + 2)(x + 3)}{x + 2} = x + 3$.
:::
