id: rat-03
title: Proportions
---
::: rule
A **proportion** says two ratios are equal: $\frac{a}{b} = \frac{c}{d}$.

To find a missing number, **cross-multiply**: $a \times d = b \times c$, then divide.
:::

::: example
$\frac{3}{4} = \frac{x}{20}$

Cross-multiply: $4x = 3 \times 20 = 60$, so $x = 60 \div 4 = 15$.
:::

::: example
On a map, 1 cm stands for 5 km. 7 cm stands for $7 \times 5 = 35$ km.
:::

::: problem id=p1 type=numeric answer="5"
$\frac{x}{6} = \frac{10}{12}$. What is x?
solution: $12x = 60$, so $x = 5$.
:::

::: problem id=p2 type=numeric answer="18"
$\frac{4}{x} = \frac{2}{9}$. What is x?
hint: Cross-multiply: $2x = 4 \times 9$.
solution: $2x = 36$, so $x = 18$.
:::

::: problem id=p3 type=numeric answer="24"
$\frac{5}{8} = \frac{15}{x}$. What is x?
solution: $5x = 120$, so $x = 24$.
:::

::: problem id=p4 type=numeric answer="10.5"
3 notebooks cost 4.50 dollars. How much do 7 notebooks cost?
hint: Find the price of one first.
solution: One costs $4.50 \div 3 = 1.50$. Seven cost $7 \times 1.50 = 10.50$ dollars.
:::

::: problem id=p5 type=numeric answer="60"
On a map, 2 cm stands for 15 km. How many km does 8 cm stand for?
solution: 8 cm is 4 times 2 cm, so $4 \times 15 = 60$ km.
:::

::: problem id=p6 type=numeric answer="11"
$\frac{x + 1}{4} = 3$. What is x?
hint: The top must be $3 \times 4$.
solution: $x + 1 = 12$, so $x = 11$.
:::

::: problem id=p7 type=text answers="yes"
Is $\frac{4}{6} = \frac{10}{15}$ a true proportion? Type yes or no.
solution: Cross-multiply: $4 \times 15 = 60$ and $6 \times 10 = 60$. They match, so **yes**.
:::

::: problem id=p8 type=numeric answer="750"
Pasta for 4 people needs 300 g. How much for 10 people, in grams?
solution: One person needs $300 \div 4 = 75$ g. Ten need $750$ g.
:::

::: problem id=c1 type=numeric answer="16" creative=true
A 2 m pole casts a 1.5 m shadow. At the same moment a tree casts a 12 m shadow. How tall is the tree in metres?
hint: Height and shadow are in the same ratio for both.
solution: $\frac{2}{1.5} = \frac{h}{12}$. $1.5h = 24$, so $h = 16$ m.
:::

::: problem id=x9 type=choice set=extra
To solve $\frac{4}{6} = \frac{x}{15}$, Mia added 9 to the top because $6 + 9 = 15$, and got $x = 13$. What is x?
- [ ] 13
- [x] 10
- [ ] 22.5
- [ ] 9
solution: Ratios scale by multiplying, not adding. $6x = 4 \times 15 = 60$, so $x = 10$.
:::

::: problem id=x10 type=numeric answer="5" set=extra

::: problem id=x11 type=numeric answer="30" set=extra
A car uses 18 L of fuel for 240 km. How many litres for 400 km?
solution: $\frac{18}{240} = \frac{x}{400}$: $240x = 7200$, so $x = 30$ L.

::: problem id=x14 type=numeric answer="4" set=extra
A model car is built to a scale of $1 : 50$. The model is 8 cm long. How long is the real car, in metres?
solution: Real length: $8 \times 50 = 400$ cm $= 4$ m.
:::

::: problem id=x15 type=numeric answer="50" set=extra
1 euro buys 1.10 dollars. How many euros do you get for 55 dollars?
solution: $\frac{1}{1.1} = \frac{x}{55}$: $x = 55 \div 1.1 = 50$ euros.
:::

::: problem id=x16 type=numeric answer="22.5" set=extra
A 1.8 m person casts a 2.4 m shadow. At the same time a building casts a 30 m shadow. How tall is the building, in metres?
hint: $\frac{1.8}{2.4} = \frac{h}{30}$.
solution: $2.4h = 54$, so $h = 22.5$ m.
:::

::: problem id=x17 type=numeric answer="300" set=extra
Scientists tag 40 fish in a lake. Later they catch 60 fish, and 8 of them are tagged. Estimate the number of fish in the lake.
hint: Tagged out of all should be the same in the lake and in the catch.
solution: $\frac{40}{N} = \frac{8}{60}$. $8N = 2400$, so $N = 300$ fish.
:::

::: problem id=x18 type=numeric answer="3.5" set=extra
A train covers 150 km in 2.5 hours. At the same speed, how many hours for 210 km?
hint: $\frac{150}{2.5} = \frac{210}{t}$.
solution: $150t = 525$, so $t = 3.5$ hours. (Speed 60 km per hour.)
:::

::: problem id=x19 type=numeric answer="6" set=extra
$\frac{x}{4} = \frac{9}{x}$, where $x$ is positive. What is x?
hint: Cross-multiplying gives $x \times x = 4 \times 9$. Which positive number times itself makes that?
solution: $x \times x = 4 \times 9 = 36$, and $6 \times 6 = 36$, so $x = 6$. Check: $\frac{6}{4} = \frac{9}{6} = 1.5$.
:::

::: problem id=x20 type=numeric answer="17" set=extra creative=true
A recipe uses 2 cups of rice for 3 people. You cook for 25 people, and you can only measure whole cups. What is the smallest number of cups that is enough?
hint: Solve the proportion, then think about rounding.
solution: $\frac{2}{3} = \frac{x}{25}$: $x = \frac{50}{3} = 16\frac{2}{3}$. 16 cups is not enough, so **17**.
:::
