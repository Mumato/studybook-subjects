---
id: lin-01
title: Multi-step equations
---
::: rule
To solve a longer equation, tidy each side first, then solve as usual:
1. Expand brackets.
2. Clear fractions by multiplying **every** term by the LCD.
3. Combine like terms on each side.
4. Get the variable on one side and solve.

If the variables cancel and what's left is always true (like $2 = 2$), **every** number is a solution.
:::

::: example
$3(x - 2) + 4x = 15$

Expand: $3x - 6 + 4x = 15$. Combine: $7x - 6 = 15$. So $7x = 21$ and $x = 3$.
:::

::: example
$\frac{x}{3} + \frac{x}{2} = 10$

Multiply every term by 6: $2x + 3x = 60$, so $5x = 60$ and $x = 12$.
:::

::: problem id=p1 type=numeric answer="4"
Solve $2(x + 3) - x = 10$.
solution: $2x + 6 - x = 10$, so $x + 6 = 10$ and $x = 4$.
:::

::: problem id=p2 type=numeric answer="3"
Solve $5x - 2(x - 4) = 17$.
hint: $-2(x - 4) = -2x + 8$.
solution: $5x - 2x + 8 = 17$, $3x = 9$, $x = 3$.
:::

::: problem id=p3 type=numeric answer="12"
Solve $\frac{x}{4} + 3 = \frac{x}{2}$.
hint: Multiply every term by 4.
solution: $x + 12 = 2x$, so $x = 12$.
:::

::: problem id=p4 type=numeric answer="8"
Solve $0.2x + 1.5 = 3.1$.
solution: $0.2x = 1.6$, so $x = 8$.
:::

::: problem id=p5 type=numeric answer="2"
Solve $4(2x - 1) = 3(x + 2)$.
solution: $8x - 4 = 3x + 6$, $5x = 10$, $x = 2$.
:::

::: problem id=p6 type=numeric answer="5"
Solve $\frac{x + 1}{3} = \frac{x - 1}{2}$.
hint: Cross-multiply.
solution: $2(x + 1) = 3(x - 1)$, $2x + 2 = 3x - 3$, $x = 5$.
:::

::: problem id=p7 type=choice
Solve $2(x + 1) = 2x + 2$.
- [ ] $x = 1$
- [ ] no solution
- [x] every number is a solution
solution: Expand: $2x + 2 = 2x + 2$. Both sides are always equal, so **every** x works.
:::

::: problem id=p8 type=numeric answer="23"
Three consecutive integers add up to 72. What is the smallest?
solution: $n + (n + 1) + (n + 2) = 72$, $3n + 3 = 72$, $n = 23$.
:::
