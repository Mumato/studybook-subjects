---
id: lin-01
title: Multi-step equations
---
::: rule
To solve a longer equation, tidy each side first, then solve as usual:
1. Expand brackets.
2. Clear fractions by multiplying **every** term by the LCD.
3. Combine like terms on each side.
4. Get the variable on one side and solve.

If the variables cancel and what's left is always true (like $2 = 2$), **every** number is a solution.
:::

::: example
$3(x - 2) + 4x = 15$

Expand: $3x - 6 + 4x = 15$. Combine: $7x - 6 = 15$. So $7x = 21$ and $x = 3$.
:::

::: example
$\frac{x}{3} + \frac{x}{2} = 10$

Multiply every term by 6: $2x + 3x = 60$, so $5x = 60$ and $x = 12$.
:::

::: problem id=p1 type=numeric answer="4"
Solve $2(x + 3) - x = 10$.
solution: $2x + 6 - x = 10$, so $x + 6 = 10$ and $x = 4$.
:::

::: problem id=p2 type=numeric answer="3"
Solve $5x - 2(x - 4) = 17$.
hint: $-2(x - 4) = -2x + 8$.
solution: $5x - 2x + 8 = 17$, $3x = 9$, $x = 3$.
:::

::: problem id=p3 type=numeric answer="12"
Solve $\frac{x}{4} + 3 = \frac{x}{2}$.
hint: Multiply every term by 4.
solution: $x + 12 = 2x$, so $x = 12$.
:::

::: problem id=p4 type=numeric answer="8"
Solve $0.2x + 1.5 = 3.1$.
solution: $0.2x = 1.6$, so $x = 8$.
:::

::: problem id=p5 type=numeric answer="2"
Solve $4(2x - 1) = 3(x + 2)$.
solution: $8x - 4 = 3x + 6$, $5x = 10$, $x = 2$.
:::

::: problem id=p6 type=numeric answer="5"
Solve $\frac{x + 1}{3} = \frac{x - 1}{2}$.
hint: Cross-multiply.
solution: $2(x + 1) = 3(x - 1)$, $2x + 2 = 3x - 3$, $x = 5$.
:::

::: problem id=p7 type=choice
Solve $2(x + 1) = 2x + 2$.
- [ ] $x = 1$
- [ ] no solution
- [x] every number is a solution
solution: Expand: $2x + 2 = 2x + 2$. Both sides are always equal, so **every** x works.
:::

::: problem id=p8 type=numeric answer="23"
Three consecutive integers add up to 72. What is the smallest?
solution: $n + (n + 1) + (n + 2) = 72$, $3n + 3 = 72$, $n = 23$.
:::

::: problem id=x1 type=numeric answer="5" set=extra
Solve $3(x + 2) = 21$.
solution: $3x + 6 = 21$, $3x = 15$, $x = 5$.
:::

::: problem id=x2 type=numeric answer="7" set=extra
Solve $4x - 3(x - 2) = 13$.
solution: $4x - 3x + 6 = 13$, so $x + 6 = 13$ and $x = 7$.
:::

::: problem id=x3 type=numeric answer="5" set=extra
Solve $6x + 4 = 2x + 24$.
solution: $4x = 20$, so $x = 5$.
:::

::: problem id=x4 type=numeric answer="20" set=extra
Solve $\frac{x}{5} + 2 = 6$.
solution: $\frac{x}{5} = 4$, so $x = 20$.
:::

::: problem id=x5 type=numeric answer="3" set=extra
Solve $0.5x - 1.2 = 0.3$.
solution: $0.5x = 1.5$, so $x = 3$.
:::

::: problem id=x6 type=numeric answer="9" set=extra
Solve $2(3x - 1) - 4 = 5x + 3$.
solution: $6x - 2 - 4 = 5x + 3$. So $6x - 6 = 5x + 3$ and $x = 9$.
:::

::: problem id=x7 type=numeric answer="7" set=extra
Solve $7 - 2(x - 5) = 3$.
hint: $-2(x - 5) = -2x + 10$.
solution: $7 - 2x + 10 = 3$, so $17 - 2x = 3$, $-2x = -14$, $x = 7$.
:::

::: problem id=x8 type=numeric answer="24" set=extra
Solve $\frac{x}{2} - \frac{x}{3} = 4$.
solution: Multiply every term by 6: $3x - 2x = 24$, so $x = 24$.
:::

::: problem id=x9 type=numeric answer="14" set=extra
Solve $\frac{2x - 1}{3} = \frac{x + 4}{2}$.
solution: Cross-multiply: $2(2x - 1) = 3(x + 4)$. So $4x - 2 = 3x + 12$ and $x = 14$.
:::

::: problem id=x10 type=choice set=extra
Solve $3(x - 2) = 3x + 5$.
- [ ] $x = 1$
- [x] no solution
- [ ] every number is a solution
solution: $3x - 6 = 3x + 5$. The x's cancel and leave $-6 = 5$, which is never true: **no solution**.
:::

::: problem id=x11 type=choice set=extra
Ana solves $5 - 2(x + 1) = 9$. Her first line is $5 - 2x + 2 = 9$. What went wrong?
- [ ] She should have added 5 and 2 first
- [x] $-2 \times (+1)$ is $-2$, not $+2$
- [ ] She should have written $5 - 2x + 1$
solution: The $-2$ multiplies both terms: $-2x - 2$. Correct: $3 - 2x = 9$, so $x = -3$.
:::

::: problem id=x12 type=numeric answer="26" set=extra
Three consecutive even integers add up to 78. What is the largest?
solution: $n + (n + 2) + (n + 4) = 78$, $3n + 6 = 78$, $n = 24$. The largest is **26**.
:::

::: problem id=x13 type=numeric answer="4.5" set=extra
A plumber charges a 40 dollar call-out fee plus 25 dollars per hour. A bill is 152.50 dollars. How many hours did the job take?
solution: $40 + 25h = 152.5$, $25h = 112.5$, $h = 4.5$ hours.
:::

::: problem id=x14 type=numeric answer="5" set=extra
Twice a number plus 7 is the same as 5 times the number minus 8. What is the number?
solution: $2n + 7 = 5n - 8$, so $15 = 3n$ and $n = 5$.
:::

::: problem id=x15 type=numeric answer="10" set=extra
Solve $0.4(x + 5) = 0.3x + 3$.
solution: $0.4x + 2 = 0.3x + 3$, so $0.1x = 1$ and $x = 10$.
:::

::: problem id=x16 type=numeric answer="16" set=extra
Solve $\frac{x + 2}{4} - \frac{x - 1}{6} = 2$.
hint: Multiply every term by 12. Keep the brackets.
solution: $3(x + 2) - 2(x - 1) = 24$. So $3x + 6 - 2x + 2 = 24$, $x + 8 = 24$, $x = 16$.
:::

::: problem id=x17 type=numeric answer="6" set=extra
Solve $5(2x - 3) - 3(x + 1) = 2(x + 6)$.
hint: Expand all three brackets first.
solution: $10x - 15 - 3x - 3 = 2x + 12$. So $7x - 18 = 2x + 12$, $5x = 30$, $x = 6$.
:::

::: problem id=x18 type=numeric answer="10" set=extra
A rectangle's length is 3 less than twice its width. Its perimeter is 54. What is the width?
hint: Length $= 2w - 3$. Perimeter $= 2l + 2w$.
solution: $2(2w - 3) + 2w = 54$. So $6w - 6 = 54$ and $w = 10$.
:::

::: problem id=x19 type=numeric answer="16" set=extra
Mia is 4 years older than Leo. In 6 years, their ages will add up to 3 times Leo's age now. How old is Leo now?
hint: In 6 years Mia is $L + 10$ and Leo is $L + 6$.
solution: $(L + 10) + (L + 6) = 3L$. So $2L + 16 = 3L$ and $L = 16$.
:::

::: problem id=x20 type=numeric answer="3" set=extra creative=true
For which number a does $2(ax + 1) = 6x + 5$ have **no** solution?
hint: When do the x terms cancel? What is left then?
solution: $2ax + 2 = 6x + 5$. If $a = 3$ the x terms cancel and leave $2 = 5$, never true. So $a = 3$. (Any other a gives one solution.)
:::
