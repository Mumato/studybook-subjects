title: Solving word problems
---
::: rule
1. **Name** the unknown with a letter (say what it stands for).
2. **Write** the other amounts using that letter.
3. **Build** an equation from the facts.
4. **Solve**, then **check** that the answer makes sense in the story.
:::

::: example
Two consecutive whole numbers add up to 45. What are they?

Let the smaller be n; the next is $n + 1$. $n + (n + 1) = 45$, so $2n = 44$ and $n = 22$. The numbers are **22 and 23**.
:::

::: example
A rectangle's length is 3 cm more than its width, and its perimeter is 30 cm. Find the width.

Width w, length $w + 3$. Perimeter: $2w + 2(w + 3) = 30$, so $4w + 6 = 30$ and $w = 6$ cm.
:::

::: problem id=p1 type=numeric answer="25"
Two consecutive whole numbers add up to 51. What is the smaller one?
solution: $n + (n + 1) = 51$, $2n = 50$, $n = 25$.
:::

::: problem id=p2 type=numeric answer="12"
Ana is 4 years older than Ben. Their ages add up to 28. How old is Ben?
hint: Ben is b, so Ana is $b + 4$.
solution: $b + (b + 4) = 28$, $2b = 24$, $b = 12$.
:::

::: problem id=p3 type=numeric answer="6"
A rectangle's length is twice its width, and its perimeter is 36 cm. What is the width in cm?
solution: $2w + 2(2w) = 36$, $6w = 36$, $w = 6$ cm.
:::

::: problem id=p4 type=numeric answer="80"
A phone plan costs 15 dollars plus 0.10 dollars per text. One month's bill was 23 dollars. How many texts were sent?
solution: $15 + 0.1t = 23$, $0.1t = 8$, $t = 80$ texts.
:::

::: problem id=p5 type=numeric answer="20"
Three consecutive even numbers add up to 66. What is the smallest?
hint: Even numbers in a row go n, n + 2, n + 4.
solution: $3n + 6 = 66$, $3n = 60$, $n = 20$.
:::

::: problem id=p6 type=numeric answer="8"
An adult ticket costs 3 dollars more than a child ticket. One adult and two children pay 27 dollars. How much is a child ticket?
solution: Child c, adult $c + 3$. $(c + 3) + 2c = 27$, $3c = 24$, $c = 8$ dollars.
:::

::: problem id=p7 type=numeric answer="8"
You have 21 coins, all dimes and quarters. You have 5 more dimes than quarters. How many quarters?
solution: Quarters q, dimes $q + 5$. $q + q + 5 = 21$, $2q = 16$, $q = 8$.
:::

::: problem id=p8 type=numeric answer="9"
Doubling a number gives 9 more than the number itself. What is the number?
solution: $2n = n + 9$, so $n = 9$.
:::

::: problem id=c1 type=numeric answer="8" creative=true
A farm has chickens and cows. Together they have 20 heads and 56 legs. How many cows are there?
hint: If all 20 were chickens there would be 40 legs. Each cow adds 2 more.
solution: All chickens would give 40 legs; there are 16 extra legs, and each cow adds 2, so **8** cows (and 12 chickens). Check: $8 \times 4 + 12 \times 2 = 56$.
:::

::: problem id=x1 type=numeric answer="43" set=extra
Two consecutive whole numbers add up to 87. What is the smaller one?
solution: $n + (n + 1) = 87$, $2n = 86$, $n = 43$.
:::

::: problem id=x2 type=numeric answer="17" set=extra
Kim is 6 years younger than Lou. Their ages add up to 40. How old is Kim?
solution: Kim k, Lou $k + 6$. $2k + 6 = 40$, $2k = 34$, $k = 17$.
:::

::: problem id=x3 type=numeric answer="8" set=extra
A rectangle's length is 3 times its width, and its perimeter is 64 cm. What is the width in cm?
solution: $2w + 2(3w) = 64$, $8w = 64$, $w = 8$ cm.
:::

::: problem id=x4 type=numeric answer="23" set=extra
Three consecutive integers add up to 72. What is the smallest?
solution: $n + (n + 1) + (n + 2) = 72$, $3n + 3 = 72$, $n = 23$.
:::

::: problem id=x5 type=numeric answer="6" set=extra
A gym charges a 25-dollar fee plus 12 dollars per class. Jo spent 97 dollars. How many classes did she take?
solution: $25 + 12c = 97$, $12c = 72$, $c = 6$.
:::

::: problem id=x6 type=numeric answer="21" set=extra
A 50 m rope is cut into two pieces. One piece is 8 m longer than the other. How long is the shorter piece?
solution: $s + (s + 8) = 50$, $2s = 42$, $s = 21$ m.
:::

::: problem id=x7 type=numeric answer="23" set=extra
Three consecutive odd numbers add up to 75. What is the smallest?
solution: $n + (n + 2) + (n + 4) = 75$, $3n + 6 = 75$, $n = 23$.
:::

::: problem id=x8 type=numeric answer="6" set=extra
An adult ticket costs twice as much as a child ticket. 2 adults and 3 children pay 42 dollars. How much is a child ticket?
solution: Child c, adult $2c$. $2(2c) + 3c = 42$, $7c = 42$, $c = 6$ dollars.
:::

::: problem id=x9 type=choice set=extra
Sara has 3 times as many stickers as Tom. Together they have 48. Let t be Tom's stickers. Which equation fits?
- [x] $t + 3t = 48$
- [ ] $3t = 48$
- [ ] $t + 3 = 48$
- [ ] $3t + 48 = t$
solution: Sara has $3t$, and together $t + 3t = 48$.
:::

::: problem id=x10 type=numeric answer="36" set=extra
Sara has 3 times as many stickers as Tom. Together they have 48. How many does Sara have?
solution: $4t = 48$, so $t = 12$. Sara has $3 \times 12 = 36$.
:::

::: problem id=x11 type=choice set=extra
"Two consecutive whole numbers add up to 40." Sam answers 20 and 21. What is wrong?
- [x] $20 + 21 = 41$. Two consecutive whole numbers always add to an odd number, so there are none.
- [ ] They should be 19 and 21.
- [ ] They should be 20 and 20.
- [ ] Nothing, Sam is right.
solution: $n + (n + 1) = 40$ gives $n = 19.5$, not a whole number. The check shows there is no answer.
:::

::: problem id=x12 type=numeric answer="14" set=extra
A triangle's sides are x, $x + 2$ and $x + 4$ cm. Its perimeter is 36 cm. How long is the longest side?
solution: $3x + 6 = 36$, so $x = 10$. Longest side: $10 + 4 = 14$ cm.
:::

::: problem id=x13 type=numeric answer="10" set=extra
You have 18 coins, all nickels (5 cents) and dimes (10 cents), worth 130 cents in total. How many nickels?
hint: Nickels n, dimes $18 - n$. Write the value in cents.
solution: $5n + 10(18 - n) = 130$
$180 - 5n = 130$, so $n = 10$.
:::

::: problem id=x14 type=numeric answer="1800" set=extra
Ben earns 200 dollars a week plus 5% of his sales. One week he earned 290 dollars. How much did he sell?
hint: $200 + 0.05s = 290$.
solution: $0.05s = 90$, so $s = 1800$ dollars.
:::

::: problem id=x15 type=numeric answer="12" set=extra
A father is 3 times as old as his son. In 12 years he will be twice as old as his son. How old is the son now?
hint: Son s, father $3s$. In 12 years: $3s + 12 = 2(s + 12)$.
solution: $3s + 12 = 2s + 24$, so $s = 12$. (Father 36; in 12 years 48 and 24.)
:::

::: problem id=x16 type=numeric answer="3" set=extra
Two cars leave the same place in opposite directions, at 60 km/h and 80 km/h. After how many hours are they 420 km apart?
hint: Each hour the gap grows by $60 + 80$ km.
solution: $140t = 420$, so $t = 3$ hours.
:::

::: problem id=x17 type=numeric answer="90" set=extra
The angles of a triangle add up to 180 degrees. Its angles are x, $2x$ and $3x$. How big is the largest angle?
solution: $6x = 180$, so $x = 30$. Largest: $3 \times 30 = 90$ degrees.
:::

::: problem id=x18 type=numeric answer="35" set=extra
After a 20% discount, a shirt costs 28 dollars. What was the original price?
solution: You pay 80%: $0.8p = 28$, so $p = 35$ dollars.
:::

::: problem id=x19 type=numeric answer="10" set=extra
Mia has 20 dollars more than Jo. Then Mia gives Jo 15 dollars. Now how many more dollars does Jo have than Mia?
hint: Jo j, Mia $j + 20$. Write both amounts after the gift.
solution: Mia: $j + 5$. Jo: $j + 15$. Jo has $(j + 15) - (j + 5) = 10$ dollars more.
:::

::: problem id=x20 type=numeric answer="20" set=extra creative=true
Ella reads a book over 4 days. Each day she reads 5 pages more than the day before. She reads 110 pages in all. How many pages did she read on day 1?
hint: Day 1 is n, day 2 is $n + 5$, and so on.
solution: $n + (n + 5) + (n + 10) + (n + 15) = 110$
$4n + 30 = 110$, so $n = 20$.
:::
