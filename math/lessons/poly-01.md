---
id: poly-01
title: Exponent rules
---
::: rule
When the bases are the same:
- multiply: **add** the exponents, $a^m \cdot a^n = a^{m+n}$
- divide: **subtract** them, $\frac{a^m}{a^n} = a^{m-n}$
- power of a power: **multiply** them, $(a^m)^n = a^{mn}$
- power of a product: $(ab)^n = a^n b^n$
:::

::: example
$x^3 \cdot x^4 = x^7$ (three x's times four x's is seven x's).
:::

::: example
$(2x^2)^3 = 2^3 (x^2)^3 = 8x^6$
:::

::: problem id=p1 type=numeric answer="7"
$x^3 \cdot x^4 = x^{?}$
solution: Add the exponents: $3 + 4 = 7$.
:::

::: problem id=p2 type=numeric answer="5"
$\frac{y^9}{y^4} = y^{?}$
solution: Subtract: $9 - 4 = 5$.
:::

::: problem id=p3 type=numeric answer="10"
$(x^2)^5 = x^{?}$
solution: Multiply: $2 \times 5 = 10$.
:::

::: problem id=p4 type=numeric answer="8"
$(2x)^3 = \square x^3$. What number goes in the box?
hint: The 2 is cubed too.
solution: $2^3 = 8$, so $8x^3$.
:::

::: problem id=p5 type=numeric answer="32"
$2^3 \cdot 2^2 = ?$
solution: $2^{3+2} = 2^5 = 32$.
:::

::: problem id=p6 type=numeric answer="6"
$(a^2 b)^3 = a^{?} b^3$. What is the exponent of a?
solution: $(a^2)^3 = a^6$.
:::

::: problem id=p7 type=numeric answer="4"
$\frac{x^5 \cdot x}{x^2} = x^{?}$
hint: x on its own is $x^1$.
solution: $x^{5+1-2} = x^4$.
:::

::: problem id=p8 type=choice
Which equals $x^6$?
- [x] $(x^2)^3$
- [ ] $x^2 \cdot x^3$
- [ ] $x^3 + x^3$
solution: $(x^2)^3 = x^6$. The others are $x^5$ and $2x^3$.
:::

::: problem id=x1 type=numeric answer="7" set=extra
$x^5 \cdot x^2 = x^{?}$
solution: Add the exponents: $5 + 2 = 7$.
:::

::: problem id=x2 type=numeric answer="5" set=extra
$\frac{a^8}{a^3} = a^{?}$
solution: Subtract: $8 - 3 = 5$.
:::

::: problem id=x3 type=numeric answer="12" set=extra
$(y^4)^3 = y^{?}$
solution: Multiply: $4 \times 3 = 12$.
:::

::: problem id=x4 type=numeric answer="9" set=extra
$(3x)^2 = \square x^2$. What number goes in the box?
solution: Both factors are squared: $3^2 = 9$, so $9x^2$.
:::

::: problem id=x5 type=numeric answer="243" set=extra
$3^2 \cdot 3^3 = ?$
solution: $3^{2+3} = 3^5 = 243$.
:::

::: problem id=x6 type=numeric answer="4" set=extra
$(x^3 y^2)^2 = x^6 y^{?}$. What is the exponent of y?
solution: $(y^2)^2 = y^4$.
:::

::: problem id=x7 type=numeric answer="7" set=extra
$2x^3 \cdot 5x^4 = 10x^{?}$
solution: Multiply the numbers, add the exponents: $3 + 4 = 7$.
:::

::: problem id=x8 type=numeric answer="3" set=extra
$\frac{12x^6}{4x^2} = \square x^4$. What number goes in the box?
solution: Divide the numbers: $12 \div 4 = 3$. (Subtract the exponents: $6 - 2 = 4$.)
:::

::: problem id=x9 type=numeric answer="-8" set=extra
$(-2x^2)^3 = \square x^6$. What number goes in the box?
hint: A negative number cubed stays negative.
solution: $(-2)^3 = -8$, so $-8x^6$.
:::

::: problem id=x10 type=choice set=extra
Which equals $x^8$?
- [x] $x^4 \cdot x^4$
- [ ] $(x^4)^4$
- [ ] $x^4 + x^4$
solution: $x^4 \cdot x^4 = x^8$. The others are $x^{16}$ and $2x^4$.
:::

::: problem id=x11 type=numeric answer="8" set=extra
Jo writes $x^3 \cdot x^5 = x^{15}$. That's wrong. What is the correct exponent?
solution: When you multiply, **add** the exponents: $3 + 5 = 8$. (Multiplying them is for a power of a power.)
:::

::: problem id=x12 type=numeric answer="8" set=extra
$\frac{2^{10}}{2^7} = ?$
solution: $2^{10-7} = 2^3 = 8$.
:::

::: problem id=x13 type=numeric answer="5" set=extra
$\frac{(5^3)^2}{5^5} = ?$
solution: $(5^3)^2 = 5^6$. Then $\frac{5^6}{5^5} = 5^1 = 5$.
:::

::: problem id=x14 type=numeric answer="16" set=extra
$(2a^3)^4 = \square a^{12}$. What number goes in the box?
solution: $2^4 = 16$, so $16a^{12}$.
:::

::: problem id=x15 type=numeric answer="27" set=extra
A cube has side $3x^2$. Its volume is $\square x^6$. What number goes in the box?
solution: $(3x^2)^3 = 3^3 x^6 = 27x^6$.
:::

::: problem id=x16 type=numeric answer="5" set=extra
$\frac{(x^2)^3 \cdot x^4}{x^5} = x^{?}$
hint: Do the power of a power first.
solution: $x^6 \cdot x^4 = x^{10}$. Then $x^{10 - 5} = x^5$.
:::

::: problem id=x17 type=numeric answer="36" set=extra
$(2x^3)^2 \cdot (3x)^2 = \square x^8$. What number goes in the box?
hint: Square each bracket first.
solution: $4x^6 \cdot 9x^2 = 36x^8$.
:::

::: problem id=x18 type=numeric answer="3" set=extra
Find n if $2^n \cdot 2^3 = 64$.
hint: Write 64 as a power of 2.
solution: $2^{n+3} = 2^6$, so $n + 3 = 6$ and $n = 3$.
:::

::: problem id=x19 type=numeric answer="5" set=extra
$\frac{(a^2 b^3)^3}{(a b^2)^2} = a^4 b^{?}$. What is the exponent of b?
hint: Expand top and bottom first.
solution: Top $a^6 b^9$, bottom $a^2 b^4$. So $b^{9 - 4} = b^5$.
:::

::: problem id=x20 type=numeric answer="13" set=extra creative=true
Write $8^3 \cdot 4^2$ as a power of 2. What is the exponent?
hint: $8 = 2^3$ and $4 = 2^2$.
solution: $(2^3)^3 \cdot (2^2)^2 = 2^9 \cdot 2^4 = 2^{13}$.
:::
