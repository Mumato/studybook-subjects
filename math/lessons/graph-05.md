id: graph-05
title: Parallel and perpendicular lines
---
::: rule
- **Parallel** lines never meet: they have the **same slope**.
- **Perpendicular** lines meet at a right angle: their slopes multiply to $-1$. The slope of one is the **negative reciprocal** of the other: if one is $m$, the other is $-\frac{1}{m}$.
:::

::: example
$y = 2x + 1$ and $y = 2x - 3$ are parallel (both slope 2). $y = 2x + 1$ and $y = -\frac{1}{2}x$ are perpendicular, because $2 \times (-\frac{1}{2}) = -1$.
:::

::: graph
plot 2x+1 blue
plot 2x-3 blue
plot -x/2 red
:::

::: problem id=p1 type=numeric answer="4"
What is the slope of a line parallel to $y = 4x - 1$?
solution: Parallel lines have the same slope: **4**.
:::

::: problem id=p2 type=numeric answer="-1/4"
What is the slope of a line perpendicular to $y = 4x$?
solution: Negative reciprocal of 4: $-\frac{1}{4}$.
:::

::: problem id=p3 type=expression answer="2x-1"
Write the line parallel to $y = 2x + 3$ through $(0, -1)$, as $y = \ldots$
solution: Same slope 2, intercept $-1$: $y = 2x - 1$.
:::

::: problem id=p4 type=expression answer="x/3+2"
Write the line perpendicular to $y = -3x + 1$ through $(0, 2)$, as $y = \ldots$
hint: The negative reciprocal of $-3$ is $\frac{1}{3}$.
solution: Slope $\frac{1}{3}$, intercept 2: $y = \frac{x}{3} + 2$.
:::

::: problem id=p5 type=choice
How are $y = 2x + 1$ and $y = -0.5x + 3$ related?

:::

::: problem id=p6 type=numeric answer="1/2"

:::

::: problem id=x17 type=expression answer="-4x/3+3" set=extra
Write the line perpendicular to $3x - 4y = 8$ through $(3, -1)$, as $y = \ldots$
hint: $3x - 4y = 8$ has slope $\frac{3}{4}$.
solution: Slope $-\frac{4}{3}$. $y + 1 = -\frac{4}{3}(x - 3)$, so $y = -\frac{4}{3}x + 4 - 1 = -\frac{4}{3}x + 3$.
:::

::: problem id=x18 type=choice set=extra
A triangle has corners $A(0, 0)$, $B(4, 2)$ and $C(3, -6)$. Which corner has a right angle?
- [x] A
- [ ] B
- [ ] C
hint: Find the slopes of the three sides.
solution: AB has slope $\frac{2}{4} = \frac{1}{2}$, AC has slope $\frac{-6}{3} = -2$. $\frac{1}{2} \times (-2) = -1$, so the right angle is at **A**.
:::
