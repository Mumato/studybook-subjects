id: ang-01
title: Angle relationships
---
::: rule
- **Complementary** angles add up to 90°. **Supplementary** angles add up to 180°.
- Angles on a straight line add up to 180°; angles around a point add up to 360°.
- **Vertical angles** (opposite each other where two lines cross) are equal.
- When a line crosses two **parallel** lines, **corresponding** angles and **alternate** angles are equal.
:::

::: example
Two lines cross. One angle is 110°. The angle next to it on the line is $180 - 110 = 70°$, and the angle opposite is also 110°.
:::

::: problem id=x8 type=numeric answer="100" set=extra
Two supplementary angles are in the ratio 4 : 5. What is the larger one?
solution: 9 parts make 180°, so one part is 20°. The larger is $5 \times 20 = 100°$.

::: problem id=x9 type=numeric answer="67.5" set=extra
An angle is 3 times its complement. How big is the angle?
solution: Complement x, angle $3x$: $4x = 90$, $x = 22.5$. The angle is $67.5°$.
:::

::: problem id=x10 type=numeric answer="75" set=extra
An angle is 30° less than its supplement. How big is the angle?
solution: $x = (180 - x) - 30$, so $2x = 150$ and $x = 75°$.
:::

::: problem id=x11 type=numeric answer="20" set=extra
Two vertical angles are $3x + 10$ and $5x - 30$ degrees. What is x?
solution: Vertical angles are equal: $3x + 10 = 5x - 30$, so $40 = 2x$ and $x = 20$.
:::

::: problem id=x12 type=numeric answer="55" set=extra
Two vertical angles are $2x + 15$ and $4x - 25$ degrees. How big is each angle?
solution: $2x + 15 = 4x - 25$ gives $x = 20$. The angle is $2(20) + 15 = 55°$.
:::

::: problem id=x13 type=choice set=extra
Sam says the complement of 120° is $-30°$. What is right?
- [ ] Sam is right
- [ ] The complement is 60°
- [x] 120° has no complement: it is already more than 90°
- [ ] The complement is 240°
solution: Complements add to 90°. An angle over 90° has no complement. (Its supplement is 60°.)
:::

::: problem id=x14 type=numeric answer="120" set=extra
What is the angle between the hands of a clock at 4:00?
solution: A full turn is 360° over 12 hours: 30° per hour. $4 \times 30 = 120°$.
:::

::: problem id=x15 type=numeric answer="65" set=extra
A line crosses two parallel lines. Between the parallel lines, on the same side of the crossing line, one angle is 115°. What is the other?
hint: The angle next to 115° on the line corresponds to the angle you want.
solution: Next to 115° on the line is 65°, and the wanted angle is corresponding to it: **65°**. These two angles always add to 180°.
:::

::: problem id=x16 type=numeric answer="144" set=extra
Four angles around a point are x, 2x, 3x and 4x. What is the largest?
solution: $10x = 360$, $x = 36$. Largest: $4 \times 36 = 144°$.
:::

::: problem id=x17 type=choice set=extra
Two angles are supplementary and equal. What are they?
- [ ] 45° each
- [x] 90° each
- [ ] 180° each
- [ ] 60° each
solution: $x + x = 180$, so each is **90°**.
:::

::: problem id=x18 type=numeric answer="60" set=extra
The complement of an angle is one quarter of its supplement. Find the angle.
hint: Write $90 - x = \frac{1}{4}(180 - x)$.
solution: $360 - 4x = 180 - x$, so $3x = 180$, $x = 60°$. Check: complement 30, supplement 120.
:::

::: problem id=x19 type=numeric answer="110" set=extra
A line crosses two parallel lines. Two alternate angles are $3x + 20$ and $5x - 40$ degrees. How big is each?
hint: Alternate angles are equal: set up an equation.
solution: $3x + 20 = 5x - 40$, so $x = 30$. Each angle is $3(30) + 20 = 110°$.
:::

::: problem id=x20 type=numeric answer="105" set=extra creative=true
What is the angle between the hands of a clock at 2:30?
hint: The hour hand moves too: at 2:30 it is halfway between 2 and 3.
solution: Minute hand at 6: 180° from 12. Hour hand: $2.5 \times 30 = 75°$. Angle: $180 - 75 = 105°$.
:::
