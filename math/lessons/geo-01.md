---
id: geo-01
title: Square roots
---
::: rule
The **square root** $\sqrt{a}$ is the number that, multiplied by itself, gives a: $\sqrt{25} = 5$ because $5^2 = 25$.

Numbers like 1, 4, 9, 16, 25, 36, 49, 64, 81, 100 are **perfect squares**. For other numbers, the root lies between two whole numbers: $\sqrt{50}$ is between 7 and 8.

Under a root sign, work out the inside first: $\sqrt{9 + 16} = \sqrt{25} = 5$.
:::

::: example
$\sqrt{49} = 7$ because $7 \times 7 = 49$.
:::

::: example
$\sqrt{50}$: $7^2 = 49$ and $8^2 = 64$, so $\sqrt{50}$ is a little more than 7.
:::

You can type square roots as sqrt(…).

::: problem id=p1 type=numeric answer="8"
$\sqrt{64} = ?$
solution: $8 \times 8 = 64$, so **8**.
:::

::: problem id=p2 type=numeric answer="11"
$\sqrt{121} = ?$
solution: $11 \times 11 = 121$, so **11**.
:::

::: problem id=p3 type=numeric answer="5"
$\sqrt{9 + 16} = ?$
hint: Add first.
solution: $\sqrt{25} = 5$. (Not $3 + 4 = 7$!)
:::

::: problem id=p4 type=choice
Between which two whole numbers is $\sqrt{30}$?
- [x] 5 and 6
- [ ] 4 and 5
- [ ] 6 and 7
solution: $5^2 = 25$ and $6^2 = 36$, and 30 is in between.
:::

::: problem id=p5 type=numeric answer="1/2"
$\sqrt{\frac{1}{4}} = ?$
solution: $\frac{1}{2} \times \frac{1}{2} = \frac{1}{4}$, so $\frac{1}{2}$.
:::

::: problem id=p6 type=numeric answer="0.6"
$\sqrt{0.36} = ?$
hint: $6 \times 6 = 36$.
solution: $0.6 \times 0.6 = 0.36$, so **0.6**.
:::

::: problem id=p7 type=numeric answer="9"
A square has an area of 81 cm². How long is each side in cm?
solution: $\sqrt{81} = 9$ cm.
:::

::: problem id=p8 type=numeric answer="12"
$3\sqrt{16} = ?$
solution: $\sqrt{16} = 4$, and $3 \times 4 = 12$.
:::
