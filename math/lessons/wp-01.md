title: From words to equations
---
::: rule
Words that become math:
- **sum**, **increased by**, **more than**: $+$
- **difference**, **decreased by**, **less than**: $-$
- **product**, **times**, **of**: $\times$
- **quotient**, **divided by**, **half of**: $\div$
- **is**, **equals**, **gives**: $=$

Write the equation, then solve it.
:::

::: example
"A number increased by 8 is 21": $n + 8 = 21$, so $n = 13$.
:::

::: example
"Three times a number, minus 5, equals 16": $3n - 5 = 16$, so $3n = 21$ and $n = 7$.
:::

::: problem id=p1 type=numeric answer="21"
A number decreased by 6 is 15. What is the number?
solution: $n - 6 = 15$, so $n = 21$.
:::

::: problem id=p2 type=numeric answer="13"
The product of 4 and a number is 52. What is the number?
solution: $4n = 52$, so $n = 13$.
:::

::: problem id=p3 type=numeric answer="27"
A number divided by 3 is 9. What is the number?
solution: $\frac{n}{3} = 9$, so $n = 27$.
:::

::: problem id=p4 type=numeric answer="9"
Twice a number plus 7 is 25. What is the number?
hint: $2n + 7 = 25$.
solution: $2n = 18$, so $n = 9$.
:::

::: problem id=p5 type=choice
Which equation means "the sum of a number and 5 is 12"?
- [x] $n + 5 = 12$
- [ ] $5n = 12$
- [ ] $n - 5 = 12$
solution: "Sum" means add: $n + 5 = 12$.
:::

::: problem id=p6 type=numeric answer="28"
Half of a number is 14. What is the number?
solution: $\frac{n}{2} = 14$, so $n = 28$.
:::

::: problem id=p7 type=numeric answer="2"
The difference between a number and 4 is $-2$. What is the number?
solution: $n - 4 = -2$, so $n = 2$.
:::

::: problem id=p8 type=numeric answer="8"
Five less than three times a number is 19. What is the number?
hint: "Five less than" something means that thing minus 5.
solution: $3n - 5 = 19$, $3n = 24$, $n = 8$.
:::

- [ ] $2n + 3 = 20$

- [ ] $n + 6 = 2$

::: problem id=x10 type=numeric answer="7" set=extra
Twice the sum of a number and 3 is 20. What is the number?
solution: $2(n + 3) = 20$, so $n + 3 = 10$ and $n = 7$.
:::

::: problem id=x11 type=choice set=extra
Which sentence matches $4n - 1 = 15$?
- [x] One less than four times a number is 15.
- [ ] Four less than a number is 15.
- [ ] Four times one less than a number is 15.
solution: Four times n is $4n$; one less than that is $4n - 1$. "Four times one less than" would be $4(n - 1)$.
:::

::: problem id=x12 type=numeric answer="36" set=extra
25% of a number is 9. What is the number?
solution: "Of" means times: $0.25n = 9$, so $n = 36$.
:::

::: problem id=x13 type=numeric answer="10" set=extra
Kai writes "8 less than a number is 2" as $8 - n = 2$ and gets $n = 6$. What is the correct number?
solution: "8 less than n" is $n - 8$. So $n - 8 = 2$ and $n = 10$.
:::

::: problem id=x14 type=numeric answer="-24" set=extra
The quotient of a number and $-4$ is 6. What is the number?
solution: $\frac{n}{-4} = 6$, so $n = 6 \times (-4) = -24$.
:::

::: problem id=x15 type=numeric answer="24" set=extra
$\frac{3}{4}$ of a number is 18. What is the number?
solution: $\frac{3}{4}n = 18$, so $n = 18 \times \frac{4}{3} = 24$.
:::

::: problem id=x16 type=numeric answer="14" set=extra
5 is subtracted from a number and the result is multiplied by 3. The answer is 27. What is the number?
hint: The subtraction happens first, so it goes in brackets.
solution: $3(n - 5) = 27$, so $n - 5 = 9$ and $n = 14$.
:::

::: problem id=x17 type=numeric answer="13" set=extra
A number added to its double gives 39. What is the number?
hint: Its double is $2n$.
solution: $n + 2n = 39$, so $3n = 39$ and $n = 13$.
:::

::: problem id=x18 type=numeric answer="12" set=extra
4 more than half a number equals 10. What is the number?
hint: $\frac{n}{2} + 4 = 10$.
solution: $\frac{n}{2} = 6$, so $n = 12$.
:::

::: problem id=x19 type=numeric answer="8" set=extra
Three times a number, minus 7, equals the number plus 9. What is the number?
hint: The variable ends up on both sides.
solution: $3n - 7 = n + 9$, so $2n = 16$ and $n = 8$.
:::

::: problem id=x20 type=numeric answer="15" set=extra creative=true
A number, twice the number and three times the number add up to 90. What is the number?
hint: Combine like terms first.
solution: $n + 2n + 3n = 90$, so $6n = 90$ and $n = 15$.
:::
