title: From words to equations
---
::: rule
Words that become math:
- **sum**, **increased by**, **more than**: $+$
- **difference**, **decreased by**, **less than**: $-$
- **product**, **times**, **of**: $\times$
- **quotient**, **divided by**, **half of**: $\div$
- **is**, **equals**, **gives**: $=$

Write the equation, then solve it.
:::

::: example
"A number increased by 8 is 21": $n + 8 = 21$, so $n = 13$.
:::

::: example
"Three times a number, minus 5, equals 16": $3n - 5 = 16$, so $3n = 21$ and $n = 7$.
:::

::: problem id=p1 type=numeric answer="21"
A number decreased by 6 is 15. What is the number?
solution: $n - 6 = 15$, so $n = 21$.
:::

::: problem id=p2 type=numeric answer="13"
The product of 4 and a number is 52. What is the number?
solution: $4n = 52$, so $n = 13$.
:::

::: problem id=p3 type=numeric answer="27"
A number divided by 3 is 9. What is the number?
solution: $\frac{n}{3} = 9$, so $n = 27$.
:::

::: problem id=p4 type=numeric answer="9"
Twice a number plus 7 is 25. What is the number?
hint: $2n + 7 = 25$.
solution: $2n = 18$, so $n = 9$.
:::

::: problem id=p5 type=choice
Which equation means "the sum of a number and 5 is 12"?
- [x] $n + 5 = 12$
- [ ] $5n = 12$
- [ ] $n - 5 = 12$
solution: "Sum" means add: $n + 5 = 12$.
:::

::: problem id=p6 type=numeric answer="28"
Half of a number is 14. What is the number?
solution: $\frac{n}{2} = 14$, so $n = 28$.
:::

::: problem id=p7 type=numeric answer="2"
The difference between a number and 4 is $-2$. What is the number?
solution: $n - 4 = -2$, so $n = 2$.
:::

::: problem id=p8 type=numeric answer="8"
Five less than three times a number is 19. What is the number?
hint: "Five less than" something means that thing minus 5.
solution: $3n - 5 = 19$, $3n = 24$, $n = 8$.
:::
