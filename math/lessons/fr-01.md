---
id: fr-01
title: What a fraction is
---
::: rule
A **fraction** $\frac{a}{b}$ means: split a whole into **b** equal parts and take **a** of them.

The top number is the **numerator**, the bottom is the **denominator**.

**Equivalent fractions** have the same value. Multiply or divide the top and bottom by the same number:
$\frac{1}{2} = \frac{2}{4} = \frac{3}{6}$.
:::

::: example
A pizza has 8 slices and you eat 3. You ate $\frac{3}{8}$ of the pizza.
:::

::: example
$\frac{2}{3} = \frac{?}{12}$

3 became 12 by multiplying by 4, so do the same to the top: $2 \times 4 = 8$. Answer: $\frac{8}{12}$.
:::

Type fractions with a slash, like 3/8.

::: problem id=p1 type=numeric answer="3/8"
A pizza is cut into 8 equal slices and you eat 3. What fraction of the pizza did you eat?
solution: 3 of 8 equal parts: $\frac{3}{8}$.
:::

::: problem id=p2 type=numeric answer="8"
$\frac{2}{3} = \frac{?}{12}$. What is the missing number?
hint: What do you multiply 3 by to get 12?
solution: $3 \times 4 = 12$, so $2 \times 4 = 8$.
:::

::: problem id=p3 type=numeric answer="24"
$\frac{5}{6} = \frac{20}{?}$. What is the missing number?
hint: What do you multiply 5 by to get 20?
solution: $5 \times 4 = 20$, so $6 \times 4 = 24$.
:::

::: problem id=p4 type=choice
Which fraction equals $\frac{1}{2}$?
- [x] $\frac{3}{6}$
- [ ] $\frac{2}{5}$
- [ ] $\frac{4}{6}$
solution: $\frac{3}{6}$: 3 is half of 6.
:::

::: problem id=p5 type=numeric answer="1/4"
What fraction of an hour is 15 minutes?
hint: An hour has 60 minutes.
solution: $\frac{15}{60} = \frac{1}{4}$.
:::

::: problem id=p6 type=numeric answer="24"
$\frac{3}{5} = \frac{?}{40}$. What is the missing number?
solution: $5 \times 8 = 40$, so $3 \times 8 = 24$.
:::

::: problem id=p7 type=numeric answer="1"
$\frac{7}{7} = ?$
solution: All 7 parts out of 7 is the whole thing: **1**.
:::

::: problem id=p8 type=numeric answer="7/12"
A class has 12 students and 5 are girls. What fraction of the class are boys?
hint: First find how many boys there are.
solution: $12 - 5 = 7$ boys, so $\frac{7}{12}$.
:::
