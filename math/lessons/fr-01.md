---
id: fr-01
title: What a fraction is
---
::: rule
A **fraction** $\frac{a}{b}$ means: split a whole into **b** equal parts and take **a** of them.

The top number is the **numerator**, the bottom is the **denominator**.

**Equivalent fractions** have the same value. Multiply or divide the top and bottom by the same number:
$\frac{1}{2} = \frac{2}{4} = \frac{3}{6}$.
:::

::: example
A bar split into 8 equal parts with 3 shaded shows $\frac{3}{8}$:
:::

::: graph
fraction bar 8 3
:::

::: example
$\frac{2}{3} = \frac{?}{12}$

3 became 12 by multiplying by 4, so do the same to the top: $2 \times 4 = 8$. Answer: $\frac{8}{12}$.
:::

Type fractions with a slash, like 3/8.

::: problem id=p1 type=numeric answer="3/8"
A pizza is cut into 8 equal slices and you eat 3. What fraction of the pizza did you eat?
solution: 3 of 8 equal parts: $\frac{3}{8}$.
:::

::: problem id=p2 type=numeric answer="8"
$\frac{2}{3} = \frac{?}{12}$. What is the missing number?
hint: What do you multiply 3 by to get 12?
solution: $3 \times 4 = 12$, so $2 \times 4 = 8$.
:::

::: problem id=p3 type=numeric answer="24"
$\frac{5}{6} = \frac{20}{?}$. What is the missing number?
hint: What do you multiply 5 by to get 20?
solution: $5 \times 4 = 20$, so $6 \times 4 = 24$.
:::

::: problem id=p4 type=shade parts=6 answer="1/2"
This bar has 6 parts. Shade $\frac{1}{2}$ of it, then press Check.
hint: Half of 6 parts is how many parts?
solution: Half of 6 is 3, so shade any 3 parts: $\frac{3}{6} = \frac{1}{2}$.
:::

::: problem id=p5 type=numeric answer="1/4"
What fraction of an hour is 15 minutes?
hint: An hour has 60 minutes.
solution: $\frac{15}{60} = \frac{1}{4}$.
:::

::: problem id=p6 type=numeric answer="24"
$\frac{3}{5} = \frac{?}{40}$. What is the missing number?

:::

::: problem id=p7 type=shade parts=4 style=pie answer="3/4"
Shade $\frac{3}{4}$ of the pie.

::: problem id=p8 type=numeric answer="7/12"
A class has 12 students and 5 are girls. What fraction of the class are boys?
hint: First find how many boys there are.
solution: $12 - 5 = 7$ boys, so $\frac{7}{12}$.
:::

$\frac{3}{4} = \frac{?}{20}$. What is the missing number?

::: problem id=x5 type=numeric answer="3" set=extra
$\frac{12}{16} = \frac{?}{4}$. What is the missing number?
hint: Here you divide instead of multiply.
solution: $16 \div 4 = 4$, so $12 \div 4 = 3$.
:::

::: problem id=x6 type=numeric answer="7" set=extra
In the fraction $\frac{4}{7}$, what is the denominator?
solution: The denominator is the bottom number: **7**.
:::

fraction bar 5 2

What fraction of a year is 5 months?
solution: A year has 12 months: $\frac{5}{12}$.

::: problem id=x9 type=numeric answer="5/7" set=extra
A week has 7 days. What fraction of a week are the weekdays Monday to Friday?

::: problem id=x10 type=choice set=extra
Which fraction is **not** equal to $\frac{2}{3}$?
- [ ] $\frac{4}{6}$
- [ ] $\frac{10}{15}$
- [x] $\frac{5}{6}$
- [ ] $\frac{14}{21}$
solution: $\frac{4}{6}$, $\frac{10}{15}$ and $\frac{14}{21}$ are $\frac{2}{3}$ with top and bottom both multiplied by 2, 5 and 7. $\frac{5}{6}$ is not.
:::

::: problem id=x11 type=choice set=extra
Sam says $\frac{2}{3} = \frac{4}{5}$, because he added 2 to the top and the bottom. Is he right?
- [ ] Yes, adding the same number keeps the value
- [x] No, you must multiply (or divide) top and bottom by the same number
- [ ] No, you must add 2 to the top only
solution: Adding changes the value: $\frac{2}{3} \approx 0.67$ but $\frac{4}{5} = 0.8$. Only multiplying or dividing both by the same number keeps it equal.
:::

::: problem id=x12 type=numeric answer="1/3" set=extra
What fraction of a day is 8 hours?
hint: A day has 24 hours.
solution: $\frac{8}{24} = \frac{1}{3}$.
:::

::: problem id=x13 type=numeric answer="3/10" set=extra
A bag holds 4 red, 3 blue and 3 green marbles. What fraction of the marbles are blue?
solution: $4 + 3 + 3 = 10$ marbles, 3 blue: $\frac{3}{10}$.
:::

::: problem id=x14 type=numeric answer="1" set=extra
What whole number is $\frac{9}{9}$ equal to?
solution: Take all 9 of 9 parts: the whole, which is 1.
:::

::: problem id=x15 type=numeric answer="18" set=extra
How many minutes are $\frac{3}{10}$ of an hour?
hint: Find $\frac{1}{10}$ of 60 first.
solution: $\frac{1}{10}$ of 60 is 6, so $\frac{3}{10}$ is $3 \times 6 = 18$ minutes.
:::

::: problem id=x16 type=numeric answer="12" set=extra
$\frac{3}{4}$ of a class is 9 students. How many students are in the class?
hint: If 3 quarters are 9 students, one quarter is how many?
solution: One quarter is $9 \div 3 = 3$. Four quarters: $4 \times 3 = 12$.
:::

::: problem id=x17 type=numeric answer="30" set=extra
$\frac{2}{5} = \frac{12}{?}$. What is the missing number?
hint: How do you get from 2 to 12?
solution: $2 \times 6 = 12$, so $5 \times 6 = 30$.
:::

::: problem id=x18 type=numeric answer="20" set=extra
$\frac{4}{5} = \frac{?}{25} = \frac{16}{?}$. What number goes in the first box?
hint: Do each box separately.
solution: $5 \times 5 = 25$, so $4 \times 5 = 20$. (The second box is 20 too.)
:::

::: problem id=x19 type=numeric answer="5" set=extra
A pie is cut into 12 slices. Anna eats $\frac{1}{4}$ of it and Ben eats $\frac{1}{3}$ of it. How many slices are left?
hint: Turn each fraction of 12 into a number of slices.
solution: Anna eats $12 \div 4 = 3$ slices, Ben $12 \div 3 = 4$. Left: $12 - 3 - 4 = 5$.
:::

::: problem id=x20 type=numeric answer="9" set=extra creative=true
$\frac{a}{b}$ is equal to $\frac{3}{4}$, and $a + b = 21$. What is $a$?
hint: Try $\frac{3}{4}, \frac{6}{8}, \frac{9}{12}, \ldots$ and add top and bottom.
solution: Top plus bottom goes $7, 14, 21$. The third one is $\frac{9}{12}$, so $a = 9$.
:::
