---
id: expr-04
title: The distributive property
---
::: rule
Multiply the number outside the brackets by **every** term inside:
$a(b + c) = ab + ac$

A minus sign in front of brackets changes every sign inside: $-(x - 3) = -x + 3$.
:::

::: example
$3(x + 4) = 3x + 12$
:::

::: example
$2(x - 5) + 4x = 2x - 10 + 4x = 6x - 10$
:::

::: problem id=p1 type=numeric answer="12"
$3(x + 4) = 3x + \square$. What goes in the box?
solution: $3 \times 4 = 12$.
:::

::: problem id=p2 type=numeric answer="5"
$5(2y - 1) = 10y - \square$. What goes in the box?
solution: $5 \times 1 = 5$, so $10y - 5$.
:::

::: problem id=p3 type=numeric answer="-6"
Expand $-2(x + 3)$. What is the number without an x?
hint: Multiply $-2$ by 3.
solution: $-2(x + 3) = -2x - 6$. The number is **−6**.
:::

::: problem id=p4 type=choice

:::

::: problem id=p5 type=numeric answer="5"

:::

::: problem id=p6 type=numeric answer="7"

:::

::: problem id=p7 type=choice

::: problem id=p8 type=numeric answer="18"
Evaluate $3(x + 2)$ when $x = 4$.
solution: $3(4 + 2) = 3 \times 6 = 18$.
:::

::: problem id=c1 type=expression answer="n" vars="n" creative=true
Think of a number n. Add 3, double it, subtract 6, then halve it. Write what you end up with, simplified.
hint: Write each step: $n + 3$, then $2(n + 3)$, ...
solution: $\frac{2(n + 3) - 6}{2} = \frac{2n + 6 - 6}{2} = \frac{2n}{2} = n$. You always get back your number!
:::

$= 4x + 10 + 6 = 4x + 16$.

::: problem id=x20 type=numeric answer="4" set=extra creative=true
What number k makes $3(x + k) - 2x = x + 12$ true for every x?
hint: Expand and simplify the left side.
solution: $3x + 3k - 2x = x + 3k$. This equals $x + 12$ when $3k = 12$, so $k = 4$.
