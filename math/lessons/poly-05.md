---
id: poly-05
title: Special products
---
::: rule
Three patterns worth knowing by heart:
- $(a + b)^2 = a^2 + 2ab + b^2$
- $(a - b)^2 = a^2 - 2ab + b^2$
- $(a + b)(a - b) = a^2 - b^2$ (the "difference of squares")
:::

::: example
$(x + 5)^2 = x^2 + 10x + 25$. (Not $x^2 + 25$: don't forget the middle term!)
:::

::: example
$51 \times 49 = (50 + 1)(50 - 1) = 2500 - 1 = 2499$.
:::

::: problem id=p1 type=numeric answer="10"
$(x + 5)^2 = x^2 + \square x + 25$. What goes in the box?
solution: $2 \times x \times 5 = 10x$.
:::

::: problem id=p2 type=numeric answer="9"
Expand $(x - 3)^2$. What is the number without x?
solution: $(-3)^2 = 9$: the answer is $x^2 - 6x + 9$.
:::

::: problem id=p3 type=numeric answer="16"
$(x + 4)(x - 4) = x^2 - \square$. What goes in the box?
solution: Difference of squares: $4^2 = 16$.
:::

::: problem id=p4 type=numeric answer="4"
Expand $(2x + 1)^2$. What is the coefficient of x?
solution: $2 \times 2x \times 1 = 4x$: $4x^2 + 4x + 1$.
:::

::: problem id=p5 type=numeric answer="2499"
Work out $51 \times 49$ using $(50 + 1)(50 - 1)$.
solution: $50^2 - 1^2 = 2499$.
:::

::: problem id=p6 type=numeric answer="441"
Work out $21^2$ using $(20 + 1)^2$.
solution: $400 + 40 + 1 = 441$.
:::

::: problem id=p7 type=choice
$(a - b)^2 = ?$
- [x] $a^2 - 2ab + b^2$
- [ ] $a^2 - b^2$
- [ ] $a^2 + b^2$
solution: $a^2 - 2ab + b^2$.
:::

::: problem id=p8 type=numeric answer="-12"
Expand $(3x - 2)^2$. What is the coefficient of x?
solution: $2 \times 3x \times (-2) = -12x$: $9x^2 - 12x + 4$.
:::

::: problem id=c1 type=numeric answer="9801" creative=true
Work out $99^2$ in your head, using a special product.
hint: $99 = 100 - 1$.
solution: $(100 - 1)^2 = 10000 - 200 + 1 = 9801$.
:::
