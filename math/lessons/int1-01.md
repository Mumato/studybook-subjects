---
id: int1-01
title: Antiderivatives
---
::: rule
An **antiderivative** of f is a function F with $F' = f$. We write

$$\int f(x)\,dx = F(x) + C$$

The **+ C** is there because constants vanish when you differentiate. Basic rules:
- $\int x^n\,dx = \frac{x^{n + 1}}{n + 1} + C$ (for $n \ne -1$)
- $\int \frac{1}{x}\,dx = \ln|x| + C$, $\int e^x\,dx = e^x + C$
- $\int \cos x\,dx = \sin x + C$, $\int \sin x\,dx = -\cos x + C$
:::

::: example
$\int (3x^2 + 4x)\,dx = x^3 + 2x^2 + C$. Check: the derivative of $x^3 + 2x^2$ is $3x^2 + 4x$.
:::

Leave out the + C when you type an answer (any constant is fine). Use brackets for fractions in front: (2/3)x^(3/2).

::: problem id=p1 type=expression answer="x^4/4" form=antiderivative
$\int x^3\,dx = ?$
solution: $\frac{x^4}{4} + C$.
:::

::: problem id=p4 type=expression answer="sin(x)" form=antiderivative

::: problem id=p5 type=expression answer="e^x" form=antiderivative

::: problem id=p6 type=expression answer="-1/x" form=antiderivative
$\int \frac{1}{x^2}\,dx = ?$
hint: $\frac{1}{x^2} = x^{-2}$.
solution: $\frac{x^{-1}}{-1} = -\frac{1}{x} + C$.
:::

::: problem id=p7 type=expression answer="(2/3)x^(3/2)" form=antiderivative
$\int \sqrt{x}\,dx = ?$
hint: $\sqrt{x} = x^{\frac{1}{2}}$, so add 1 to the power and divide by the new power.
solution: $\frac{x^{3/2}}{3/2} = \frac{2}{3}x^{\frac{3}{2}} + C$.
:::

::: problem id=p8 type=expression answer="x^2+3"
$F'(x) = 2x$ and $F(0) = 3$. What is $F(x)$?
hint: $F(x) = x^2 + C$. Use $F(0) = 3$ to find C.
solution: $C = 3$, so $F(x) = x^2 + 3$.
:::

::: problem id=x2 type=expression answer="x^4-3x^2" form=antiderivative set=extra
$\int (4x^3 - 6x)\,dx = ?$
solution: $x^4 - 3x^2 + C$.
:::

::: problem id=x3 type=expression answer="x^3/3+x" form=antiderivative set=extra
$\int (x^2 + 1)\,dx = ?$
solution: $\frac{x^3}{3} + x + C$.
:::

::: problem id=x4 type=expression answer="-3cos(x)" form=antiderivative set=extra
$\int 3\sin x\,dx = ?$
solution: $-3\cos x + C$. Check: $(-3\cos x)' = 3\sin x$.
:::

::: problem id=x5 type=expression answer="4e^x" form=antiderivative set=extra
$\int 4e^x\,dx = ?$
solution: $4e^x + C$.
:::

::: problem id=x6 type=expression answer="-1/(2x^2)" form=antiderivative set=extra
$\int \frac{1}{x^3}\,dx = ?$
solution: $\int x^{-3}\,dx = \frac{x^{-2}}{-2} = -\frac{1}{2x^2} + C$.
:::

::: problem id=x7 type=expression answer="2sqrt(x)" form=antiderivative set=extra
$\int \frac{1}{\sqrt{x}}\,dx = ?$
solution: $\int x^{-1/2}\,dx = \frac{x^{1/2}}{1/2} = 2\sqrt{x} + C$.
:::

::: problem id=x8 type=expression answer="x^3/3+x^2+x" form=antiderivative set=extra
$\int (x + 1)^2\,dx = ?$
hint: Multiply out first: $(x + 1)^2 = x^2 + 2x + 1$.
solution: $\frac{x^3}{3} + x^2 + x + C$.
:::

::: problem id=x9 type=expression answer="sin(x)+cos(x)" form=antiderivative set=extra
$\int (\cos x - \sin x)\,dx = ?$
solution: $\sin x + \cos x + C$.
:::

::: problem id=x10 type=expression answer="x^2/2-1/x" form=antiderivative set=extra
$\int \frac{x^3 + 1}{x^2}\,dx = ?$
hint: Split the fraction: $x + x^{-2}$.
solution: $\frac{x^2}{2} + \frac{x^{-1}}{-1} = \frac{x^2}{2} - \frac{1}{x} + C$.
:::

::: problem id=x11 type=expression answer="x^3-2x+5" set=extra
$F'(x) = 3x^2 - 2$ and $F(1) = 4$. What is $F(x)$?
solution: $F = x^3 - 2x + C$. $1 - 2 + C = 4$, $C = 5$.
:::

::: problem id=x12 type=numeric answer="1" set=extra
$f'(x) = 6x$ and $f(2) = 10$. What is $f(1)$?
solution: $f = 3x^2 + C$; $12 + C = 10$, $C = -2$.
$f(1) = 3 - 2 = 1$.
:::

::: problem id=x13 type=choice set=extra
Which is an antiderivative of $2x\cos(x^2)$?
- [x] $\sin(x^2)$
- [ ] $x^2\sin(x^2)$
- [ ] $-\sin(x^2)$
- [ ] $\cos(x^2)$
solution: Check by differentiating: $(\sin x^2)' = \cos(x^2) \cdot 2x$.
:::

::: problem id=x14 type=choice set=extra
A student writes $\int x^{-1}\,dx = \frac{x^0}{0} + C$. What is right?
- [ ] $\frac{x^0}{0}$ is fine
- [ ] $-x^{-2} + C$
- [x] $\ln|x| + C$
- [ ] $x^{-1} + C$
solution: The power rule fails for $n = -1$ (division by 0). The antiderivative of $\frac{1}{x}$ is $\ln|x|$.
:::

::: problem id=x15 type=numeric answer="10" set=extra
An object has velocity $v(t) = 3t^2$ and starts at $s(0) = 2$. Where is it at $t = 2$?
solution: $s = t^3 + C$, $C = 2$. $s(2) = 8 + 2 = 10$.
:::

::: problem id=x16 type=numeric answer="12" set=extra
$a(t) = 6t$, $v(0) = 2$ and $s(0) = 0$. Find $s(2)$.
hint: Antidifferentiate twice, finding a constant each time.
solution: $v = 3t^2 + 2$, $s = t^3 + 2t$.
$s(2) = 8 + 4 = 12$.
:::

::: problem id=x17 type=expression answer="x^4+x+2" set=extra
$f''(x) = 12x^2$, $f'(0) = 1$ and $f(0) = 2$. What is $f(x)$?
hint: First $f'(x) = 4x^3 + C_1$.
solution: $f' = 4x^3 + 1$, then $f = x^4 + x + C_2$ with $C_2 = 2$.
:::

::: problem id=x18 type=numeric answer="165/4" set=extra
A ball is thrown up at 25 m/s from 10 m high. Its acceleration is $-10$ m/s². What is its greatest height?
hint: $v = 25 - 10t$, so $h = 10 + 25t - 5t^2$.
solution: $v = 0$ at $t = 2.5$.
$h = 10 + 62.5 - 31.25 = 41.25$ m.
:::

::: problem id=x19 type=expression answer="tan(x)" form=antiderivative set=extra
$\int \sec^2 x\,dx = ?$
hint: Which function has derivative $\sec^2 x$?
solution: $\frac{d}{dx}\tan x = \sec^2 x$, so $\tan x + C$.
:::

::: problem id=x20 type=numeric answer="6" set=extra creative=true
A car brakes from 30 m/s with constant deceleration a and stops after 75 m. Find a (in m/s²).
hint: $v = 30 - at$ and $s = 30t - \frac{a}{2}t^2$. It stops when $v = 0$.
solution: Stops at $t = \frac{30}{a}$. Then $s = \frac{900}{a} - \frac{450}{a} = \frac{450}{a}$.
$\frac{450}{a} = 75$, so $a = 6$ m/s².
:::
