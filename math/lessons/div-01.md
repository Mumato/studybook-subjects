---
id: div-01
title: What division means
---
::: rule
**Division splits a number into equal groups.** $12 \div 3 = 4$: split 12 into 3 equal groups and each gets 4.

Division undoes multiplication: $12 \div 3 = 4$ because $3 \times 4 = 12$.

- a number divided by itself is 1
- a number divided by 1 is itself
- 0 divided by any number is 0
- you **can't** divide by 0
:::

::: example
$56 \div 8 = ?$

Ask: what times 8 is 56? $7 \times 8 = 56$, so $56 \div 8 = 7$.
:::

hint: What times 5 is 35?
solution: $7 \times 5 = 35$, so the answer is **7**.
:::

::: problem id=p4 type=numeric answer="1"

:::

::: problem id=p5 type=numeric answer="4"

solution: $9 \times 7 = 63$, so the answer is **9**.
:::

::: problem id=x9 type=choice set=extra
Which multiplication fact shows that $40 \div 5 = 8$?
- [x] $5 \times 8 = 40$
- [ ] $5 \times 40 = 200$
- [ ] $8 \times 8 = 64$
- [ ] $40 \times 8 = 320$
solution: $40 \div 5 = 8$ because $5 \times 8 = 40$.
:::

::: problem id=x10 type=numeric answer="8" set=extra
48 stickers are shared equally over 6 pages. How many stickers go on each page?
solution: $48 \div 6 = 8$ stickers.
:::

::: problem id=x11 type=numeric answer="9" set=extra
How many weeks are in 63 days?
solution: A week has 7 days: $63 \div 7 = 9$ weeks.
:::

::: problem id=x12 type=choice set=extra
Raj says "$0 \div 5$ can't be done". Is he right?
- [ ] Yes, you can't divide with 0
- [x] No: $0 \div 5 = 0$; it is $5 \div 0$ that can't be done
- [ ] No: $0 \div 5 = 5$
solution: Sharing 0 things among 5 gives each 0, and $5 \times 0 = 0$. Only dividing **by** 0 is not defined.
:::

::: problem id=x13 type=numeric answer="6" set=extra
A box had 50 pencils. 2 were lost and the rest were shared equally by 8 children. How many did each child get?
solution: $50 - 2 = 48$, then $48 \div 8 = 6$ pencils each.
:::

::: problem id=x14 type=numeric answer="7" set=extra
Multiply 7 by 8, then divide the result by 8. What do you get?
solution: $7 \times 8 = 56$ and $56 \div 8 = 7$. Dividing by 8 undoes multiplying by 8.
:::

::: problem id=x15 type=choice set=extra
Which is greater?
- [x] $56 \div 7$
- [ ] $54 \div 9$
- [ ] They are equal
solution: $56 \div 7 = 8$ and $54 \div 9 = 6$, so $56 \div 7$ is greater.
:::

::: problem id=x16 type=numeric answer="12" set=extra
Three friends buy a pizza for 27 dollars and drinks for 9 dollars. They split the cost equally. How many dollars does each pay?
hint: Find the total first.
solution: $27 + 9 = 36$, then $36 \div 3 = 12$ dollars each.
:::

::: problem id=x17 type=numeric answer="30" set=extra
A pack of 6 cans costs 18 dollars. At the same price per can, how many dollars do 10 cans cost?
hint: Find the price of one can.
solution: One can: $18 \div 6 = 3$ dollars. Ten cans: $10 \times 3 = 30$ dollars.
:::

::: problem id=x18 type=numeric answer="6" set=extra
A number divided by 4 is 9. What is the number divided by 6?
hint: First find the number.
solution: The number is $9 \times 4 = 36$. Then $36 \div 6 = 6$.
:::

::: problem id=x19 type=numeric answer="6" set=extra
72 chairs are set out in rows of 9. Then 18 chairs are taken away, a whole row at a time. How many rows are left?
hint: How many rows at the start, and how many rows are 18 chairs?
solution: Rows: $72 \div 9 = 8$. Removed rows: $18 \div 9 = 2$. Left: $8 - 2 = 6$ rows.
:::

::: problem id=x20 type=numeric answer="8" set=extra creative=true
How many of the numbers from 1 to 50 divide by 6 with nothing left over?
hint: List the multiples of 6 up to 50.
solution: 6, 12, 18, 24, 30, 36, 42, 48. That's **8** numbers.
:::
