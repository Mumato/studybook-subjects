---
id: div-01
title: What division means
---
::: rule
**Division splits a number into equal groups.** $12 \div 3 = 4$: split 12 into 3 equal groups and each gets 4.

Division undoes multiplication: $12 \div 3 = 4$ because $3 \times 4 = 12$.

- a number divided by itself is 1
- a number divided by 1 is itself
- 0 divided by any number is 0
- you **can't** divide by 0
:::

::: example
$56 \div 8 = ?$

Ask: what times 8 is 56? $7 \times 8 = 56$, so $56 \div 8 = 7$.
:::

::: problem id=p1 type=numeric answer="7"
$35 \div 5 = ?$
hint: What times 5 is 35?
solution: $7 \times 5 = 35$, so the answer is **7**.
:::

::: problem id=p2 type=numeric answer="8"
$72 \div 9 = ?$
solution: $8 \times 9 = 72$, so the answer is **8**.
:::

::: problem id=p3 type=numeric answer="0"
$0 \div 6 = ?$
solution: 0 divided by any number is **0**.
:::

::: problem id=p4 type=numeric answer="1"
$45 \div 45 = ?$
solution: A number divided by itself is **1**.
:::

::: problem id=p5 type=numeric answer="4"
24 cookies are shared equally by 6 friends. How many does each friend get?
hint: Split 24 into 6 equal groups.
solution: $24 \div 6 = 4$ cookies each.
:::

::: problem id=p6 type=numeric answer="9"
$63 \div 7 = ?$
solution: $9 \times 7 = 63$, so the answer is **9**.
:::

::: problem id=p7 type=choice
What is $8 \div 0$?
- [ ] 0
- [ ] 8
- [x] It isn't defined: you can't divide by 0
solution: No number times 0 gives 8, so $8 \div 0$ has no answer. Dividing by 0 is **not defined**.
:::

::: problem id=p8 type=numeric answer="9"
$81 \div 9 = ?$
hint: Which number times itself is 81?
solution: $9 \times 9 = 81$, so the answer is **9**.
:::
