---
id: wn-02
title: Adding whole numbers
---
::: rule
To add, line the numbers up by place value and add one column at a time, starting with the **ones**.

If a column adds up to 10 or more, write the ones digit and **carry** the 1 to the next column.

Order doesn't matter: $a + b = b + a$. Adding 0 changes nothing.
:::

::: example
Add $358 + 275$.

Ones: $8 + 5 = 13$. Write 3, carry 1.
Tens: $5 + 7 + 1 = 13$. Write 3, carry 1.
Hundreds: $3 + 2 + 1 = 6$.

The answer is **633**.
:::

::: example
A shop sells 1,245 apples on Monday, 380 on Tuesday and 99 on Wednesday. How many in total?

$1245 + 380 = 1625$, then $1625 + 99 = 1724$. The shop sold **1724** apples.
:::

::: problem id=p1 type=numeric answer="85"
$47 + 38 = ?$
hint: $7 + 8 = 15$, so carry 1 into the tens.
solution: Ones: $7 + 8 = 15$, write 5 carry 1. Tens: $4 + 3 + 1 = 8$. Answer: **85**.
:::

::: problem id=p2 type=numeric answer="801"
$206 + 595 = ?$
solution: Ones: $6 + 5 = 11$, carry 1. Tens: $0 + 9 + 1 = 10$, carry 1. Hundreds: $2 + 5 + 1 = 8$. Answer: **801**.
:::

::: problem id=p3 type=numeric answer="4063"
$1374 + 2689 = ?$
hint: You will carry in three columns.
solution: Ones: $4 + 9 = 13$. Tens: $7 + 8 + 1 = 16$. Hundreds: $3 + 6 + 1 = 10$. Thousands: $1 + 2 + 1 = 4$. Answer: **4063**.
:::

::: problem id=p4 type=numeric answer="1000"
$999 + 1 = ?$
solution: Every column becomes 10 and carries: **1000**.
:::

::: problem id=p5 type=numeric answer="100"
$45 + 0 + 55 = ?$
hint: Adding 0 changes nothing.
solution: $45 + 55 = 100$.
:::

::: problem id=p6 type=numeric answer="1603"
A library has 1,208 books and gets 395 more. How many books does it have now?
solution: $1208 + 395 = 1603$ books.
:::

::: problem id=p7 type=numeric answer="8045"
$3050 + 4870 + 125 = ?$
hint: Add two numbers first, then add the third.
solution: $3050 + 4870 = 7920$, then $7920 + 125 = 8045$.
:::

::: problem id=p8 type=numeric answer="37"
What number goes in place of the box? $63 + \square = 100$
hint: How far is it from 63 to 100?
solution: $100 - 63 = 37$. Check: $63 + 37 = 100$.
:::
