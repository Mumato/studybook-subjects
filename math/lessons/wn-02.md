---
id: wn-02
title: Adding whole numbers
---
::: rule
To add, line the numbers up by place value and add one column at a time, starting with the **ones**.

If a column adds up to 10 or more, write the ones digit and **carry** the 1 to the next column.

Order doesn't matter: $a + b = b + a$. Adding 0 changes nothing.
:::

::: example
Add $358 + 275$.

Ones: $8 + 5 = 13$. Write 3, carry 1.
Tens: $5 + 7 + 1 = 13$. Write 3, carry 1.
Hundreds: $3 + 2 + 1 = 6$.

The answer is **633**.
:::

::: example
A shop sells 1,245 apples on Monday, 380 on Tuesday and 99 on Wednesday. How many in total?

$1245 + 380 = 1625$, then $1625 + 99 = 1724$. The shop sold **1724** apples.
:::

::: problem id=x20 type=numeric answer="1173" set=extra creative=true

hint: The biggest digits should go in the hundreds places.
solution: Hundreds 6 and 5, tens 4 and 3, ones 2 and 1. For example $642 + 531 = 1173$. Any swap inside a column gives the same sum.
