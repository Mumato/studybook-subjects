---
id: rad-02
title: Working with roots
---
::: rule
- Add or subtract **like** roots only (same number under the root): $3\sqrt{2} + 5\sqrt{2} = 8\sqrt{2}$. Simplify first to spot them.
- Multiply: $\sqrt{a} \cdot \sqrt{b} = \sqrt{ab}$, and $(\sqrt{a})^2 = a$.
- **Rationalize** a denominator by multiplying top and bottom by the root: $\frac{1}{\sqrt{2}} = \frac{\sqrt{2}}{2}$.
:::

::: example
$\sqrt{12} + \sqrt{27} = 2\sqrt{3} + 3\sqrt{3} = 5\sqrt{3}$
:::

::: example
$\frac{6}{\sqrt{3}} = \frac{6\sqrt{3}}{3} = 2\sqrt{3}$
:::

::: problem id=p1 type=numeric answer="8"
$3\sqrt{2} + 5\sqrt{2} = \square\sqrt{2}$. What goes in the box?
solution: $3 + 5 = 8$.
:::

::: problem id=p2 type=numeric answer="5"
$\sqrt{12} + \sqrt{27} = \square\sqrt{3}$. What goes in the box?
hint: Simplify each root first.
solution: $2\sqrt{3} + 3\sqrt{3} = 5\sqrt{3}$.
:::

::: problem id=p3 type=numeric answer="4"
$\sqrt{2} \cdot \sqrt{8} = ?$
solution: $\sqrt{16} = 4$.
:::

::: problem id=p4 type=numeric answer="5"
$(\sqrt{5})^2 = ?$
solution: **5**.
:::

::: problem id=p5 type=numeric answer="2"
$\frac{6}{\sqrt{3}} = \square\sqrt{3}$. What goes in the box?
solution: $\frac{6\sqrt{3}}{3} = 2\sqrt{3}$.
:::

::: problem id=p6 type=numeric answer="2"
$(\sqrt{3} + 1)(\sqrt{3} - 1) = ?$
hint: Difference of squares.
solution: $3 - 1 = 2$.
:::

::: problem id=p7 type=numeric answer="2"
$(1 + \sqrt{2})^2 = 3 + \square\sqrt{2}$. What goes in the box?
solution: $1 + 2\sqrt{2} + 2 = 3 + 2\sqrt{2}$.
:::

::: problem id=p8 type=choice
Which equals $\frac{1}{\sqrt{2}}$?
- [x] $\frac{\sqrt{2}}{2}$
- [ ] $\sqrt{2}$
- [ ] $\frac{2}{\sqrt{2}}$
solution: Multiply top and bottom by $\sqrt{2}$: $\frac{\sqrt{2}}{2}$.
:::
