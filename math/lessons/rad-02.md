---
id: rad-02
title: Working with roots
---
::: rule
- Add or subtract **like** roots only (same number under the root): $3\sqrt{2} + 5\sqrt{2} = 8\sqrt{2}$. Simplify first to spot them.
- Multiply: $\sqrt{a} \cdot \sqrt{b} = \sqrt{ab}$, and $(\sqrt{a})^2 = a$.
- **Rationalize** a denominator by multiplying top and bottom by the root: $\frac{1}{\sqrt{2}} = \frac{\sqrt{2}}{2}$.
:::

::: example
$\sqrt{12} + \sqrt{27} = 2\sqrt{3} + 3\sqrt{3} = 5\sqrt{3}$
:::

::: example
$\frac{6}{\sqrt{3}} = \frac{6\sqrt{3}}{3} = 2\sqrt{3}$
:::

::: problem id=x11 type=choice set=extra
Is $\sqrt{2} + \sqrt{3} = \sqrt{5}$?
- [x] No: unlike roots can't be combined
- [ ] Yes: add the numbers under the roots
- [ ] No: it is $\sqrt{6}$
- [ ] No: it is $2\sqrt{5}$
solution: $\sqrt{2} + \sqrt{3} \approx 3.15$ but $\sqrt{5} \approx 2.24$. It stays as $\sqrt{2} + \sqrt{3}$.
:::

::: problem id=x15 type=choice set=extra
Which equals $\frac{1}{\sqrt{3} - 1}$?
- [x] $\frac{\sqrt{3} + 1}{2}$
- [ ] $\frac{\sqrt{3} - 1}{2}$
- [ ] $\sqrt{3} + 1$
- [ ] $\frac{\sqrt{3}}{3} - 1$
hint: Multiply top and bottom by $\sqrt{3} + 1$.
solution: The bottom becomes $(\sqrt{3})^2 - 1 = 2$, the top $\sqrt{3} + 1$.
:::

::: problem id=x16 type=numeric answer="10" set=extra
A rectangle has sides $\sqrt{12}$ and $\sqrt{27}$. Its perimeter is $\square\sqrt{3}$. What goes in the box?
solution: $2(2\sqrt{3} + 3\sqrt{3}) = 2 \cdot 5\sqrt{3} = 10\sqrt{3}$.
:::

::: problem id=x17 type=numeric answer="2" set=extra

:::

::: problem id=x18 type=numeric answer="3" set=extra
$\sqrt{\frac{2}{3}} = \frac{\sqrt{6}}{\square}$. What goes in the box?
hint: Write it as $\frac{\sqrt{2}}{\sqrt{3}}$ and rationalize.
solution: $\frac{\sqrt{2}}{\sqrt{3}} \cdot \frac{\sqrt{3}}{\sqrt{3}} = \frac{\sqrt{6}}{3}$.
:::

::: problem id=x19 type=numeric answer="3" set=extra
$\frac{6}{3 - \sqrt{3}} = a + \sqrt{3}$. What is a?
hint: Multiply top and bottom by $3 + \sqrt{3}$.
solution: $\frac{6(3 + \sqrt{3})}{9 - 3} = 3 + \sqrt{3}$. So $a = 3$.
:::

::: problem id=x20 type=numeric answer="8" set=extra creative=true
$\sqrt{18} + \sqrt{n} = 5\sqrt{2}$ for a whole number n. What is n?
hint: Simplify $\sqrt{18}$ first.
solution: $3\sqrt{2} + \sqrt{n} = 5\sqrt{2}$, so $\sqrt{n} = 2\sqrt{2} = \sqrt{8}$. $n = 8$.
:::
