---
id: fr-04
title: Mixed numbers
---
::: rule
A **mixed number** like $2\frac{1}{3}$ means $2 + \frac{1}{3}$. As an **improper fraction** (top bigger than bottom) it is $\frac{7}{3}$.

- Mixed to improper: whole × denominator + numerator, over the denominator.
- Improper to mixed: divide. The answer is the whole number, the remainder is the new numerator.
:::

::: example
$3\frac{2}{5} = \frac{3 \times 5 + 2}{5} = \frac{17}{5}$
:::

::: example
$\frac{23}{4}$: $23 \div 4 = 5$ remainder 3, so $\frac{23}{4} = 5\frac{3}{4}$.
:::

You can type a mixed number with a space, like 5 3/4.

::: problem id=p1 type=numeric answer="11"
$2\frac{3}{4} = \frac{?}{4}$. What is the missing numerator?
solution: $2 \times 4 + 3 = 11$.
:::

::: problem id=p2 type=numeric answer="13"
$1\frac{5}{8} = \frac{?}{8}$. What is the missing numerator?
solution: $1 \times 8 + 5 = 13$.
:::

::: problem id=p3 type=numeric answer="5"
Write $\frac{17}{3}$ as a mixed number. What is the whole-number part?
hint: $17 \div 3$.
solution: $17 \div 3 = 5$ remainder 2, so $5\frac{2}{3}$. The whole part is **5**.
:::

::: problem id=p4 type=numeric answer="5"
Write $\frac{29}{6}$ as a mixed number. What is the numerator of the fraction part?
solution: $29 \div 6 = 4$ remainder 5, so $4\frac{5}{6}$. The numerator is **5**.
:::

::: problem id=p5 type=numeric answer="9/2"
Write $4\frac{1}{2}$ as an improper fraction.
solution: $4 \times 2 + 1 = 9$, so $\frac{9}{2}$.
:::

::: problem id=p6 type=choice
You have 7 quarter-pizzas. How much pizza is that?
- [x] $1\frac{3}{4}$
- [ ] $2\frac{1}{4}$
- [ ] $1\frac{1}{3}$
hint: Four quarters make one whole pizza.
solution: $\frac{7}{4} = 1\frac{3}{4}$: one whole pizza and 3 quarters.
:::

::: problem id=p7 type=choice
Which is bigger?
- [ ] $2\frac{1}{3}$
- [x] $\frac{7}{2}$
solution: $\frac{7}{2} = 3\frac{1}{2}$, which is more than $2\frac{1}{3}$.
:::

::: problem id=p8 type=numeric answer="2 1/2"
Write $\frac{10}{4}$ as a mixed number in simplest form.
solution: $10 \div 4 = 2$ remainder 2: $2\frac{2}{4} = 2\frac{1}{2}$.
:::

::: problem id=c1 type=numeric answer="5/12" creative=true
Find a fraction between $\frac{1}{3}$ and $\frac{1}{2}$ whose denominator is 12.
hint: Write both fractions with denominator 12 first.
solution: $\frac{1}{3} = \frac{4}{12}$ and $\frac{1}{2} = \frac{6}{12}$. The one in between is $\frac{5}{12}$.
:::
