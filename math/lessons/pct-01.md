---
id: pct-01
title: What a percent is
---
::: rule
**Percent** means "out of 100": $35\% = \frac{35}{100} = 0.35$.

- percent to decimal: divide by 100 (move the point two places left)
- decimal to percent: multiply by 100 (move the point two places right)
- fraction to percent: make the denominator 100, or divide and then multiply by 100
:::

::: example
$\frac{3}{4} = \frac{75}{100} = 75\%$
:::

::: example
$0.08 = 8\%$ and $8\% = 0.08$.
:::

When a question asks for a percent, you can type 75 or 75%.

::: problem id=p1 type=numeric answer="0.45"
Write 45% as a decimal.
solution: $45 \div 100 = 0.45$.
:::

::: problem id=p2 type=numeric answer="60"
Write 0.6 as a percent.
solution: $0.6 \times 100 = 60\%$.
:::

::: problem id=p3 type=numeric answer="20"
Write $\frac{1}{5}$ as a percent.
hint: $\frac{1}{5} = \frac{?}{100}$
solution: $\frac{1}{5} = \frac{20}{100} = 20\%$.
:::

::: problem id=p4 type=numeric answer="0.07"
Write 7% as a decimal.
hint: 7% is 7 out of 100.
solution: $7 \div 100 = 0.07$.
:::

::: problem id=p5 type=numeric answer="37.5"
Write $\frac{3}{8}$ as a percent.
solution: $3 \div 8 = 0.375 = 37.5\%$.
:::

::: problem id=p6 type=numeric answer="1.5"
Write 150% as a decimal.
solution: $150 \div 100 = 1.5$.
:::

::: problem id=p7 type=numeric answer="1/4"
Write 25% as a fraction in simplest form.
solution: $\frac{25}{100} = \frac{1}{4}$.
:::

::: problem id=p8 type=choice
Which is the largest?
- [ ] 0.6
- [x] 65%
- [ ] $\frac{5}{8}$
hint: Turn them all into percents.
solution: $0.6 = 60\%$, $\frac{5}{8} = 62.5\%$, so **65%** is largest.
:::
