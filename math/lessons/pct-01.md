id: pct-01
title: What a percent is
---
::: rule
**Percent** means "out of 100": $35\% = \frac{35}{100} = 0.35$.

- percent to decimal: divide by 100 (move the point two places left)
- decimal to percent: multiply by 100 (move the point two places right)
- fraction to percent: make the denominator 100, or divide and then multiply by 100
:::

::: example
$\frac{3}{4} = \frac{75}{100} = 75\%$
:::

::: example
$0.08 = 8\%$ and $8\% = 0.08$.
:::

When a question asks for a percent, you can type 75 or 75%.

solution: $45 \div 100 = 0.45$.

solution: $0.6 \times 100 = 60\%$.
:::

::: problem id=x16 type=numeric answer="40" set=extra
A class has 12 girls and 8 boys. What percent of the class are boys?
hint: First find the total.
solution: $12 + 8 = 20$. $\frac{8}{20} = \frac{40}{100} = 40\%$.
:::

::: problem id=x17 type=numeric answer="65" set=extra

hint: Write $\frac{4}{5}$ as a percent first.
solution: $\frac{4}{5} = 80\%$. $80\% - 15\% = 65\%$.
:::

::: problem id=x20 type=numeric answer="18" set=extra creative=true
A grid of 100 squares has 37 squares red, 0.25 of the grid blue and $\frac{1}{5}$ of it green. What percent of the grid is not coloured?
hint: Turn each part into a percent.
solution: Red 37%, blue 25%, green 20%: 82% coloured. Not coloured: $100\% - 82\% = 18\%$.
