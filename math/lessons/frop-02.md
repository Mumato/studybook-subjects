---
id: frop-02
title: Dividing fractions
---
::: rule
The **reciprocal** of $\frac{c}{d}$ is $\frac{d}{c}$ (flip it).

To divide by a fraction, multiply by its reciprocal:
$\frac{a}{b} \div \frac{c}{d} = \frac{a}{b} \times \frac{d}{c}$

Remember it as: **keep, change, flip**.
:::

::: example
$\frac{3}{4} \div \frac{1}{2} = \frac{3}{4} \times \frac{2}{1} = \frac{6}{4} = \frac{3}{2}$
:::

::: example
How many quarter-cups are in 3 cups? $3 \div \frac{1}{4} = 3 \times 4 = 12$.
:::

::: problem id=p1 type=numeric answer="8/5"
What is the reciprocal of $\frac{5}{8}$?
solution: Flip it: $\frac{8}{5}$.
:::

::: problem id=p2 type=numeric answer="2"
$\frac{1}{2} \div \frac{1}{4} = ?$
hint: How many quarters fit in a half?
solution: $\frac{1}{2} \times 4 = 2$.
:::

::: problem id=p3 type=numeric answer="3/2"
$\frac{2}{3} \div \frac{4}{9} = ?$
solution: $\frac{2}{3} \times \frac{9}{4} = \frac{18}{12} = \frac{3}{2}$.
:::

::: problem id=p4 type=numeric answer="9"
$6 \div \frac{2}{3} = ?$
hint: Multiply 6 by $\frac{3}{2}$.
solution: $6 \times \frac{3}{2} = \frac{18}{2} = 9$.
:::

::: problem id=p5 type=numeric answer="1/5"
$\frac{3}{5} \div 3 = ?$
hint: Dividing by 3 is multiplying by $\frac{1}{3}$.
solution: $\frac{3}{5} \times \frac{1}{3} = \frac{3}{15} = \frac{1}{5}$.
:::

::: problem id=p6 type=numeric answer="10"
A 5 m ribbon is cut into pieces $\frac{1}{2}$ m long. How many pieces?
solution: $5 \div \frac{1}{2} = 5 \times 2 = 10$ pieces.
:::

::: problem id=p7 type=numeric answer="1"
$\frac{7}{8} \div \frac{7}{8} = ?$
solution: Any number (except 0) divided by itself is 1.
:::

::: problem id=p8 type=numeric answer="6"
$\frac{4}{5} \div \frac{2}{15} = ?$
solution: $\frac{4}{5} \times \frac{15}{2} = \frac{60}{10} = 6$.
:::

::: problem id=x1 type=numeric answer="1/7" set=extra
What is the reciprocal of 7?
hint: Write 7 as $\frac{7}{1}$.
solution: $7 = \frac{7}{1}$, so its reciprocal is $\frac{1}{7}$.
:::

::: problem id=x2 type=numeric answer="3" set=extra
$\frac{3}{5} \div \frac{1}{5} = ?$
solution: $\frac{3}{5} \times 5 = 3$. (Three fifths hold three fifths.)
:::

::: problem id=x3 type=numeric answer="5/4" set=extra
$\frac{5}{6} \div \frac{2}{3} = ?$
solution: $\frac{5}{6} \times \frac{3}{2} = \frac{15}{12} = \frac{5}{4}$.
:::

::: problem id=x4 type=numeric answer="10" set=extra
$8 \div \frac{4}{5} = ?$
solution: $8 \times \frac{5}{4} = \frac{40}{4} = 10$.
:::

::: problem id=x5 type=numeric answer="2/9" set=extra
$\frac{4}{9} \div 2 = ?$
solution: $\frac{4}{9} \times \frac{1}{2} = \frac{4}{18} = \frac{2}{9}$.
:::

::: problem id=x6 type=numeric answer="2" set=extra
$\frac{7}{10} \div \frac{7}{20} = ?$
solution: $\frac{7}{10} \times \frac{20}{7} = \frac{20}{10} = 2$.
:::

::: problem id=x7 type=numeric answer="1/2" set=extra
$\frac{3}{8} \div \frac{3}{4} = ?$
solution: $\frac{3}{8} \times \frac{4}{3} = \frac{12}{24} = \frac{1}{2}$.
:::

::: problem id=x8 type=numeric answer="2/5" set=extra
What is the reciprocal of $2\frac{1}{2}$?
hint: Change it to an improper fraction first.
solution: $2\frac{1}{2} = \frac{5}{2}$, so the reciprocal is $\frac{2}{5}$.
:::

::: problem id=x9 type=choice set=extra
Lee worked out $\frac{2}{3} \div \frac{4}{5}$ as $\frac{3}{2} \times \frac{4}{5} = \frac{6}{5}$. What is the right answer?
- [ ] $\frac{6}{5}$
- [x] $\frac{5}{6}$
- [ ] $\frac{8}{15}$
- [ ] $\frac{12}{10}$
solution: Flip the **second** fraction, not the first: $\frac{2}{3} \times \frac{5}{4} = \frac{10}{12} = \frac{5}{6}$.
:::

::: problem id=x10 type=numeric answer="8" set=extra
A pot holds 6 cups of soup. One serving is $\frac{3}{4}$ cup. How many servings is that?
solution: $6 \div \frac{3}{4} = 6 \times \frac{4}{3} = 8$ servings.
:::

::: problem id=x11 type=choice set=extra
$10 \div \frac{1}{2}$ is...
- [ ] 5
- [x] 20
- [ ] $\frac{1}{20}$
solution: How many halves fit in 10? $10 \times 2 = 20$. Dividing by a number less than 1 gives a bigger answer.
:::

::: problem id=x12 type=numeric answer="3/16" set=extra
A board $\frac{3}{4}$ m long is cut into 4 equal pieces. How long is each piece, in metres?
solution: $\frac{3}{4} \div 4 = \frac{3}{4} \times \frac{1}{4} = \frac{3}{16}$ m.
:::

::: problem id=x13 type=numeric answer="4" set=extra
$? \div \frac{2}{3} = 6$. What is the missing number?
hint: Undo the division: multiply 6 by $\frac{2}{3}$.
solution: $6 \times \frac{2}{3} = 4$. Check: $4 \times \frac{3}{2} = 6$.
:::

::: problem id=x14 type=numeric answer="3" set=extra
$2\frac{1}{4} \div \frac{3}{4} = ?$
solution: $\frac{9}{4} \times \frac{4}{3} = \frac{36}{12} = 3$.
:::

::: problem id=x15 type=numeric answer="210" set=extra
Ken has read $\frac{2}{5}$ of a book, which is 84 pages. How many pages does the book have?
hint: 84 pages is $\frac{2}{5}$ of the total, so divide by $\frac{2}{5}$.
solution: $84 \div \frac{2}{5} = 84 \times \frac{5}{2} = 210$ pages.
:::

::: problem id=x16 type=numeric answer="3/2" set=extra
$\frac{1}{2} \div \frac{1}{3} = ?$
solution: $\frac{1}{2} \times 3 = \frac{3}{2}$. (One half holds one and a half thirds.)
:::

::: problem id=x17 type=numeric answer="360" set=extra
A car uses $\frac{2}{3}$ of a tank to drive 240 km. How far can it go on a full tank?
hint: Find how far it goes on $\frac{1}{3}$ of a tank.
solution: $240 \div \frac{2}{3} = 240 \times \frac{3}{2} = 360$ km.
:::

::: problem id=x18 type=numeric answer="3/4" set=extra
A rectangle has area $\frac{15}{8}$ m² and length $\frac{5}{2}$ m. What is its width, in metres?
hint: Width = area ÷ length.
solution: $\frac{15}{8} \div \frac{5}{2} = \frac{15}{8} \times \frac{2}{5} = \frac{30}{40} = \frac{3}{4}$ m.
:::

::: problem id=x19 type=numeric answer="1" set=extra
$\left(\frac{3}{4} \div \frac{3}{8}\right) \times \frac{1}{2} = ?$
hint: Do the bracket first.
solution: $\frac{3}{4} \times \frac{8}{3} = 2$, then $2 \times \frac{1}{2} = 1$.
:::

::: problem id=x20 type=numeric answer="1/3" set=extra creative=true
One batch of cookies needs $\frac{2}{3}$ cup of sugar. You have 5 cups. You make as many **full** batches as you can. How many cups of sugar are left?
hint: $5 \div \frac{2}{3}$ is not a whole number. How many whole batches fit? Then count in thirds: 5 cups is $\frac{15}{3}$.
solution: $5 \div \frac{2}{3} = \frac{15}{2} = 7\frac{1}{2}$, so 7 full batches. They use $7 \times \frac{2}{3} = \frac{14}{3}$ cups, which is 14 thirds. 5 cups is 15 thirds, so 1 third is left: $\frac{1}{3}$ cup.
:::
