---
id: rad-03
title: Rational exponents
---
::: rule
A fractional exponent is a root:
- $a^{\frac{1}{n}} = \sqrt[n]{a}$
- $a^{\frac{m}{n}} = \left(\sqrt[n]{a}\right)^m$ (take the root first, it keeps numbers small)

All the exponent rules still work: add when multiplying, multiply for a power of a power.
:::

::: example
$16^{\frac{3}{4}} = \left(\sqrt[4]{16}\right)^3 = 2^3 = 8$
:::

::: example
$4^{-\frac{1}{2}} = \frac{1}{\sqrt{4}} = \frac{1}{2}$
:::

You can type fractional powers with brackets, like 9^(1/2).

::: problem id=p1 type=numeric answer="3"
$9^{\frac{1}{2}} = ?$
solution: $\sqrt{9} = 3$.
:::

::: problem id=p2 type=numeric answer="2"
$8^{\frac{1}{3}} = ?$
solution: $\sqrt[3]{8} = 2$.
:::

::: problem id=p3 type=numeric answer="8"
$16^{\frac{3}{4}} = ?$
solution: $\left(\sqrt[4]{16}\right)^3 = 2^3 = 8$.
:::

::: problem id=p4 type=numeric answer="9"
$27^{\frac{2}{3}} = ?$
hint: Cube root first.
solution: $3^2 = 9$.
:::

::: problem id=p5 type=numeric answer="1/2"
$4^{-\frac{1}{2}} = ?$
solution: $\frac{1}{\sqrt{4}} = \frac{1}{2}$.
:::

::: problem id=p6 type=numeric answer="5/6"
$x^{\frac{1}{2}} \cdot x^{\frac{1}{3}} = x^{?}$
solution: $\frac{1}{2} + \frac{1}{3} = \frac{5}{6}$.
:::

::: problem id=p7 type=numeric answer="2"
$\left(x^{\frac{2}{3}}\right)^3 = x^{?}$
solution: $\frac{2}{3} \times 3 = 2$.
:::

::: problem id=p8 type=choice
Which equals $\sqrt{x}$?
- [x] $x^{\frac{1}{2}}$
- [ ] $x^2$
- [ ] $x^{-2}$
solution: A square root is the power $\frac{1}{2}$.
:::
