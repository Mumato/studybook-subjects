---
id: rad-03
title: Rational exponents
---
::: rule
A fractional exponent is a root:
- $a^{\frac{1}{n}} = \sqrt[n]{a}$
- $a^{\frac{m}{n}} = \left(\sqrt[n]{a}\right)^m$ (take the root first, it keeps numbers small)

All the exponent rules still work: add when multiplying, multiply for a power of a power.
:::

::: example
$16^{\frac{3}{4}} = \left(\sqrt[4]{16}\right)^3 = 2^3 = 8$
:::

::: example
$4^{-\frac{1}{2}} = \frac{1}{\sqrt{4}} = \frac{1}{2}$
:::

You can type fractional powers with brackets, like 9^(1/2).

solution: $\frac{2}{3} \times 3 = 2$.
:::

::: problem id=x10 type=choice set=extra
Which equals $\sqrt[3]{x^2}$?
- [x] $x^{\frac{2}{3}}$
- [ ] $x^{\frac{3}{2}}$
- [ ] $x^6$
- [ ] $x^{-\frac{2}{3}}$
solution: The root index goes on the bottom: $x^{\frac{2}{3}}$.
:::

::: problem id=x11 type=choice set=extra
Nia says $8^{\frac{2}{3}} = \frac{8^2}{3} = \frac{64}{3}$. What is right?
- [x] 4
- [ ] $\frac{64}{3}$
- [ ] $\frac{16}{3}$
- [ ] 16
solution: The 3 is a cube root, not a division: $\left(\sqrt[3]{8}\right)^2 = 2^2 = 4$.
:::

::: problem id=x14 type=numeric answer="9" set=extra
$\left(\frac{1}{27}\right)^{-\frac{2}{3}} = ?$
hint: A negative power flips the fraction.
solution: $27^{\frac{2}{3}} = 3^2 = 9$.
:::

::: problem id=x15 type=numeric answer="64" set=extra
Solve $x^{\frac{1}{3}} = 4$.
solution: Cube both sides: $x = 4^3 = 64$.
:::

::: problem id=x16 type=numeric answer="1" set=extra
$\sqrt[4]{x^3} \cdot x^{\frac{1}{4}} = x^{?}$
solution: $x^{\frac{3}{4}} \cdot x^{\frac{1}{4}} = x^{1}$.
:::

::: problem id=x17 type=numeric answer="12" set=extra
$4^{\frac{3}{2}} + 8^{\frac{2}{3}} = ?$
solution: $2^3 + 2^2 = 8 + 4 = 12$.
:::

::: problem id=x18 type=numeric answer="8" set=extra
$\left(16x^8\right)^{\frac{3}{4}} = \square x^6$. What goes in the box?
hint: Raise each factor to the $\frac{3}{4}$.
solution: $16^{\frac{3}{4}} = 2^3 = 8$ and $\left(x^8\right)^{\frac{3}{4}} = x^6$.
:::

::: problem id=x19 type=numeric answer="150" set=extra
A cube has volume 125 cm³. What is its surface area, in cm²?
hint: Side $= 125^{\frac{1}{3}}$.
solution: Side $= 5$. Six faces of $5^2 = 25$: $6 \times 25 = 150$.
:::

::: problem id=x20 type=numeric answer="9" set=extra creative=true
Solve $a^{\frac{3}{2}} = 27$ (with $a > 0$).
hint: Raise both sides to the power $\frac{2}{3}$.
solution: $a = 27^{\frac{2}{3}} = 3^2 = 9$. Check: $9^{\frac{3}{2}} = 3^3 = 27$.
:::
