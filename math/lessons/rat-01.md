---
id: rat-01
title: Ratios
---
::: rule
A **ratio** compares two amounts: 12 boys to 18 girls is $12 : 18$, which can also be written $\frac{12}{18}$.

Simplify a ratio like a fraction: $12 : 18 = 2 : 3$.

To **share** an amount in a ratio $a : b$, split it into $a + b$ equal parts.
:::

::: example
A class has 12 boys and 18 girls. Boys to girls is $12 : 18 = 2 : 3$. Boys to the whole class is $12 : 30 = 2 : 5$.
:::

::: example
Share 30 sweets in the ratio $2 : 3$. There are $2 + 3 = 5$ parts, each part is $30 \div 5 = 6$. The shares are $2 \times 6 = 12$ and $3 \times 6 = 18$.
:::

::: problem id=p1 type=numeric answer="3"
Simplify the ratio $8 : 12$. What is the second number?
solution: Divide both by 4: $2 : 3$. The second number is **3**.
:::

::: problem id=p2 type=numeric answer="2/5"
A class has 10 boys and 15 girls. What fraction of the class are boys?
hint: Boys out of everyone.
solution: $\frac{10}{25} = \frac{2}{5}$.
:::

::: problem id=p3 type=numeric answer="9"
A recipe uses flour and milk in the ratio $2 : 3$. If you use 6 cups of flour, how many cups of milk?
solution: 6 is $2 \times 3$, so use $3 \times 3 = 9$ cups of milk.
:::

::: problem id=p4 type=numeric answer="15"
Red and blue marbles are in the ratio $3 : 5$. There are 40 marbles. How many are red?
hint: How many parts are there altogether?
solution: $3 + 5 = 8$ parts, each $40 \div 8 = 5$. Red: $3 \times 5 = 15$.
:::

::: problem id=p5 type=choice
Which ratio is the same as $4 : 6$?
- [x] $2 : 3$
- [ ] $3 : 4$
- [ ] $6 : 4$
solution: Divide both by 2: $2 : 3$.
:::

::: problem id=p6 type=numeric answer="25"
35 dollars are shared in the ratio $2 : 5$. How big is the larger share?
solution: 7 parts of 5 dollars each. The larger share is $5 \times 5 = 25$ dollars.
:::

::: problem id=p7 type=numeric answer="3/4"
Write the ratio of 45 minutes to 1 hour as a fraction in simplest form.
hint: Use the same unit for both.
solution: 1 hour is 60 minutes: $\frac{45}{60} = \frac{3}{4}$.
:::

::: problem id=p8 type=numeric answer="16"
Cats and dogs at a shelter are in the ratio $3 : 4$. There are 12 cats. How many dogs?
solution: 12 is $3 \times 4$, so dogs: $4 \times 4 = 16$.
:::

::: problem id=x1 type=numeric answer="5" set=extra
Simplify the ratio $21 : 35$. What is the second number?
solution: Divide both by 7: $3 : 5$. The second number is **5**.
:::

::: problem id=x2 type=numeric answer="2" set=extra
Simplify the ratio $24 : 36$. What is the first number?
solution: Divide both by 12: $2 : 3$. The first number is **2**.
:::

::: problem id=x3 type=numeric answer="3" set=extra
Simplify the ratio $14 : 42$. What is the second number?
solution: Divide both by 14: $1 : 3$. The second number is **3**.
:::

::: problem id=x4 type=numeric answer="42" set=extra
Share 56 in the ratio $1 : 3$. How big is the larger share?
solution: 4 parts of $56 \div 4 = 14$. Larger share: $3 \times 14 = 42$.
:::

::: problem id=x5 type=numeric answer="25" set=extra
Share 60 in the ratio $5 : 7$. How big is the smaller share?
solution: 12 parts of $60 \div 12 = 5$. Smaller share: $5 \times 5 = 25$.
:::

::: problem id=x6 type=choice set=extra
Which ratio is the same as $9 : 12$?
- [ ] $4 : 3$
- [x] $3 : 4$
- [ ] $9 : 4$
- [ ] $1 : 3$
solution: Divide both by 3: $3 : 4$. (Order matters: $4 : 3$ is different.)
:::

::: problem id=x7 type=numeric answer="3" set=extra
A bag has 6 red and 9 green sweets. Simplify the ratio of green to red. What is the first number?
solution: Green to red is $9 : 6 = 3 : 2$. The first number is **3**.
:::

::: problem id=x8 type=numeric answer="1/5" set=extra
Write the ratio of 20 cm to 1 m as a fraction in simplest form.
hint: 1 m is 100 cm.
solution: $\frac{20}{100} = \frac{1}{5}$.
:::

::: problem id=x9 type=choice set=extra
Boys and girls in a club are in the ratio $3 : 5$. Sam says $\frac{3}{5}$ of the club are boys. What is right?
- [x] $\frac{3}{8}$ are boys
- [ ] Sam is right
- [ ] $\frac{5}{8}$ are boys
solution: There are $3 + 5 = 8$ parts and 3 are boys: $\frac{3}{8}$. ($\frac{3}{5}$ compares boys to girls, not to everyone.)
:::

::: problem id=x10 type=numeric answer="12" set=extra
Juice is made from concentrate and water in the ratio $1 : 4$. How many cups of water go with 3 cups of concentrate?
solution: $3 \times 1 : 3 \times 4 = 3 : 12$: **12** cups.
:::

::: problem id=x11 type=numeric answer="49" set=extra
Two numbers are in the ratio $2 : 7$. The smaller one is 14. What is the larger one?
solution: 14 is $2 \times 7$, so the larger is $7 \times 7 = 49$.
:::

::: problem id=x12 type=numeric answer="63" set=extra
Money is shared in the ratio $4 : 5$. The smaller share is 28 dollars. How much was shared in total?
solution: 4 parts are 28, so one part is 7. Total: $9 \times 7 = 63$ dollars.
:::

::: problem id=x13 type=numeric answer="5" set=extra
Write the ratio $2.5 : 1$ using whole numbers in simplest form. What is the first number?
solution: Multiply both by 2: $5 : 2$. The first number is **5**.
:::

::: problem id=x14 type=numeric answer="3" set=extra
Simplify the ratio $3 : 4.5$ to whole numbers. What is the second number?
solution: Multiply by 2: $6 : 9$, then divide by 3: $2 : 3$. The second number is **3**.
:::

::: problem id=x15 type=numeric answer="3" set=extra
Write $\frac{1}{2} : \frac{1}{3}$ as a ratio of whole numbers in simplest form. What is the first number?
hint: Multiply both by 6.
solution: $\frac{1}{2} \times 6 = 3$ and $\frac{1}{3} \times 6 = 2$: $3 : 2$.
:::

::: problem id=x16 type=numeric answer="40" set=extra
Share 90 in the ratio $2 : 3 : 4$. How big is the largest share?
hint: Count all the parts.
solution: $2 + 3 + 4 = 9$ parts of 10. Largest: $4 \times 10 = 40$.
:::

::: problem id=x17 type=numeric answer="42" set=extra
Boys and girls in a class are in the ratio $3 : 4$. There are 6 more girls than boys. How many students are in the class?
hint: The difference of 6 is one part.
solution: $4 - 3 = 1$ part is 6 students. Total: $7 \times 6 = 42$.
:::

::: problem id=x18 type=numeric answer="15" set=extra
Green paint is blue and yellow in the ratio $3 : 2$. You have only 9 L of blue and lots of yellow. How many litres of green can you make?
hint: 9 L of blue is 3 parts.
solution: One part is $9 \div 3 = 3$ L. Green is 5 parts: $5 \times 3 = 15$ L.
:::

::: problem id=x19 type=numeric answer="30" set=extra
$A : B = 2 : 3$ and $B : C = 4 : 5$. If $A + B + C = 70$, what is $C$?
hint: Make B the same in both ratios: use 12.
solution: $A : B = 8 : 12$ and $B : C = 12 : 15$, so $A : B : C = 8 : 12 : 15$. 35 parts make 70, so one part is 2 and $C = 30$.
:::

::: problem id=x20 type=numeric answer="1" set=extra creative=true
Start with the numbers 3 and 5 (ratio $3 : 5$). The same whole number is added to both, and the ratio becomes $2 : 3$. What number was added?
hint: Try adding 1, 2, 3, ... and simplify each time.
solution: Add 1: $4 : 6 = 2 : 3$. So **1**.
:::
