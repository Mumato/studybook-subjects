id: int-01
title: Negative numbers and absolute value
---
::: rule
**Integers** are the whole numbers and their negatives: ..., −3, −2, −1, 0, 1, 2, 3, ...

On a number line, numbers get **bigger to the right**. So $-2$ is bigger than $-5$.

The **opposite** of 4 is $-4$, and the opposite of $-4$ is 4: $-(-4) = 4$.

The **absolute value** $|a|$ is the distance from 0, so it is never negative: $|-7| = 7$.
:::

::: example
Which is bigger, $-5$ or $-2$? $-2$ is further right on the number line, so $-2 > -5$.
:::

::: graph
numberline -6..6
point -5 A
point -2 B blue
:::

::: example
$|-7| = 7$ and $|7| = 7$: both are 7 steps from 0.
:::

Type negative numbers with a minus sign, like -4.

::: problem id=p1 type=numeric answer="12"
$|-12| = ?$
solution: $-12$ is 12 steps from 0: **12**.
:::

::: problem id=p2 type=numeric answer="-8"
What is the opposite of 8?
solution: **−8**.
:::

::: problem id=p3 type=choice
Which is bigger?
- [x] $-3$
- [ ] $-8$
hint: Which is further to the right on the number line?
solution: $-3$ is closer to 0 and further right, so $-3 > -8$.
:::

::: problem id=p4 type=numeric answer="10"
$|5| + |-5| = ?$
solution: $5 + 5 = 10$.
:::

::: problem id=p5 type=numeric answer="-4"
The temperature is 4 degrees below zero. Write it as an integer.
solution: Below zero is negative: **−4**.
:::

solution: $-6$ is furthest left on the number line.
:::
