---
id: int1-03
title: The Fundamental Theorem of Calculus
---
::: rule
If F is any antiderivative of f, then

$$\int_a^b f(x)\,dx = F(b) - F(a)$$

So areas come from antiderivatives: integration and differentiation undo each other. (The + C cancels, so leave it out.)

The other half of the theorem: an integral with a variable top limit is an antiderivative of what's inside.

$$\frac{d}{dx}\int_a^x f(t)\,dt = f(x)$$
:::

::: example
$\int_0^2 x^2\,dx = \left[\frac{x^3}{3}\right]_0^2 = \frac{8}{3} - 0 = \frac{8}{3}$.
:::

::: problem id=p1 type=numeric answer="8/3"
$\int_0^2 x^2\,dx = ?$
solution: $\frac{8}{3}$.
:::

::: problem id=p2 type=numeric answer="8"
$\int_1^3 2x\,dx = ?$
solution: $[x^2]_1^3 = 9 - 1 = 8$.
:::

::: problem id=p3 type=numeric answer="2"
$\int_0^1 (3x^2 + 1)\,dx = ?$
solution: $[x^3 + x]_0^1 = 2$.
:::

::: problem id=p4 type=numeric answer="2"
$\int_0^{\pi} \sin x\,dx = ?$
hint: An antiderivative of $\sin x$ is $-\cos x$.
solution: $-\cos\pi + \cos 0 = 1 + 1 = 2$.
:::

::: problem id=p5 type=numeric answer="1"
$\int_1^{e} \frac{1}{x}\,dx = ?$
solution: $\ln e - \ln 1 = 1$.
:::

::: problem id=p6 type=numeric answer="e-1"
$\int_0^1 e^x\,dx = ?$ (exact)
solution: $e^1 - e^0 = e - 1$.
:::

::: problem id=p7 type=numeric answer="0"
$\int_2^2 (x^3 + 5)\,dx = ?$
hint: How wide is the region?
solution: From 2 to 2 there's no width: **0**.
:::

::: problem id=p8 type=numeric answer="0"
$\int_{-1}^{1} x^3\,dx = ?$
hint: The area below the axis cancels the area above.
solution: $\left[\frac{x^4}{4}\right]_{-1}^{1} = \frac{1}{4} - \frac{1}{4} = 0$.
:::

::: problem id=c1 type=expression answer="x^2" creative=true
$\frac{d}{dx}\int_0^x t^2\,dt = ?$
hint: Work out the integral first, then differentiate.
solution: $\int_0^x t^2\,dt = \frac{x^3}{3}$, whose derivative is $x^2$. Differentiating an integral gives back the function you started with.
:::

::: problem id=x1 type=numeric answer="9" set=extra
$\int_0^3 x^2\,dx = ?$
solution: $\left[\frac{x^3}{3}\right]_0^3 = 9$.
:::

::: problem id=x2 type=numeric answer="15" set=extra
$\int_1^2 4x^3\,dx = ?$
solution: $[x^4]_1^2 = 16 - 1 = 15$.
:::

::: problem id=x3 type=numeric answer="2" set=extra
$\int_0^2 (x^3 - x)\,dx = ?$
solution: $\left[\frac{x^4}{4} - \frac{x^2}{2}\right]_0^2 = 4 - 2 = 2$.
:::

::: problem id=x4 type=numeric answer="14/3" set=extra
$\int_1^4 \sqrt{x}\,dx = ?$
solution: $\left[\frac{2}{3}x^{3/2}\right]_1^4 = \frac{2}{3}(8 - 1) = \frac{14}{3}$.
:::

::: problem id=x5 type=numeric answer="1" set=extra
$\int_0^{\pi/2} \sin x\,dx = ?$
solution: $[-\cos x]_0^{\pi/2} = 0 + 1 = 1$.
:::

::: problem id=x6 type=numeric answer="1/2" set=extra
$\int_1^2 \frac{1}{x^2}\,dx = ?$
solution: $\left[-\frac{1}{x}\right]_1^2 = -\frac{1}{2} + 1 = \frac{1}{2}$.
:::

::: problem id=x7 type=numeric answer="1" set=extra
$\int_0^{\ln 2} e^x\,dx = ?$
solution: $e^{\ln 2} - e^0 = 2 - 1 = 1$.
:::

::: problem id=x8 type=numeric answer="28/3" set=extra
$\int_{-2}^{2} (x^2 + 1)\,dx = ?$
solution: $\left[\frac{x^3}{3} + x\right]_{-2}^{2}$
$= \frac{14}{3} - \left(-\frac{14}{3}\right) = \frac{28}{3}$.
:::

::: problem id=x9 type=numeric answer="2" set=extra
$\int_1^{e^2} \frac{1}{x}\,dx = ?$
solution: $\ln e^2 - \ln 1 = 2$.
:::

::: problem id=x10 type=expression answer="cos(x)" set=extra
$\frac{d}{dx}\int_1^x \cos t\,dt = ?$
hint: Work out the integral first ($\sin x - \sin 1$), then differentiate.
solution: The derivative of the integral up to x gives back the integrand: $\cos x$.
:::

::: problem id=x11 type=expression answer="2x^3" set=extra
$\frac{d}{dx}\int_0^{x^2} t\,dt = ?$
hint: Work out the integral first, or use the chain rule.
solution: $\int_0^{x^2} t\,dt = \frac{x^4}{2}$, whose derivative is $2x^3$.
:::

::: problem id=x12 type=numeric answer="4" set=extra
An object's velocity is $v(t) = 3t^2 - 2$. What is its displacement from $t = 0$ to $t = 2$?
solution: $\int_0^2 (3t^2 - 2)\,dt = [t^3 - 2t]_0^2 = 8 - 4 = 4$.
:::

::: problem id=x13 type=choice set=extra
A student computes $\int_{-1}^{1} \frac{1}{x^2}\,dx = \left[-\frac{1}{x}\right]_{-1}^{1} = -2$. What is wrong?
- [ ] Nothing
- [ ] The antiderivative is wrong
- [x] $\frac{1}{x^2}$ is not continuous on $[-1, 1]$, so the theorem doesn't apply
- [ ] The limits are in the wrong order
solution: $\frac{1}{x^2}$ blows up at 0. (A positive function can't have a negative area: a warning sign.)
:::

::: problem id=x14 type=numeric answer="32/3" set=extra
Find the area between $y = 4 - x^2$ and the x-axis.
hint: The curve crosses the axis at $x = \pm 2$.
solution: $\int_{-2}^{2}(4 - x^2)\,dx = \left[4x - \frac{x^3}{3}\right]_{-2}^{2}$
$= \frac{16}{3} + \frac{16}{3} = \frac{32}{3}$.
:::

::: problem id=x15 type=numeric answer="0" set=extra
$\int_0^{\pi} \cos x\,dx = ?$
solution: $\sin\pi - \sin 0 = 0$. The part above the axis cancels the part below.
:::

::: problem id=x16 type=numeric answer="1/2" set=extra
What is the **total** area (not net) between $y = x^3$ and the x-axis for $-1 \le x \le 1$?
hint: Find each piece separately and count both as positive.
solution: $\int_0^1 x^3\,dx = \frac{1}{4}$. The left piece is also $\frac{1}{4}$.
Total $\frac{1}{2}$.
:::

::: problem id=x17 type=numeric answer="20" set=extra
Water flows into a tank at $r(t) = 2t + 1$ litres per minute. How much flows in from $t = 0$ to $t = 4$?
hint: Total amount = integral of the rate.
solution: $\int_0^4 (2t + 1)\,dt = [t^2 + t]_0^4 = 20$ litres.
:::

::: problem id=x18 type=numeric answer="3" set=extra
For which $k > 0$ is $\int_0^k 2x\,dx = 9$?
hint: Evaluate the integral in terms of k.
solution: $[x^2]_0^k = k^2 = 9$, so $k = 3$.
:::

::: problem id=x19 type=numeric answer="3" set=extra
The average value of f on $[a, b]$ is $\frac{1}{b - a}\int_a^b f(x)\,dx$. Find the average value of $x^2$ on $[0, 3]$.
hint: $\int_0^3 x^2\,dx = 9$.
solution: $\frac{1}{3} \cdot 9 = 3$.
:::

::: problem id=x20 type=numeric answer="2" set=extra creative=true
$F(x) = \int_0^x (t^2 - 4)\,dt$. At which $x > 0$ does F have a local minimum?
hint: $F'(x) = x^2 - 4$.
solution: $F' = 0$ at $x = 2$ and goes − to + there. So F has a local min at $x = 2$, without ever working out the integral.
:::
