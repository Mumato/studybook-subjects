---
id: int-02
title: Adding integers
---
::: rule
- **Same signs:** add the absolute values and keep the sign. $-4 + (-6) = -10$
- **Different signs:** subtract the smaller absolute value from the larger, and take the sign of the one with the larger absolute value. $-9 + 5 = -4$

Think of money: negative is owing, positive is having.
:::

::: example
$-4 + (-6)$: both negative, $4 + 6 = 10$, so $-10$.
:::

::: example
$-9 + 5$: different signs, $9 - 5 = 4$. 9 is the bigger one and it's negative, so $-4$.
:::

::: problem id=p1 type=numeric answer="-8"
$-3 + (-5) = ?$
solution: Same signs: $3 + 5 = 8$, keep the minus: **−8**.
:::

::: problem id=p2 type=numeric answer="5"
$7 + (-2) = ?$
solution: $7 - 2 = 5$, and 7 is positive: **5**.
:::

::: problem id=p3 type=numeric answer="-6"
$-10 + 4 = ?$
hint: Different signs: subtract, then take the sign of the bigger one.
solution: $10 - 4 = 6$, and 10 is negative: **−6**.
:::

::: problem id=p4 type=numeric answer="0"
$-6 + 6 = ?$
solution: A number plus its opposite is **0**.
:::

::: problem id=p5 type=numeric answer="5"
$-15 + 20 = ?$
solution: $20 - 15 = 5$, and 20 is positive: **5**.
:::

::: problem id=p6 type=numeric answer="3"
It is $-8$ degrees in the morning and the temperature rises 11 degrees. What is it now?
solution: $-8 + 11 = 3$ degrees.
:::

::: problem id=p7 type=numeric answer="2"
$-2 + (-3) + 7 = ?$
hint: Add the first two, then the third.
solution: $-2 + (-3) = -5$, then $-5 + 7 = 2$.
:::

::: problem id=p8 type=numeric answer="15"
Your account is at $-20$ dollars and you deposit 35 dollars. What is the balance?
solution: $-20 + 35 = 15$ dollars.
:::
