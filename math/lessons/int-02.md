id: int-02
title: Adding integers
---
::: rule
- **Same signs:** add the absolute values and keep the sign. $-4 + (-6) = -10$
- **Different signs:** subtract the smaller absolute value from the larger, and take the sign of the one with the larger absolute value. $-9 + 5 = -4$

Think of money: negative is owing, positive is having.
:::

::: example
$-4 + (-6)$: both negative, $4 + 6 = 10$, so $-10$.
:::

::: example
$-9 + 5$: different signs, $9 - 5 = 4$. 9 is the bigger one and it's negative, so $-4$.
:::
