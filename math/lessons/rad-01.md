---
id: rad-01
title: Simplifying roots
---
::: rule
- $\sqrt{ab} = \sqrt{a} \cdot \sqrt{b}$ and $\sqrt{\frac{a}{b}} = \frac{\sqrt{a}}{\sqrt{b}}$
- To simplify $\sqrt{n}$, split off the biggest perfect square factor: $\sqrt{50} = \sqrt{25 \cdot 2} = 5\sqrt{2}$.
- The **cube root** $\sqrt[3]{a}$ is the number whose cube is a. Cube roots of negative numbers are negative.
- Careful: $\sqrt{a + b}$ is **not** $\sqrt{a} + \sqrt{b}$.
:::

::: example
$\sqrt{72} = \sqrt{36 \cdot 2} = 6\sqrt{2}$
:::

::: example
$\sqrt[3]{-8} = -2$ because $(-2)^3 = -8$.
:::

::: problem id=p1 type=numeric answer="5"
$\sqrt{50} = \square\sqrt{2}$. What goes in the box?
solution: $\sqrt{25 \cdot 2} = 5\sqrt{2}$.
:::

::: problem id=p2 type=numeric answer="6"
$\sqrt{72} = \square\sqrt{2}$. What goes in the box?
hint: Find the biggest square that divides 72.
solution: $72 = 36 \cdot 2$, so $6\sqrt{2}$.
:::

::: problem id=p3 type=numeric answer="3"
$\sqrt{27} = 3\sqrt{\square}$. What goes in the box?
solution: $\sqrt{9 \cdot 3} = 3\sqrt{3}$.
:::

::: problem id=p4 type=numeric answer="6"
$\sqrt{4 \cdot 9} = ?$
solution: $\sqrt{4} \cdot \sqrt{9} = 2 \cdot 3 = 6$.
:::

::: problem id=p5 type=numeric answer="3"
$\sqrt[3]{27} = ?$
solution: $3^3 = 27$, so **3**.
:::

::: problem id=p6 type=numeric answer="-2"
$\sqrt[3]{-8} = ?$
solution: $(-2)^3 = -8$, so **−2**.
:::

::: problem id=p7 type=numeric answer="6"
$\sqrt{12} \cdot \sqrt{3} = ?$
solution: $\sqrt{36} = 6$.
:::

::: problem id=p8 type=text answers="no"
Is $\sqrt{16 + 9}$ equal to $\sqrt{16} + \sqrt{9}$? Type yes or no.
solution: $\sqrt{25} = 5$ but $4 + 3 = 7$: **no**.
:::
