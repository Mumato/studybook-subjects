id: dec-02
title: Adding and subtracting decimals
---
::: rule
Line up the **decimal points**, fill empty places with zeros, then add or subtract as with whole numbers. The decimal point in the answer goes straight below.
:::

::: example
$4.75 + 12.3$

Write 12.3 as 12.30. $4.75 + 12.30 = 17.05$.
:::

::: example
$10 - 3.46$

Write 10 as 10.00. $10.00 - 3.46 = 6.54$.
:::

::: problem id=p1 type=numeric answer="6.2"
$2.5 + 3.7 = ?$
solution: $2.5 + 3.7 = 6.2$.
:::

::: problem id=p2 type=numeric answer="5.16"
$8.06 - 2.9 = ?$
hint: Write 2.9 as 2.90.
solution: $8.06 - 2.90 = 5.16$.
:::

::: problem id=p3 type=numeric answer="1"
$0.75 + 0.25 = ?$
solution: 75 hundredths + 25 hundredths = 100 hundredths = **1**.
:::

::: problem id=p4 type=numeric answer="7.62"
$15 - 7.38 = ?$
hint: Write 15 as 15.00.
solution: $15.00 - 7.38 = 7.62$.
:::

::: problem id=p5 type=numeric answer="6.24"
A drink costs 3.49 dollars and a sandwich 2.75 dollars. What is the total in dollars?
solution: $3.49 + 2.75 = 6.24$ dollars.
:::

::: problem id=p6 type=numeric answer="6.35"
You pay with a 20-dollar note for something that costs 13.65 dollars. How much change do you get?
solution: $20.00 - 13.65 = 6.35$ dollars.
:::

::: problem id=p7 type=numeric answer="3.105"
$1.005 + 2.1 = ?$
hint: Write 2.1 as 2.100.
solution: $1.005 + 2.100 = 3.105$.
:::

::: problem id=p8 type=numeric answer="9.01"
$9.1 - 0.09 = ?$
solution: $9.10 - 0.09 = 9.01$.
:::
