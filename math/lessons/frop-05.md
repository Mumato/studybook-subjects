---
id: frop-05
title: Working with mixed numbers
---
::: rule
- To **multiply or divide** mixed numbers, change them to improper fractions first.
- To **add or subtract**, you can add the whole numbers and the fractions separately, or change to improper fractions. When subtracting, borrow 1 from the whole number if the fraction part is too small.
:::

::: example
$2\frac{1}{2} \times 1\frac{1}{3} = \frac{5}{2} \times \frac{4}{3} = \frac{20}{6} = \frac{10}{3} = 3\frac{1}{3}$
:::

::: example
$3\frac{1}{4} - 1\frac{3}{4}$

$\frac{1}{4}$ is less than $\frac{3}{4}$, so use improper fractions: $\frac{13}{4} - \frac{7}{4} = \frac{6}{4} = 1\frac{1}{2}$.
:::

::: problem id=p1 type=numeric answer="3 3/4"
$1\frac{1}{2} + 2\frac{1}{4} = ?$
hint: $\frac{1}{2} = \frac{2}{4}$.
solution: Wholes: $1 + 2 = 3$. Fractions: $\frac{2}{4} + \frac{1}{4} = \frac{3}{4}$. Answer: $3\frac{3}{4}$.
:::

::: problem id=p2 type=numeric answer="3 1/3"
$4\frac{2}{3} - 1\frac{1}{3} = ?$
solution: Wholes: $4 - 1 = 3$. Fractions: $\frac{2}{3} - \frac{1}{3} = \frac{1}{3}$. Answer: $3\frac{1}{3}$.
:::

::: problem id=p3 type=numeric answer="10"
$2\frac{1}{2} \times 4 = ?$
solution: $\frac{5}{2} \times 4 = \frac{20}{2} = 10$.
:::

::: problem id=p4 type=numeric answer="4"
$1\frac{1}{2} \times 2\frac{2}{3} = ?$
hint: $\frac{3}{2} \times \frac{8}{3}$.
solution: $\frac{3}{2} \times \frac{8}{3} = \frac{24}{6} = 4$.
:::

::: problem id=p5 type=numeric answer="3"
$3\frac{3}{4} \div 1\frac{1}{4} = ?$
solution: $\frac{15}{4} \div \frac{5}{4} = \frac{15}{4} \times \frac{4}{5} = 3$.
:::

::: problem id=p6 type=numeric answer="2 2/3"
$5 - 2\frac{1}{3} = ?$
hint: Write 5 as $4\frac{3}{3}$.
solution: $4\frac{3}{3} - 2\frac{1}{3} = 2\frac{2}{3}$.
:::

::: problem id=p7 type=numeric answer="3 1/2"
A recipe needs $1\frac{3}{4}$ cups of flour. How much for a double batch?
solution: $1\frac{3}{4} \times 2 = \frac{7}{4} \times 2 = \frac{14}{4} = 3\frac{1}{2}$ cups.
:::

::: problem id=p8 type=numeric answer="4 1/6"
$2\frac{5}{6} + 1\frac{1}{3} = ?$
solution: $\frac{1}{3} = \frac{2}{6}$. $2\frac{5}{6} + 1\frac{2}{6} = 3\frac{7}{6} = 4\frac{1}{6}$.
:::

::: problem id=x1 type=numeric answer="5 3/5" set=extra
$2\frac{1}{5} + 3\frac{2}{5} = ?$
solution: Wholes $2 + 3 = 5$, fractions $\frac{1}{5} + \frac{2}{5} = \frac{3}{5}$: $5\frac{3}{5}$.
:::

::: problem id=x2 type=numeric answer="4 1/2" set=extra
$6\frac{3}{4} - 2\frac{1}{4} = ?$
solution: Wholes $6 - 2 = 4$, fractions $\frac{3}{4} - \frac{1}{4} = \frac{2}{4} = \frac{1}{2}$: $4\frac{1}{2}$.
:::

::: problem id=x3 type=numeric answer="5" set=extra
$1\frac{2}{3} \times 3 = ?$
solution: $\frac{5}{3} \times 3 = 5$.
:::

::: problem id=x4 type=numeric answer="3" set=extra
$2\frac{1}{4} \times 1\frac{1}{3} = ?$
solution: $\frac{9}{4} \times \frac{4}{3} = \frac{36}{12} = 3$.
:::

::: problem id=x5 type=numeric answer="3" set=extra
$4\frac{1}{2} \div 1\frac{1}{2} = ?$
solution: $\frac{9}{2} \div \frac{3}{2} = \frac{9}{2} \times \frac{2}{3} = 3$.
:::

::: problem id=x6 type=numeric answer="5 1/6" set=extra
$3\frac{1}{3} + 1\frac{5}{6} = ?$
hint: $\frac{1}{3} = \frac{2}{6}$.
solution: $3\frac{2}{6} + 1\frac{5}{6} = 4\frac{7}{6} = 5\frac{1}{6}$.
:::

::: problem id=x7 type=numeric answer="2 1/2" set=extra
$5\frac{1}{4} - 2\frac{3}{4} = ?$
solution: Borrow: $\frac{21}{4} - \frac{11}{4} = \frac{10}{4} = 2\frac{1}{2}$.
:::

::: problem id=x8 type=numeric answer="3 5/8" set=extra
$7 - 3\frac{3}{8} = ?$
solution: $7 = 6\frac{8}{8}$. $6\frac{8}{8} - 3\frac{3}{8} = 3\frac{5}{8}$.
:::

::: problem id=x9 type=choice set=extra
Kai wrote $4\frac{1}{5} - 1\frac{3}{5} = 3\frac{2}{5}$. What is the right answer?
- [ ] $3\frac{2}{5}$
- [x] $2\frac{3}{5}$
- [ ] $3\frac{3}{5}$
- [ ] $2\frac{2}{5}$
solution: $\frac{1}{5}$ is less than $\frac{3}{5}$, so borrow: $\frac{21}{5} - \frac{8}{5} = \frac{13}{5} = 2\frac{3}{5}$. Kai took $\frac{1}{5}$ from $\frac{3}{5}$ the wrong way round.
:::

::: problem id=x10 type=choice set=extra
Zoe worked out $2\frac{1}{2} \times 1\frac{1}{2}$ as $2 \times 1 + \frac{1}{2} \times \frac{1}{2} = 2\frac{1}{4}$. What is the right answer?
- [ ] $2\frac{1}{4}$
- [ ] $3\frac{1}{4}$
- [x] $3\frac{3}{4}$
- [ ] $2\frac{3}{4}$
solution: Change to improper fractions: $\frac{5}{2} \times \frac{3}{2} = \frac{15}{4} = 3\frac{3}{4}$. You can't multiply wholes and fractions separately.
:::

::: problem id=x11 type=numeric answer="4 3/4" set=extra
A board is $8\frac{1}{2}$ ft long. You cut off $3\frac{3}{4}$ ft. How long is the rest?
solution: $\frac{34}{4} - \frac{15}{4} = \frac{19}{4} = 4\frac{3}{4}$ ft.
:::

::: problem id=x12 type=numeric answer="4" set=extra
$2\frac{1}{2} \times 1\frac{3}{5} = ?$
solution: $\frac{5}{2} \times \frac{8}{5} = \frac{40}{10} = 4$.
:::

::: problem id=x13 type=numeric answer="4 3/8" set=extra
$1\frac{3}{4} + 2\frac{5}{8} = ?$
solution: $1\frac{6}{8} + 2\frac{5}{8} = 3\frac{11}{8} = 4\frac{3}{8}$.
:::

::: problem id=x14 type=numeric answer="8" set=extra
One serving is $1\frac{1}{4}$ cups. How many servings are in 10 cups?
solution: $10 \div \frac{5}{4} = 10 \times \frac{4}{5} = 8$.
:::

::: problem id=x15 type=numeric answer="7 7/8" set=extra
A rug is $3\frac{1}{2}$ m by $2\frac{1}{4}$ m. What is its area in m²?
solution: $\frac{7}{2} \times \frac{9}{4} = \frac{63}{8} = 7\frac{7}{8}$ m².
:::

::: problem id=x16 type=numeric answer="11 1/2" set=extra
What is the perimeter of the same $3\frac{1}{2}$ m by $2\frac{1}{4}$ m rug, in m?
solution: $3\frac{1}{2} + 2\frac{1}{4} = 5\frac{3}{4}$. Twice that: $\frac{23}{4} \times 2 = \frac{23}{2} = 11\frac{1}{2}$ m.
:::

::: problem id=x17 type=numeric answer="3 3/8" set=extra
A recipe for 4 people uses $2\frac{1}{4}$ cups of rice. How many cups for 6 people?
hint: 6 people is $\frac{6}{4} = 1\frac{1}{2}$ times the recipe.
solution: $\frac{9}{4} \times \frac{3}{2} = \frac{27}{8} = 3\frac{3}{8}$ cups.
:::

::: problem id=x18 type=numeric answer="10 5/6" set=extra
Eva walks $1\frac{2}{3}$ km on each of 5 school days, and $2\frac{1}{2}$ km on Saturday. How far does she walk in total?
hint: First multiply, then add with denominator 6.
solution: $\frac{5}{3} \times 5 = \frac{25}{3} = 8\frac{1}{3}$. Then $8\frac{2}{6} + 2\frac{3}{6} = 10\frac{5}{6}$ km.
:::

::: problem id=x19 type=numeric answer="5" set=extra
A tank holds $12\frac{1}{2}$ L and has $4\frac{3}{4}$ L in it. How many full $1\frac{1}{2}$ L jugs can you pour in without it overflowing?
hint: Find the free space, then divide by $1\frac{1}{2}$.
solution: Space: $\frac{50}{4} - \frac{19}{4} = \frac{31}{4}$ L. $\frac{31}{4} \div \frac{3}{2} = \frac{31}{6} = 5\frac{1}{6}$, so **5** full jugs.
:::

::: problem id=x20 type=numeric answer="1 2/3" set=extra creative=true
Find the number $m$ for which $m \times 2\frac{1}{2}$ is the same as $m + 2\frac{1}{2}$.
hint: Multiplying by $2\frac{1}{2}$ adds $1\frac{1}{2}$ copies of $m$ to $m$.
solution: $m \times \frac{5}{2} = m + \frac{5}{2}$ means $\frac{3}{2} \times m = \frac{5}{2}$, so $m = \frac{5}{2} \div \frac{3}{2} = \frac{5}{3} = 1\frac{2}{3}$. Check: both give $4\frac{1}{6}$.
:::
