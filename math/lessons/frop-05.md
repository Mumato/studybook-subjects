---
id: frop-05
title: Working with mixed numbers
---
::: rule
- To **multiply or divide** mixed numbers, change them to improper fractions first.
- To **add or subtract**, you can add the whole numbers and the fractions separately, or change to improper fractions. When subtracting, borrow 1 from the whole number if the fraction part is too small.
:::

::: example
$2\frac{1}{2} \times 1\frac{1}{3} = \frac{5}{2} \times \frac{4}{3} = \frac{20}{6} = \frac{10}{3} = 3\frac{1}{3}$
:::

::: example
$3\frac{1}{4} - 1\frac{3}{4}$

$\frac{1}{4}$ is less than $\frac{3}{4}$, so use improper fractions: $\frac{13}{4} - \frac{7}{4} = \frac{6}{4} = 1\frac{1}{2}$.
:::

::: problem id=p1 type=numeric answer="3 3/4"
$1\frac{1}{2} + 2\frac{1}{4} = ?$
hint: $\frac{1}{2} = \frac{2}{4}$.
solution: Wholes: $1 + 2 = 3$. Fractions: $\frac{2}{4} + \frac{1}{4} = \frac{3}{4}$. Answer: $3\frac{3}{4}$.
:::

::: problem id=p2 type=numeric answer="3 1/3"
$4\frac{2}{3} - 1\frac{1}{3} = ?$
solution: Wholes: $4 - 1 = 3$. Fractions: $\frac{2}{3} - \frac{1}{3} = \frac{1}{3}$. Answer: $3\frac{1}{3}$.
:::

::: problem id=p3 type=numeric answer="10"
$2\frac{1}{2} \times 4 = ?$
solution: $\frac{5}{2} \times 4 = \frac{20}{2} = 10$.
:::

::: problem id=p4 type=numeric answer="4"
$1\frac{1}{2} \times 2\frac{2}{3} = ?$
hint: $\frac{3}{2} \times \frac{8}{3}$.
solution: $\frac{3}{2} \times \frac{8}{3} = \frac{24}{6} = 4$.
:::

::: problem id=p5 type=numeric answer="3"
$3\frac{3}{4} \div 1\frac{1}{4} = ?$
solution: $\frac{15}{4} \div \frac{5}{4} = \frac{15}{4} \times \frac{4}{5} = 3$.
:::

::: problem id=p6 type=numeric answer="2 2/3"
$5 - 2\frac{1}{3} = ?$
hint: Write 5 as $4\frac{3}{3}$.
solution: $4\frac{3}{3} - 2\frac{1}{3} = 2\frac{2}{3}$.
:::

::: problem id=p7 type=numeric answer="3 1/2"
A recipe needs $1\frac{3}{4}$ cups of flour. How much for a double batch?
solution: $1\frac{3}{4} \times 2 = \frac{7}{4} \times 2 = \frac{14}{4} = 3\frac{1}{2}$ cups.
:::

::: problem id=p8 type=numeric answer="4 1/6"
$2\frac{5}{6} + 1\frac{1}{3} = ?$
solution: $\frac{1}{3} = \frac{2}{6}$. $2\frac{5}{6} + 1\frac{2}{6} = 3\frac{7}{6} = 4\frac{1}{6}$.
:::
