id: unit-01
title: Radians
---
::: rule
**Radians** measure angles by arc length on a circle of radius 1. A full turn is $2\pi$ radians, so

$$180° = \pi \text{ radians}$$

- degrees to radians: multiply by $\frac{\pi}{180}$
- radians to degrees: multiply by $\frac{180}{\pi}$

Arc length on a circle of radius r: $s = r\theta$ (θ in radians).
:::

::: example
$60° = 60 \times \frac{\pi}{180} = \frac{\pi}{3}$.
:::

::: example
$\frac{\pi}{4} = \frac{180}{4} = 45°$.
:::

Type π as pi, like pi/3.

::: problem id=p1 type=numeric answer="pi/2"
Write 90° in radians.
solution: $90 \times \frac{\pi}{180} = \frac{\pi}{2}$.
:::

::: problem id=p2 type=numeric answer="pi/3"
Write 60° in radians.
solution: $\frac{\pi}{3}$.
:::

::: problem id=p3 type=numeric answer="45"
Write $\frac{\pi}{4}$ in degrees.
solution: $\frac{180}{4} = 45°$.
:::

::: problem id=p4 type=numeric answer="360"
Write $2\pi$ in degrees.
solution: A full turn: $360°$.
:::

::: problem id=p5 type=numeric answer="3pi/4"
Write 135° in radians.
hint: 135 is 3 times 45.
solution: $3 \times \frac{\pi}{4} = \frac{3\pi}{4}$.
:::

::: problem id=p6 type=numeric answer="30"
Write $\frac{\pi}{6}$ in degrees.
solution: $\frac{180}{6} = 30°$.
:::

::: problem id=p7 type=numeric answer="6"
A circle has radius 3. How long is the arc for an angle of 2 radians?
solution: $s = r\theta = 3 \times 2 = 6$.
:::

::: problem id=p8 type=choice
How many radians is one full turn?
- [ ] $\pi$
- [x] $2\pi$
- [ ] $360$
solution: $360° = 2\pi$.
:::
