---
id: frop-03
title: Adding and subtracting with the same denominator
---
::: rule
When the denominators are the same, add or subtract the **numerators** and keep the denominator. Then simplify.

$\frac{a}{c} + \frac{b}{c} = \frac{a + b}{c}$

Don't add the denominators: $\frac{1}{4} + \frac{1}{4}$ is $\frac{2}{4}$, not $\frac{2}{8}$.
:::

::: example
$\frac{2}{9} + \frac{4}{9} = \frac{6}{9} = \frac{2}{3}$
:::

::: example
$\frac{7}{8} - \frac{3}{8} = \frac{4}{8} = \frac{1}{2}$
:::

::: problem id=p1 type=numeric answer="3/5"
$\frac{1}{5} + \frac{2}{5} = ?$
solution: $\frac{1 + 2}{5} = \frac{3}{5}$.
:::

::: problem id=p2 type=numeric answer="1/2"
$\frac{5}{12} + \frac{1}{12} = ?$
hint: Add, then simplify.
solution: $\frac{6}{12} = \frac{1}{2}$.
:::

::: problem id=p3 type=numeric answer="3/5"
$\frac{9}{10} - \frac{3}{10} = ?$
solution: $\frac{6}{10} = \frac{3}{5}$.
:::

::: problem id=p4 type=numeric answer="1"
$\frac{3}{7} + \frac{4}{7} = ?$
solution: $\frac{7}{7} = 1$.
:::

::: problem id=p5 type=numeric answer="1"
$\frac{11}{6} - \frac{5}{6} = ?$
solution: $\frac{6}{6} = 1$.
:::

::: problem id=p6 type=numeric answer="5/8"
You eat $\frac{3}{8}$ of a pizza and your friend eats $\frac{2}{8}$. How much did you eat together?
solution: $\frac{3}{8} + \frac{2}{8} = \frac{5}{8}$.
:::

::: problem id=p7 type=choice
$\frac{1}{4} + \frac{1}{4} = ?$
- [x] $\frac{1}{2}$
- [ ] $\frac{2}{8}$
- [ ] $\frac{1}{8}$
hint: Keep the denominator.
solution: $\frac{2}{4} = \frac{1}{2}$. ($\frac{2}{8}$ is the mistake of adding the denominators.)
:::

::: problem id=p8 type=numeric answer="1/3"
$\frac{5}{9} + \frac{2}{9} - \frac{4}{9} = ?$
solution: $\frac{5 + 2 - 4}{9} = \frac{3}{9} = \frac{1}{3}$.
:::

:::

solution: $\frac{8}{10} = \frac{4}{5}$.
:::

::: problem id=x3 type=numeric answer="1/2" set=extra
$\frac{11}{12} - \frac{5}{12} = ?$
solution: $\frac{6}{12} = \frac{1}{2}$.
:::

::: problem id=x4 type=numeric answer="3/2" set=extra
$\frac{5}{8} + \frac{7}{8} = ?$
solution: $\frac{12}{8} = \frac{3}{2}$, or $1\frac{1}{2}$.

::: problem id=x5 type=numeric answer="3/5" set=extra
$\frac{13}{15} - \frac{4}{15} = ?$
solution: $\frac{9}{15} = \frac{3}{5}$.
:::

::: problem id=x6 type=numeric answer="1/2" set=extra
$\frac{1}{6} + \frac{1}{6} + \frac{1}{6} = ?$
solution: $\frac{3}{6} = \frac{1}{2}$.
:::

::: problem id=x7 type=shade parts=8 answer="1/2" set=extra
Shade $\frac{3}{8} + \frac{1}{8}$ of the bar.
solution: $\frac{3}{8} + \frac{1}{8} = \frac{4}{8}$: shade any 4 parts (that is half).
:::

::: problem id=x8 type=numeric answer="7/10" set=extra
$1 - \frac{3}{10} = ?$
hint: Write 1 as $\frac{10}{10}$.
solution: $\frac{10}{10} - \frac{3}{10} = \frac{7}{10}$.
:::

::: problem id=x9 type=choice set=extra
Ana wrote $\frac{2}{5} + \frac{1}{5} = \frac{3}{10}$. What is the right answer?
- [ ] $\frac{3}{10}$
- [x] $\frac{3}{5}$
- [ ] $\frac{2}{25}$
- [ ] $\frac{1}{5}$
solution: Fifths plus fifths are still fifths: $\frac{3}{5}$. Ana added the denominators.
:::

::: problem id=x10 type=numeric answer="1" set=extra
You walk $\frac{5}{12}$ of a mile in the morning and $\frac{7}{12}$ of a mile in the afternoon. How many miles in total?
solution: $\frac{5}{12} + \frac{7}{12} = \frac{12}{12} = 1$ mile.
:::

::: problem id=x11 type=numeric answer="3/5" set=extra
A tank is $\frac{9}{10}$ full. You use $\frac{3}{10}$ of a tank. How full is it now?
solution: $\frac{9}{10} - \frac{3}{10} = \frac{6}{10} = \frac{3}{5}$.
:::

::: problem id=x12 type=numeric answer="5" set=extra
$\frac{?}{9} + \frac{4}{9} = 1$. What is the missing number?
solution: $1 = \frac{9}{9}$, so $? = 9 - 4 = 5$.
:::

::: problem id=x13 type=numeric answer="9/11" set=extra
$x - \frac{2}{11} = \frac{7}{11}$. What is $x$?
hint: Undo the subtraction by adding.
solution: $x = \frac{7}{11} + \frac{2}{11} = \frac{9}{11}$.
:::

::: problem id=x14 type=numeric answer="7/6" set=extra
$2 - \frac{5}{6} = ?$
hint: $2 = \frac{12}{6}$.
solution: $\frac{12}{6} - \frac{5}{6} = \frac{7}{6}$, or $1\frac{1}{6}$.
:::

::: problem id=x15 type=choice set=extra
Which sum equals 1?
- [x] $\frac{3}{8} + \frac{5}{8}$
- [ ] $\frac{2}{5} + \frac{2}{5}$
- [ ] $\frac{4}{7} + \frac{4}{7}$
- [ ] $\frac{1}{3} + \frac{1}{2}$
solution: $\frac{3 + 5}{8} = \frac{8}{8} = 1$. The others give $\frac{4}{5}$, $\frac{8}{7}$ and $\frac{5}{6}$.
:::

::: problem id=x16 type=numeric answer="2/3" set=extra
$\frac{2}{9} + \frac{2}{9} + \frac{2}{9} = ?$
solution: $\frac{6}{9} = \frac{2}{3}$. (This is also $3 \times \frac{2}{9}$.)
:::

::: problem id=x17 type=numeric answer="1/5" set=extra
In a class, $\frac{7}{20}$ of the students walk to school and $\frac{9}{20}$ take the bus. The rest come by car. What fraction come by car?
hint: All the students together make $\frac{20}{20}$.
solution: $\frac{20}{20} - \frac{7}{20} - \frac{9}{20} = \frac{4}{20} = \frac{1}{5}$.
:::

::: problem id=x18 type=numeric answer="8" set=extra
$\frac{a}{13} + \frac{b}{13} = 1$ and $a - b = 3$, with whole numbers $a$ and $b$. What is $a$?
hint: $a + b = 13$. Which two numbers add to 13 and differ by 3?
solution: $a + b = 13$ and $a - b = 3$: $a = 8$, $b = 5$.
:::

::: problem id=x19 type=numeric answer="3/10" set=extra
From a 1 m rope you cut $\frac{3}{10}$ m, then another $\frac{4}{10}$ m. How many metres are left?
hint: Add the two pieces, then take them from $\frac{10}{10}$.
solution: Cut $\frac{7}{10}$ m. Left: $\frac{10}{10} - \frac{7}{10} = \frac{3}{10}$ m.
:::

::: problem id=x20 type=numeric answer="9/2" set=extra creative=true
$\frac{1}{10} + \frac{2}{10} + \frac{3}{10} + \cdots + \frac{9}{10} = ?$
hint: Add the numerators. Pair 1 with 9, 2 with 8, and so on.
solution: Numerators: $1 + 2 + \cdots + 9 = 45$. So $\frac{45}{10} = \frac{9}{2}$, or $4\frac{1}{2}$.
:::
