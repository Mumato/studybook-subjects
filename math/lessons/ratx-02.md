---
id: ratx-02
title: Multiplying and dividing rational expressions
---
::: rule
Same as with number fractions:
- **multiply:** factor everything, cancel common factors, multiply what's left
- **divide:** flip the second fraction and multiply
:::

::: example
$\frac{x^2 - 4}{3x} \cdot \frac{6}{x + 2} = \frac{(x + 2)(x - 2)}{3x} \cdot \frac{6}{x + 2} = \frac{2(x - 2)}{x}$
:::

::: problem id=p1 type=numeric answer="2"
$\frac{x}{3} \cdot \frac{6}{x} = ?$
solution: $\frac{6x}{3x} = 2$.
:::

::: problem id=p2 type=choice
$\frac{x + 1}{x} \cdot \frac{x^2}{x + 1} = ?$
- [x] $x$
- [ ] $x + 1$
- [ ] $\frac{1}{x}$
solution: Cancel $x + 1$ and one x: $x$.
:::

::: problem id=p3 type=numeric answer="2"
$\frac{4}{x} \div \frac{2}{x} = ?$
solution: $\frac{4}{x} \cdot \frac{x}{2} = 2$.
:::

::: problem id=p4 type=choice
$\frac{x^2 - 4}{3x} \cdot \frac{6}{x + 2} = ?$
- [x] $\frac{2(x - 2)}{x}$
- [ ] $\frac{2(x + 2)}{x}$
- [ ] $2(x - 2)$
solution: Factor $x^2 - 4$, cancel $x + 2$ and 3: $\frac{2(x - 2)}{x}$.
:::

::: problem id=p5 type=numeric answer="2"
$\frac{x + 2}{5} \div \frac{x + 2}{10} = ?$
solution: $\frac{x + 2}{5} \cdot \frac{10}{x + 2} = 2$.
:::

::: problem id=p6 type=choice
$\frac{x - 3}{x + 1} \div \frac{x - 3}{x + 4} = ?$
- [x] $\frac{x + 4}{x + 1}$
- [ ] $\frac{x + 1}{x + 4}$
- [ ] $1$
solution: Flip and multiply: $\frac{x - 3}{x + 1} \cdot \frac{x + 4}{x - 3} = \frac{x + 4}{x + 1}$.
:::

::: problem id=p7 type=numeric answer="1"
Evaluate $\frac{x}{2} \cdot \frac{4}{x^2}$ at $x = 2$.
solution: It simplifies to $\frac{2}{x} = 1$.
:::

::: problem id=p8 type=expression answer="x/2"
Simplify $\frac{2x}{x + 1} \cdot \frac{x + 1}{4}$.
solution: Cancel $x + 1$: $\frac{2x}{4} = \frac{x}{2}$.
:::

::: problem id=x1 type=numeric answer="2" set=extra
$\frac{x}{5} \cdot \frac{10}{x} = ?$
solution: $\frac{10x}{5x} = 2$.
:::

::: problem id=x2 type=choice set=extra
$\frac{3x}{4} \cdot \frac{8}{x^2} = ?$
- [x] $\frac{6}{x}$
- [ ] $6x$
- [ ] $\frac{24}{x}$
- [ ] $\frac{3}{2x}$
solution: $\frac{24x}{4x^2} = \frac{6}{x}$.
:::

::: problem id=x3 type=numeric answer="2" set=extra
$\frac{6}{x} \div \frac{3}{x} = ?$
solution: $\frac{6}{x} \cdot \frac{x}{3} = 2$.
:::

::: problem id=x4 type=choice set=extra
$\frac{x - 1}{x + 2} \cdot \frac{x + 2}{(x - 1)^2} = ?$
- [x] $\frac{1}{x - 1}$
- [ ] $x - 1$
- [ ] $\frac{1}{x + 2}$
- [ ] $1$
solution: Cancel $x + 2$ and one $x - 1$: $\frac{1}{x - 1}$.
:::

::: problem id=x5 type=choice set=extra
$\frac{x^2 - 9}{2x} \cdot \frac{4}{x - 3} = ?$
- [x] $\frac{2(x + 3)}{x}$
- [ ] $\frac{2(x - 3)}{x}$
- [ ] $2(x + 3)$
- [ ] $\frac{x + 3}{2x}$
solution: $\frac{(x + 3)(x - 3)}{2x} \cdot \frac{4}{x - 3} = \frac{4(x + 3)}{2x} = \frac{2(x + 3)}{x}$.
:::

::: problem id=x6 type=numeric answer="4" set=extra
$\frac{x + 5}{3} \div \frac{x + 5}{12} = ?$
solution: $\frac{x + 5}{3} \cdot \frac{12}{x + 5} = 4$.
:::

::: problem id=x7 type=choice set=extra
$\frac{x}{x - 2} \div \frac{x^2}{x - 2} = ?$
- [x] $\frac{1}{x}$
- [ ] $x$
- [ ] $\frac{x^3}{(x - 2)^2}$
- [ ] $1$
solution: $\frac{x}{x - 2} \cdot \frac{x - 2}{x^2} = \frac{1}{x}$.
:::

::: problem id=x8 type=numeric answer="4" set=extra
Evaluate $\frac{x^2 - 1}{x} \cdot \frac{x}{x + 1}$ at $x = 5$.
solution: It simplifies to $x - 1 = 4$.
:::

::: problem id=x9 type=choice set=extra
Tom works out $\frac{2}{x} \div \frac{4}{x^2}$ by flipping the **first** fraction. What is the right answer?
- [x] $\frac{x}{2}$
- [ ] $\frac{2}{x}$
- [ ] $\frac{8}{x^3}$
- [ ] $\frac{1}{2}$
solution: Flip the second: $\frac{2}{x} \cdot \frac{x^2}{4} = \frac{2x^2}{4x} = \frac{x}{2}$.
:::

::: problem id=x10 type=choice set=extra
$\frac{x^2 + 3x + 2}{x + 2} \cdot \frac{1}{x + 1} = ?$
- [x] $1$
- [ ] $x + 1$
- [ ] $\frac{1}{x + 2}$
- [ ] $x + 2$
solution: $\frac{(x + 1)(x + 2)}{x + 2} \cdot \frac{1}{x + 1} = 1$.
:::

::: problem id=x11 type=numeric answer="1" set=extra
$\frac{x^2 - 4}{x + 2} \div (x - 2) = ?$
solution: $\frac{(x + 2)(x - 2)}{x + 2} \cdot \frac{1}{x - 2} = 1$.
:::

::: problem id=x12 type=choice set=extra
$\frac{2x + 6}{x - 1} \cdot \frac{x^2 - 1}{x + 3} = ?$
- [x] $2(x + 1)$
- [ ] $2(x - 1)$
- [ ] $\frac{2}{x + 1}$
- [ ] $x + 1$
solution: $\frac{2(x + 3)}{x - 1} \cdot \frac{(x - 1)(x + 1)}{x + 3} = 2(x + 1)$.
:::

::: problem id=x13 type=choice set=extra
$\frac{x^2 - x - 6}{x^2 - 4} \div \frac{x - 3}{x - 2} = ?$
- [x] $1$
- [ ] $x + 2$
- [ ] $\frac{1}{x + 2}$
- [ ] $\frac{(x - 3)^2}{(x - 2)^2}$
hint: Factor both quadratics.
solution: $\frac{(x - 3)(x + 2)}{(x - 2)(x + 2)} \cdot \frac{x - 2}{x - 3} = 1$.
:::

::: problem id=x14 type=numeric answer="2" set=extra
$\frac{4x}{x + 1} \cdot \frac{x + 1}{2x^2}$ simplifies to $\frac{\square}{x}$. What goes in the box?
solution: Cancel $x + 1$: $\frac{4x}{2x^2} = \frac{2}{x}$.
:::

::: problem id=x15 type=numeric answer="5" set=extra
A rectangle has sides $\frac{x^2 - 1}{x}$ and $\frac{x}{x + 1}$. What is its area when $x = 6$?
solution: Area $= \frac{(x - 1)(x + 1)}{x} \cdot \frac{x}{x + 1} = x - 1 = 5$.
:::

::: problem id=x16 type=choice set=extra
$\frac{x^2 - 25}{x^2 + 5x} \div \frac{x - 5}{x^2} = ?$
- [x] $x$
- [ ] $\frac{1}{x}$
- [ ] $x^2$
- [ ] $\frac{x - 5}{x}$
solution: $\frac{(x - 5)(x + 5)}{x(x + 5)} \cdot \frac{x^2}{x - 5} = \frac{x^2}{x} = x$.
:::

::: problem id=x17 type=numeric answer="4" set=extra
Evaluate $\frac{x^2 + 2x}{x - 3} \cdot \frac{x^2 - 9}{x^2 + 5x + 6}$ at $x = 4$.
hint: Factor everything and cancel first.
solution: $\frac{x(x + 2)}{x - 3} \cdot \frac{(x - 3)(x + 3)}{(x + 2)(x + 3)} = x$. At $x = 4$: 4.
:::

::: problem id=x18 type=multi answers="1;-2;0" set=extra
Which three values of x are excluded from $\frac{1}{x - 1} \div \frac{x}{x + 2}$?
hint: You can't divide by a fraction that equals 0.
solution: Denominators: $x \ne 1$, $x \ne -2$. And the divisor $\frac{x}{x + 2}$ can't be 0: $x \ne 0$.
:::

::: problem id=x19 type=numeric answer="1" set=extra
$\frac{x^2 - 4x + 4}{x^2 - 4} \cdot \frac{x + 2}{x - 2} = ?$
hint: The top left is a perfect square.
solution: $\frac{(x - 2)^2}{(x - 2)(x + 2)} \cdot \frac{x + 2}{x - 2} = 1$.
:::

::: problem id=x20 type=numeric answer="3" set=extra creative=true
$\frac{x + a}{x - 1} \cdot \frac{x^2 - 1}{x + 3}$ simplifies to $x + 1$. What is a?
hint: What must cancel the $x + 3$?
solution: $\frac{x^2 - 1}{x - 1} = x + 1$, so $\frac{x + a}{x + 3}$ must be 1: $a = 3$.
:::
