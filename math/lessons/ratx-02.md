---
id: ratx-02
title: Multiplying and dividing rational expressions
---
::: rule
Same as with number fractions:
- **multiply:** factor everything, cancel common factors, multiply what's left
- **divide:** flip the second fraction and multiply
:::

::: example
$\frac{x^2 - 4}{3x} \cdot \frac{6}{x + 2} = \frac{(x + 2)(x - 2)}{3x} \cdot \frac{6}{x + 2} = \frac{2(x - 2)}{x}$
:::

::: problem id=p1 type=numeric answer="2"
$\frac{x}{3} \cdot \frac{6}{x} = ?$
solution: $\frac{6x}{3x} = 2$.
:::

::: problem id=p2 type=choice
$\frac{x + 1}{x} \cdot \frac{x^2}{x + 1} = ?$
- [x] $x$
- [ ] $x + 1$
- [ ] $\frac{1}{x}$
solution: Cancel $x + 1$ and one x: $x$.
:::

::: problem id=p3 type=numeric answer="2"
$\frac{4}{x} \div \frac{2}{x} = ?$
solution: $\frac{4}{x} \cdot \frac{x}{2} = 2$.
:::

::: problem id=p4 type=choice
$\frac{x^2 - 4}{3x} \cdot \frac{6}{x + 2} = ?$
- [x] $\frac{2(x - 2)}{x}$
- [ ] $\frac{2(x + 2)}{x}$
- [ ] $2(x - 2)$
solution: Factor $x^2 - 4$, cancel $x + 2$ and 3: $\frac{2(x - 2)}{x}$.
:::

::: problem id=p5 type=numeric answer="2"
$\frac{x + 2}{5} \div \frac{x + 2}{10} = ?$
solution: $\frac{x + 2}{5} \cdot \frac{10}{x + 2} = 2$.
:::

::: problem id=p6 type=choice
$\frac{x - 3}{x + 1} \div \frac{x - 3}{x + 4} = ?$
- [x] $\frac{x + 4}{x + 1}$
- [ ] $\frac{x + 1}{x + 4}$
- [ ] $1$
solution: Flip and multiply: $\frac{x - 3}{x + 1} \cdot \frac{x + 4}{x - 3} = \frac{x + 4}{x + 1}$.
:::

::: problem id=p7 type=numeric answer="1"
Evaluate $\frac{x}{2} \cdot \frac{4}{x^2}$ at $x = 2$.
solution: It simplifies to $\frac{2}{x} = 1$.
:::

::: problem id=p8 type=expression answer="x/2"
Simplify $\frac{2x}{x + 1} \cdot \frac{x + 1}{4}$.
solution: Cancel $x + 1$: $\frac{2x}{4} = \frac{x}{2}$.
:::
