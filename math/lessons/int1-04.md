---
id: int1-04
title: Substitution
---
::: rule
**Substitution** undoes the chain rule. When you see a function and its inside's derivative:

$$\int f(g(x))\,g'(x)\,dx$$

let $u = g(x)$, so $du = g'(x)\,dx$. Integrate in u, then put $g(x)$ back.
:::

::: example
$\int 2x(x^2 + 1)^3\,dx$: let $u = x^2 + 1$, $du = 2x\,dx$. Then $\int u^3\,du = \frac{u^4}{4} = \frac{(x^2 + 1)^4}{4} + C$.
:::

Leave out the + C.

::: problem id=p1 type=expression answer="(x^2+1)^4/4" form=antiderivative
$\int 2x(x^2 + 1)^3\,dx = ?$
solution: $\frac{(x^2 + 1)^4}{4} + C$.
:::

::: problem id=p2 type=expression answer="sin(3x)/3" form=antiderivative
$\int \cos(3x)\,dx = ?$
hint: $u = 3x$, $du = 3\,dx$.
solution: $\frac{1}{3}\sin(3x) + C$.
:::

::: problem id=p3 type=expression answer="e^(5x)/5" form=antiderivative
$\int e^{5x}\,dx = ?$
solution: $\frac{1}{5}e^{5x} + C$.
:::

::: problem id=p4 type=expression answer="e^(x^2)" form=antiderivative
$\int 2xe^{x^2}\,dx = ?$
hint: $u = x^2$.
solution: $e^{x^2} + C$.
:::

::: problem id=p5 type=expression answer="ln(x^2+1)/2" form=antiderivative
$\int \frac{x}{x^2 + 1}\,dx = ?$
hint: $u = x^2 + 1$, $du = 2x\,dx$, so $x\,dx = \frac{du}{2}$.
solution: $\frac{1}{2}\ln(x^2 + 1) + C$.
:::

::: problem id=p6 type=expression answer="(2x+1)^5/10" form=antiderivative
$\int (2x + 1)^4\,dx = ?$
solution: $u = 2x + 1$: $\frac{1}{2} \cdot \frac{u^5}{5} = \frac{(2x + 1)^5}{10} + C$.
:::

::: problem id=p7 type=numeric answer="3/2"
$\int_0^1 2x(x^2 + 1)\,dx = ?$
hint: With $u = x^2 + 1$, u goes from 1 to 2.
solution: $\int_1^2 u\,du = \frac{4}{2} - \frac{1}{2} = \frac{3}{2}$.
:::

::: problem id=p8 type=expression answer="sin(x^3)" form=antiderivative
$\int 3x^2\cos(x^3)\,dx = ?$
solution: $u = x^3$: $\sin(x^3) + C$.
:::

::: problem id=c1 type=expression answer="sin(x)^2/2" form=antiderivative creative=true
$\int \sin x\cos x\,dx = ?$ Try it with $u = \sin x$, then again with $u = \cos x$. Why are both answers right?
solution: $u = \sin x$ gives $\frac{\sin^2 x}{2}$. $u = \cos x$ gives $-\frac{\cos^2 x}{2}$. They differ by $\frac{1}{2}$ (because $\sin^2 + \cos^2 = 1$), a constant, which the + C absorbs. Both are accepted.
:::
