---
id: int1-04
title: Substitution
---
::: rule
**Substitution** undoes the chain rule. When you see a function and its inside's derivative:

$$\int f(g(x))\,g'(x)\,dx$$

let $u = g(x)$, so $du = g'(x)\,dx$. Integrate in u, then put $g(x)$ back.
:::

::: example
$\int 2x(x^2 + 1)^3\,dx$: let $u = x^2 + 1$, $du = 2x\,dx$. Then $\int u^3\,du = \frac{u^4}{4} = \frac{(x^2 + 1)^4}{4} + C$.
:::

Leave out the + C.

::: problem id=c1 type=expression answer="sin(x)^2/2" form=antiderivative creative=true
$\int \sin x\cos x\,dx = ?$ Try it with $u = \sin x$, then again with $u = \cos x$. Why are both answers right?
solution: $u = \sin x$ gives $\frac{\sin^2 x}{2}$. $u = \cos x$ gives $-\frac{\cos^2 x}{2}$. They differ by $\frac{1}{2}$ (because $\sin^2 + \cos^2 = 1$), a constant, which the + C absorbs. Both are accepted.
:::

::: problem id=x14 type=choice set=extra
Which substitution works for $\int x^2e^{x^3}\,dx$?
- [ ] $u = x^2$
- [x] $u = x^3$
- [ ] $u = e^x$
- [ ] $u = e^{x^3}$
solution: $u = x^3$ gives $du = 3x^2\,dx$, and $x^2\,dx$ is right there: $\frac{1}{3}e^{x^3} + C$.
:::

::: problem id=x15 type=choice set=extra
A student writes $\int \cos(x^2)\,dx = \frac{\sin(x^2)}{2x} + C$. Is that right?
- [ ] Yes
- [x] No: there is no factor x to make $du = 2x\,dx$, and you can't divide by a variable
- [ ] No: it should be $\sin(x^2) + C$
solution: Differentiate the answer: the quotient rule does not give $\cos(x^2)$. Substitution only works when $g'(x)$ is a factor (up to a constant).
:::

::: problem id=x20 type=numeric answer="58/15" set=extra creative=true
$\int_0^{\sqrt{3}} x^3\sqrt{x^2 + 1}\,dx = ?$
hint: $u = x^2 + 1$, so $x^2 = u - 1$ and $x\,dx = \frac{du}{2}$; u goes from 1 to 4.
solution: $\frac{1}{2}\int_1^4 (u - 1)u^{1/2}\,du$
$= \left[\frac{u^{5/2}}{5} - \frac{u^{3/2}}{3}\right]_1^4$
$= \left(\frac{32}{5} - \frac{8}{3}\right) - \left(\frac{1}{5} - \frac{1}{3}\right) = \frac{58}{15}$.
:::
