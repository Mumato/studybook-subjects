---
id: sys-03
title: Elimination
---
::: rule
**Add or subtract** the two equations so that one variable cancels out.

If no variable cancels yet, first **multiply** one (or both) equations so the numbers in front of one variable are opposites.
:::

::: example
$x + y = 10$ and $x - y = 4$. Add them: $2x = 14$, so $x = 7$. Then $7 + y = 10$, so $y = 3$.
:::

::: example
$2x + 3y = 13$ and $x - y = -1$. Multiply the second by 3: $3x - 3y = -3$. Add: $5x = 10$, so $x = 2$, and then $y = 3$.
:::

::: problem id=p4 type=numeric answer="3"
$2x + y = 7$ and $x + y = 4$. What is x?
hint: Subtract the second equation from the first.
solution: $(2x + y) - (x + y) = 7 - 4$, so $x = 3$.
:::

::: problem id=p5 type=numeric answer="2"

::: problem id=p7 type=numeric answer="2"

solution: Multiply by **2**: $4x + 2y = 10$, and $+2y$ cancels $-2y$.

::: problem id=x13 type=numeric answer="2" set=extra
Ana subtracts $x - y = 3$ from $x + y = 7$ and gets $0 = 4$. She forgot that $y - (-y) = 2y$. What is y?
solution: $(x + y) - (x - y) = 2y$, so $2y = 7 - 3 = 4$ and $y = 2$.
:::

::: problem id=x14 type=numeric answer="32" set=extra

:::

::: problem id=x19 type=numeric answer="2.5" set=extra
A boat goes 30 km downstream in 2 hours and back upstream in 3 hours. What is the speed of the current, in km/h?
hint: Downstream speed is $b + c$, upstream $b - c$.
solution: $b + c = 15$ and $b - c = 10$. Subtract: $2c = 5$, $c = 2.5$ km/h.
:::

::: problem id=x20 type=numeric answer="4" set=extra creative=true

hint: Add all three equations.
solution: $2x + 2y + 2z = 18$, so $x + y + z = 9$. Subtract $x + y = 5$: $z = 4$.
:::
