---
id: sys-03
title: Elimination
---
::: rule
**Add or subtract** the two equations so that one variable cancels out.

If no variable cancels yet, first **multiply** one (or both) equations so the numbers in front of one variable are opposites.
:::

::: example
$x + y = 10$ and $x - y = 4$. Add them: $2x = 14$, so $x = 7$. Then $7 + y = 10$, so $y = 3$.
:::

::: example
$2x + 3y = 13$ and $x - y = -1$. Multiply the second by 3: $3x - 3y = -3$. Add: $5x = 10$, so $x = 2$, and then $y = 3$.
:::

::: problem id=p1 type=numeric answer="5"
$x + y = 8$ and $x - y = 2$. What is x?
solution: Add: $2x = 10$, $x = 5$.
:::

::: problem id=p2 type=numeric answer="3"
For the same system ($x + y = 8$, $x - y = 2$), what is y?
solution: $5 + y = 8$, $y = 3$.
:::

::: problem id=p3 type=numeric answer="3"
$3x + y = 11$ and $x - y = 1$. What is x?
solution: Add: $4x = 12$, $x = 3$.
:::

::: problem id=p4 type=numeric answer="3"
$2x + y = 7$ and $x + y = 4$. What is x?
hint: Subtract the second equation from the first.
solution: $(2x + y) - (x + y) = 7 - 4$, so $x = 3$.
:::

::: problem id=p5 type=numeric answer="2"
$2x + 3y = 12$ and $4x - 3y = 6$. What is y?
solution: Add: $6x = 18$, $x = 3$. Then $6 + 3y = 12$, $y = 2$.
:::

::: problem id=p6 type=numeric answer="2.5"
$x + 2y = 9$ and $3x - 2y = 7$. What is y?
solution: Add: $4x = 16$, $x = 4$. Then $4 + 2y = 9$, $y = 2.5$.
:::

::: problem id=p7 type=numeric answer="2"
In $2x + y = 5$ and $3x - 2y = 4$, what do you multiply the first equation by so that y cancels when you add?
solution: Multiply by **2**: $4x + 2y = 10$, and $+2y$ cancels $-2y$.
:::

::: problem id=p8 type=point answer="3,1"
Solve $x + y = 4$ and $x - y = 2$, then click the solution.
graph:
x -1..5
y -2..4
solution: Add: $2x = 6$, $x = 3$, $y = 1$.
:::
