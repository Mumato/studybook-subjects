title: Inequalities
---
::: rule
An **inequality** compares with $<$ (less than), $>$ (greater than), $\le$ (at most) or $\ge$ (at least).

Solve it like an equation, with one extra rule: when you **multiply or divide by a negative number, flip the sign**.
:::

::: example
$x + 3 > 7$. Subtract 3: $x > 4$. On a number line: an open dot at 4 (4 itself isn't included) and an arrow to the right.
:::

::: graph
numberline 0..8
ray 4 right open
:::

::: example
$-2x \le 6$. Divide by $-2$ and flip: $x \ge -3$. A filled dot means $-3$ is included.
:::

::: graph
numberline -6..2
ray -3 right closed
:::

::: problem id=p1 type=choice
Solve $x - 4 < 6$.
- [x] $x < 10$
- [ ] $x < 2$
- [ ] $x > 10$
solution: Add 4: $x < 10$.
:::

::: problem id=p2 type=choice
Solve $3x \ge 12$.
- [x] $x \ge 4$
- [ ] $x \le 4$
- [ ] $x \ge 9$
solution: Divide by 3 (positive, no flip): $x \ge 4$.
:::

::: problem id=p3 type=choice
Solve $-x > 2$.
- [ ] $x > -2$
- [x] $x < -2$
- [ ] $x > 2$
hint: Dividing by $-1$ flips the sign.
solution: Divide by $-1$ and flip: $x < -2$.
:::

::: problem id=p4 type=choice
Solve $2x + 1 \le 9$.
- [x] $x \le 4$
- [ ] $x \le 5$
- [ ] $x \ge 4$
solution: $2x \le 8$, so $x \le 4$.
:::

::: problem id=p5 type=numeric answer="5"
What is the smallest whole number that makes $2x > 9$ true?
solution: $x > 4.5$, so the smallest whole number is **5**.
:::

::: problem id=p6 type=numeric answer="-5"
What is the largest integer that makes $x + 7 < 3$ true?
solution: $x < -4$, so the largest integer is **−5**.
:::

::: problem id=p7 type=text answers="yes"
Is 3 a solution of $5 - x \ge 2$? Type yes or no.
solution: $5 - 3 = 2$, and $2 \ge 2$ is true, so **yes**.
:::

::: problem id=p8 type=numeric answer="6"
You need at least 50 points. You have 32, and each puzzle you solve is worth 3 points. What is the least number of puzzles you must solve?
hint: $32 + 3p \ge 50$.
solution: $3p \ge 18$, so $p \ge 6$: at least **6** puzzles.
:::

::: problem id=x11 type=choice set=extra
Which inequality means "x is at most 12"?
- [x] $x \le 12$
- [ ] $x < 12$
- [ ] $x \ge 12$
- [ ] $x > 12$
solution: "At most 12" means 12 or less: $x \le 12$.
:::

::: problem id=x12 type=choice set=extra
A number line shows an open dot at 1 and an arrow pointing left. Which inequality is it?
- [x] $x < 1$
- [ ] $x \le 1$
- [ ] $x > 1$
- [ ] $x \ge 1$
solution: Open dot: 1 is not included. Arrow left: smaller numbers. So $x < 1$.
:::

::: problem id=x13 type=choice set=extra
Lee solves $-4x < 8$ and writes $x < -2$. What is correct?
- [x] $x > -2$, because dividing by $-4$ flips the sign.
- [ ] $x < -2$ is right.
- [ ] $x < 2$
- [ ] $x > 2$
solution: Dividing by a negative flips the sign: $x > -2$. Check with $x = 0$: $0 < 8$ is true.
:::

::: problem id=x14 type=numeric answer="20" set=extra
An elevator can carry at most 900 kg. The operator weighs 80 kg and each box weighs 40 kg. What is the greatest number of boxes it can carry with the operator?
solution: $80 + 40b \le 900$, so $40b \le 820$ and $b \le 20.5$. At most **20** boxes.
:::

::: problem id=x15 type=numeric answer="10" set=extra
A taxi costs 4 dollars plus 2.50 dollars per km. You have 30 dollars. What is the greatest whole number of km you can ride?
solution: $4 + 2.5k \le 30$, so $2.5k \le 26$ and $k \le 10.4$. At most **10** km.
:::

::: problem id=x16 type=choice set=extra
Solve $3(x - 2) \ge x + 4$.
- [x] $x \ge 5$
- [ ] $x \le 5$
- [ ] $x \ge 1$
- [ ] $x \ge 3$
hint: Expand, then collect x on one side.
solution: $3x - 6 \ge x + 4$, so $2x \ge 10$ and $x \ge 5$.
:::

::: problem id=x17 type=numeric answer="5" set=extra
How many integers make $-2 < x \le 3$ true?
hint: $-2$ is not included, 3 is.
solution: $-1, 0, 1, 2, 3$: **5** integers.
:::

::: problem id=x18 type=numeric answer="87" set=extra
To pass a course, your four test scores must add up to at least 340. Your first three scores are 78, 85 and 90. What is the lowest score you can get on the fourth test?
hint: Write $78 + 85 + 90 + s \ge 340$.
solution: $78 + 85 + 90 + s \ge 340$, so $253 + s \ge 340$ and $s \ge 87$.
:::

::: problem id=x19 type=numeric answer="199" set=extra
Phone plan A costs 10 dollars plus 0.20 dollars a minute. Plan B costs 0.25 dollars a minute. What is the largest whole number of minutes for which plan B is cheaper?
hint: Solve $0.25m < 10 + 0.2m$.
solution: $0.05m < 10$, so $m < 200$. The largest whole number is **199**.
:::

::: problem id=x20 type=numeric answer="12" set=extra creative=true
A rectangle is 8 cm long. Its perimeter must be at least 30 cm and at most 40 cm. What is the largest whole-number width it can have?
hint: Perimeter is $16 + 2w$.
solution: $16 + 2w \le 40$ gives $w \le 12$, and $16 + 2w \ge 30$ gives $w \ge 7$. Largest width: **12** cm.
:::
