title: What multiplication means
---
::: rule
**Multiplication is repeated addition.** $3 \times 4$ means 3 groups of 4:
$4 + 4 + 4 = 12$.

You can also picture it as an **array**: 3 rows of 4.

Two special facts:
- anything times 0 is 0
- anything times 1 is itself

Knowing the facts up to $10 \times 10$ by heart makes everything later faster.
:::

![3 rows of 4 dots make 12](assets/arrays.png)

::: example
$6 \times 7$ is 6 groups of 7. Count up by 7s:
7, 14, 21, 28, 35, **42**.

So $6 \times 7 = 42$.
:::

::: problem id=p1 type=numeric answer="48"
$8 \times 6 = ?$
hint: Count up by 6s, eight times.
solution: 6, 12, 18, 24, 30, 36, 42, **48**.
:::

::: problem id=p2 type=numeric answer="54"
$9 \times 6 = ?$
hint: $10 \times 6 = 60$. Nine 6s is one 6 less.
solution: $60 - 6 = 54$.
:::

::: problem id=p3 type=numeric answer="0"
$0 \times 483 = ?$
solution: Anything times 0 is **0**.
:::

::: problem id=p4 type=numeric answer="97"
$1 \times 97 = ?$
solution: Anything times 1 is itself: **97**.
:::

::: problem id=p5 type=numeric answer="30"
You have 5 bags with 6 apples in each. How many apples?
solution: 5 groups of 6: $5 \times 6 = 30$.
:::

::: problem id=p6 type=numeric answer="36"
Chairs are set out in 4 rows of 9. How many chairs?
hint: Rows times chairs in each row.
solution: $4 \times 9 = 36$.
:::

::: problem id=p7 type=choice
Which is the same as $4 + 4 + 4 + 4 + 4$?
- [x] $5 \times 4$
- [ ] $4 + 5$
- [ ] $5 + 5 + 5 + 5$
solution: There are five 4s, so it is $5 \times 4 = 20$.
:::

::: problem id=p8 type=numeric answer="56"
$7 \times 8 = ?$
hint: A trick: 5, 6, 7, 8 → $56 = 7 \times 8$.
solution: $7 \times 8 = 56$.
:::

::: problem id=x1 type=numeric answer="63" set=extra
$7 \times 9 = ?$
solution: $10 \times 7 = 70$, and nine 7s is one 7 less: $70 - 7 = 63$.
:::

::: problem id=x2 type=numeric answer="36" set=extra
$6 \times 6 = ?$
solution: 6, 12, 18, 24, 30, **36**.
:::

::: problem id=x3 type=numeric answer="64" set=extra
$8 \times 8 = ?$
solution: $8 \times 8 = 64$.
:::

::: problem id=x4 type=numeric answer="21" set=extra
$3 \times 7 = ?$
solution: $7 + 7 + 7 = 21$.
:::

::: problem id=x5 type=numeric answer="60" set=extra
$10 \times 6 = ?$
solution: Ten 6s: put a 0 on the end of 6: **60**.
:::

::: problem id=x6 type=numeric answer="45" set=extra
$5 \times 9 = ?$

:::

::: problem id=x7 type=choice set=extra
Which is the same as $7 + 7 + 7$?
- [ ] $7 \times 7$
- [x] $3 \times 7$
- [ ] $7 + 3$
- [ ] $3 + 3 + 3$
solution: There are three 7s: $3 \times 7 = 21$.
:::

::: problem id=x8 type=numeric answer="56" set=extra
A spider has 8 legs. How many legs do 7 spiders have?
solution: 7 groups of 8: $7 \times 8 = 56$.
:::

::: problem id=x9 type=numeric answer="6" set=extra
What number goes in the box? $\square \times 7 = 42$
hint: Count by 7s until you reach 42.
solution: 7, 14, 21, 28, 35, 42 is six 7s, so the box is **6**.
:::

::: problem id=x10 type=numeric answer="9" set=extra
What number goes in the box? $9 \times \square = 81$
solution: $9 \times 9 = 81$, so the box is **9**.
:::

::: problem id=x11 type=choice set=extra
Tom says $0 \times 25 = 25$. Is he right?
- [ ] Yes, multiplying by 0 changes nothing
- [x] No, it is 0: zero groups of 25 is nothing
- [ ] No, it is 1
solution: $0 \times 25$ means no groups of 25, so it is **0**. (Adding 0 changes nothing; multiplying by 0 gives 0.)
:::

::: problem id=x12 type=numeric answer="29" set=extra
You have 4 packs of 6 juice boxes and 5 more loose ones. How many juice boxes is that?
solution: $4 \times 6 = 24$, then $24 + 5 = 29$.
:::

::: problem id=x13 type=choice set=extra
Which is greater?
- [x] $6 \times 7$
- [ ] $5 \times 8$
- [ ] They are equal
solution: $6 \times 7 = 42$ and $5 \times 8 = 40$, so $6 \times 7$ is greater.
:::

::: problem id=x14 type=numeric answer="54" set=extra
Write $9 + 9 + 9 + 9 + 9 + 9$ as a multiplication and work it out.
solution: Six 9s: $6 \times 9 = 54$.
:::

::: problem id=x15 type=numeric answer="48" set=extra
Tickets cost 8 dollars each. How many dollars do 6 tickets cost?
solution: $6 \times 8 = 48$ dollars.
:::

::: problem id=x16 type=numeric answer="36" set=extra
An egg box has 2 rows of 6 eggs. How many eggs are in 3 boxes?
hint: First find the eggs in one box.
solution: One box: $2 \times 6 = 12$. Three boxes: $12 + 12 + 12 = 36$.
:::

::: problem id=x17 type=numeric answer="38" set=extra
A class has 5 tables with 4 children each and 3 tables with 6 children each. How many children are there?
hint: Work out each kind of table, then add.
solution: $5 \times 4 = 20$ and $3 \times 6 = 18$. $20 + 18 = 38$ children.
:::

::: problem id=x18 type=numeric answer="26" set=extra
Pencils cost 3 dollars and pens cost 7 dollars. You buy 4 pencils and 2 pens. How many dollars do you pay?
hint: Pencils first, then pens, then add.
solution: Pencils: $4 \times 3 = 12$. Pens: $2 \times 7 = 14$. Total: $12 + 14 = 26$ dollars.
:::

::: problem id=x19 type=numeric answer="7" set=extra
How much more is $9 \times 7$ than $8 \times 7$?
hint: Nine 7s compared to eight 7s.
solution: Nine 7s is one more 7 than eight 7s, so the difference is **7** ($63 - 56 = 7$).
:::

::: problem id=x20 type=numeric answer="4" set=extra creative=true
24 dots are set out in a rectangle of equal rows. How many different rectangles are possible? Count 4 rows of 6 and 6 rows of 4 as the same, and allow a single row.
hint: Find pairs of numbers that multiply to 24.
solution: $1 \times 24$, $2 \times 12$, $3 \times 8$, $4 \times 6$: **4** rectangles.
:::
