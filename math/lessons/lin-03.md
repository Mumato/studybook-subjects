id: lin-03
title: Solving and graphing inequalities
---
::: rule
Solve an inequality like an equation, but **flip the sign** whenever you multiply or divide by a negative number.

On a number line: a **closed** dot means the number is included ($\le$, $\ge$), an **open** dot means it isn't ($<$, $>$). The arrow points toward the solutions.
:::

::: example
$2x + 3 < 11$: $2x < 8$, so $x < 4$.
:::

::: graph
numberline -2..8
ray 4 left open
:::

::: example
$-3x + 2 \le 11$: $-3x \le 9$. Divide by $-3$ and flip: $x \ge -3$.
:::

::: graph
numberline -6..4
ray -3 right closed
:::

::: problem id=p1 type=choice
Solve $3x - 5 \ge 7$.
- [x] $x \ge 4$
- [ ] $x \le 4$
- [ ] $x \ge \frac{2}{3}$
solution: $3x \ge 12$, so $x \ge 4$.
:::

::: problem id=p2 type=point answer="-3"
Solve $-2x + 1 > 7$, then click the boundary number on the number line.
graph:
numberline -6..6
hint: Dividing by $-2$ flips the sign.
solution: $-2x > 6$, so $x < -3$. The boundary is $-3$ (with an open dot).
:::

::: problem id=p3 type=choice
Which describes the graph of $x < 2$?
- [ ] closed dot at 2, arrow to the right
- [x] open dot at 2, arrow to the left
- [ ] open dot at 2, arrow to the right
solution: $<$ doesn't include 2 (open dot), and the solutions are smaller numbers (left).
:::

::: problem id=p4 type=numeric answer="4"
What is the smallest integer that makes $5x - 3 > 12$ true?
solution: $5x > 15$, so $x > 3$. The smallest integer is **4**.
:::

::: problem id=p5 type=choice
Solve $4(x - 1) \le 2x + 6$.
- [x] $x \le 5$
- [ ] $x \ge 5$
- [ ] $x \le 1$
solution: $4x - 4 \le 2x + 6$, $2x \le 10$, $x \le 5$.
:::

:::

::: problem id=p7 type=numeric answer="300"
A phone plan costs 20 dollars plus 0.05 dollars per minute. You want to spend at most 35 dollars. What is the most minutes you can use?
hint: $20 + 0.05m \le 35$.
solution: $0.05m \le 15$, so $m \le 300$ minutes.
:::

::: problem id=p8 type=text answers="yes"

::: problem id=x11 type=choice set=extra
Kim solves $-4x > 12$ and writes $x > -3$. What is the correct answer?
- [x] $x < -3$
- [ ] $x > 3$
- [ ] $x < 3$
solution: Dividing by $-4$ flips the sign: $x < -3$. Check $x = -4$: $16 > 12$, true.
:::

::: problem id=x12 type=numeric answer="2" set=extra
What is the largest integer with $6 - 2x > 1$?
solution: $-2x > -5$, so $x < 2.5$. The largest integer is **2**.
:::

::: problem id=x13 type=choice set=extra
A number line shows a closed dot at 1 and an arrow to the left. Which inequality is it?
- [ ] $x < 1$
- [x] $x \le 1$
- [ ] $x \ge 1$
solution: Closed dot: 1 is included. Arrow left: smaller numbers. So $x \le 1$.
:::

::: problem id=x14 type=numeric answer="11" set=extra
A taxi charges 3 dollars plus 2 dollars per km. You have 25 dollars. What is the longest ride, in whole km?
solution: $3 + 2k \le 25$, $2k \le 22$, $k \le 11$ km.
:::

::: problem id=x15 type=numeric answer="87" set=extra
Your test scores are 78, 85 and 90. What is the lowest score on the fourth test that gives an average of at least 85?
hint: $\frac{78 + 85 + 90 + s}{4} \ge 85$.
solution: $253 + s \ge 340$, so $s \ge 87$.
:::

::: problem id=x16 type=point answer="8" set=extra
Solve $5(x - 2) - 2(x + 1) \le x + 4$, then click the boundary number.
graph:
numberline 0..10
hint: Expand both brackets and combine like terms first.
solution: $5x - 10 - 2x - 2 \le x + 4$. So $3x - 12 \le x + 4$, $2x \le 16$, $x \le 8$.
:::

::: problem id=x17 type=numeric answer="13" set=extra
What is the smallest integer with $\frac{x}{3} - \frac{x}{4} > 1$?
hint: Multiply every term by 12. That's positive, so the sign stays.
solution: $4x - 3x > 12$, so $x > 12$. Smallest integer: **13**.
:::

::: problem id=x18 type=choice set=extra
Solve $-2(x - 3) \ge 3(x + 7)$.
- [x] $x \le -3$
- [ ] $x \ge -3$
- [ ] $x \le 3$
hint: You will end up dividing by a negative number.
solution: $-2x + 6 \ge 3x + 21$. So $-5x \ge 15$. Divide by $-5$ and flip: $x \le -3$.
:::

::: problem id=x19 type=numeric answer="4" set=extra
Gym plan A costs 30 dollars a month plus 2 dollars a visit. Plan B costs 10 dollars a visit. What is the fewest visits in a month for which plan A is cheaper?
hint: Solve $30 + 2v < 10v$.
solution: $30 < 8v$, so $v > 3.75$. The fewest whole visits: **4**.
:::

::: problem id=x20 type=numeric answer="-2" set=extra creative=true
For which number a is the solution of $ax + 3 > 7$ exactly $x < -2$?
hint: The sign flipped, so a must be negative.
solution: $ax > 4$. Dividing by a negative a flips it: $x < \frac{4}{a}$. We need $\frac{4}{a} = -2$, so $a = -2$.
:::
