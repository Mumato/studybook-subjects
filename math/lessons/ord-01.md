---
id: ord-01
title: Exponents
---
::: rule
An **exponent** says how many times to multiply a number by itself.

$2^3 = 2 \times 2 \times 2 = 8$. The 2 is the **base** and the 3 is the **exponent**.

- $a^2$ is "a squared", $a^3$ is "a cubed"
- any number to the power 1 is itself
- any number (except 0) to the power 0 is 1
- $10^n$ is a 1 followed by n zeros
:::

::: example
$3^4 = 3 \times 3 \times 3 \times 3 = 9 \times 9 = 81$.
:::

::: example
$10^5 = 100000$ (a 1 followed by five zeros).
:::

You can type exponents with ^, like 2^5.

::: problem id=p1 type=numeric answer="32"
$2^5 = ?$
hint: Keep doubling: 2, 4, 8, ...
solution: $2 \times 2 \times 2 \times 2 \times 2 = 32$.
:::

::: problem id=p2 type=numeric answer="25"
$5^2 = ?$
solution: $5 \times 5 = 25$.
:::

::: problem id=p3 type=numeric answer="64"
$4^3 = ?$
hint: $4 \times 4 = 16$, then times 4 again.
solution: $4 \times 4 \times 4 = 16 \times 4 = 64$.
:::

::: problem id=p4 type=numeric answer="7"
$7^1 = ?$
solution: Any number to the power 1 is itself: **7**.
:::

::: problem id=p5 type=numeric answer="1"
$9^0 = ?$
solution: Any number except 0 to the power 0 is **1**.
:::

::: problem id=p6 type=numeric answer="10000"
$10^4 = ?$
solution: A 1 followed by four zeros: **10000**.
:::

::: problem id=p7 type=numeric answer="3"
$6 \times 6 \times 6$ written as a power is $6^{?}$. What is the exponent?
hint: Count the 6s.
solution: Three 6s are multiplied: $6^3$. The exponent is **3**.
:::

::: problem id=p8 type=numeric answer="1"
$1^{100} = ?$
solution: 1 times 1, as often as you like, is still **1**.
:::
