---
id: int-04
title: Multiplying and dividing integers
---
::: rule
Multiply or divide the absolute values, then choose the sign:
- **same signs:** positive
- **different signs:** negative

With several factors, an **even** number of negatives gives a positive answer, an **odd** number gives a negative one.
:::

::: example
$-6 \times 4 = -24$ (different signs). $-8 \times (-3) = 24$ (same signs).
:::

::: example
$-20 \div (-5) = 4$ and $(-2)^3 = (-2)(-2)(-2) = -8$.
:::

::: problem id=p1 type=numeric answer="-21"
$-7 \times 3 = ?$
solution: Different signs: **−21**.
:::

::: problem id=p2 type=numeric answer="30"
$-5 \times (-6) = ?$
solution: Same signs: **30**.
:::

::: problem id=p3 type=numeric answer="-9"
$36 \div (-4) = ?$
solution: Different signs: **−9**.
:::

::: problem id=p4 type=numeric answer="6"
$-48 \div (-8) = ?$
solution: Same signs: **6**.
:::

::: problem id=p5 type=numeric answer="-8"
$(-2)^3 = ?$
hint: Three negatives multiplied.
solution: $(-2)(-2) = 4$, then $4 \times (-2) = -8$.
:::

::: problem id=p6 type=numeric answer="1"
$(-1)^{10} = ?$
solution: Ten negatives is an even number, so **1**.
:::

::: problem id=p7 type=numeric answer="-24"
$-2 \times (-3) \times (-4) = ?$
solution: Three negatives (odd), so negative: $2 \times 3 \times 4 = 24$, answer **−24**.
:::

- [ ] It is $-9$.

::: problem id=x14 type=numeric answer="-2/3" set=extra

:::

::: problem id=x18 type=numeric answer="-20" set=extra
$-12 \div (-3) \times (-5) = ?$

::: problem id=x19 type=multi answers="6;-6" set=extra
Two integers have product $-36$ and sum 0. Find them. Type both, like 1, -1.
hint: Sum 0 means they are opposites.
solution: Opposites $a$ and $-a$ give $-a^2 = -36$, so $a = 6$. The numbers are **6 and −6**.
:::

::: problem id=x20 type=numeric answer="-1" set=extra creative=true
Find the sum
$(-1)^1 + (-1)^2 + (-1)^3$
$+ \ldots + (-1)^{99}$.
hint: Odd powers give $-1$, even powers give $1$.
solution: The terms go $-1, 1, -1, 1, \ldots$. The first 98 make 49 pairs that each sum to 0. The last term $(-1)^{99} = -1$, so the total is **−1**.
:::
