id: int-03
title: Subtracting integers
---
::: rule
**Subtracting is adding the opposite:**
$a - b = a + (-b)$

So subtracting a negative is the same as adding: $a - (-b) = a + b$.
:::

::: example
$3 - 8 = 3 + (-8) = -5$
:::

::: example
$-4 - (-9) = -4 + 9 = 5$
:::

::: problem id=p1 type=numeric answer="-4"
$5 - 9 = ?$
solution: $5 + (-9) = -4$.
:::

::: problem id=p2 type=numeric answer="-10"
$-6 - 4 = ?$
solution: $-6 + (-4) = -10$.
:::

::: problem id=p3 type=numeric answer="9"
$2 - (-7) = ?$
hint: Subtracting a negative is adding.
solution: $2 + 7 = 9$.
:::

::: problem id=p4 type=numeric answer="0"
$-3 - (-3) = ?$
solution: $-3 + 3 = 0$.
:::

::: problem id=p5 type=numeric answer="-7"
$-12 - (-5) = ?$
solution: $-12 + 5 = -7$.
:::

::: problem id=p6 type=numeric answer="12"
The temperature falls from 5 degrees to $-7$ degrees. By how many degrees did it fall?
hint: Subtract the new temperature from the old one.
solution: $5 - (-7) = 5 + 7 = 12$ degrees.
:::

::: problem id=p7 type=numeric answer="-15"
$0 - 15 = ?$
solution: **−15**.
:::

::: problem id=p8 type=numeric answer="100"
A bird flies 40 m above sea level and a submarine is at $-60$ m. How far apart are they vertically?
solution: $40 - (-60) = 100$ m.
:::
