title: Subtracting integers
---
::: rule
**Subtracting is adding the opposite:**
$a - b = a + (-b)$

So subtracting a negative is the same as adding: $a - (-b) = a + b$.
:::

::: example
$3 - 8 = 3 + (-8) = -5$
:::

::: example
$-4 - (-9) = -4 + 9 = 5$
:::

::: problem id=x19 type=numeric answer="-60" set=extra

hint: Total minus March.
solution: $-15 - 45 = -15 + (-45) = -60$ dollars, a loss of 60.
:::

::: problem id=x20 type=numeric answer="-3" set=extra creative=true
In a magic row, each number is the one before it minus the one before that: after $a, b$ comes $b - a$. The row starts $3, -5$. What is the fourth number?
hint: Third number: $-5 - 3$.
solution: Third: $-5 - 3 = -8$. Fourth: $-8 - (-5) = -8 + 5 = -3$.
:::
