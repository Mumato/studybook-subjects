---
id: mul-03
title: Properties that make it easier
---
::: rule
Three rules let you rearrange a multiplication to make it easier:

- **Commutative:** order doesn't matter. $a \times b = b \times a$
- **Associative:** grouping doesn't matter. $(a \times b) \times c = a \times (b \times c)$
- **Distributive:** you can split a number. $a \times (b + c) = a \times b + a \times c$
:::

::: example
$25 \times 7 \times 4$

Swap and group: $(25 \times 4) \times 7 = 100 \times 7 = 700$.
:::

::: example
$6 \times 47$

Split 47 into $40 + 7$:
$6 \times 40 + 6 \times 7 = 240 + 42 = 282$.
:::

::: problem id=p1 type=numeric answer="1900"
$4 \times 19 \times 25 = ?$
hint: Which two numbers make 100?
solution: $(4 \times 25) \times 19 = 100 \times 19 = 1900$.
:::

::: problem id=p2 type=numeric answer="424"
$8 \times 53 = ?$
hint: Split 53 into $50 + 3$.
solution: $8 \times 50 + 8 \times 3 = 400 + 24 = 424$.
:::

::: problem id=p3 type=numeric answer="3"
What number goes in the box? $7 \times (10 + 3) = 7 \times 10 + 7 \times \square$
solution: The distributive property multiplies 7 by each part: the box is **3**.
:::

::: problem id=p4 type=text answers="commutative;commutative property;the commutative property"
$5 \times 8 = 8 \times 5$ shows which property? Type its name.
hint: Commutative, associative or distributive?
solution: Only the order changed, so it's the **commutative** property.
:::

::: problem id=p5 type=numeric answer="370"
$2 \times 37 \times 5 = ?$
solution: $(2 \times 5) \times 37 = 10 \times 37 = 370$.
:::

::: problem id=p6 type=numeric answer="891"
$9 \times 99 = ?$
hint: $99 = 100 - 1$.
solution: $9 \times 100 - 9 \times 1 = 900 - 9 = 891$.
:::

::: problem id=p7 type=numeric answer="180"
$12 \times 15 = ?$
hint: Split 15 into $10 + 5$.
solution: $12 \times 10 + 12 \times 5 = 120 + 60 = 180$.
:::

::: problem id=p8 type=choice
$(2 \times 3) \times 4 = 2 \times (3 \times 4)$ shows which property?
- [ ] commutative
- [x] associative
- [ ] distributive
solution: Only the grouping (the brackets) changed, so it's the **associative** property.
:::
