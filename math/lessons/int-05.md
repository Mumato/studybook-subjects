---
id: int-05
title: Order of operations with negatives
---
::: rule
The order is the same as always: brackets, exponents, multiply and divide, add and subtract.

Watch the exponent: $(-3)^2 = 9$, but $-3^2 = -(3^2) = -9$. The exponent only applies to what it touches.
:::

::: example
$-3 + 4 \times (-2) = -3 + (-8) = -11$
:::

::: example
$(-3)^2 - 3^2 = 9 - 9 = 0$
:::

::: problem id=p1 type=numeric answer="-14"
$-2 + 3 \times (-4) = ?$
solution: $3 \times (-4) = -12$, then $-2 + (-12) = -14$.
:::

::: problem id=p2 type=numeric answer="25"
$(-5)^2 = ?$
solution: $(-5)(-5) = 25$.
:::

::: problem id=p3 type=numeric answer="-25"
$-5^2 = ?$
hint: The square applies only to the 5.
solution: $-(5^2) = -25$.
:::

::: problem id=p4 type=numeric answer="16"
$10 - 2 \times (-3) = ?$
solution: $2 \times (-3) = -6$, then $10 - (-6) = 16$.
:::

::: problem id=p5 type=numeric answer="-2"
$(-8 + 2) \div 3 = ?$
solution: $-8 + 2 = -6$, then $-6 \div 3 = -2$.
:::

::: problem id=p6 type=numeric answer="-16"
$-4 \times (-2)^2 = ?$
hint: Exponent first.
solution: $(-2)^2 = 4$, then $-4 \times 4 = -16$.
:::

::: problem id=p7 type=numeric answer="14"
$6 - (-2)^3 = ?$
solution: $(-2)^3 = -8$, then $6 - (-8) = 14$.
:::

::: problem id=p8 type=numeric answer="8"
$-12 \div (-3) \times 2 = ?$
solution: Left to right: $-12 \div (-3) = 4$, then $4 \times 2 = 8$.
:::

::: problem id=c1 type=multi answers="3;-5" creative=true
Find two integers whose sum is $-2$ and whose product is $-15$. Type both, like 1, -2.
hint: The product is negative, so one is positive and one is negative.
solution: Pairs that multiply to $-15$: $1, -15$; $-1, 15$; $3, -5$; $-3, 5$. Only $3 + (-5) = -2$. The numbers are **3 and −5**.
:::

::: problem id=x16 type=numeric answer="5" set=extra
At 6 am it is $-4$ degrees. It warms 3 degrees each hour for 5 hours, then drops 6 degrees. What is the temperature now?
solution: $-4 + 3 \times 5 - 6$
$= -4 + 15 - 6 = 5$ degrees.
:::

::: problem id=x17 type=numeric answer="44" set=extra
$-3(-2)^3 - 4(-5) = ?$
hint: Exponent first, then the two products.
solution: $(-2)^3 = -8$. $-3(-8) = 24$ and $-4(-5) = 20$. Total $24 + 20 = 44$.
:::

::: problem id=x18 type=numeric answer="-25" set=extra
$(-1)^4 - 2(-3)^2 + (-2)^3 = ?$
hint: Work out each power separately.
solution: $1 - 2(9) + (-8)$
$= 1 - 18 - 8 = -25$.
:::

::: problem id=x19 type=numeric answer="38" set=extra
A quiz gives $+4$ for each right answer, $-2$ for each wrong answer and 0 for a blank. Mia has 12 right, 5 wrong and 3 blank. What is her score?
hint: Write one expression: $12(4) + 5(-2) + 3(0)$.
solution: $48 + (-10) + 0 = 38$.
:::

::: problem id=x20 type=choice set=extra creative=true
Which operation goes in the box so that $-12 \square (-3) + 5 = 9$?
- [ ] $+$
- [ ] $-$
- [ ] $\times$
- [x] $\div$
hint: Try each one, remembering $\times$ and $\div$ come before $+$.
solution: $+$: $-10$. $-$: $-4$. $\times$: $41$. $\div$: $4 + 5 = 9$. So it is **÷**.
