---
id: int-05
title: Order of operations with negatives
---
::: rule
The order is the same as always: brackets, exponents, multiply and divide, add and subtract.

Watch the exponent: $(-3)^2 = 9$, but $-3^2 = -(3^2) = -9$. The exponent only applies to what it touches.
:::

::: example
$-3 + 4 \times (-2) = -3 + (-8) = -11$
:::

::: example
$(-3)^2 - 3^2 = 9 - 9 = 0$
:::

::: problem id=p1 type=numeric answer="-14"
$-2 + 3 \times (-4) = ?$
solution: $3 \times (-4) = -12$, then $-2 + (-12) = -14$.
:::

::: problem id=p2 type=numeric answer="25"
$(-5)^2 = ?$
solution: $(-5)(-5) = 25$.
:::

::: problem id=p3 type=numeric answer="-25"
$-5^2 = ?$
hint: The square applies only to the 5.
solution: $-(5^2) = -25$.
:::

::: problem id=p4 type=numeric answer="16"
$10 - 2 \times (-3) = ?$
solution: $2 \times (-3) = -6$, then $10 - (-6) = 16$.
:::

::: problem id=p5 type=numeric answer="-2"
$(-8 + 2) \div 3 = ?$
solution: $-8 + 2 = -6$, then $-6 \div 3 = -2$.
:::

::: problem id=p6 type=numeric answer="-16"
$-4 \times (-2)^2 = ?$
hint: Exponent first.
solution: $(-2)^2 = 4$, then $-4 \times 4 = -16$.
:::

::: problem id=p7 type=numeric answer="14"
$6 - (-2)^3 = ?$
solution: $(-2)^3 = -8$, then $6 - (-8) = 14$.
:::

::: problem id=p8 type=numeric answer="8"
$-12 \div (-3) \times 2 = ?$
solution: Left to right: $-12 \div (-3) = 4$, then $4 \times 2 = 8$.
:::

::: problem id=c1 type=multi answers="3;-5" creative=true
Find two integers whose sum is $-2$ and whose product is $-15$. Type both, like 1, -2.
hint: The product is negative, so one is positive and one is negative.
solution: Pairs that multiply to $-15$: $1, -15$; $-1, 15$; $3, -5$; $-3, 5$. Only $3 + (-5) = -2$. The numbers are **3 and −5**.
:::
