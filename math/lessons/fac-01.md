title: Factors, multiples and divisibility
---
3 is a **factor** of 12 because 12 divides by 3 with no remainder. 12 is a **multiple** of 3.

::: rule
Quick tests to see what a number divides by:
- **2:** the last digit is even
- **3:** the sum of the digits divides by 3
- **5:** the last digit is 0 or 5
- **9:** the sum of the digits divides by 9
- **10:** the last digit is 0
:::

::: example
Does 7,452 divide by 3? By 9? By 5?

Digit sum: $7 + 4 + 5 + 2 = 18$. 18 divides by 3 and by 9, so 7,452 does too. It ends in 2, so not by 5.
:::

::: problem id=p1 type=choice
Which number divides by 3?
- [ ] 413
- [x] 522
- [ ] 805
hint: Add up the digits of each.
solution: Digit sums: 8, 9 and 13. Only 9 divides by 3, so **522**.
:::

::: problem id=p2 type=numeric answer="3"
How many of these divide by 5? 15, 22, 40, 75, 91
solution: 15, 40 and 75 end in 0 or 5: **3** of them.
:::

::: problem id=p3 type=text answers="no"
Does 1,236 divide by 9? Type yes or no.
solution: $1 + 2 + 3 + 6 = 12$, and 12 doesn't divide by 9, so **no**.
:::

::: problem id=p4 type=numeric answer="6"
How many factors does 12 have?
hint: Find pairs that multiply to 12: $1 \times 12$, ...
solution: $1 \times 12$, $2 \times 6$, $3 \times 4$. The factors are 1, 2, 3, 4, 6, 12: **6** factors.
:::

::: problem id=p5 type=numeric answer="28"
What is the 4th multiple of 7?
solution: 7, 14, 21, **28**.
:::

::: problem id=p6 type=choice
Which number divides by both 2 and 5?
- [ ] 125
- [ ] 452
- [x] 370
hint: To divide by 2 and by 5, it must end in 0.
solution: Only **370** ends in 0.
:::

::: problem id=p7 type=numeric answer="0"
What is the smallest digit that can go in the box so that $4\square2$ divides by 3?
hint: The digit sum is $4 + \square + 2$.
solution: $4 + 2 = 6$ already divides by 3, so the smallest digit is **0** (402 = $3 \times 134$).
:::

::: problem id=p8 type=numeric answer="2"
How many factors does 17 have?
solution: Only $1 \times 17$ works, so 17 has **2** factors: 1 and 17.
:::
