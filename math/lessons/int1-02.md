---
id: int1-02
title: Area under a curve
---
::: rule
The **definite integral** $\int_a^b f(x)\,dx$ is the area between the graph of f and the x-axis, from $x = a$ to $x = b$. Area **below** the axis counts as negative.

To estimate it, cut it into rectangles of width $\Delta x$ and add up their areas (a **Riemann sum**). More, thinner rectangles get closer to the exact value.
:::

::: example
$\int_0^4 x\,dx$ is a triangle with base 4 and height 4: area $\frac{1}{2} \times 4 \times 4 = 8$.
:::

::: graph

y -1..5
polygon 0,0 4,0 4,4 fill
plot x blue
:::

::: problem id=p1 type=numeric answer="15"
$\int_0^5 3\,dx = ?$
hint: It's a rectangle.
solution: Width 5, height 3: 15.
:::

::: problem id=p2 type=numeric answer="8"
$\int_0^4 x\,dx = ?$
solution: A triangle: $\frac{1}{2} \cdot 4 \cdot 4 = 8$.
:::

::: problem id=p3 type=numeric answer="1"
Estimate $\int_0^2 x^2\,dx$ with 2 rectangles of width 1, using the **left** edge for each height.
hint: The heights are $f(0)$ and $f(1)$.
solution: $1 \cdot 0 + 1 \cdot 1 = 1$.
:::

::: problem id=p4 type=numeric answer="5"
Same, but using the **right** edges.
solution: Heights $f(1) = 1$ and $f(2) = 4$: $1 + 4 = 5$.
:::

::: problem id=p5 type=numeric answer="9"
$\int_0^3 2x\,dx = ?$
hint: Draw it: a triangle.
solution: Base 3, height 6: $\frac{1}{2} \cdot 3 \cdot 6 = 9$.
:::

::: problem id=p6 type=numeric answer="-2"
$\int_{-2}^{0} x\,dx = ?$
solution: A triangle of area 2 **below** the axis: $-2$.
:::

::: problem id=p7 type=choice
Using more, thinner rectangles makes the estimate:
- [x] closer to the exact area
- [ ] further from it
- [ ] no different
solution: That's exactly how the integral is defined: the limit as the rectangles get thinner.
:::

::: problem id=p8 type=numeric answer="2pi"
$\int_{-2}^{2} \sqrt{4 - x^2}\,dx = ?$ (in terms of pi)
hint: The graph is the top half of a circle of radius 2.
solution: Half of $\pi \cdot 2^2$: $2\pi$.
:::
