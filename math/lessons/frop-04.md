---
id: frop-04
title: Adding and subtracting with different denominators
---
::: rule
1. Find a common denominator (the LCM of the denominators is easiest).
2. Rewrite each fraction with that denominator.
3. Add or subtract the numerators, and simplify.
:::

::: example
$\frac{1}{3} + \frac{1}{4}$

Common denominator 12: $\frac{4}{12} + \frac{3}{12} = \frac{7}{12}$.
:::

::: example
$\frac{5}{6} - \frac{1}{4}$

Common denominator 12: $\frac{10}{12} - \frac{3}{12} = \frac{7}{12}$.
:::

::: problem id=p1 type=numeric answer="5/6"
$\frac{1}{2} + \frac{1}{3} = ?$
hint: Use 6 as the denominator.
solution: $\frac{3}{6} + \frac{2}{6} = \frac{5}{6}$.
:::

::: problem id=p2 type=numeric answer="1/4"
$\frac{3}{4} - \frac{1}{2} = ?$
solution: $\frac{3}{4} - \frac{2}{4} = \frac{1}{4}$.
:::

::: problem id=p3 type=numeric answer="1/2"
$\frac{2}{5} + \frac{1}{10} = ?$
solution: $\frac{4}{10} + \frac{1}{10} = \frac{5}{10} = \frac{1}{2}$.
:::

::: problem id=p4 type=numeric answer="29/24"
$\frac{5}{6} + \frac{3}{8} = ?$
hint: The LCM of 6 and 8 is 24.
solution: $\frac{20}{24} + \frac{9}{24} = \frac{29}{24}$ (or $1\frac{5}{24}$).
:::

::: problem id=p5 type=numeric answer="5/24"
$\frac{7}{8} - \frac{2}{3} = ?$
solution: $\frac{21}{24} - \frac{16}{24} = \frac{5}{24}$.
:::

::: problem id=p6 type=numeric answer="5/6"
You spend $\frac{1}{2}$ an hour on math and $\frac{1}{3}$ of an hour on reading. What fraction of an hour is that in total?
solution: $\frac{3}{6} + \frac{2}{6} = \frac{5}{6}$ of an hour (50 minutes).
:::

::: problem id=p7 type=numeric answer="1/2"
$\frac{1}{4} + \frac{1}{6} + \frac{1}{12} = ?$
hint: All three go into 12.
solution: $\frac{3}{12} + \frac{2}{12} + \frac{1}{12} = \frac{6}{12} = \frac{1}{2}$.
:::

::: problem id=p8 type=numeric answer="18"
What is the smallest common denominator for $\frac{1}{6} + \frac{4}{9}$?
solution: The LCM of 6 and 9 is **18**.
:::

::: problem id=c1 type=numeric answer="4" creative=true
Ancient Egyptians wrote fractions as sums of fractions with 1 on top. $\frac{3}{4} = \frac{1}{2} + \frac{1}{n}$. What is n?
hint: What is $\frac{3}{4} - \frac{1}{2}$?
solution: $\frac{3}{4} - \frac{1}{2} = \frac{3}{4} - \frac{2}{4} = \frac{1}{4}$, so $n = 4$.
:::

::: problem id=x9 type=choice set=extra
Ben wrote $\frac{1}{2} + \frac{1}{3} = \frac{2}{5}$. What is the right answer?
- [ ] $\frac{2}{5}$
- [ ] $\frac{2}{6}$
- [x] $\frac{5}{6}$
- [ ] $\frac{1}{6}$
solution: $\frac{3}{6} + \frac{2}{6} = \frac{5}{6}$. Ben added tops and bottoms. (His $\frac{2}{5}$ is even less than $\frac{1}{2}$ alone.)
:::

::: problem id=x10 type=numeric answer="5/12" set=extra
Tom eats $\frac{1}{3}$ of a pizza and Jen eats $\frac{1}{4}$. What fraction of the pizza is left?
solution: Eaten: $\frac{4}{12} + \frac{3}{12} = \frac{7}{12}$. Left: $\frac{12}{12} - \frac{7}{12} = \frac{5}{12}$.
:::

::: problem id=x11 type=numeric answer="7/12" set=extra
$x + \frac{1}{4} = \frac{5}{6}$. What is $x$?
solution: $x = \frac{5}{6} - \frac{1}{4} = \frac{10}{12} - \frac{3}{12} = \frac{7}{12}$.
:::

::: problem id=x12 type=choice set=extra
Is $\frac{1}{3} + \frac{1}{4}$ more or less than $\frac{1}{2}$?
- [x] More
- [ ] Less
- [ ] Exactly equal
solution: $\frac{1}{3} + \frac{1}{4} = \frac{7}{12}$, and $\frac{1}{2} = \frac{6}{12}$. So it is more.
:::

::: problem id=x15 type=numeric answer="1/6" set=extra
A garden is $\frac{1}{2}$ vegetables and $\frac{1}{3}$ flowers. The rest is grass. What fraction is grass?
solution: $\frac{3}{6} + \frac{2}{6} = \frac{5}{6}$ is planted, so $\frac{1}{6}$ is grass.
:::

::: problem id=x16 type=numeric answer="5/12" set=extra
$\frac{1}{2} - \frac{1}{3} + \frac{1}{4} = ?$
hint: Use 12 for all three, then go left to right.
solution: $\frac{6}{12} - \frac{4}{12} + \frac{3}{12} = \frac{5}{12}$.
:::

::: problem id=x17 type=numeric answer="17/20" set=extra
Mark walks $\frac{3}{4}$ km, then $\frac{2}{5}$ km. How many more km must he walk to make 2 km?
hint: Add what he walked, then subtract from 2.
solution: $\frac{15}{20} + \frac{8}{20} = \frac{23}{20}$. Then $\frac{40}{20} - \frac{23}{20} = \frac{17}{20}$ km.
:::

::: problem id=x18 type=numeric answer="3" set=extra
$\frac{a}{4} + \frac{1}{6} = \frac{11}{12}$. What is $a$?
hint: Find $\frac{11}{12} - \frac{1}{6}$ first.
solution: $\frac{11}{12} - \frac{2}{12} = \frac{9}{12} = \frac{3}{4}$, so $a = 3$.
:::

::: problem id=x19 type=numeric answer="16" set=extra
In a survey of 60 people, $\frac{2}{5}$ prefer cats, $\frac{1}{3}$ prefer dogs, and the rest have no pet preference. How many have no preference?
hint: Find the fraction for "rest" first, then take that fraction of 60.
solution: $\frac{6}{15} + \frac{5}{15} = \frac{11}{15}$, rest $\frac{4}{15}$. $\frac{4}{15} \times 60 = 16$.
:::

::: problem id=x20 type=numeric answer="1/16" set=extra creative=true
You eat half a cake, then half of what is left, then half of that, then half again. What fraction of the cake is left?
hint: You ate $\frac{1}{2} + \frac{1}{4} + \frac{1}{8} + \frac{1}{16}$.
solution: Eaten: $\frac{8}{16} + \frac{4}{16} + \frac{2}{16} + \frac{1}{16} = \frac{15}{16}$. Left: $\frac{1}{16}$.
:::
