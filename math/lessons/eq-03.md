---
id: eq-03
title: Two-step equations
---
::: rule
Undo the steps in **reverse order**:
1. first undo adding or subtracting
2. then undo multiplying or dividing

If there are brackets, you can expand them first.
:::

::: example
$3x + 4 = 19$

Subtract 4: $3x = 15$. Divide by 3: $x = 5$. Check: $3(5) + 4 = 19$.
:::

::: example
$\frac{x}{2} - 3 = 5$

Add 3: $\frac{x}{2} = 8$. Multiply by 2: $x = 16$.
:::

::: problem id=p1 type=numeric answer="4"
Solve $2x + 3 = 11$.
solution: $2x = 8$, so $x = 4$.
:::

::: problem id=p2 type=numeric answer="5"
Solve $5x - 7 = 18$.
solution: $5x = 25$, so $x = 5$.
:::

::: problem id=p3 type=numeric answer="18"
Solve $\frac{x}{3} + 4 = 10$.
hint: Subtract 4 first.
solution: $\frac{x}{3} = 6$, so $x = 18$.
:::

::: problem id=p4 type=numeric answer="-4"
Solve $-2x + 5 = 13$.
solution: $-2x = 8$, so $x = -4$.
:::

::: problem id=p5 type=numeric answer="6"
Solve $4(x - 1) = 20$.
hint: Divide both sides by 4 first, or expand.
solution: $x - 1 = 5$, so $x = 6$.
:::

::: problem id=p6 type=numeric answer="8"
A taxi charges 3 dollars plus 2 dollars per km. A ride cost 19 dollars. How many km was it?
hint: Write $3 + 2k = 19$.
solution: $2k = 16$, so $k = 8$ km.
:::

::: problem id=p7 type=numeric answer="9"
Solve $\frac{x + 5}{2} = 7$.
solution: Multiply by 2: $x + 5 = 14$, so $x = 9$.
:::

::: problem id=p8 type=numeric answer="2"
Solve $7 - 3x = 1$.
solution: $-3x = -6$, so $x = 2$.
:::
