id: eq-03
title: Two-step equations
---
::: rule
Undo the steps in **reverse order**:
1. first undo adding or subtracting
2. then undo multiplying or dividing

If there are brackets, you can expand them first.
:::

::: example
$3x + 4 = 19$

Subtract 4: $3x = 15$. Divide by 3: $x = 5$. Check: $3(5) + 4 = 19$.
:::

::: example
$\frac{x}{2} - 3 = 5$

Add 3: $\frac{x}{2} = 8$. Multiply by 2: $x = 16$.
:::

::: problem id=x15 type=choice set=extra
What is a good first step to solve $5x - 8 = 22$?
- [x] Add 8 to both sides.
- [ ] Subtract 8 from both sides.
- [ ] Subtract 5 from both sides.
- [ ] Multiply both sides by 5.
solution: Undo the subtraction first: add 8 to get $5x = 30$, then $x = 6$.
:::

::: problem id=x18 type=numeric answer="7" set=extra
A rectangle is $x + 3$ long and 5 wide. Its perimeter is 30. Find x.
hint: $2(x + 3) + 2(5) = 30$.
solution: $2x + 6 + 10 = 30$, so $2x = 14$ and $x = 7$.
:::

::: problem id=x19 type=numeric answer="15" set=extra
Three integers in a row add up to 48. What is the smallest?
hint: Call them $n$, $n + 1$, $n + 2$.
solution: $3n + 3 = 48$, so $3n = 45$ and $n = 15$. (15, 16, 17.)
:::

::: problem id=x20 type=numeric answer="-20" set=extra creative=true
$F = \frac{9}{5}C + 32$ turns Celsius into Fahrenheit. At what Celsius temperature is it $-4$ degrees Fahrenheit?
hint: Put $F = -4$ and solve for C.
solution: $\frac{9}{5}C + 32 = -4$, so $\frac{9}{5}C = -36$ and $C = -36 \times \frac{5}{9} = -20$.
:::
