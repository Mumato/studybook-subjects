---
id: poly-02
title: Zero and negative exponents
---
::: rule
- any number (except 0) to the power 0 is 1: $a^0 = 1$
- a negative exponent means "one over": $a^{-n} = \frac{1}{a^n}$

These keep the exponent rules working: $\frac{x^3}{x^5} = x^{-2} = \frac{1}{x^2}$.
:::

::: example
$2^{-3} = \frac{1}{2^3} = \frac{1}{8}$
:::

::: example
$\left(\frac{1}{2}\right)^{-2} = 2^2 = 4$ (a negative exponent flips the fraction).
:::

::: problem id=p1 type=numeric answer="1"
$5^0 = ?$
solution: Any non-zero number to the power 0 is **1**.
:::

::: problem id=p2 type=numeric answer="1/8"
$2^{-3} = ?$
solution: $\frac{1}{2^3} = \frac{1}{8}$.
:::

::: problem id=p3 type=numeric answer="0.01"
$10^{-2} = ?$
solution: $\frac{1}{100} = 0.01$.
:::

::: problem id=p4 type=numeric answer="4"
$\left(\frac{1}{2}\right)^{-2} = ?$
hint: Flip the fraction, then square.
solution: $2^2 = 4$.
:::

::: problem id=p5 type=numeric answer="2"
$x^{-3} \cdot x^5 = x^{?}$
solution: $-3 + 5 = 2$.
:::

::: problem id=p6 type=numeric answer="4/3"
$3^{-1} + 3^0 = ?$
solution: $\frac{1}{3} + 1 = \frac{4}{3}$.
:::

::: problem id=p7 type=numeric answer="-3"
$\frac{x^4}{x^7} = x^{?}$
solution: $4 - 7 = -3$.
:::

::: problem id=p8 type=choice
Which equals $\frac{1}{x^2}$?
- [x] $x^{-2}$
- [ ] $-x^2$
- [ ] $x^{\frac{1}{2}}$
solution: A negative exponent means one over: $x^{-2}$.
:::

::: problem id=x11 type=numeric answer="1/8" set=extra
Max says $2^{-3} = -8$. What is $2^{-3}$ really?
solution: A negative exponent means "one over", not a negative number: $\frac{1}{2^3} = \frac{1}{8}$.
:::

::: problem id=x12 type=numeric answer="-6" set=extra

::: problem id=x13 type=choice set=extra
Which equals $x^{-1}$?
- [x] $\frac{1}{x}$
- [ ] $-x$
- [ ] $x - 1$
solution: $x^{-1} = \frac{1}{x^1} = \frac{1}{x}$.
:::

::: problem id=x14 type=numeric answer="25" set=extra
$5^{-2} \cdot 5^4 = ?$
solution: $5^{-2+4} = 5^2 = 25$.
:::

::: problem id=x15 type=numeric answer="8" set=extra
$(2^{-1})^{-3} = ?$
solution: $(-1)(-3) = 3$, so $2^3 = 8$.
:::

::: problem id=x16 type=numeric answer="2" set=extra
$(x^3)^{-2} \cdot x^8 = x^{?}$
hint: Power of a power first.
solution: $x^{-6} \cdot x^8 = x^{2}$.
:::

::: problem id=x17 type=numeric answer="3/4" set=extra
Work out $3x^{-2}$ when $x = 2$.
hint: The exponent belongs only to x, not to the 3.
solution: $3 \times \frac{1}{2^2} = \frac{3}{4}$.
:::

::: problem id=x18 type=numeric answer="-6" set=extra
$(2x^{-3})^2 = 4x^{?}$
hint: Square the 2 and the $x^{-3}$ separately.
solution: $(x^{-3})^2 = x^{-6}$, so $4x^{-6}$.
:::

::: problem id=x19 type=numeric answer="4" set=extra
$\frac{a^{-2} b^3}{a^4 b^{-1}} = a^{-6} b^{?}$. What is the exponent of b?
hint: Subtract the bottom exponent from the top one, even when it's negative.
solution: $3 - (-1) = 4$, so $b^4$. (For a: $-2 - 4 = -6$.)
:::

::: problem id=x20 type=numeric answer="-5" set=extra creative=true
Find x if $2^x = \frac{1}{32}$.
hint: Write 32 as a power of 2.
solution: $\frac{1}{32} = \frac{1}{2^5} = 2^{-5}$, so $x = -5$.
:::
