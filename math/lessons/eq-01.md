id: eq-01
title: Equations with adding and subtracting
---
::: rule
An **equation** says two things are equal, like a balanced scale. To **solve** it, get the variable alone. Whatever you do to one side, do to the other.

- to undo $+ 7$, subtract 7 from both sides
- to undo $- 4$, add 4 to both sides

**Check** by putting your answer back into the equation.
:::

::: example
$x + 7 = 12$

Subtract 7 from both sides: $x = 5$. Check: $5 + 7 = 12$.
:::

::: example
$y - 4 = -2$

Add 4 to both sides: $y = 2$. Check: $2 - 4 = -2$.
:::

Type just the value, like 5.

::: problem id=x9 type=choice set=extra
Which value is a solution of $x - 7 = -2$?
- [x] $5$
- [ ] $-9$
- [ ] $9$
- [ ] $-5$
solution: $x = -2 + 7 = 5$. Check: $5 - 7 = -2$.
:::

::: problem id=x10 type=numeric answer="-4" set=extra
Pat solves $x + 6 = 2$ and gets $x = 8$. What is the correct solution?
solution: Undo $+6$ by subtracting 6: $x = 2 - 6 = -4$. (Check: $8 + 6 \ne 2$.)
:::

::: problem id=x11 type=numeric answer="45" set=extra

solution: $m - 18 = 27$, so $m = 27 + 18 = 45$ dollars.
:::

::: problem id=x15 type=choice set=extra
Which equation has the solution $x = 3$?
- [x] $x + 5 = 8$
- [ ] $x - 3 = 6$

- [ ] $x - 5 = 2$
solution: $3 + 5 = 8$. The others are solved by 9, $-3$ and 7.

::: problem id=x17 type=numeric answer="4" set=extra
Solve $2x - x + 5 = 9$.

::: problem id=x18 type=numeric answer="8" set=extra
A triangle has sides 7, 10 and x. Its perimeter is 25. Find x.
hint: Perimeter is the sum of the sides.
solution: $7 + 10 + x = 25$, so $17 + x = 25$ and $x = 8$.
:::

::: problem id=x19 type=numeric answer="85" set=extra
Leo deposits 45 dollars, then takes out 20 dollars. His balance is now 110 dollars. What was it at the start?
hint: Write $b + 45 - 20 = 110$.
solution: $b + 25 = 110$, so $b = 85$ dollars.
:::

::: problem id=x20 type=numeric answer="12" set=extra creative=true
$a + 5 = b$ and $b + 5 = 22$. What is a?
hint: Find b first.
solution: $b = 22 - 5 = 17$. Then $a + 5 = 17$, so $a = 12$.
:::
