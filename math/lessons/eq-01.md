---
id: eq-01
title: Equations with adding and subtracting
---
::: rule
An **equation** says two things are equal, like a balanced scale. To **solve** it, get the variable alone. Whatever you do to one side, do to the other.

- to undo $+ 7$, subtract 7 from both sides
- to undo $- 4$, add 4 to both sides

**Check** by putting your answer back into the equation.
:::

::: example
$x + 7 = 12$

Subtract 7 from both sides: $x = 5$. Check: $5 + 7 = 12$.
:::

::: example
$y - 4 = -2$

Add 4 to both sides: $y = 2$. Check: $2 - 4 = -2$.
:::

Type just the value, like 5.

::: problem id=p1 type=numeric answer="6"
Solve $x + 5 = 11$.
solution: $x = 11 - 5 = 6$.
:::

::: problem id=p2 type=numeric answer="13"
Solve $x - 3 = 10$.
solution: $x = 10 + 3 = 13$.
:::

::: problem id=p3 type=numeric answer="-5"
Solve $9 + x = 4$.
hint: Subtract 9 from both sides.
solution: $x = 4 - 9 = -5$.
:::

::: problem id=p4 type=numeric answer="5"
Solve $y - 8 = -3$.
solution: $y = -3 + 8 = 5$.
:::

::: problem id=p5 type=numeric answer="4.5"
Solve $x + 2.5 = 7$.
solution: $x = 7 - 2.5 = 4.5$.
:::

::: problem id=p6 type=numeric answer="16"
A number plus 14 is 30. What is the number?
hint: Write it as an equation: $n + 14 = 30$.
solution: $n = 30 - 14 = 16$.
:::

::: problem id=p7 type=numeric answer="5/4"
Solve $x - \frac{1}{2} = \frac{3}{4}$.
solution: $x = \frac{3}{4} + \frac{1}{2} = \frac{3}{4} + \frac{2}{4} = \frac{5}{4}$.
:::

::: problem id=p8 type=numeric answer="4"
Solve $-6 = x - 10$.
hint: The variable can be on the right side too.
solution: Add 10 to both sides: $4 = x$.
:::
