id: dec-05
title: Fractions and decimals
---
::: rule
- **Fraction to decimal:** divide the top by the bottom. $\frac{3}{8} = 3 \div 8 = 0.375$
- **Decimal to fraction:** write the digits over 10, 100 or 1000 (one zero per decimal place), then simplify. $0.65 = \frac{65}{100} = \frac{13}{20}$

Some fractions never end: $\frac{1}{3} = 0.333\ldots$ For these, round.
:::

::: example
$\frac{3}{8}$: $3.000 \div 8 = 0.375$.
:::

::: example
$0.65 = \frac{65}{100}$. Divide top and bottom by 5: $\frac{13}{20}$.
:::

::: problem id=p1 type=numeric answer="0.25"
Write $\frac{1}{4}$ as a decimal.
solution: $1 \div 4 = 0.25$.
:::

::: problem id=p2 type=numeric answer="5"
Write 0.6 as a fraction in simplest form. What is the denominator?
solution: $0.6 = \frac{6}{10} = \frac{3}{5}$. The denominator is **5**.
:::

::: problem id=p3 type=numeric answer="0.35"
Write $\frac{7}{20}$ as a decimal.
hint: Make the denominator 100.
solution: $\frac{7}{20} = \frac{35}{100} = 0.35$.
:::

::: problem id=p4 type=choice
Which fraction equals 0.125?
- [x] $\frac{1}{8}$
- [ ] $\frac{1}{125}$
- [ ] $\frac{12}{5}$
solution: $0.125 = \frac{125}{1000} = \frac{1}{8}$.
:::

::: problem id=p5 type=numeric answer="0.67"
Write $\frac{2}{3}$ as a decimal rounded to the nearest hundredth.
hint: $2 \div 3 = 0.666\ldots$
solution: $0.666\ldots$ rounds to **0.67**.
:::

::: problem id=p6 type=numeric answer="1 3/4"
Write 1.75 as a mixed number.
solution: $0.75 = \frac{75}{100} = \frac{3}{4}$, so $1.75 = 1\frac{3}{4}$.
:::

::: problem id=p7 type=choice
Which fraction equals 0.4?
- [x] $\frac{2}{5}$
- [ ] $\frac{4}{100}$
- [ ] $\frac{1}{4}$
solution: $0.4 = \frac{4}{10} = \frac{2}{5}$.
:::

::: problem id=p8 type=numeric answer="0.8"
Write $\frac{5}{6}$ as a decimal rounded to the nearest tenth.
solution: $5 \div 6 = 0.833\ldots$, which rounds to **0.8**.
:::

::: problem id=c1 type=numeric answer="4" creative=true
$\frac{1}{7} = 0.142857142857\ldots$ (the six digits 142857 repeat forever). What is the 20th digit after the decimal point?
hint: The pattern repeats every 6 digits. Where in the pattern is digit 20?
solution: $20 = 3 \times 6 + 2$. Three full patterns, then the 2nd digit of 142857, which is **4**.
:::
