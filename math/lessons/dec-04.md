---
id: dec-04
title: Dividing decimals
---
::: rule
- **Dividing by a whole number:** divide as usual and put the decimal point in the answer straight above the one in the number.
- **Dividing by a decimal:** move the decimal point in **both** numbers to the right until the divisor is a whole number, then divide.

Dividing by 10, 100, 1000 moves the decimal point 1, 2, 3 places to the **left**.
:::

::: example
$7.2 \div 4 = 1.8$ (because $72 \div 4 = 18$, and the point stays in place).
:::

::: example
$1.5 \div 0.03$

Move both points two places: $150 \div 3 = 50$.
:::

::: problem id=p1 type=numeric answer="4.2"
$8.4 \div 2 = ?$
solution: $84 \div 2 = 42$, so **4.2**.
:::

::: problem id=p2 type=numeric answer="2.25"
$9 \div 4 = ?$
hint: Write 9 as 9.00 and keep dividing.
solution: $9.00 \div 4 = 2.25$.
:::

::: problem id=p3 type=numeric answer="9"
$6.3 \div 0.7 = ?$
hint: Move both points one place: $63 \div 7$.
solution: $63 \div 7 = 9$.
:::

::: problem id=p4 type=numeric answer="8"
$0.48 \div 0.06 = ?$
solution: Move both points two places: $48 \div 6 = 8$.
:::

::: problem id=p5 type=numeric answer="0.456"
$45.6 \div 100 = ?$
solution: Move the point two places left: **0.456**.
:::

::: problem id=p6 type=numeric answer="6.45"
4 friends share 25.80 dollars equally. How much does each get?
solution: $25.80 \div 4 = 6.45$ dollars.
:::

::: problem id=p7 type=numeric answer="5"
$2.5 \div 0.5 = ?$
solution: $25 \div 5 = 5$.
:::

::: problem id=p8 type=numeric answer="0.125"
$1 \div 8 = ?$
hint: Write 1 as 1.000.
solution: $1.000 \div 8 = 0.125$.
:::
