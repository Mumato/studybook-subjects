---
id: expr-02
title: Evaluating expressions
---
::: rule
To **evaluate** an expression, replace each variable with its value (use brackets around negative numbers), then follow the order of operations.
:::

::: example
$3x + 2$ when $x = 4$: $3(4) + 2 = 12 + 2 = 14$.
:::

::: example
$a^2 - b$ when $a = -3$ and $b = 2$: $(-3)^2 - 2 = 9 - 2 = 7$.
:::

::: problem id=p1 type=numeric answer="11"
Evaluate $2x + 5$ when $x = 3$.
solution: $2(3) + 5 = 6 + 5 = 11$.
:::

::: problem id=p2 type=numeric answer="20"
Evaluate $4(y - 1)$ when $y = 6$.
solution: $4(6 - 1) = 4 \times 5 = 20$.
:::

::: problem id=p3 type=numeric answer="5"
Evaluate $x^2 + 1$ when $x = -2$.
hint: $(-2)^2$ is positive.
solution: $(-2)^2 + 1 = 4 + 1 = 5$.
:::

::: problem id=p4 type=numeric answer="11"
Evaluate $ab - 3$ when $a = 2$ and $b = 7$.
solution: $2 \times 7 - 3 = 14 - 3 = 11$.
:::

::: problem id=p5 type=numeric answer="6"
Evaluate $\frac{x + y}{2}$ when $x = 8$ and $y = 4$.
solution: $\frac{8 + 4}{2} = \frac{12}{2} = 6$.
:::

::: problem id=p6 type=numeric answer="77"
Temperature in Fahrenheit is $F = \frac{9}{5}C + 32$. Find F when $C = 25$.
hint: $\frac{9}{5} \times 25 = 45$.
solution: $\frac{9}{5} \times 25 + 32 = 45 + 32 = 77$.
:::

::: problem id=p7 type=numeric answer="-3"
Evaluate $5 - 2n$ when $n = 4$.
solution: $5 - 2(4) = 5 - 8 = -3$.
:::

::: problem id=p8 type=numeric answer="30"
The area of a rectangle is $A = lw$. Find A when $l = 7.5$ and $w = 4$.
solution: $7.5 \times 4 = 30$.
:::

::: problem id=x1 type=numeric answer="17" set=extra
Evaluate $5x - 3$ when $x = 4$.
solution: $5(4) - 3 = 20 - 3 = 17$.
:::

::: problem id=x2 type=numeric answer="21" set=extra
Evaluate $3(a + 2)$ when $a = 5$.
solution: $3(5 + 2) = 3 \times 7 = 21$.
:::

::: problem id=x3 type=numeric answer="5" set=extra
Evaluate $x^2 - 4$ when $x = -3$.
solution: $(-3)^2 - 4 = 9 - 4 = 5$.
:::

::: problem id=x4 type=numeric answer="5" set=extra
Evaluate $2a + 3b$ when $a = 4$ and $b = -1$.
solution: $2(4) + 3(-1) = 8 - 3 = 5$.
:::

::: problem id=x5 type=numeric answer="4" set=extra
Evaluate $\frac{m - n}{3}$ when $m = 10$ and $n = -2$.
solution: $\frac{10 - (-2)}{3} = \frac{12}{3} = 4$.
:::

::: problem id=x6 type=numeric answer="-25" set=extra
Evaluate $-x^2$ when $x = 5$.
solution: Square first, then the minus: $-(5^2) = -25$.
:::

::: problem id=x7 type=numeric answer="13" set=extra
Evaluate $7 - 3k$ when $k = -2$.
solution: $7 - 3(-2) = 7 + 6 = 13$.
:::

::: problem id=x8 type=numeric answer="27" set=extra
The perimeter of a rectangle is $P = 2l + 2w$. Find P when $l = 9$ and $w = 4.5$.
solution: $2(9) + 2(4.5) = 18 + 9 = 27$.
:::

::: problem id=x9 type=numeric answer="35" set=extra
To turn Fahrenheit into Celsius, use $C = \frac{5(F - 32)}{9}$. Find C when $F = 95$.
solution: $95 - 32 = 63$, $5 \times 63 = 315$, $315 \div 9 = 35$.
:::

::: problem id=x10 type=numeric answer="227.5" set=extra
Distance is $d = rt$. Find d when $r = 65$ km per hour and $t = 3.5$ hours.
solution: $65 \times 3.5 = 227.5$ km.
:::

::: problem id=x11 type=numeric answer="-7" set=extra
Tom evaluates $-x^2 + 2$ when $x = 3$ and gets 11. What is the correct value?
solution: $-x^2$ means $-(3^2) = -9$. Then $-9 + 2 = -7$.
:::

::: problem id=x12 type=choice set=extra
Which expression has the value 10 when $x = 2$?
- [x] $3x + 4$
- [ ] $x^2 + 4$
- [ ] $5x - 1$
- [ ] $2(x + 4)$
solution: $3(2) + 4 = 10$. The others give 8, 9 and 12.
:::

::: problem id=x13 type=numeric answer="4" set=extra
Evaluate $x^2 - 2x + 1$ when $x = -1$.
solution: $(-1)^2 - 2(-1) + 1 = 1 + 2 + 1 = 4$.
:::

::: problem id=x14 type=numeric answer="2" set=extra
Evaluate $\frac{3}{4}x + \frac{1}{2}$ when $x = 2$.
solution: $\frac{3}{4} \times 2 = \frac{3}{2}$, and $\frac{3}{2} + \frac{1}{2} = 2$.
:::

::: problem id=x15 type=numeric answer="22" set=extra
A taxi costs $12 + 0.25m$ dollars for m minutes. What does a 40-minute ride cost?
solution: $12 + 0.25 \times 40 = 12 + 10 = 22$ dollars.
:::

::: problem id=x16 type=numeric answer="25" set=extra
Evaluate $a^2 + b^2$ when $a = -3$ and $b = 4$.
solution: $9 + 16 = 25$.
:::

::: problem id=x17 type=numeric answer="-12" set=extra
Let $a = 5$ and $b = 2$. Find $(a - b)^2 - (a^2 - b^2)$.
hint: Work out each bracket on its own first.
solution: $(a - b)^2 = 3^2 = 9$. $a^2 - b^2 = 25 - 4 = 21$. So $9 - 21 = -12$.
:::

::: problem id=x18 type=numeric answer="120" set=extra
Simple interest is $I = Prt$. Find I when $P = 800$, $r = 0.05$ and $t = 3$.
hint: Multiply all three.
solution: $800 \times 0.05 = 40$, then $40 \times 3 = 120$.
:::

::: problem id=x19 type=choice set=extra
For which value of x does $2x^2 - 3x$ equal 9?
- [ ] $x = 1$
- [ ] $x = 2$
- [x] $x = 3$
- [ ] $x = 4$
hint: Evaluate the expression for each choice.
solution: $x = 3$: $2(9) - 9 = 9$. The others give $-1$, $2$ and $20$.
:::

::: problem id=x20 type=numeric answer="4" set=extra creative=true
A ball is thrown up. Its height in metres after t seconds is $h = 20t - 5t^2$. After how many seconds (a whole number above 0) is it back on the ground?
hint: Back on the ground means $h = 0$. Try $t = 1, 2, 3, \ldots$
solution: $t = 1$: 15. $t = 2$: 20. $t = 3$: 15. $t = 4$: $80 - 80 = 0$. So after **4** seconds.
:::
