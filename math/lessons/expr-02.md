---
id: expr-02
title: Evaluating expressions
---
::: rule
To **evaluate** an expression, replace each variable with its value (use brackets around negative numbers), then follow the order of operations.
:::

::: example
$3x + 2$ when $x = 4$: $3(4) + 2 = 12 + 2 = 14$.
:::

::: example
$a^2 - b$ when $a = -3$ and $b = 2$: $(-3)^2 - 2 = 9 - 2 = 7$.
:::

::: problem id=p1 type=numeric answer="11"
Evaluate $2x + 5$ when $x = 3$.
solution: $2(3) + 5 = 6 + 5 = 11$.
:::

::: problem id=p2 type=numeric answer="20"
Evaluate $4(y - 1)$ when $y = 6$.
solution: $4(6 - 1) = 4 \times 5 = 20$.
:::

::: problem id=p3 type=numeric answer="5"
Evaluate $x^2 + 1$ when $x = -2$.
hint: $(-2)^2$ is positive.
solution: $(-2)^2 + 1 = 4 + 1 = 5$.
:::

::: problem id=p4 type=numeric answer="11"
Evaluate $ab - 3$ when $a = 2$ and $b = 7$.
solution: $2 \times 7 - 3 = 14 - 3 = 11$.
:::

::: problem id=p5 type=numeric answer="6"
Evaluate $\frac{x + y}{2}$ when $x = 8$ and $y = 4$.
solution: $\frac{8 + 4}{2} = \frac{12}{2} = 6$.
:::

::: problem id=p6 type=numeric answer="77"
Temperature in Fahrenheit is $F = \frac{9}{5}C + 32$. Find F when $C = 25$.
hint: $\frac{9}{5} \times 25 = 45$.
solution: $\frac{9}{5} \times 25 + 32 = 45 + 32 = 77$.
:::

::: problem id=p7 type=numeric answer="-3"
Evaluate $5 - 2n$ when $n = 4$.
solution: $5 - 2(4) = 5 - 8 = -3$.
:::

::: problem id=p8 type=numeric answer="30"
The area of a rectangle is $A = lw$. Find A when $l = 7.5$ and $w = 4$.
solution: $7.5 \times 4 = 30$.
:::
