---
id: eq-02
title: Equations with multiplying and dividing
---
::: rule
- to undo multiplying by a number, **divide** both sides by it
- to undo dividing by a number, **multiply** both sides by it
- to undo multiplying by a fraction, multiply by its **reciprocal**
:::

::: example
$4x = 28$. Divide both sides by 4: $x = 7$.
:::

::: example
$\frac{x}{3} = 6$. Multiply both sides by 3: $x = 18$.
:::

::: problem id=p1 type=numeric answer="7"
Solve $5x = 35$.
solution: $x = 35 \div 5 = 7$.
:::

::: problem id=p2 type=numeric answer="36"
Solve $\frac{x}{4} = 9$.
solution: $x = 9 \times 4 = 36$.
:::

::: problem id=p3 type=numeric answer="-7"
Solve $-3x = 21$.
hint: Divide by $-3$, sign included.
solution: $x = 21 \div (-3) = -7$.
:::

::: problem id=p4 type=numeric answer="-10"
Solve $\frac{x}{-2} = 5$.
solution: $x = 5 \times (-2) = -10$.
:::

::: problem id=p5 type=numeric answer="12"
Solve $\frac{2}{3}x = 8$.
hint: Multiply both sides by $\frac{3}{2}$.
solution: $x = 8 \times \frac{3}{2} = 12$.
:::

::: problem id=p6 type=numeric answer="4.5"
6 equal bags weigh 27 kg together. How much does one bag weigh in kg?
solution: $6b = 27$, so $b = 27 \div 6 = 4.5$ kg.
:::

::: problem id=p7 type=numeric answer="18"
Solve $0.5x = 9$.
solution: $x = 9 \div 0.5 = 18$.
:::

::: problem id=p8 type=numeric answer="-4"
Solve $-x = 4$.
solution: $-x$ means $-1 \times x$. Divide by $-1$: $x = -4$.
:::
