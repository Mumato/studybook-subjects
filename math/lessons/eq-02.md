id: eq-02
title: Equations with multiplying and dividing
---
::: rule
- to undo multiplying by a number, **divide** both sides by it
- to undo dividing by a number, **multiply** both sides by it
- to undo multiplying by a fraction, multiply by its **reciprocal**
:::

::: example
$4x = 28$. Divide both sides by 4: $x = 7$.
:::

::: example
$\frac{x}{3} = 6$. Multiply both sides by 3: $x = 18$.
:::

::: problem id=p1 type=numeric answer="7"
Solve $5x = 35$.
solution: $x = 35 \div 5 = 7$.
:::

::: problem id=p2 type=numeric answer="36"

solution: $x = 9 \times 4 = 36$.
:::

::: problem id=p3 type=numeric answer="-7"

solution: $x = 21 \div (-3) = -7$.

::: problem id=x10 type=choice set=extra
Lin solves $3x = 12$ by subtracting 3 from both sides and gets $x = 9$. What should she do?
- [x] Divide both sides by 3: $x = 4$.
- [ ] Add 3 to both sides: $x = 15$.
- [ ] Multiply both sides by 3: $x = 36$.
- [ ] Nothing, $x = 9$ is right.
solution: $3x$ means 3 times x, so undo it by dividing: $x = 4$. Check: $3 \times 4 = 12$.
:::
