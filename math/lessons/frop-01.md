---
id: frop-01
title: Multiplying fractions
---
::: rule
To multiply fractions, multiply the tops and multiply the bottoms:
$\frac{a}{b} \times \frac{c}{d} = \frac{a \times c}{b \times d}$

Then simplify. The word **of** means multiply: $\frac{3}{4}$ of 20 is $\frac{3}{4} \times 20$.
:::

::: example
$\frac{2}{3} \times \frac{3}{4} = \frac{6}{12} = \frac{1}{2}$
:::

::: example
$\frac{3}{4}$ of 20: $\frac{3}{4} \times 20 = \frac{60}{4} = 15$. (Or: a quarter of 20 is 5, so three quarters is 15.)
:::

::: problem id=p1 type=numeric answer="3/10"
$\frac{1}{2} \times \frac{3}{5} = ?$
solution: $\frac{1 \times 3}{2 \times 5} = \frac{3}{10}$.
:::

::: problem id=p2 type=numeric answer="3/5"
$\frac{2}{3} \times \frac{9}{10} = ?$
hint: Multiply, then simplify.
solution: $\frac{18}{30} = \frac{3}{5}$.
:::

::: problem id=p3 type=numeric answer="18"
What is $\frac{3}{4}$ of 24?
hint: Find a quarter of 24 first.
solution: A quarter of 24 is 6, so three quarters is 18.
:::

::: problem id=p4 type=numeric answer="10/3"
$5 \times \frac{2}{3} = ?$
solution: $\frac{5 \times 2}{3} = \frac{10}{3}$ (that is $3\frac{1}{3}$).
:::

::: problem id=p5 type=numeric answer="1"
$\frac{4}{7} \times \frac{7}{4} = ?$
solution: $\frac{28}{28} = 1$.
:::

::: problem id=p6 type=numeric answer="12"
$\frac{2}{5}$ of the 30 students in a class walk to school. How many walk?
solution: $\frac{2}{5} \times 30 = \frac{60}{5} = 12$.
:::

::: problem id=p7 type=numeric answer="4/9"
$\left(\frac{2}{3}\right)^2 = ?$
hint: Squaring means multiplying the fraction by itself.
solution: $\frac{2}{3} \times \frac{2}{3} = \frac{4}{9}$.
:::

::: problem id=p8 type=numeric answer="1/6"
$\frac{3}{8} \times \frac{4}{9} = ?$
solution: $\frac{12}{72} = \frac{1}{6}$.
:::
