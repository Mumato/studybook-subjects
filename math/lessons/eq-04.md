---
id: eq-04
title: Variables on both sides
---
::: rule
1. Expand any brackets.
2. Move all the variable terms to one side and the numbers to the other (by adding or subtracting on both sides).
3. Solve the simpler equation.

If the variables cancel out and what's left is false (like $3 = 1$), there is **no solution**.
:::

::: example
$5x + 2 = 3x + 10$

Subtract $3x$: $2x + 2 = 10$. Subtract 2: $2x = 8$. So $x = 4$.
:::

::: example
$2(x + 3) = x - 1$

Expand: $2x + 6 = x - 1$. Subtract x: $x + 6 = -1$. So $x = -7$.
:::

::: problem id=p1 type=numeric answer="4"
Solve $4x + 1 = 2x + 9$.
solution: $2x + 1 = 9$, $2x = 8$, $x = 4$.
:::

::: problem id=p2 type=numeric answer="5"
Solve $7x - 3 = 4x + 12$.
solution: $3x - 3 = 12$, $3x = 15$, $x = 5$.
:::

::: problem id=p3 type=numeric answer="5"
Solve $3x = x + 10$.
solution: $2x = 10$, $x = 5$.
:::

::: problem id=p4 type=numeric answer="2"
Solve $6 - x = x + 2$.
hint: Add x to both sides.
solution: $6 = 2x + 2$, $4 = 2x$, $x = 2$.
:::

::: problem id=p5 type=numeric answer="7"
Solve $3(x - 2) = 2x + 1$.
solution: $3x - 6 = 2x + 1$, so $x - 6 = 1$, $x = 7$.
:::

::: problem id=p6 type=numeric answer="10"
Gym A costs 30 dollars plus 4 dollars per visit. Gym B costs 7 dollars per visit. After how many visits do they cost the same?
hint: Solve $30 + 4v = 7v$.
solution: $30 = 3v$, so $v = 10$ visits.
:::

::: problem id=p7 type=choice
Solve $5x + 3 = 5x + 1$.
- [ ] $x = 0$
- [ ] $x = 2$
- [x] There is no solution
solution: Subtract $5x$: $3 = 1$, which is never true. There is **no solution**.
:::

::: problem id=p8 type=numeric answer="1"
Solve $0.5x + 2 = 3 - 0.5x$.
solution: Add $0.5x$: $x + 2 = 3$, so $x = 1$.
:::

::: problem id=c1 type=numeric answer="10" creative=true
I think of a number. Tripling it and subtracting 4 gives the same as doubling it and adding 6. What is my number?
hint: Write both descriptions as expressions with n.
solution: $3n - 4 = 2n + 6$. Subtract $2n$: $n - 4 = 6$, so $n = 10$. Check: $26 = 26$.
:::

Solve $10 - 2x = 3x - 5$.

Solve $2(x + 4) = x + 3$.

::: problem id=x6 type=numeric answer="5" set=extra
Solve $4(x - 1) = 2(x + 3)$.
solution: $4x - 4 = 2x + 6$, so $2x = 10$ and $x = 5$.

::: problem id=x7 type=numeric answer="5" set=extra
Solve $0.3x + 1 = 0.1x + 2$.
solution: $0.2x + 1 = 2$, so $0.2x = 1$ and $x = 5$.

::: problem id=x8 type=numeric answer="8" set=extra
Solve $\frac{x}{2} + 3 = x - 1$.
solution: Subtract $\frac{x}{2}$: $3 = \frac{x}{2} - 1$. Then $4 = \frac{x}{2}$, so $x = 8$.
:::

::: problem id=x9 type=choice set=extra
Solve $2(x + 3) = 2x + 6$.
- [ ] $x = 0$
- [ ] $x = 3$
- [ ] There is no solution
- [x] Every number is a solution
solution: Expand: $2x + 6 = 2x + 6$. Subtract $2x$: $6 = 6$, which is always true. **Every number** works.
:::

::: problem id=x10 type=choice set=extra
Solve $3x - 7 = 3(x - 2)$.
- [ ] $x = 1$
- [ ] $x = -1$
- [x] There is no solution
- [ ] Every number is a solution
solution: $3x - 7 = 3x - 6$. Subtract $3x$: $-7 = -6$, which is false. **No solution**.
:::

::: problem id=x11 type=numeric answer="-4" set=extra
Max solves $5x + 4 = 2x - 8$. He gets $3x + 4 = -8$, then adds 4 to get $3x = -4$. What is the correct solution?
solution: Undo $+4$ by subtracting 4: $3x = -12$, so $x = -4$.
:::

::: problem id=x12 type=numeric answer="200" set=extra
Phone plan A costs 20 dollars plus 0.05 dollars a minute. Plan B costs 0.15 dollars a minute. For how many minutes do they cost the same?
solution: $20 + 0.05m = 0.15m$, so $20 = 0.1m$ and $m = 200$.
:::

::: problem id=x13 type=numeric answer="10" set=extra
Ana has 50 dollars and saves 5 dollars a week. Ben has 20 dollars and saves 8 dollars a week. After how many weeks do they have the same amount?
solution: $50 + 5w = 20 + 8w$, so $30 = 3w$ and $w = 10$.
:::

::: problem id=x14 type=numeric answer="-9" set=extra
Five more than twice a number equals the number minus 4. What is the number?
solution: $2n + 5 = n - 4$, so $n + 5 = -4$ and $n = -9$.
:::

::: problem id=x15 type=numeric answer="-3" set=extra
Solve $-3(x - 2) = x + 18$.
solution: $-3x + 6 = x + 18$, so $-12 = 4x$ and $x = -3$.
:::

::: problem id=x16 type=numeric answer="2" set=extra
Solve $5(2x - 1) - 3 = 4(x + 1)$.
hint: Expand both sides and simplify before moving terms.
solution: $10x - 8 = 4x + 4$, so $6x = 12$ and $x = 2$.
:::

::: problem id=x17 type=numeric answer="-11" set=extra
Solve $\frac{x + 3}{2} = \frac{x - 1}{3}$.
hint: Multiply both sides by 6 to clear the fractions.
solution: $3(x + 3) = 2(x - 1)$, so $3x + 9 = 2x - 2$ and $x = -11$.
:::

::: problem id=x18 type=numeric answer="300" set=extra
Car rental A charges 40 dollars plus 0.20 dollars per km. Rental B charges 25 dollars plus 0.25 dollars per km. For how many km do they cost the same?
hint: $40 + 0.2k = 25 + 0.25k$.
solution: $15 = 0.05k$, so $k = 300$ km.
:::

::: problem id=x19 type=numeric answer="7" set=extra
A rectangle is $2x + 1$ long and x wide. A square has side $x + 4$. Their perimeters are equal. Find x.
hint: Rectangle: $2(2x + 1) + 2x$. Square: $4(x + 4)$.
solution: $6x + 2 = 4x + 16$, so $2x = 14$ and $x = 7$.
:::

::: problem id=x20 type=numeric answer="2" set=extra creative=true
For which number a does $ax + 3 = 2x + 5$ have **no** solution?
hint: When do the x terms cancel?
solution: If $a = 2$, subtracting $2x$ leaves $3 = 5$, which is false. For any other a there is one solution. So $a = 2$.
:::
