---
id: poly-03
title: Scientific notation
---
::: rule
**Scientific notation** writes a number as $a \times 10^n$ with $1 \le a < 10$.

- big numbers: positive n (count how far the point moves left)
- small numbers: negative n (count how far it moves right)

To multiply, multiply the front numbers and add the exponents.
:::

::: example
$4500 = 4.5 \times 10^3$ and $0.0007 = 7 \times 10^{-4}$.
:::

::: example
$(2 \times 10^3)(3 \times 10^4) = 6 \times 10^7$.
:::

You can type powers of ten like 6*10^7.

::: problem id=p1 type=numeric answer="3"
$4500 = 4.5 \times 10^{?}$
solution: The point moves 3 places left: $10^3$.
:::

::: problem id=p2 type=numeric answer="-4"
$0.0007 = 7 \times 10^{?}$
solution: The point moves 4 places right: $10^{-4}$.
:::

::: problem id=p3 type=numeric answer="32000"
Write $3.2 \times 10^4$ as an ordinary number.
solution: Move the point 4 places right: **32000**.
:::

::: problem id=p4 type=numeric answer="0.006"
Write $6 \times 10^{-3}$ as an ordinary number.
solution: Move the point 3 places left: **0.006**.
:::

::: problem id=p5 type=numeric answer="6*10^7"
$(2 \times 10^3)(3 \times 10^4) = ?$
hint: Multiply 2 by 3, add the exponents.
solution: $6 \times 10^7$.
:::

::: problem id=p6 type=numeric answer="40000"
$\frac{8 \times 10^6}{2 \times 10^2} = ?$
solution: $4 \times 10^4 = 40000$.
:::

::: problem id=p7 type=choice
Which is the largest?
- [x] $3 \times 10^5$
- [ ] $9 \times 10^4$
- [ ] $2.5 \times 10^5$
solution: $3 \times 10^5 = 300000$ beats $250000$ and $90000$.
:::

::: problem id=p8 type=numeric answer="3*10^10"
Light travels $3 \times 10^8$ m every second. How far in 100 seconds?
solution: $3 \times 10^8 \times 10^2 = 3 \times 10^{10}$ m.
:::
