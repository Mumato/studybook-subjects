---
id: poly-03
title: Scientific notation
---
::: rule
**Scientific notation** writes a number as $a \times 10^n$ with $1 \le a < 10$.

- big numbers: positive n (count how far the point moves left)
- small numbers: negative n (count how far it moves right)

To multiply, multiply the front numbers and add the exponents.
:::

::: example
$4500 = 4.5 \times 10^3$ and $0.0007 = 7 \times 10^{-4}$.
:::

::: example
$(2 \times 10^3)(3 \times 10^4) = 6 \times 10^7$.
:::

You can type powers of ten like 6*10^7.

$(2 \times 10^3)(3 \times 10^4) = ?$

$\frac{8 \times 10^6}{2 \times 10^2} = ?$

::: problem id=p8 type=numeric answer="3*10^10"
Light travels $3 \times 10^8$ m every second. How far in 100 seconds?
solution: $3 \times 10^8 \times 10^2 = 3 \times 10^{10}$ m.
:::

::: problem id=x5 type=numeric answer="8*10^8" set=extra
$(4 \times 10^2)(2 \times 10^6) = ?$
solution: $4 \times 2 = 8$ and $2 + 6 = 8$: $8 \times 10^8$.
:::

::: problem id=x6 type=numeric answer="3*10^4" set=extra
$\frac{9 \times 10^7}{3 \times 10^3} = ?$
solution: $9 \div 3 = 3$ and $7 - 3 = 4$: $3 \times 10^4$.
:::

::: problem id=x7 type=numeric answer="2*10^6" set=extra
$(5 \times 10^3)(4 \times 10^2) = ?$
hint: $5 \times 4 = 20$, which is too big for the front number.
solution: $20 \times 10^5 = 2 \times 10^1 \times 10^5 = 2 \times 10^6$.
:::

Which is written in scientific notation?
- [x] $4.7 \times 10^3$

- [ ] $0.47 \times 10^4$
solution: The front number must be at least 1 and less than 10: only 4.7.

::: problem id=x9 type=numeric answer="-3" set=extra
Liz writes $0.0045 = 4.5 \times 10^3$. What should the exponent be?

:::

::: problem id=x10 type=choice set=extra

- [ ] $2 \times 10^{-3}$
- [x] $5 \times 10^{-4}$
- [ ] $1 \times 10^{-2}$

::: problem id=x11 type=numeric answer="4*10^6" set=extra
$\frac{6 \times 10^4}{1.5 \times 10^{-2}} = ?$
solution: $6 \div 1.5 = 4$ and $4 - (-2) = 6$: $4 \times 10^6$.
:::

::: problem id=x12 type=numeric answer="6*10^-7" set=extra
$(3 \times 10^{-4})(2 \times 10^{-3}) = ?$
solution: $3 \times 2 = 6$ and $-4 + (-3) = -7$: $6 \times 10^{-7}$.
:::

::: problem id=x13 type=numeric answer="100000" set=extra
A virus is $1 \times 10^{-7}$ m long. How many viruses in a row make 1 cm ($10^{-2}$ m)?
solution: $\frac{10^{-2}}{10^{-7}} = 10^5 = 100000$.
:::

::: problem id=x14 type=numeric answer="1.8*10^11" set=extra
A computer does $3 \times 10^9$ operations per second. How many in one minute?
solution: $3 \times 10^9 \times 60 = 180 \times 10^9 = 1.8 \times 10^{11}$.
:::

::: problem id=x16 type=numeric answer="4" set=extra
Work out $(6 \times 10^5)(8 \times 10^{-2})$ in scientific notation. What is the exponent of 10?
hint: $6 \times 8 = 48$: fix the front number afterwards.
solution: $48 \times 10^3 = 4.8 \times 10^4$. The exponent is **4**.
:::

::: problem id=x17 type=numeric answer="8*10^9" set=extra
$(2 \times 10^3)^3 = ?$
hint: Cube both parts.
solution: $2^3 \times (10^3)^3 = 8 \times 10^9$.
:::

::: problem id=x18 type=numeric answer="500" set=extra
The Sun is about $1.5 \times 10^8$ km from Earth. Light travels $3 \times 10^5$ km per second. How many seconds does sunlight take to reach us?
hint: time = distance ÷ speed.
solution: $\frac{1.5 \times 10^8}{3 \times 10^5} = 0.5 \times 10^3 = 500$ s.
:::

::: problem id=x19 type=numeric answer="4*10^5" set=extra
$(3.6 \times 10^5) + (4 \times 10^4) = ?$
hint: To add, write both with the same power of 10 first.
solution: $4 \times 10^4 = 0.4 \times 10^5$. So $(3.6 + 0.4) \times 10^5 = 4 \times 10^5$.
:::

::: problem id=x20 type=numeric answer="13" set=extra creative=true
How many digits does $2^{10} \times 5^{13}$ have?
hint: Pair up each 2 with a 5 to make a 10.
solution: $2^{10} \times 5^{10} \times 5^3 = 10^{10} \times 125$. That is 125 followed by 10 zeros: **13** digits.
:::
