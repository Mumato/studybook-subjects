---
id: fr-03
title: Comparing fractions
---
::: rule
- **Same denominator:** the bigger numerator is the bigger fraction.
- **Different denominators:** rewrite both with a common denominator (the LCM of the denominators), then compare the numerators.

Shortcut for two fractions: compare $\frac{a}{b}$ and $\frac{c}{d}$ by cross-multiplying, $a \times d$ against $b \times c$.
:::

::: example
Which is bigger, $\frac{3}{4}$ or $\frac{5}{7}$?

Common denominator 28: $\frac{3}{4} = \frac{21}{28}$ and $\frac{5}{7} = \frac{20}{28}$. 21 is more than 20, so $\frac{3}{4}$ is bigger.
:::

::: problem id=p4 type=numeric answer="12"
What is the smallest common denominator for $\frac{1}{4}$ and $\frac{1}{6}$?
hint: The LCM of 4 and 6.
solution: Multiples of 6: 6, 12. 4 divides 12, so **12**.
:::

::: problem id=p5 type=choice
Which is the smallest?
- [ ] $\frac{1}{3}$
- [x] $\frac{2}{7}$
- [ ] $\frac{3}{10}$
solution: Cross-multiply pairs: $\frac{2}{7}$ vs $\frac{1}{3}$: $6 < 7$. $\frac{2}{7}$ vs $\frac{3}{10}$: $20 < 21$. So $\frac{2}{7}$ is smallest.
:::

::: problem id=p6 type=numeric answer="5/8"
Which is larger, $\frac{7}{12}$ or $\frac{5}{8}$? Type the larger fraction.
hint: Use 24 as the denominator.
solution: $\frac{7}{12} = \frac{14}{24}$ and $\frac{5}{8} = \frac{15}{24}$, so $\frac{5}{8}$ is larger.
:::

::: problem id=p7 type=choice
How do $\frac{3}{5}$ and $\frac{6}{10}$ compare?
- [ ] $\frac{3}{5}$ is bigger
- [ ] $\frac{6}{10}$ is bigger
- [x] they are equal
solution: $\frac{3}{5} = \frac{3 \times 2}{5 \times 2} = \frac{6}{10}$: **equal**.
:::

::: problem id=p8 type=numeric answer="1/4"
How much bigger is $\frac{3}{4}$ than $\frac{1}{2}$?
hint: Write $\frac{1}{2}$ in quarters: $\frac{1}{2} = \frac{2}{4}$. How many more quarters is 3 quarters than 2 quarters?
solution: $\frac{1}{2} = \frac{2}{4}$. 3 quarters is 1 quarter more than 2 quarters, so $\frac{3}{4}$ is $\frac{1}{4}$ bigger.
:::

::: problem id=x9 type=choice set=extra
Which fraction is more than $\frac{1}{2}$?
- [ ] $\frac{5}{11}$
- [ ] $\frac{6}{12}$
- [x] $\frac{8}{15}$
- [ ] $\frac{3}{7}$
solution: A fraction is more than $\frac{1}{2}$ when the top is more than half the bottom. Half of 15 is 7.5, and 8 is more.
:::

::: problem id=x10 type=choice set=extra
Lee ate $\frac{2}{5}$ of a pizza and Kim ate $\frac{3}{8}$ of the same size pizza. Who ate more?
- [x] Lee
- [ ] Kim
- [ ] They ate the same
solution: Cross-multiply: $2 \times 8 = 16$ and $5 \times 3 = 15$. So $\frac{2}{5} > \frac{3}{8}$: Lee.
:::

::: problem id=x11 type=choice set=extra

- [ ] $\frac{1}{2}, \frac{3}{4}, \frac{2}{5}$
solution: Denominator 20: $\frac{10}{20}$, $\frac{8}{20}$, $\frac{15}{20}$. Order: $\frac{2}{5}, \frac{1}{2}, \frac{3}{4}$.
:::

::: problem id=x12 type=choice set=extra
Raj says $\frac{1}{8} > \frac{1}{6}$ because 8 is bigger than 6. What is wrong?
- [x] More parts means smaller parts, so $\frac{1}{8} < \frac{1}{6}$
- [ ] Nothing, he is right
- [ ] They are equal, both have numerator 1
solution: Cutting a whole into 8 parts makes each part smaller than cutting it into 6. So $\frac{1}{8} < \frac{1}{6}$.
:::

::: problem id=x13 type=choice set=extra
One bar has 4 of its 6 parts shaded. An equal bar has 5 of its 9 parts shaded. Which shaded amount is bigger?
- [x] $\frac{4}{6}$
- [ ] $\frac{5}{9}$
- [ ] They are equal
solution: $\frac{4}{6} = \frac{2}{3} = \frac{6}{9}$, which is more than $\frac{5}{9}$.
:::

::: problem id=x14 type=numeric answer="3/10" set=extra
Which is smaller, $\frac{3}{10}$ or $\frac{1}{3}$? Type the smaller fraction.

::: problem id=x15 type=numeric answer="5" set=extra
What is the largest whole number $n$ that makes $\frac{n}{12} < \frac{1}{2}$ true?
solution: $\frac{1}{2} = \frac{6}{12}$, so $n < 6$. The largest is **5**.
:::
