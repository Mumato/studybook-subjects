---
id: poly-04
title: Adding and multiplying polynomials
---
::: rule
A **polynomial** is a sum of terms like $3x^2 - 5x + 7$. Its **degree** is the highest power.

- **add or subtract:** combine like terms (careful: a minus in front of brackets changes every sign)
- **multiply:** multiply **every** term in the first by **every** term in the second, then combine
:::

::: example
$(3x^2 + 2x) + (x^2 - 5x) = 4x^2 - 3x$
:::

::: example
$(x + 3)(x + 5)$ $= x^2 + 5x + 3x + 15$ $= x^2 + 8x + 15$
:::

::: problem id=p1 type=numeric answer="-3"
Simplify $(3x^2 + 2x) + (x^2 - 5x)$. What is the coefficient of x?
solution: $2x - 5x = -3x$.
:::

::: problem id=p2 type=numeric answer="4"
In the same sum, what is the coefficient of $x^2$?
solution: $3x^2 + x^2 = 4x^2$.
:::

::: problem id=p3 type=numeric answer="-7"
Simplify $(5x - 3) - (2x + 4)$. What is the number without x?
hint: The minus changes $+4$ to $-4$.
solution: $5x - 3 - 2x - 4 = 3x - 7$.
:::

::: problem id=p4 type=numeric answer="8"
$(x + 3)(x + 5) = x^2 + \square x + 15$. What goes in the box?
solution: $5x + 3x = 8x$.
:::

::: problem id=p5 type=numeric answer="7"
Expand $(2x - 1)(x + 4)$. What is the coefficient of x?
solution: $2x^2 + 8x - x - 4 = 2x^2 + 7x - 4$.
:::

::: problem id=p6 type=numeric answer="-3"
Expand $x(x^2 - 3x + 2)$. What is the coefficient of $x^2$?
solution: $x^3 - 3x^2 + 2x$.
:::

::: problem id=p7 type=choice
$(x + 2)(x - 2) = ?$
- [x] $x^2 - 4$
- [ ] $x^2 + 4$
- [ ] $x^2 - 4x - 4$
solution: $x^2 - 2x + 2x - 4 = x^2 - 4$.
:::

::: problem id=p8 type=numeric answer="3"
What is the degree of $4x^3 - x + 7$?
solution: The highest power is $x^3$: degree **3**.
:::

::: problem id=x1 type=numeric answer="-2" set=extra
Simplify $(2x^2 + 3x - 1) + (x^2 - 5x + 4)$. What is the coefficient of x?
solution: $3x - 5x = -2x$. The sum is $3x^2 - 2x + 3$.
:::

::: problem id=x2 type=numeric answer="3" set=extra
In the same sum, $(2x^2 + 3x - 1) + (x^2 - 5x + 4)$, what is the number without x?
solution: $-1 + 4 = 3$.
:::

::: problem id=x3 type=numeric answer="-4" set=extra
Simplify $(4x^2 - x) - (x^2 + 3x)$. What is the coefficient of x?
hint: The minus changes $+3x$ to $-3x$.
solution: $4x^2 - x - x^2 - 3x = 3x^2 - 4x$.
:::

::: problem id=x4 type=numeric answer="9" set=extra
$(x + 2)(x + 7) = x^2 + \square x + 14$. What goes in the box?
solution: $7x + 2x = 9x$.
:::

::: problem id=x5 type=numeric answer="-18" set=extra
Expand $(x - 3)(x + 6)$. What is the number without x?
solution: $(-3)(6) = -18$. The product is $x^2 + 3x - 18$.
:::

::: problem id=x6 type=numeric answer="-13" set=extra
Expand $(3x + 2)(x - 5)$. What is the coefficient of x?
solution: $3x^2 - 15x + 2x - 10 = 3x^2 - 13x - 10$.
:::

::: problem id=x7 type=numeric answer="6" set=extra
Expand $2x(3x - 4)$. What is the coefficient of $x^2$?
solution: $2x \cdot 3x = 6x^2$. The product is $6x^2 - 8x$.
:::

::: problem id=x8 type=numeric answer="4" set=extra
What is the degree of $5x^4 - 2x^2 + x - 9$?
solution: The highest power is $x^4$: degree **4**.
:::

::: problem id=x9 type=choice set=extra
$(x + 4)(x - 1) = ?$
- [x] $x^2 + 3x - 4$
- [ ] $x^2 - 3x - 4$
- [ ] $x^2 + 3x + 4$
solution: $x^2 - x + 4x - 4 = x^2 + 3x - 4$.
:::

::: problem id=x10 type=numeric answer="3" set=extra
Pat writes $(6x - 2) - (4x - 5) = 2x - 7$. What should the number without x be?
solution: The minus changes $-5$ to $+5$: $-2 + 5 = 3$. The answer is $2x + 3$.
:::

::: problem id=x11 type=numeric answer="5" set=extra
A rectangle is $x + 3$ long and $x + 2$ wide. Its area is $x^2 + \square x + 6$. What goes in the box?
solution: $(x + 3)(x + 2)$ $= x^2 + 2x + 3x + 6$ $= x^2 + 5x + 6$.
:::

::: problem id=x12 type=numeric answer="-4" set=extra
A rectangle has sides $2x + 1$ and $x - 3$. Its perimeter is $6x + \square$. What goes in the box?
solution: $2(2x + 1) + 2(x - 3)$ $= 4x + 2 + 2x - 6 = 6x - 4$.
:::

::: problem id=x13 type=numeric answer="3" set=extra
Expand $(x + 1)(x^2 + 2x + 3)$. What is the coefficient of $x^2$?
solution: $x^3 + 2x^2 + 3x + x^2 + 2x + 3$. So $x^2$ terms: $2 + 1 = 3$.
:::

::: problem id=x14 type=numeric answer="5" set=extra
In the same product, $(x + 1)(x^2 + 2x + 3)$, what is the coefficient of x?
solution: $3x + 2x = 5x$. The product is $x^3 + 3x^2 + 5x + 3$.
:::

::: problem id=x15 type=numeric answer="5" set=extra
What is the degree of $(x^2 + 1)(x^3 - x)$?
solution: The highest term is $x^2 \cdot x^3 = x^5$: degree **5**.
:::

::: problem id=x16 type=numeric answer="-9" set=extra
Expand $(2x - 1)(3x^2 + x - 4)$. What is the coefficient of x?
hint: Multiply each of the 2 terms by each of the 3 terms: 6 products.
solution: $6x^3 + 2x^2 - 8x - 3x^2 - x + 4$. The x terms: $-8x - x = -9x$.
:::

::: problem id=x17 type=numeric answer="-5" set=extra
Simplify $(x + 2)(x - 3) - (x - 1)(x + 1)$. What is the number without x?
hint: Expand each product, then subtract the whole second one.
solution: $(x^2 - x - 6) - (x^2 - 1) = -x - 5$.
:::

::: problem id=x18 type=numeric answer="4" set=extra
Find a if $(x + a)(x + 3) = x^2 + 7x + 12$.
hint: Look at the x term or the number term.
solution: The number term is $3a = 12$, so $a = 4$. Check: $4x + 3x = 7x$.
:::

::: problem id=x19 type=numeric answer="8" set=extra
A square garden has side x m. A path 2 m wide goes all round it, so the outer square has side $x + 4$. The path's area is $\square x + 16$. What goes in the box?
hint: Path = outer area minus garden area.
solution: $(x + 4)(x + 4) = x^2 + 8x + 16$. Subtract $x^2$: $8x + 16$.
:::

::: problem id=x20 type=numeric answer="3" set=extra creative=true
Expand $(x^2 + x + 1)(x^2 - x + 1)$ and combine like terms. How many terms are left?
hint: Write out all 9 products and watch which cancel.
solution: $x^4 - x^3 + x^2 + x^3 - x^2$ $+ x + x^2 - x + 1$ $= x^4 + x^2 + 1$: **3** terms.
:::
