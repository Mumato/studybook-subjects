---
id: ratx-04
title: Rational equations
---
::: rule
1. Multiply **every** term by the LCD to clear the fractions.
2. Solve the equation that's left.
3. **Check** each answer: throw away any that make a denominator 0 (an **extraneous** solution).

Work problems: if a job takes a hours, you do $\frac{1}{a}$ of it per hour. Rates add up.
:::

::: example
$\frac{x}{4} + \frac{x}{6} = 5$. Multiply by 12: $3x + 2x = 60$, so $x = 12$.
:::

::: example
A paints a fence in 3 hours, B in 6. Together, per hour: $\frac{1}{3} + \frac{1}{6} = \frac{1}{2}$ of the fence, so **2 hours**.
:::

::: problem id=p1 type=numeric answer="1/2"
Solve $\frac{3}{x} = 6$.
solution: $3 = 6x$, $x = \frac{1}{2}$.
:::

::: problem id=p2 type=numeric answer="12"
Solve $\frac{x}{4} + \frac{x}{6} = 5$.
solution: $3x + 2x = 60$, $x = 12$.
:::

::: problem id=p3 type=numeric answer="3/2"
Solve $\frac{2}{x - 1} = 4$.
solution: $2 = 4(x - 1)$, $x - 1 = \frac{1}{2}$, $x = \frac{3}{2}$.
:::

::: problem id=p4 type=numeric answer="1/2"
Solve $\frac{1}{x} + \frac{1}{2x} = 3$.
solution: Multiply by $2x$: $2 + 1 = 6x$, $x = \frac{1}{2}$.
:::

::: problem id=p5 type=choice
Solve $\frac{x}{x - 2} = \frac{2}{x - 2}$.
- [ ] $x = 2$
- [ ] $x = 0$
- [x] no solution
hint: What happens to the denominator at your answer?
solution: Multiplying out gives $x = 2$, but that makes the denominator 0. It's extraneous, so **no solution**.
:::

::: problem id=p6 type=multi answers="2;3"
Solve $x + \frac{6}{x} = 5$.
solution: Multiply by x: $x^2 - 5x + 6 = 0$, $(x - 2)(x - 3) = 0$: 2 and 3.
:::

::: problem id=p7 type=numeric answer="2"
A paints a fence in 3 hours and B in 6 hours. How many hours together?
solution: $\frac{1}{3} + \frac{1}{6} = \frac{1}{2}$ per hour, so 2 hours.
:::

::: problem id=p8 type=numeric answer="2"
Solve $\frac{4}{x + 2} = 1$.
solution: $4 = x + 2$, $x = 2$.
:::

::: problem id=c1 type=numeric answer="12" creative=true
Pipe A fills a tank in 4 hours. Pipe B empties it in 6 hours. With both open, how many hours to fill the empty tank?
hint: B's rate counts as negative.
solution: $\frac{1}{4} - \frac{1}{6} = \frac{1}{12}$ of the tank per hour: **12** hours.
:::

::: problem id=x1 type=numeric answer="4" set=extra
Solve $\frac{8}{x} = 2$.
solution: $8 = 2x$, $x = 4$.
:::

::: problem id=x2 type=numeric answer="8" set=extra
Solve $\frac{x}{3} + \frac{x}{6} = 4$.
solution: Multiply by 6: $2x + x = 24$, $x = 8$.
:::

::: problem id=x3 type=numeric answer="1" set=extra
Solve $\frac{6}{x + 1} = 3$.
solution: $6 = 3(x + 1)$, $x + 1 = 2$, $x = 1$.
:::

::: problem id=x4 type=numeric answer="2" set=extra
Solve $\frac{3}{x} + \frac{1}{x} = 2$.
solution: $\frac{4}{x} = 2$, so $x = 2$.
:::

::: problem id=x5 type=numeric answer="7" set=extra
Solve $\frac{x - 2}{5} = \frac{x + 1}{8}$.
solution: Multiply by 40: $8x - 16 = 5x + 5$, $3x = 21$, $x = 7$.
:::

::: problem id=x6 type=numeric answer="6" set=extra
Solve $\frac{5}{2x} - \frac{1}{x} = \frac{1}{4}$.
solution: Multiply by $4x$: $10 - 4 = x$, so $x = 6$.
:::

::: problem id=x7 type=choice set=extra
Solve $\frac{x}{x - 3} = \frac{3}{x - 3} + 2$.
- [ ] $x = 3$
- [ ] $x = 0$
- [x] no solution
solution: Multiply by $x - 3$: $x = 3 + 2x - 6$, so $x = 3$. That makes the denominator 0: **no solution**.
:::

::: problem id=x8 type=multi answers="4;-1" set=extra
Solve $x - \frac{4}{x} = 3$.
solution: Multiply by x: $x^2 - 3x - 4 = 0$, $(x - 4)(x + 1) = 0$: 4 and $-1$.
:::

::: problem id=x9 type=numeric answer="3" set=extra
A does a job in 4 hours, B in 12 hours. How many hours together?
solution: $\frac{1}{4} + \frac{1}{12} = \frac{4}{12} = \frac{1}{3}$ per hour: **3** hours.
:::

::: problem id=x10 type=numeric answer="6" set=extra
Together A and B do a job in 2 hours. A alone takes 3 hours. How many hours does B take alone?
solution: $\frac{1}{B} = \frac{1}{2} - \frac{1}{3} = \frac{1}{6}$: **6** hours.
:::

::: problem id=x11 type=choice set=extra
Solving an equation with denominators $x - 2$ and $x + 3$ gives $x = 2$ and $x = -1$. Which is extraneous?
- [x] $x = 2$
- [ ] $x = -1$
- [ ] both
- [ ] neither
solution: $x = 2$ makes $x - 2 = 0$, so it must be thrown away.
:::

::: problem id=x12 type=numeric answer="5" set=extra
Solve $\frac{4}{x - 1} = \frac{3}{x - 2}$.
solution: Cross-multiply: $4(x - 2) = 3(x - 1)$, $4x - 8 = 3x - 3$, $x = 5$.
:::

::: problem id=x13 type=numeric answer="6" set=extra
Solve $\frac{2}{x} + \frac{x}{x + 3} = 1$.
solution: Multiply by $x(x + 3)$: $2(x + 3) + x^2 = x^2 + 3x$. So $2x + 6 = 3x$, $x = 6$.
:::

::: problem id=x14 type=multi answers="3;-5" set=extra
Solve $x + 2 = \frac{15}{x}$.
solution: $x^2 + 2x - 15 = 0$, $(x + 5)(x - 3) = 0$: 3 and $-5$.
:::

::: problem id=x15 type=numeric answer="-1" set=extra
Solve $\frac{1}{x - 3} = \frac{2}{x^2 - 9}$.
hint: The LCD is $x^2 - 9 = (x - 3)(x + 3)$.
solution: Multiply by $x^2 - 9$: $x + 3 = 2$, $x = -1$. It makes no denominator 0, so it stays.
:::

::: problem id=x16 type=numeric answer="2" set=extra
A boat goes 10 km/h in still water. It goes 24 km downstream in the same time as 16 km upstream. How fast is the current, in km/h?
hint: Downstream speed $10 + c$, upstream $10 - c$. Time = distance ÷ speed.
solution: $\frac{24}{10 + c} = \frac{16}{10 - c}$. $240 - 24c = 160 + 16c$, $40c = 80$, $c = 2$.
:::

::: problem id=x17 type=numeric answer="2" set=extra
A number plus twice its reciprocal is 3. There are two such numbers. What is the larger one?
solution: $x + \frac{2}{x} = 3$, $x^2 - 3x + 2 = 0$, $(x - 1)(x - 2) = 0$. Larger: **2**.
:::

::: problem id=x18 type=numeric answer="12" set=extra
Pipe A fills a tank in 6 hours. With pipe B also open, it takes 4 hours. How long would B take alone, in hours?
hint: Subtract rates.
solution: $\frac{1}{4} - \frac{1}{6} = \frac{1}{12}$ per hour: **12** hours.
:::

::: problem id=x19 type=choice set=extra
Solve $\frac{x + 3}{x - 1} = 1 + \frac{8}{x^2 - 1}$.
- [ ] $x = 1$
- [ ] $x = -1$
- [x] no solution
hint: Multiply every term by $x^2 - 1$, then check.
solution: $(x + 3)(x + 1) = x^2 - 1 + 8$, so $x^2 + 4x + 3 = x^2 + 7$ and $x = 1$. But $x = 1$ makes a denominator 0: **no solution**.
:::

::: problem id=x20 type=numeric answer="40" set=extra creative=true
A 120 km trip would take 1 hour less at 20 km/h faster. What is the usual speed, in km/h?
hint: $\frac{120}{x} - \frac{120}{x + 20} = 1$.
solution: Multiply by $x(x + 20)$: $2400 = x^2 + 20x$. $(x + 60)(x - 40) = 0$, so $x = 40$.
:::
