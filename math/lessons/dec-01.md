id: dec-01
title: Decimal place value and rounding
---
::: rule
After the decimal point come **tenths**, **hundredths**, **thousandths**:
$3.47 = 3 + \frac{4}{10} + \frac{7}{100}$

Round decimals exactly like whole numbers: look at the next digit to the right (5 or more rounds up), then drop the digits after.

To **compare**, line up the decimal points and add zeros so they have the same length: 0.5 = 0.50.
:::

::: example
Round 6.374 to the nearest tenth. The tenths digit is 3; the next digit is 7, so round up: **6.4**.
:::

::: example
Which is bigger, 0.5 or 0.45? Write 0.5 as 0.50. 50 hundredths is more than 45 hundredths, so **0.5** is bigger.
:::

::: problem id=p1 type=numeric answer="0.06"
What is the digit 6 worth in 2.068? Type it as a decimal.
hint: Tenths, hundredths, thousandths.
solution: The 6 is in the hundredths place: **0.06**.
:::

::: problem id=p2 type=numeric answer="4.4"
Round 4.36 to the nearest tenth.
solution: The hundredths digit is 6, so round up: **4.4**.
:::

::: problem id=p3 type=numeric answer="12.85"
Round 12.849 to the nearest hundredth.
hint: Look at the thousandths digit.
solution: The thousandths digit is 9, so round the 4 up: **12.85**.
:::

::: problem id=p4 type=choice
Which is bigger?
- [x] 0.7
- [ ] 0.68
solution: 0.7 = 0.70, and 70 hundredths is more than 68.
:::

::: problem id=p6 type=numeric answer="3.405"
Write $3 + \frac{4}{10} + \frac{5}{1000}$ as a decimal.
hint: There are no hundredths, so that place is 0.
solution: 3 ones, 4 tenths, 0 hundredths, 5 thousandths: **3.405**.
:::

::: problem id=p7 type=choice
Which is the smallest?
- [ ] 0.305
- [ ] 0.35
- [x] 0.3
hint: Write them all with three decimal places.
solution: 0.305, 0.350 and 0.300. The smallest is **0.3**.
:::

::: problem id=p8 type=numeric answer="0.1"
Round 0.0961 to the nearest hundredth.
solution: The hundredths digit is 9 and the next digit is 6, so round up: 0.10, which is **0.1**.
