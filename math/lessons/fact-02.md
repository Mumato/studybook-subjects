---
id: fact-02
title: Factoring x² + bx + c
---
::: rule
To factor $x^2 + bx + c$, find two numbers that **multiply to c** and **add to b**. Then
$x^2 + bx + c = (x + p)(x + q)$.

Signs: if c is positive, both numbers have the sign of b. If c is negative, one is positive and one negative.
:::

::: example
$x^2 + 5x + 6$: numbers that multiply to 6 and add to 5 are 2 and 3. So $(x + 2)(x + 3)$.
:::

::: example
$x^2 + 2x - 15$: multiply to $-15$, add to 2: 5 and $-3$. So $(x + 5)(x - 3)$.
:::

::: problem id=p1 type=expression answer="(x+2)(x+3)" form=factored
Factor $x^2 + 5x + 6$.
solution: 2 and 3 multiply to 6 and add to 5: $(x + 2)(x + 3)$.
:::

::: problem id=p2 type=expression answer="(x+3)(x+4)" form=factored
Factor $x^2 + 7x + 12$.
solution: 3 and 4: $(x + 3)(x + 4)$.
:::

::: problem id=p3 type=expression answer="(x-2)(x-3)" form=factored
Factor $x^2 - 5x + 6$.
hint: c is positive and b negative, so both numbers are negative.
solution: $-2$ and $-3$: $(x - 2)(x - 3)$.
:::

::: problem id=p4 type=expression answer="(x+5)(x-3)" form=factored
Factor $x^2 + 2x - 15$.
solution: 5 and $-3$: $(x + 5)(x - 3)$.
:::

::: problem id=p5 type=expression answer="(x-4)(x+3)" form=factored
Factor $x^2 - x - 12$.
solution: $-4$ and 3 multiply to $-12$ and add to $-1$: $(x - 4)(x + 3)$.
:::

::: problem id=p6 type=multi answers="4;5"
Find two numbers that multiply to 20 and add to 9. Type both, like 1, 2.
solution: **4 and 5**.
:::

::: problem id=p7 type=expression answer="(x-4)^2" form=factored
Factor $x^2 - 8x + 16$.
hint: The two numbers are the same.
solution: $-4$ and $-4$: $(x - 4)^2$.
:::

::: problem id=p8 type=choice
Which is $x^2 + 4x - 21$ factored?
- [x] $(x + 7)(x - 3)$
- [ ] $(x - 7)(x + 3)$
- [ ] $(x + 7)(x + 3)$
solution: 7 and $-3$ multiply to $-21$ and add to 4.
:::
