---
id: fact-02
title: Factoring x² + bx + c
---
::: rule
To factor $x^2 + bx + c$, find two numbers that **multiply to c** and **add to b**. Then
$x^2 + bx + c = (x + p)(x + q)$.

Signs: if c is positive, both numbers have the sign of b. If c is negative, one is positive and one negative.
:::

::: example
$x^2 + 5x + 6$: numbers that multiply to 6 and add to 5 are 2 and 3. So $(x + 2)(x + 3)$.
:::

::: example
$x^2 + 2x - 15$: multiply to $-15$, add to 2: 5 and $-3$. So $(x + 5)(x - 3)$.
:::

::: problem id=p1 type=expression answer="(x+2)(x+3)" form=factored

solution: 2 and 3 multiply to 6 and add to 5: $(x + 2)(x + 3)$.
:::

solution: $-2$ and $-3$: $(x - 2)(x - 3)$.
:::

::: problem id=p4 type=expression answer="(x+5)(x-3)" form=factored

:::

::: problem id=p5 type=expression answer="(x-4)(x+3)" form=factored

solution: $-4$ and 3 multiply to $-12$ and add to $-1$: $(x - 4)(x + 3)$.
:::

:::

::: problem id=x10 type=expression answer="(x-4)(x+3)" form=factored set=extra

solution: $(x + 4)(x - 3) = x^2 + x - 12$: wrong sign in the middle. Use $-4$ and 3: $(x - 4)(x + 3)$.

::: problem id=x14 type=expression answer="x+5" set=extra
A rectangle has area $x^2 + 7x + 10$ and width $x + 2$. What is its length?
solution: $x^2 + 7x + 10 = (x + 2)(x + 5)$, so the length is $x + 5$.
:::

::: problem id=x15 type=text answers="no" set=extra
Can $x^2 + 2x + 5$ be factored using integers? Type yes or no.
solution: The only integer pairs that multiply to 5 are 1, 5 and $-1$, $-5$. Neither adds to 2: **no**.
:::

::: problem id=x16 type=expression answer="2(x+2)(x+3)" form=factored set=extra

hint: Take out the common factor first.
solution: $2(x^2 + 5x + 6) = 2(x + 2)(x + 3)$.
:::

::: problem id=x17 type=expression answer="(x+2y)(x+3y)" vars="x,y" form=factored set=extra

solution: $2y$ and $3y$ multiply to $6y^2$ and add to $5y$: $(x + 2y)(x + 3y)$.
:::

::: problem id=x18 type=expression answer="3(x-4)(x+3)" form=factored set=extra

::: problem id=x19 type=expression answer="(x^2+1)(x^2+4)" form=factored set=extra
Factor $x^4 + 5x^2 + 4$.
hint: Treat $x^2$ as one thing: $u^2 + 5u + 4$.
solution: $u^2 + 5u + 4 = (u + 1)(u + 4)$. With $u = x^2$: $(x^2 + 1)(x^2 + 4)$.
:::

::: problem id=x20 type=multi answers="7;5;-7;-5" set=extra creative=true

solution: Pairs 1, 6 / 2, 3 / $-1$, $-6$ / $-2$, $-3$. Their sums: 7, 5, $-7$, $-5$.
