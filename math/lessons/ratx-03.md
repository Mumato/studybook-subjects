---
id: ratx-03
title: Adding and subtracting rational expressions
---
::: rule
Just like fractions: get a **common denominator** (the LCD), rewrite each fraction with it, then add or subtract the tops.

Put brackets around a top you subtract, so the minus reaches every term.
:::

::: example
$\frac{1}{x} + \frac{1}{2x} = \frac{2}{2x} + \frac{1}{2x} = \frac{3}{2x}$
:::

::: example
$\frac{1}{x + 1} + \frac{1}{x - 1} = \frac{(x - 1) + (x + 1)}{(x + 1)(x - 1)} = \frac{2x}{x^2 - 1}$
:::

::: problem id=p1 type=expression answer="5/x"
$\frac{3}{x} + \frac{2}{x} = ?$
solution: Same denominator: $\frac{5}{x}$.
:::

::: problem id=p2 type=expression answer="3/(2x)"
$\frac{1}{x} + \frac{1}{2x} = ?$
solution: LCD $2x$: $\frac{2 + 1}{2x} = \frac{3}{2x}$.
:::

::: problem id=p3 type=choice
$\frac{1}{x + 1} + \frac{1}{x - 1} = ?$
- [x] $\frac{2x}{x^2 - 1}$
- [ ] $\frac{2}{2x}$
- [ ] $\frac{2}{x^2 - 1}$
solution: $\frac{(x - 1) + (x + 1)}{x^2 - 1} = \frac{2x}{x^2 - 1}$.
:::

::: problem id=p4 type=expression answer="(x-2)/(x+2)"
$\frac{x}{x + 2} - \frac{2}{x + 2} = ?$
solution: $\frac{x - 2}{x + 2}$.
:::

::: problem id=p5 type=expression answer="3x^2"
What is the lowest common denominator of $\frac{1}{x^2}$ and $\frac{1}{3x}$?
solution: $3x^2$.
:::

::: problem id=p6 type=numeric answer="3/2"
Evaluate $\frac{1}{x} + \frac{1}{x + 1}$ at $x = 1$.
solution: $1 + \frac{1}{2} = \frac{3}{2}$.
:::

::: problem id=p7 type=expression answer="(2x-1)/x^2"
$\frac{2}{x} - \frac{1}{x^2} = ?$
hint: LCD is $x^2$.
solution: $\frac{2x}{x^2} - \frac{1}{x^2} = \frac{2x - 1}{x^2}$.
:::

::: problem id=p8 type=expression answer="6/(x^2-9)"
$\frac{1}{x - 3} - \frac{1}{x + 3} = ?$
solution: $\frac{(x + 3) - (x - 3)}{(x - 3)(x + 3)} = \frac{6}{x^2 - 9}$.
:::

::: problem id=x1 type=expression answer="5/x" set=extra
$\frac{7}{x} - \frac{2}{x} = ?$
solution: Same denominator: $\frac{7 - 2}{x} = \frac{5}{x}$.
:::

::: problem id=x2 type=expression answer="1/(2x)" set=extra
$\frac{1}{3x} + \frac{1}{6x} = ?$
solution: LCD $6x$: $\frac{2 + 1}{6x} = \frac{3}{6x} = \frac{1}{2x}$.
:::

::: problem id=x3 type=numeric answer="1" set=extra
$\frac{x}{x - 1} - \frac{1}{x - 1} = ?$
solution: $\frac{x - 1}{x - 1} = 1$.
:::

::: problem id=x4 type=expression answer="(x+1)/x^2" set=extra
$\frac{1}{x} + \frac{1}{x^2} = ?$
solution: LCD $x^2$: $\frac{x}{x^2} + \frac{1}{x^2} = \frac{x + 1}{x^2}$.
:::

::: problem id=x5 type=expression answer="x^2-4" set=extra
What is the lowest common denominator of $\frac{1}{x + 2}$ and $\frac{1}{x^2 - 4}$?
solution: $x^2 - 4 = (x + 2)(x - 2)$ already contains $x + 2$: LCD $x^2 - 4$.
:::

::: problem id=x6 type=expression answer="5/(x+1)" set=extra
$\frac{3}{x + 1} + \frac{2}{x + 1} = ?$
solution: $\frac{5}{x + 1}$.
:::

::: problem id=x7 type=expression answer="1/(x(x+1))" set=extra
$\frac{1}{x} - \frac{1}{x + 1} = ?$
solution: $\frac{(x + 1) - x}{x(x + 1)} = \frac{1}{x(x + 1)}$.
:::

::: problem id=x8 type=numeric answer="0" set=extra
Evaluate $\frac{2}{x} - \frac{1}{x - 1}$ at $x = 2$.
solution: $1 - 1 = 0$.
:::

::: problem id=x9 type=choice set=extra
Ben writes $\frac{1}{2} + \frac{1}{x} = \frac{2}{2 + x}$. What is the right sum?
- [x] $\frac{x + 2}{2x}$
- [ ] $\frac{2}{2 + x}$
- [ ] $\frac{1}{2x}$
- [ ] $\frac{2}{2x}$
solution: You can't add the bottoms. LCD $2x$: $\frac{x}{2x} + \frac{2}{2x} = \frac{x + 2}{2x}$.
:::

::: problem id=x10 type=expression answer="5/x" set=extra
$\frac{x + 3}{x} - \frac{x - 2}{x} = ?$
hint: Brackets: the minus reaches the $-2$ too.
solution: $\frac{x + 3 - x + 2}{x} = \frac{5}{x}$.
:::

::: problem id=x11 type=numeric answer="2" set=extra
$\frac{2x}{x - 3} - \frac{6}{x - 3} = ?$
solution: $\frac{2x - 6}{x - 3} = \frac{2(x - 3)}{x - 3} = 2$.
:::

::: problem id=x12 type=expression answer="2x/(x^2-4)" set=extra
$\frac{1}{x - 2} + \frac{1}{x + 2} = ?$
solution: $\frac{(x + 2) + (x - 2)}{(x - 2)(x + 2)} = \frac{2x}{x^2 - 4}$.
:::

::: problem id=x13 type=expression answer="(x^2+x+1)/(x(x+1))" set=extra
$\frac{x}{x + 1} + \frac{1}{x} = ?$
solution: LCD $x(x + 1)$: $\frac{x^2 + (x + 1)}{x(x + 1)} = \frac{x^2 + x + 1}{x(x + 1)}$.
:::

::: problem id=x14 type=numeric answer="6" set=extra
$\frac{3}{x - 1} - \frac{3}{x + 1} = \frac{\square}{x^2 - 1}$. What goes in the box?
solution: $3(x + 1) - 3(x - 1)$ $= 3x + 3 - 3x + 3 = 6$.
:::

::: problem id=x15 type=expression answer="1/(x-1)" set=extra
$\frac{2}{x^2 - 1} + \frac{1}{x + 1} = ?$ (simplify as far as you can)
solution: $\frac{2 + (x - 1)}{x^2 - 1} = \frac{x + 1}{(x - 1)(x + 1)} = \frac{1}{x - 1}$.
:::

::: problem id=x16 type=numeric answer="5/2" set=extra
A cyclist rides 6 km at x km/h, then 6 km at $x + 2$ km/h. The time is $\frac{6}{x} + \frac{6}{x + 2}$ hours. Find it for $x = 4$.
hint: Time = distance ÷ speed.
solution: $\frac{6}{4} + \frac{6}{6} = \frac{3}{2} + 1 = \frac{5}{2}$ hours.
:::

::: problem id=x17 type=expression answer="1/(x^3-x)" set=extra
$\frac{1}{x^2 - x} - \frac{1}{x^2 - 1} = ?$
hint: Factor: $x(x - 1)$ and $(x - 1)(x + 1)$. LCD $x(x - 1)(x + 1)$.
solution: $\frac{(x + 1) - x}{x(x - 1)(x + 1)} = \frac{1}{x(x - 1)(x + 1)} = \frac{1}{x^3 - x}$.
:::

::: problem id=x18 type=expression answer="(x+3)/(x-3)" set=extra
$\frac{x}{x - 3} - \frac{3}{3 - x} = ?$
hint: $3 - x = -(x - 3)$.
solution: $-\frac{3}{3 - x} = +\frac{3}{x - 3}$. So the sum is $\frac{x + 3}{x - 3}$.
:::

::: problem id=x19 type=numeric answer="11" set=extra
$\frac{1}{x} + \frac{1}{2x} + \frac{1}{3x} = \frac{\square}{6x}$. What goes in the box?
hint: LCD $6x$.
solution: $\frac{6}{6x} + \frac{3}{6x} + \frac{2}{6x} = \frac{11}{6x}$.
:::

::: problem id=x20 type=numeric answer="-1" set=extra creative=true
$\frac{5}{(x - 1)(x + 4)} = \frac{A}{x - 1} + \frac{B}{x + 4}$ for all allowed x. What is B?
hint: Combine the right side: $A(x + 4) + B(x - 1) = 5$. Try $x = -4$.
solution: $x = -4$: $B(-5) = 5$, so $B = -1$. (And $x = 1$ gives $A = 1$.)
:::
