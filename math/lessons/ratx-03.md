---
id: ratx-03
title: Adding and subtracting rational expressions
---
::: rule
Just like fractions: get a **common denominator** (the LCD), rewrite each fraction with it, then add or subtract the tops.

Put brackets around a top you subtract, so the minus reaches every term.
:::

::: example
$\frac{1}{x} + \frac{1}{2x} = \frac{2}{2x} + \frac{1}{2x} = \frac{3}{2x}$
:::

::: example
$\frac{1}{x + 1} + \frac{1}{x - 1} = \frac{(x - 1) + (x + 1)}{(x + 1)(x - 1)} = \frac{2x}{x^2 - 1}$
:::

::: problem id=p1 type=expression answer="5/x"
$\frac{3}{x} + \frac{2}{x} = ?$
solution: Same denominator: $\frac{5}{x}$.
:::

::: problem id=p2 type=expression answer="3/(2x)"
$\frac{1}{x} + \frac{1}{2x} = ?$
solution: LCD $2x$: $\frac{2 + 1}{2x} = \frac{3}{2x}$.
:::

::: problem id=p3 type=choice
$\frac{1}{x + 1} + \frac{1}{x - 1} = ?$
- [x] $\frac{2x}{x^2 - 1}$
- [ ] $\frac{2}{2x}$
- [ ] $\frac{2}{x^2 - 1}$
solution: $\frac{(x - 1) + (x + 1)}{x^2 - 1} = \frac{2x}{x^2 - 1}$.
:::

::: problem id=p4 type=expression answer="(x-2)/(x+2)"
$\frac{x}{x + 2} - \frac{2}{x + 2} = ?$
solution: $\frac{x - 2}{x + 2}$.
:::

::: problem id=p5 type=expression answer="3x^2"
What is the lowest common denominator of $\frac{1}{x^2}$ and $\frac{1}{3x}$?
solution: $3x^2$.
:::

::: problem id=p6 type=numeric answer="3/2"
Evaluate $\frac{1}{x} + \frac{1}{x + 1}$ at $x = 1$.
solution: $1 + \frac{1}{2} = \frac{3}{2}$.
:::

::: problem id=p7 type=expression answer="(2x-1)/x^2"
$\frac{2}{x} - \frac{1}{x^2} = ?$
hint: LCD is $x^2$.
solution: $\frac{2x}{x^2} - \frac{1}{x^2} = \frac{2x - 1}{x^2}$.
:::

::: problem id=p8 type=expression answer="6/(x^2-9)"
$\frac{1}{x - 3} - \frac{1}{x + 3} = ?$
solution: $\frac{(x + 3) - (x - 3)}{(x - 3)(x + 3)} = \frac{6}{x^2 - 9}$.
:::
