::: problem id=e2 type=numeric answer="3"
Solve $3(2x - 1) - 2(x + 4) = 1$.

::: problem id=e4 type=expression answer="3v/b" vars="v,b"

solution: Multiply by 3: $3v = bh$. So $h = \frac{3v}{b}$.
:::

::: problem id=e14 type=numeric answer="225"
A plumber's charge is a straight line in the hours worked. A 2-hour job costs 150 dollars and a 5-hour job costs 300 dollars. What does a 3.5-hour job cost?
solution: Slope $\frac{300 - 150}{5 - 2} = 50$ per hour, fee $150 - 100 = 50$. Cost $50(3.5) + 50 = 225$ dollars.
:::

::: problem id=e19 type=numeric answer="2"

::: problem id=e20 type=numeric answer="20"
40 tickets were sold: adult tickets at 12 dollars and child tickets at 7 dollars, for 380 dollars in total. How many adult tickets were sold?
solution: $a + c = 40$, $12a + 7c = 380$. $12a + 280 - 7a = 380$, $5a = 100$, $a = 20$.
:::

::: problem id=e21 type=numeric answer="6"
A 5% and a 15% solution are mixed to make 20 L of a 12% solution. How many litres of the 5% solution are used?
solution: $x + y = 20$, $0.05x + 0.15y = 2.4$. $1 - 0.05y + 0.15y = 2.4$, $y = 14$, so $x = 6$ L.
:::

::: problem id=e35 type=numeric answer="38"
A garden's length is 5 m more than its width, and its area is 84 m². What is its perimeter?
solution: $w(w + 5) = 84$, $w^2 + 5w - 84 = 0$, $(w + 12)(w - 7) = 0$. So $w = 7$, $l = 12$, perimeter $2(7 + 12) = 38$ m.
:::
