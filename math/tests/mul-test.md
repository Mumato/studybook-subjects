::: problem id=t1 type=numeric answer="72"
$9 \times 8 = ?$
solution: $9 \times 8 = 72$.
:::

::: problem id=t2 type=numeric answer="0"
$7 \times 0 = ?$
solution: Anything times 0 is 0.
:::

::: problem id=t3 type=numeric answer="320"
$64 \times 5 = ?$
solution: $4 \times 5 = 20$: write 0 carry 2. $6 \times 5 + 2 = 32$. Answer: **320**.
:::

::: problem id=t4 type=numeric answer="851"
$37 \times 23 = ?$
solution: $37 \times 3 = 111$, $37 \times 20 = 740$, $111 + 740 = 851$.
:::

::: problem id=t5 type=numeric answer="1000"
$125 \times 8 = ?$
solution: $100 \times 8 + 25 \times 8 = 800 + 200 = 1000$.
:::

::: problem id=t6 type=numeric answer="1700"
$4 \times 17 \times 25 = ?$
solution: $(4 \times 25) \times 17 = 100 \times 17 = 1700$.
:::

::: problem id=t7 type=numeric answer="270"
A hall has 15 rows with 18 seats in each. How many seats?
solution: $15 \times 18 = 15 \times 10 + 15 \times 8 = 150 + 120 = 270$.
:::
