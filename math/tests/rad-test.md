::: problem id=t1 type=numeric answer="7"
$\sqrt{98} = \square\sqrt{2}$. What goes in the box?
solution: $98 = 49 \cdot 2$: $7\sqrt{2}$.
:::

::: problem id=t2 type=numeric answer="6"
$2\sqrt{5} + 4\sqrt{5} = \square\sqrt{5}$. What goes in the box?
solution: $6\sqrt{5}$.
:::

::: problem id=t3 type=numeric answer="6"
$\sqrt{6} \cdot \sqrt{6} = ?$
solution: $6$.
:::

::: problem id=t4 type=numeric answer="2"
$\frac{10}{\sqrt{5}} = \square\sqrt{5}$. What goes in the box?
solution: $\frac{10\sqrt{5}}{5} = 2\sqrt{5}$.
:::

::: problem id=t5 type=numeric answer="2"
$32^{\frac{1}{5}} = ?$
solution: $2^5 = 32$, so 2.
:::

::: problem id=t6 type=numeric answer="4"

solution: $2^2 = 4$.
:::

::: problem id=t7 type=numeric answer="11"
Solve $\sqrt{x - 2} = 3$.
solution: $x - 2 = 9$, $x = 11$.
:::

::: problem id=t8 type=numeric answer="4"
Solve $\sqrt{x + 12} = x$.
solution: $x^2 - x - 12 = 0$: 4 or $-3$. Only 4 checks out.
:::
