::: problem id=t9 type=choice

- [x] $\frac{x + 2}{x - 2}$
- [ ] $\frac{x - 2}{x + 2}$
- [ ] $-x - 1$
- [ ] $1$
solution: $\frac{(x + 2)^2}{(x + 2)(x - 2)} = \frac{x + 2}{x - 2}$.
:::

::: problem id=t10 type=choice
$\frac{x^2 - 1}{4x} \cdot \frac{8x^2}{x + 1} = ?$
- [x] $2x(x - 1)$
- [ ] $2x(x + 1)$
- [ ] $\frac{x - 1}{2x}$
- [ ] $2(x - 1)$
solution: $\frac{(x - 1)(x + 1)}{4x} \cdot \frac{8x^2}{x + 1} = \frac{8x^2(x - 1)}{4x} = 2x(x - 1)$.
:::

::: problem id=t15 type=choice
Solve $\frac{2x}{x - 1} = \frac{2}{x - 1} + 1$.
- [ ] $x = 1$
- [ ] $x = -1$
- [x] no solution
solution: Multiply by $x - 1$: $2x = 2 + x - 1$, so $x = 1$. That makes the denominator 0: **no solution**.
:::

::: problem id=t16 type=multi answers="3;-1/2"
Solve $\frac{3}{x} + \frac{4}{x + 1} = 2$.
solution: Multiply by $x(x + 1)$: $3x + 3 + 4x = 2x^2 + 2x$. So $2x^2 - 5x - 3 = 0$, $(2x + 1)(x - 3) = 0$: 3 and $-\frac{1}{2}$.
:::

::: problem id=t17 type=numeric answer="15/2"
A alone does a job in 5 hours. A and B together take 3 hours. How many hours does B take alone?
solution: $\frac{1}{3} - \frac{1}{5} = \frac{2}{15}$ per hour, so $\frac{15}{2} = 7.5$ hours.
:::

::: problem id=t18 type=numeric answer="50"
A car drives 150 km. At 10 km/h faster it would arrive half an hour sooner. What is its speed, in km/h?
solution: $\frac{150}{x} - \frac{150}{x + 10} = \frac{1}{2}$ gives $3000 = x^2 + 10x$. $(x + 60)(x - 50) = 0$: **50**.
:::
