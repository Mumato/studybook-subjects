::: problem id=t1 type=numeric answer="-4"
Which value of x is excluded from $\frac{3}{x + 4}$?
solution: $x + 4 = 0$ at $x = -4$.
:::

::: problem id=t2 type=choice
Simplify $\frac{x^2 - 25}{x + 5}$.
- [x] $x - 5$
- [ ] $x + 5$
- [ ] $x - 25$
solution: $\frac{(x + 5)(x - 5)}{x + 5} = x - 5$.
:::

::: problem id=t3 type=expression answer="5/x"
$\frac{4}{x} + \frac{1}{x} = ?$
solution: $\frac{5}{x}$.
:::

::: problem id=t4 type=expression answer="2/(3x)"
$\frac{1}{x} - \frac{1}{3x} = ?$
solution: $\frac{3 - 1}{3x} = \frac{2}{3x}$.
:::

::: problem id=t5 type=numeric answer="1/2"
Solve $\frac{5}{x} = 10$.
solution: $x = \frac{1}{2}$.
:::

::: problem id=t6 type=multi answers="4;-2"
Solve $x - \frac{8}{x} = 2$.
solution: $x^2 - 2x - 8 = 0$, $(x - 4)(x + 2) = 0$: 4 and $-2$.
:::

::: problem id=t7 type=numeric answer="6/5"
A does a job in 2 hours and B in 3 hours. How many hours together?
solution: $\frac{1}{2} + \frac{1}{3} = \frac{5}{6}$ per hour: $\frac{6}{5}$ hours (1.2 h).
:::
