::: problem id=t1 type=numeric answer="3000"
What is the digit 3 worth in 43,210?
solution: The 3 is in the thousands place: $3 \times 1000 = 3000$.
:::

::: problem id=t2 type=numeric answer="6700"
Round 6,749 to the nearest hundred.
solution: The tens digit is 4, less than 5, so the 7 stays: **6700**.
:::

::: problem id=t3 type=numeric answer="100"
Round 95 to the nearest ten.
solution: The ones digit is 5, so round up. 9 tens + 1 ten = 10 tens: **100**.
:::

::: problem id=t4 type=numeric answer="1225"
$768 + 457 = ?$
solution: Ones: $8 + 7 = 15$. Tens: $6 + 5 + 1 = 12$. Hundreds: $7 + 4 + 1 = 12$. Answer: **1225**.
:::
