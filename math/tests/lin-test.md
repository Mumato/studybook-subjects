::: problem id=t1 type=numeric answer="7"
Solve $3(x - 4) = x + 2$.
solution: $3x - 12 = x + 2$, $2x = 14$, $x = 7$.
:::

::: problem id=t2 type=numeric answer="6"
Solve $\frac{x}{2} + \frac{x}{3} = 5$.
solution: Multiply by 6: $3x + 2x = 30$, $x = 6$.
:::

::: problem id=t3 type=expression answer="a/b" vars="a,b"
Solve $a = bh$ for h.
solution: $h = \frac{a}{b}$.
:::

::: problem id=t4 type=expression answer="(v-u)/t" vars="v,u,t"
Solve $v = u + at$ for a.
solution: $v - u = at$, so $a = \frac{v - u}{t}$.
:::
