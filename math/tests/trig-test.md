::: problem id=t1 type=numeric answer="8/17"
A right triangle has sides 8, 15, 17. What is the sine of the angle opposite 8?
solution: $\frac{8}{17}$.
:::

::: problem id=t2 type=numeric answer="15/8"
Same triangle: what is the tangent of the angle opposite 15?
solution: Opposite 15, adjacent 8: $\frac{15}{8}$.
:::

::: problem id=t3 type=numeric answer="1/2"
$\cos 60° = ?$
solution: $\frac{1}{2}$.
:::

::: problem id=t4 type=numeric answer="7"
The hypotenuse is 14 and one angle is 30°. How long is the side opposite the 30°?
solution: $14 \times \frac{1}{2} = 7$.
:::

::: problem id=t5 type=numeric answer="60"
$\cos A = \frac{1}{2}$. What is A in degrees?
solution: $60°$.
:::

::: problem id=t6 type=numeric answer="3sqrt(2)"
A 45-45-90 triangle has legs of 3. How long is the hypotenuse? (exact)
solution: $3\sqrt{2}$.
:::

::: problem id=t7 type=numeric answer="sqrt(3)"
$\tan 60° = ?$ (exact)
solution: $\sqrt{3}$.
:::
