::: problem id=t1 type=numeric answer="5"
Simplify the ratio $15 : 25$. What is the second number?
solution: Divide both by 5: $3 : 5$.
:::

::: problem id=t2 type=numeric answer="36"
48 is shared in the ratio $1 : 3$. How big is the larger share?
solution: 4 parts of 12. The larger share is $3 \times 12 = 36$.
:::

::: problem id=t3 type=numeric answer="60"
A bus travels 180 km in 3 hours. What is its speed in km per hour?
solution: $180 \div 3 = 60$.
:::

::: problem id=t4 type=numeric answer="1.5"
4 pens cost 6 dollars. How much does one pen cost?
solution: $6 \div 4 = 1.5$ dollars.
:::

::: problem id=t5 type=numeric answer="3"
$\frac{x}{9} = \frac{4}{12}$. What is x?
solution: $12x = 36$, so $x = 3$.
:::

::: problem id=t6 type=numeric answer="350"
A drawing uses the scale 1 : 50. A wall is 7 cm long in the drawing. How long is the real wall in cm?
solution: $7 \times 50 = 350$ cm.
:::

::: problem id=t7 type=numeric answer="20"
Juice and water are mixed in the ratio $1 : 4$. How many cups of water for 5 cups of juice?
solution: $5 \times 4 = 20$ cups.
:::

::: problem id=t8 type=numeric answer="3"
Simplify the ratio $36 : 48$. What is the first number?
solution: Divide both by 12: $3 : 4$. The first number is **3**.
:::

::: problem id=t9 type=choice
Boys and girls in a choir are in the ratio $2 : 3$. What fraction of the choir are girls?
- [ ] $\frac{2}{3}$
- [ ] $\frac{3}{2}$
- [x] $\frac{3}{5}$
- [ ] $\frac{2}{5}$
solution: $2 + 3 = 5$ parts, 3 of them girls: $\frac{3}{5}$.
:::

::: problem id=t10 type=numeric answer="32"
Share 72 in the ratio $4 : 5$. How big is the smaller share?
solution: 9 parts of $72 \div 9 = 8$. Smaller share: $4 \times 8 = 32$.
:::

::: problem id=t11 type=numeric answer="3.5"
2.5 kg of grapes cost 8.75 dollars. What is the price per kg?
solution: $8.75 \div 2.5 = 3.50$ dollars per kg.
:::

::: problem id=t12 type=choice
Which is the better buy?
- [ ] 6 bottles for 4.20 dollars
- [x] 8 bottles for 5.20 dollars
solution: $4.20 \div 6 = 0.70$ and $5.20 \div 8 = 0.65$ dollars per bottle. The 8-pack.
:::

::: problem id=t13 type=numeric answer="4"
A car drives at 75 km per hour. How many hours does it take to drive 300 km?
solution: $300 \div 75 = 4$ hours.
:::

::: problem id=t14 type=numeric answer="4"
$\frac{7}{x} = \frac{21}{12}$. What is x?
solution: $21x = 84$, so $x = 4$.
:::

::: problem id=t15 type=numeric answer="7"
$\frac{x + 3}{4} = \frac{15}{6}$. What is x?
solution: $6(x + 3) = 60$, so $x + 3 = 10$ and $x = 7$.
:::

::: problem id=t16 type=text answers="yes"
Is $\frac{6}{8} = \frac{9}{12}$ a true proportion? Type yes or no.
solution: $6 \times 12 = 72$ and $8 \times 9 = 72$. They match: **yes**.
:::

::: problem id=t17 type=numeric answer="12"
3 kg of apples cost 7.20 dollars. How much do 5 kg cost?
solution: One kg: $7.20 \div 3 = 2.40$. Five kg: $5 \times 2.40 = 12$ dollars.
:::

::: problem id=t18 type=numeric answer="14"
On a map, 2 cm stands for 15 km. How many cm stand for 105 km?
solution: $\frac{2}{15} = \frac{x}{105}$: $15x = 210$, so $x = 14$ cm.
:::
