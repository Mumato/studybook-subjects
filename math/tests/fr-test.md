::: problem id=t1 type=numeric answer="15"
$\frac{3}{4} = \frac{?}{20}$. What is the missing number?
solution: $4 \times 5 = 20$, so $3 \times 5 = 15$.
:::

::: problem id=t2 type=numeric answer="5"
Simplify $\frac{16}{20}$. What is the denominator in simplest form?
solution: Divide both by 4: $\frac{4}{5}$. The denominator is **5**.
:::

::: problem id=t3 type=choice
Which is bigger?
- [x] $\frac{5}{6}$
- [ ] $\frac{7}{9}$
solution: Common denominator 18: $\frac{15}{18}$ and $\frac{14}{18}$, so $\frac{5}{6}$.
:::

::: problem id=t4 type=numeric answer="24"
What is the smallest common denominator for $\frac{1}{6}$ and $\frac{3}{8}$?
solution: LCM of 6 and 8: 24.
:::

::: problem id=t5 type=numeric answer="13"
$3\frac{1}{4} = \frac{?}{4}$. What is the missing numerator?
solution: $3 \times 4 + 1 = 13$.
:::

::: problem id=t6 type=numeric answer="4"
Write $\frac{22}{5}$ as a mixed number. What is the whole-number part?
solution: $22 \div 5 = 4$ remainder 2, so $4\frac{2}{5}$.
:::

::: problem id=t7 type=numeric answer="2/7"
What fraction of a week is the weekend (Saturday and Sunday)?
solution: 2 days out of 7: $\frac{2}{7}$.
:::

::: problem id=t8 type=choice
Which fraction equals $\frac{6}{9}$?
- [x] $\frac{2}{3}$
- [ ] $\frac{3}{6}$
- [ ] $\frac{9}{6}$
solution: Divide top and bottom by 3: $\frac{2}{3}$.
:::
