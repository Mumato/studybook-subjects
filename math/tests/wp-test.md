::: problem id=t1 type=numeric answer="18"
A number increased by 12 is 30. What is the number?
solution: $n + 12 = 30$, $n = 18$.
:::

::: problem id=t2 type=numeric answer="9"
Four times a number, minus 3, is 33. What is the number?
solution: $4n - 3 = 33$, $4n = 36$, $n = 9$.
:::

::: problem id=t3 type=numeric answer="38"
Two consecutive whole numbers add up to 77. What is the smaller one?
solution: $2n + 1 = 77$, $n = 38$.
:::

::: problem id=t4 type=numeric answer="10"
A rectangle's length is 5 cm more than its width, and its perimeter is 50 cm. What is the width?
solution: $2w + 2(w + 5) = 50$, $4w + 10 = 50$, $w = 10$ cm.
:::

::: problem id=t5 type=choice
Solve $\frac{x}{2} > 3$.
- [x] $x > 6$
- [ ] $x > 1.5$
- [ ] $x < 6$
solution: Multiply by 2: $x > 6$.
:::

::: problem id=t6 type=choice
Solve $-3x < 12$.
- [ ] $x < -4$
- [x] $x > -4$
- [ ] $x > 4$
solution: Divide by $-3$ and flip: $x > -4$.
:::

::: problem id=t7 type=numeric answer="8"
What is the smallest whole number n with $4n \ge 30$?
solution: $n \ge 7.5$, so **8**.
:::
