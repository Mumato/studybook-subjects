::: problem id=t1 type=numeric answer="pi/4"
Write 45° in radians.
solution: $\frac{\pi}{4}$.
:::

::: problem id=t2 type=numeric answer="120"
Write $\frac{2\pi}{3}$ in degrees.
solution: $120°$.
:::

::: problem id=t3 type=numeric answer="-1"
$\sin \frac{3\pi}{2} = ?$
solution: The bottom point $(0, -1)$: $-1$.
:::

::: problem id=t4 type=point answer="0,1"
Click where the angle $\frac{\pi}{2}$ lands on the unit circle.
graph:
x -2..2
y -2..2
circle 0,0 1
solution: $(0, 1)$.
:::

::: problem id=t5 type=numeric answer="2pi/3"
What is the period of $y = \sin 3x$?
solution: $\frac{2\pi}{3}$.
:::

::: problem id=t6 type=numeric answer="5"
What is the amplitude of $y = 5\cos 2x$?
solution: 5.
:::

::: problem id=t7 type=numeric answer="12/13"
$\sin\theta = \frac{5}{13}$ in quadrant I. What is $\cos\theta$?
solution: $\sqrt{1 - \frac{25}{169}} = \frac{12}{13}$.
:::
