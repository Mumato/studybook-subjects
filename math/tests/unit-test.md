::: problem id=t1 type=numeric answer="pi/4"
Write 45° in radians.
solution: $\frac{\pi}{4}$.
:::

::: problem id=t2 type=numeric answer="120"
Write $\frac{2\pi}{3}$ in degrees.
solution: $120°$.
:::

::: problem id=t3 type=numeric answer="-1"
$\sin \frac{3\pi}{2} = ?$
solution: The bottom point $(0, -1)$: $-1$.
:::

::: problem id=t5 type=numeric answer="2pi/3"
What is the period of $y = \sin 3x$?
solution: $\frac{2\pi}{3}$.
:::

::: problem id=t6 type=numeric answer="5"
What is the amplitude of $y = 5\cos 2x$?
solution: 5.
:::

::: problem id=t7 type=numeric answer="12/13"
$\sin\theta = \frac{5}{13}$ in quadrant I. What is $\cos\theta$?
solution: $\sqrt{1 - \frac{25}{169}} = \frac{12}{13}$.
:::

::: problem id=t8 type=numeric answer="5pi/3"
Write 300° in radians.
solution: $300 \times \frac{\pi}{180} = \frac{5\pi}{3}$.
:::

::: problem id=t9 type=numeric answer="3pi/2"
A circle has radius 6. How long is the arc for an angle of $\frac{\pi}{4}$?
solution: $s = r\theta = 6 \cdot \frac{\pi}{4} = \frac{3\pi}{2}$.
:::

::: problem id=t10 type=numeric answer="-sqrt(3)/2"
$\cos\frac{7\pi}{6} = ?$ (exact)
solution: $210°$, quadrant III, reference 30°. Cosine negative: $-\frac{\sqrt{3}}{2}$.
:::

::: problem id=t11 type=numeric answer="8pi"
What is the period of $y = \cos\frac{x}{4}$?
solution: $\frac{2\pi}{1/4} = 8\pi$.
:::

::: problem id=t12 type=multi answers="pi/3;5pi/3"
Solve $\cos x = \frac{1}{2}$ for $0 \le x < 2\pi$.
solution: Cosine positive in I and IV: $\frac{\pi}{3}$ and $2\pi - \frac{\pi}{3} = \frac{5\pi}{3}$.
:::

::: problem id=t13 type=numeric answer="3/4"
$\sin\theta = -\frac{3}{5}$ and θ is in quadrant III. What is $\tan\theta$?
solution: $\cos\theta = -\frac{4}{5}$ in III. $\tan\theta = \frac{-3/5}{-4/5} = \frac{3}{4}$.
:::

::: problem id=t14 type=numeric answer="5pi/6"
$\arccos\left(-\frac{\sqrt{3}}{2}\right) = ?$
solution: In $[0, \pi]$, cosine is $-\frac{\sqrt{3}}{2}$ at $\frac{5\pi}{6}$.
:::

::: problem id=t15 type=numeric answer="4/3"
$\tan\left(\arccos\frac{3}{5}\right) = ?$
solution: Adjacent 3, hypotenuse 5, opposite 4. The angle is in quadrant I: $\frac{4}{3}$.
:::

::: problem id=t16 type=numeric answer="pi/4"
$\arcsin\left(\sin\frac{3\pi}{4}\right) = ?$
solution: $\sin\frac{3\pi}{4} = \frac{\sqrt{2}}{2}$, and $\arcsin\frac{\sqrt{2}}{2} = \frac{\pi}{4}$.
:::

::: problem id=t17 type=numeric answer="(sqrt(6)-sqrt(2))/4"
$\cos\frac{5\pi}{12} = ?$ (exact)
solution: $\frac{5\pi}{12} = 75° = 45° + 30°$. $\cos 45°\cos 30° - \sin 45°\sin 30°$ $= \frac{\sqrt{6} - \sqrt{2}}{4}$.
:::

::: problem id=t18 type=numeric answer="120/169"
$\sin\theta = \frac{5}{13}$ and θ is in quadrant I. What is $\sin 2\theta$?
solution: $\cos\theta = \frac{12}{13}$. $2 \cdot \frac{5}{13} \cdot \frac{12}{13} = \frac{120}{169}$.
:::

::: problem id=t19 type=multi answers="pi/6;pi/2;5pi/6;3pi/2"
Solve $\sin 2x = \cos x$ for $0 \le x < 2\pi$.
solution: $2\sin x\cos x - \cos x = 0$, $\cos x(2\sin x - 1) = 0$. $\cos x = 0$: $\frac{\pi}{2}, \frac{3\pi}{2}$. $\sin x = \frac{1}{2}$: $\frac{\pi}{6}, \frac{5\pi}{6}$.
:::
