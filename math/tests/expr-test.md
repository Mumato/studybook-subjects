::: problem id=t1 type=expression answer="2n-7" vars="n"
Write "7 less than twice n".
solution: $2n - 7$.
:::

::: problem id=t2 type=numeric answer="11"
Evaluate $3x - 4$ when $x = 5$.
solution: $15 - 4 = 11$.
:::

::: problem id=t3 type=numeric answer="10"
Evaluate $a^2 + b$ when $a = -3$ and $b = 1$.
solution: $9 + 1 = 10$.
:::

::: problem id=t4 type=numeric answer="8"
Simplify $6y + 2y$. What number goes in front of y?
solution: $6 + 2 = 8$.
:::

::: problem id=t5 type=numeric answer="7"
Simplify $5x + 3 - 2x + 4$. What is the number without an x?
solution: $3 + 4 = 7$ (the answer is $3x + 7$).
:::

::: problem id=t6 type=numeric answer="20"
$4(x + 5) = 4x + \square$. What goes in the box?
solution: $4 \times 5 = 20$.
:::

::: problem id=t7 type=numeric answer="3"
Expand $-3(2 - x)$. What number goes in front of x?
solution: $-3(2 - x) = -6 + 3x$. The coefficient is **3**.
:::

::: problem id=t8 type=choice
Simplify $2(x + 3) + x$.
- [x] $3x + 6$
- [ ] $3x + 3$
- [ ] $2x + 6$
solution: $2x + 6 + x = 3x + 6$.
:::
