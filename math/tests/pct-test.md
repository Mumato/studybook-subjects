::: problem id=t1 type=numeric answer="85"
Write 0.85 as a percent.
solution: $0.85 \times 100 = 85\%$.
:::

::: problem id=t2 type=numeric answer="15"
Write $\frac{3}{20}$ as a percent.
solution: $\frac{3}{20} = \frac{15}{100} = 15\%$.
:::

::: problem id=t3 type=numeric answer="27"

solution: $0.3 \times 90 = 27$.
:::
