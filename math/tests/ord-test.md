::: problem id=t1 type=numeric answer="27"
$3^3 = ?$
solution: $3 \times 3 \times 3 = 27$.
:::

::: problem id=t2 type=numeric answer="64"
$2^6 = ?$
solution: 2, 4, 8, 16, 32, **64**.
:::

::: problem id=t3 type=numeric answer="18"
$8 + 2 \times 5 = ?$
solution: $2 \times 5 = 10$, then $8 + 10 = 18$.
:::

::: problem id=t4 type=numeric answer="50"
$(8 + 2) \times 5 = ?$
solution: $8 + 2 = 10$, then $10 \times 5 = 50$.
:::

::: problem id=t5 type=numeric answer="10"
$36 \div 2^2 + 1 = ?$
solution: $2^2 = 4$, $36 \div 4 = 9$, $9 + 1 = 10$.
:::

::: problem id=t6 type=numeric answer="984"
$10^3 - 4^2 = ?$
solution: $1000 - 16 = 984$.
:::
