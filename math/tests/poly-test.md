::: problem id=t1 type=numeric answer="10"
$x^4 \cdot x^6 = x^{?}$
solution: $4 + 6 = 10$.
:::

::: problem id=t2 type=numeric answer="12"
$(y^3)^4 = y^{?}$
solution: $3 \times 4 = 12$.
:::

::: problem id=t3 type=numeric answer="1/4"
$2^{-2} = ?$
solution: $\frac{1}{4}$.
:::

::: problem id=t4 type=numeric answer="-4"
$0.00052 = 5.2 \times 10^{?}$
solution: The point moves 4 places right: $-4$.
:::

::: problem id=t5 type=numeric answer="6*10^7"
$(3 \times 10^2)(2 \times 10^5) = ?$
solution: $6 \times 10^7$.
:::

::: problem id=t6 type=numeric answer="8"
$(x + 2)(x + 6) = x^2 + \square x + 12$. What goes in the box?
solution: $6x + 2x = 8x$.
:::

::: problem id=t7 type=numeric answer="49"
Expand $(x - 7)^2$. What is the number without x?
solution: $(-7)^2 = 49$.
:::

::: problem id=t8 type=numeric answer="81"
$(x + 9)(x - 9) = x^2 - \square$. What goes in the box?
solution: $9^2 = 81$.
:::
