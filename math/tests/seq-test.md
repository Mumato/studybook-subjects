::: problem id=t1 type=numeric answer="81"
What is the 20th term of $5, 9, 13, \ldots$?
solution: $5 + 19 \times 4 = 81$.
:::

::: problem id=t2 type=numeric answer="420"
Add up $2 + 4 + 6 + \cdots + 40$.
solution: 20 terms: $\frac{20}{2}(2 + 40) = 420$.
:::

::: problem id=t3 type=numeric answer="96"
What is the 6th term of $3, 6, 12, \ldots$?
solution: $3 \times 2^5 = 96$.
:::

::: problem id=t4 type=numeric answer="30"
$\sum_{k=1}^{4} k^2 = ?$
solution: $1 + 4 + 9 + 16 = 30$.
:::

::: problem id=t5 type=numeric answer="16"
$8 + 4 + 2 + 1 + \cdots = ?$
solution: $\frac{8}{1/2} = 16$.
:::

::: problem id=t6 type=numeric answer="5/9"
Write $0.555\ldots$ as a fraction.
solution: $\frac{5}{9}$.
:::

::: problem id=t7 type=choice
Which infinite series adds up to a number?
- [x] $1 + \frac{1}{3} + \frac{1}{9} + \cdots$
- [ ] $1 + \frac{3}{2} + \frac{9}{4} + \cdots$
- [ ] $1 + 1 + 1 + \cdots$
solution: Only the first has $|r| < 1$.
:::
