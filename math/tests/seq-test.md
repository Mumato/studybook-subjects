::: problem id=t1 type=numeric answer="81"
What is the 20th term of $5, 9, 13, \ldots$?
solution: $5 + 19 \times 4 = 81$.
:::

::: problem id=t2 type=numeric answer="420"
Add up $2 + 4 + 6 + \cdots + 40$.
solution: 20 terms: $\frac{20}{2}(2 + 40) = 420$.
:::

::: problem id=t7 type=choice
Which infinite series adds up to a number?
- [x] $1 + \frac{1}{3} + \frac{1}{9} + \cdots$
- [ ] $1 + \frac{3}{2} + \frac{9}{4} + \cdots$
- [ ] $1 + 1 + 1 + \cdots$
solution: Only the first has $|r| < 1$.
:::

::: problem id=t8 type=numeric answer="5"
An arithmetic sequence has $a_3 = 11$ and $a_7 = 23$. What is $a_1$?
solution: $4d = 12$, $d = 3$. $a_1 = 11 - 2 \times 3 = 5$.
:::

::: problem id=t9 type=numeric answer="375"
Add up the first 15 terms of $4, 7, 10, \ldots$
solution: $a_{15} = 4 + 14 \times 3 = 46$.
$\frac{15}{2}(4 + 46) = 375$.
:::

::: problem id=t10 type=numeric answer="6"
Which term of $2, 6, 18, \ldots$ is 486?
solution: $2 \cdot 3^{n - 1} = 486$, so $3^{n - 1} = 243 = 3^5$ and $n = 6$.
:::

::: problem id=t16 type=numeric answer="54"
What is the coefficient of $x^2$ in $(x + 3)^4$?
solution: $k = 2$: $\binom{4}{2} \cdot 3^2 = 6 \times 9 = 54$.
:::

::: problem id=t17 type=numeric answer="1"
What is the constant term of $(2x - 1)^6$?
solution: $k = 6$: $(-1)^6 = 1$.
:::

::: problem id=t18 type=numeric answer="80"
What is the coefficient of $x^3$ in $(2x + 1)^5$?
solution: $5 - k = 3$, $k = 2$: $\binom{5}{2}(2)^3 = 10 \times 8 = 80$.
:::
