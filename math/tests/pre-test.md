::: problem id=t1 type=multi answers="0;4;-1"
What are the zeros of $x(x - 4)(x + 1)$?
solution: 0, 4 and $-1$.
:::

::: problem id=t2 type=choice
What does $y = -x^3$ do at its two ends?
- [x] up on the left, down on the right
- [ ] down on the left, up on the right
- [ ] up at both ends
solution: Odd degree, negative leading coefficient.
:::

::: problem id=t3 type=numeric answer="4"
What is the remainder of $(x^2 + 3) \div (x - 1)$?
solution: $p(1) = 4$.
:::

::: problem id=t4 type=expression answer="x+4"
$(x^2 + 7x + 12) \div (x + 3) = ?$
solution: $x + 4$.
:::

::: problem id=t5 type=numeric answer="-5"
Where is the vertical asymptote of $\frac{3}{x + 5}$? Type the x value.
solution: $x = -5$.
:::

::: problem id=t6 type=numeric answer="3"
What is the horizontal asymptote of $\frac{3x^2 + 1}{x^2 - 2}$? Type the y value.
solution: $\frac{3}{1} = 3$.
:::

::: problem id=t7 type=text answers="no"
Is $(x - 2)$ a factor of $x^2 + 4$? Type yes or no.
solution: $p(2) = 8 \ne 0$: **no**.
:::

::: problem id=t8 type=numeric answer="5"
What is the most turning points a degree 6 polynomial can have?
solution: $6 - 1 = 5$.
:::

::: problem id=t9 type=numeric answer="8"
What is the y-intercept of $y = (x + 2)(x - 1)(x - 4)$?
solution: $(2)(-1)(-4) = 8$.
:::

::: problem id=t10 type=choice
What does $y = (x + 3)^2(x - 1)$ do at $x = -3$?
- [x] touches the x-axis and bounces
- [ ] crosses the x-axis
- [ ] has a vertical asymptote
solution: The factor $(x + 3)$ is squared.
:::

::: problem id=t11 type=choice
What does $y = -x^4 + 3x$ do at its two ends?
- [x] down at both ends
- [ ] up at both ends
- [ ] up on the left, down on the right
solution: Even degree, negative leading coefficient.
:::

::: problem id=t12 type=expression answer="2x+1"
$(2x^2 - 3x - 2) \div (x - 2) = ?$
solution: $(x - 2)(2x + 1) = 2x^2 - 3x - 2$.
:::

::: problem id=t13 type=numeric answer="-1"
What is the remainder of $(x^3 - 3x + 1) \div (x + 2)$?
solution: $p(-2) = -8 + 6 + 1 = -1$.
:::

::: problem id=t14 type=numeric answer="-1"
For which k is $(x - 2)$ a factor of $x^3 + kx^2 - 4$?
solution: $p(2) = 8 + 4k - 4 = 0$, so $k = -1$.
:::

::: problem id=t15 type=multi answers="3;-3"
Where are the vertical asymptotes of $\frac{x}{x^2 - 9}$?
solution: $x^2 = 9$: $x = 3$ and $x = -3$.
:::

::: problem id=t16 type=numeric answer="2"
What is the horizontal asymptote of $\frac{4x^2 - 1}{2x^2 + x}$? Type the y value.
solution: Equal degrees: $\frac{4}{2} = 2$.
:::

::: problem id=t17 type=numeric answer="4"
Where does $\frac{3x - 12}{x + 5}$ cross the x-axis? Type the x value.
solution: $3x - 12 = 0$ at $x = 4$.
:::

::: problem id=t18 type=numeric answer="6"
$\frac{x^2 - 9}{x - 3}$ has a hole. What is its y-coordinate?
solution: It equals $x + 3$ for $x \ne 3$; at $x = 3$ that is 6.
:::
