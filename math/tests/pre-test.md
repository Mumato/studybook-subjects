::: problem id=t1 type=multi answers="0;4;-1"
What are the zeros of $x(x - 4)(x + 1)$?
solution: 0, 4 and $-1$.
:::

::: problem id=t2 type=choice
What does $y = -x^3$ do at its two ends?
- [x] up on the left, down on the right
- [ ] down on the left, up on the right
- [ ] up at both ends
solution: Odd degree, negative leading coefficient.
:::

::: problem id=t3 type=numeric answer="4"
What is the remainder of $(x^2 + 3) \div (x - 1)$?
solution: $p(1) = 4$.
:::

::: problem id=t4 type=expression answer="x+4"
$(x^2 + 7x + 12) \div (x + 3) = ?$
solution: $x + 4$.
:::

::: problem id=t5 type=numeric answer="-5"
Where is the vertical asymptote of $\frac{3}{x + 5}$? Type the x value.
solution: $x = -5$.
:::

::: problem id=t6 type=numeric answer="3"
What is the horizontal asymptote of $\frac{3x^2 + 1}{x^2 - 2}$? Type the y value.
solution: $\frac{3}{1} = 3$.
:::

::: problem id=t7 type=text answers="no"
Is $(x - 2)$ a factor of $x^2 + 4$? Type yes or no.
solution: $p(2) = 8 \ne 0$: **no**.
:::
