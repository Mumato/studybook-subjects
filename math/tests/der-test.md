::: problem id=t1 type=expression answer="4x^3-6x"
$\frac{d}{dx}(x^4 - 3x^2 + 2) = ?$

:::

::: problem id=t2 type=numeric answer="12"

:::

::: problem id=t7 type=expression answer="6x-9"
