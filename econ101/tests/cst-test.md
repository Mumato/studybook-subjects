::: problem id=t1 type=numeric answer="30000"
Revenue is \$400,000, explicit costs \$250,000 and implicit costs \$120,000. What is the economic profit?
solution: $400000 - 250000 - 120000 = \$30{,}000$.
:::

::: problem id=t2 type=numeric answer="150000"
Same firm: revenue \$400,000, explicit costs \$250,000. What is its accounting profit?
solution: $400000 - 250000 = \$150{,}000$.
:::

::: problem id=t3 type=numeric answer="8"
Output: 1 worker 12, 2 workers 30, 3 workers 42, 4 workers 50. What is the marginal product of the 4th worker?
solution: $50 - 42 = 8$.
:::

::: problem id=t4 type=numeric answer="20"
Fixed costs are \$200 and variable costs are \$600 at 40 units. What is the ATC?
solution: $(200 + 600) / 40 = 20$.
:::

::: problem id=t5 type=numeric answer="30"
Total cost is \$500 at 20 units and \$530 at 21 units. What is the marginal cost of the 21st unit?
solution: $530 - 500 = 30$.
:::

::: problem id=t6 type=choice
Marginal cost is above average total cost. As output rises, ATC:
- [ ] falls
- [x] rises
- [ ] stays the same
solution: Each new unit costs more than the average, pulling it up.
:::

::: problem id=t7 type=choice
Diminishing marginal returns is a short-run idea because:
- [x] some input, like the factory, is fixed
- [ ] wages are fixed
- [ ] prices are fixed
- [ ] firms can't hire in the short run
solution: Adding workers to a fixed plant is what makes each one add less.
:::

::: problem id=t8 type=choice
Long-run average cost falls as the firm grows. This is:
- [x] economies of scale
- [ ] diseconomies of scale
- [ ] diminishing marginal returns
- [ ] constant returns to scale
solution: Bigger means cheaper per unit.
:::
