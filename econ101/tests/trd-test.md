::: problem id=t1 type=numeric answer="4"
In an hour, Kim types 10 pages or files 20 folders; Lou types 4 pages or files 16 folders. How many folders does one typed page cost Lou?
solution: $16 / 4 = 4$ folders.
:::

::: problem id=t2 type=choice
Same: Kim 10 pages or 20 folders an hour, Lou 4 pages or 16 folders. Who has the comparative advantage in filing?
- [ ] Kim
- [x] Lou
solution: A folder costs Lou $4/16 = 0.25$ pages and Kim $10/20 = 0.5$ pages.
:::

::: problem id=t3 type=choice
Same workers. Who has the absolute advantage in both tasks?
- [x] Kim
- [ ] Lou
- [ ] Neither
solution: Kim does more of each in an hour.
:::

::: problem id=t4 type=choice
Same workers. At which price (folders per page) can both gain from trade?
- [ ] 1
- [x] 3
- [ ] 5
- [ ] 6
solution: A page costs Kim 2 folders and Lou 4. The price must be between 2 and 4.
:::

::: problem id=t5 type=choice
Comparative advantage means making a good:
- [ ] faster than anyone else
- [x] at a lower opportunity cost than others
- [ ] with more workers
- [ ] at a lower money price
solution: It's about what you give up, not about speed.
:::

::: problem id=t6 type=numeric answer="10"
A worker can make 5 cars or 50 bikes in a month. How many bikes does one car cost?
solution: $50 / 5 = 10$ bikes.
:::

::: problem id=t7 type=choice
When two countries trade voluntarily, following comparative advantage:
- [x] both can gain
- [ ] only the richer one gains
- [ ] one's gain is exactly the other's loss
- [ ] they gain only if each has an absolute advantage
solution: Specializing raises total output, and trading at a price between the opportunity costs shares it.
:::
