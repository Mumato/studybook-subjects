id: ela-01
title: Price elasticity of demand
---
All demand curves slope down, but some buyers barely react to a price change and others run away. Elasticity measures how much. (OpenStax ch. 5)

::: rule
$$E_d = \frac{\% \text{ change in quantity demanded}}{\% \text{ change in price}}$$
Drop the minus sign. Between two points, use the **midpoint method**: divide each change by the average of the two values.
- $E_d > 1$: **elastic**. $E_d < 1$: **inelastic**. $E_d = 1$: **unit elastic**.
- Demand is more elastic with close **substitutes**, for **luxuries**, for goods that take a big share of the budget, and over a **longer time**.
:::

::: example
The price rises from \$10 to \$12 and the quantity falls from 100 to 80.
$$\%\Delta Q = \frac{-20}{90} = -22.2\%$$
$$\%\Delta P = \frac{2}{11} = 18.2\%$$
$E_d = 22.2 / 18.2 = 1.22$: elastic.
:::

::: problem id=p1 type=numeric answer="1" tolerance=0.01
The price rises from \$4 to \$6 and the quantity demanded falls from 120 to 80. Using the midpoint method, what is $E_d$?
solution: $\%\Delta Q = 40/100 = 40\%$, $\%\Delta P = 2/5 = 40\%$. $E_d = 1$: unit elastic.
:::

::: problem id=p2 type=numeric answer="0.263" tolerance=0.01
The price rises from \$20 to \$30 and the quantity demanded falls from 50 to 45. Using the midpoint method, what is $E_d$?
solution: $\%\Delta Q = 5/47.5 = 10.5\%$, $\%\Delta P = 10/25 = 40\%$. $E_d = 10.5/40 = 0.263$.
:::

::: problem id=p3 type=choice
Demand with $E_d = 0.263$ is:
- [ ] elastic
- [x] inelastic
- [ ] unit elastic
solution: It's less than 1: buyers barely react.
:::

::: problem id=p4 type=numeric answer="2.5" tolerance=0.01
A 10% price rise cuts the quantity demanded by 25%. What is $E_d$?
solution: $25 / 10 = 2.5$.
:::

::: problem id=p5 type=numeric answer="2" tolerance=0.01
$E_d = 0.4$. The price rises 5%. By what percent does the quantity demanded fall?
solution: $0.4 \times 5\% = 2\%$.
:::

::: problem id=p6 type=choice
Which probably has the **most** elastic demand?
- [x] One brand of breakfast cereal
- [ ] Insulin
- [ ] Salt
- [ ] Gasoline next week
solution: There are many other cereals to switch to. The others have few substitutes, at least in the short run.
:::

::: problem id=p7 type=choice
Compared with the first month after a price rise, demand a few years later is usually:
- [x] more elastic
- [ ] less elastic
- [ ] exactly as elastic
solution: Given time, people find substitutes: they buy fuel-efficient cars, move closer to work, change habits.
:::
