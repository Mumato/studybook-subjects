title: Public goods and common resources
---
Some goods are hard to sell, because you can't stop people from using them without paying. (OpenStax ch. 13)

::: rule
Two questions sort every good:
- **Rival?** Does one person's use leave less for others?
- **Excludable?** Can people who don't pay be kept out?

- **Private goods:** rival and excludable (a sandwich).
- **Club goods:** excludable, not rival (a streaming service).
- **Common resources:** rival, not excludable (ocean fish). They get overused: the **tragedy of the commons**.
- **Public goods:** neither (national defence, a lighthouse). People can **free ride**, so markets provide too little and governments often step in.
A public good is worth building if the **total** of everyone's values is more than its cost.
:::

::: example
A fireworks show: watching it doesn't use it up (not rival), and you can't stop people from looking up (not excludable). It's a public good, so towns usually pay for it with taxes.
:::

::: problem id=p1 type=choice
National defence is a:
- [ ] private good
- [ ] club good
- [ ] common resource
- [x] public good
solution: It protects everyone at once, and no one in the country can be left out.
:::

::: problem id=p2 type=choice
Fish in the open ocean are a:
- [ ] private good
- [ ] club good
- [x] common resource
- [ ] public good
solution: A fish caught is gone for others (rival), but no one can be stopped from fishing (not excludable).
:::

::: problem id=p3 type=choice
A streaming service is a:
- [ ] private good
- [x] club good
- [ ] common resource
- [ ] public good
solution: You need a subscription (excludable), but your watching doesn't use the show up (not rival).
:::

::: problem id=p4 type=choice
A free rider is someone who:
- [x] benefits from a good without paying for it
- [ ] rides public transit for free
- [ ] pays more than their share
- [ ] produces a public good
solution: If everyone waits for others to pay, a public good may never be paid for.
:::

::: problem id=p5 type=choice
Why are common resources like fish often overused?
- [x] Each user gains the full catch but shares the cost of a smaller stock with everyone
- [ ] They're too expensive
- [ ] People don't value them
- [ ] The government owns them
solution: That's the tragedy of the commons. Fixes include quotas and fishing licences.
:::

::: problem id=p6 type=numeric answer="90"
Three neighbours value a new streetlight at \$40, \$30 and \$20. It costs \$75. What is its total value to them, in dollars?
solution: Everyone uses the same light, so add up the values: $40 + 30 + 20 = \$90$. That's more than \$75, so it's worth building.
:::

::: problem id=p7 type=choice
Would any one of those neighbours buy the \$75 streetlight alone?
- [ ] Yes, the one who values it at \$40
- [x] No: each values it at less than \$75
- [ ] Yes, all three would
solution: That's why public goods go unprovided without some way to share the cost.
:::

::: problem id=p8 type=numeric answer="2" creative=true
The three neighbours (values \$40, \$30, \$20) split the \$75 cost equally. How many of them end up better off?
solution: Each pays \$25. The ones valuing it at \$40 and \$30 gain; the one at \$20 loses \$5. So **2**, and the third might vote no, though the light is worth more than it costs overall.
:::
