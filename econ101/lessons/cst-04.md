---
id: cst-04
title: Long-run costs and economies of scale
---
In the long run a firm can build a bigger plant. Does getting bigger make each unit cheaper?

::: rule
The **long-run average cost (LRAC)** is the lowest cost per unit at each output, once every input can change.
- **Economies of scale:** LRAC **falls** as output grows (specialization, bulk buying, big machines).
- **Constant returns to scale:** LRAC stays the same.
- **Diseconomies of scale:** LRAC **rises** (a huge firm gets hard to manage).
- **Minimum efficient scale:** the smallest output at which LRAC reaches its lowest level.
:::

::: example
A plant makes 1,000 units for \$50,000 (\$50 each). A bigger plant makes 2,000 for \$90,000 (\$45 each). Cost per unit fell: economies of scale.
:::

::: problem id=p1 type=numeric answer="35"
Making 3,000 units costs \$105,000. What is the average cost per unit?
solution: $105000 / 3000 = 35$.
:::

::: problem id=p2 type=choice
Average cost is \$40 at 1,000 units and \$35 at 3,000 units in the long run. This shows:
- [x] economies of scale
- [ ] constant returns to scale
- [ ] diseconomies of scale
- [ ] diminishing marginal returns
solution: Cost per unit falls as the firm grows.
:::

::: problem id=p3 type=choice
Doubling every input doubles output and doubles total cost. This is:
- [ ] economies of scale
- [x] constant returns to scale
- [ ] diseconomies of scale
solution: Average cost stays the same.
:::

::: problem id=p4 type=choice
In the long run, average cost is \$20 at 500 units and \$24 at 1,000 units. This shows:
- [ ] economies of scale
- [ ] constant returns to scale
- [x] diseconomies of scale
solution: Cost per unit rises as the firm grows.
:::

::: problem id=p5 type=choice
Which is a common cause of diseconomies of scale?
- [ ] Buying materials in bulk
- [x] Layers of managers and slow communication in a huge firm
- [ ] Workers specializing in single tasks
- [ ] Using bigger, faster machines
solution: The others lower costs; coordination problems raise them.
:::

::: problem id=p6 type=numeric answer="300"
Long-run average cost: 100 units \$50, 200 units \$40, 300 units \$35, 400 units \$35, 500 units \$38. What is the minimum efficient scale?
solution: The lowest cost, \$35, is first reached at 300 units.
:::

::: problem id=p7 type=choice
Strong economies of scale help explain why:
- [x] some industries, like car making, have only a few large firms
- [ ] most cities have many small hair salons
- [ ] small firms always have lower costs
- [ ] prices rise as firms grow
solution: If cost per unit keeps falling with size, small firms can't compete.
:::
