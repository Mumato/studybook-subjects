---
id: cst-02
title: Production and diminishing returns
---
In the short run a firm can hire more workers, but its building and machines stay the same. Each new worker then helps a little less.

::: rule
- **Short run:** at least one input (like the factory) is fixed. **Long run:** every input can change.
- **Marginal product (MP)** of labour = the extra output from one more worker.
- **Average product** = output ÷ workers.
- **Diminishing marginal returns:** with a fixed input, each extra worker eventually adds less than the one before.
:::

::: example
Workers and output: 1 worker 10, 2 workers 25, 3 workers 36, 4 workers 44, 5 workers 48.
Marginal products: 10, 15, 11, 8, 4. Returns diminish from the 3rd worker on.
:::

::: problem id=p1 type=numeric answer="11"
Output with 2 workers is 25 and with 3 workers is 36. What is the marginal product of the 3rd worker?
solution: $36 - 25 = 11$.
:::

::: problem id=p2 type=numeric answer="4"
Output with 4 workers is 44 and with 5 workers is 48. What is the marginal product of the 5th worker?
solution: $48 - 44 = 4$.
:::

::: problem id=p3 type=numeric answer="11"
4 workers produce 44 units. What is the average product?
solution: $44 / 4 = 11$.
:::

::: problem id=p4 type=numeric answer="3"
Output: 1 worker 8, 2 workers 18, 3 workers 26, 4 workers 30. Which worker is the first to add less than the one before?
solution: Marginal products: 8, 10, 8, 4. The 3rd worker adds 8, less than the 2nd's 10.
:::

::: problem id=p5 type=choice
Why do diminishing marginal returns happen?
- [x] More workers share the same fixed equipment and space
- [ ] Later workers are always lazier
- [ ] Wages rise as more workers are hired
- [ ] The firm can't sell the extra output
solution: With a fixed kitchen, the 10th cook mostly waits for a stove.
:::

::: problem id=p6 type=choice
In the long run:
- [x] all inputs, including buildings and machines, can be changed
- [ ] only labour can be changed
- [ ] nothing can be changed
- [ ] diminishing returns no longer exist anywhere
solution: That's the definition: the long run is long enough to change everything.
:::

::: problem id=p7 type=numeric answer="53"
5 workers produce 48 units. The 6th worker's marginal product is 5. How many units do 6 workers produce?
solution: $48 + 5 = 53$.
:::
