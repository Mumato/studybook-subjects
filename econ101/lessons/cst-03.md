---
id: cst-03
title: Short-run costs
---
Every cost a firm pays either changes with how much it makes or doesn't. Splitting them up shows the cost of each unit.

::: rule
- $TC = FC + VC$: **fixed costs** don't change with output; **variable costs** do.
- Averages: $AFC = FC/Q$, $AVC = VC/Q$, $ATC = TC/Q = AFC + AVC$.
- **Marginal cost:** $MC = \Delta TC / \Delta Q$, the cost of one more unit.
- When MC is below ATC, ATC falls; when MC is above ATC, ATC rises. So MC crosses ATC (and AVC) at its lowest point.
:::

::: example
FC = \$100 and making 10 units costs \$200 in variable costs. $TC = 300$, $ATC = 30$, $AVC = 20$, $AFC = 10$.
:::

::: problem id=p1 type=numeric answer="20"
Fixed costs are \$500 and making 100 units costs \$1,500 in variable costs. What is the ATC?
solution: $TC = 2000$, so $ATC = 2000/100 = 20$.
:::

::: problem id=p2 type=numeric answer="15"
Same firm: FC \$500, VC \$1,500 at 100 units. What is the AVC?
solution: $1500 / 100 = 15$.
:::

::: problem id=p3 type=numeric answer="5"
Same firm: FC \$500, VC \$1,500 at 100 units. What is the AFC?
solution: $500 / 100 = 5$. Check: $5 + 15 = 20 = ATC$.
:::

::: problem id=p4 type=numeric answer="18"
Total cost is \$250 for 10 units and \$268 for 11. What is the marginal cost of the 11th unit?
solution: $268 - 250 = 18$.
:::

::: problem id=p5 type=numeric answer="30"
Total cost by output: 0 units \$60, 1 unit \$100, 2 units \$130, 3 units \$150, 4 units \$180, 5 units \$225. What is the marginal cost of the 4th unit?
solution: $180 - 150 = 30$.
:::

::: problem id=p6 type=numeric answer="45"
Same firm (total cost \$180 for 4 units). What is the ATC at 4 units?
solution: $180 / 4 = 45$.
:::

::: problem id=p7 type=choice
At the current output, marginal cost is below average total cost. As output rises, ATC:
- [x] falls
- [ ] rises
- [ ] stays the same
solution: A unit cheaper than the average pulls the average down, like a low quiz mark pulls down your average.
:::

::: problem id=p8 type=choice
Which cost stays the same whatever the firm produces in the short run?
- [x] Fixed cost
- [ ] Variable cost
- [ ] Marginal cost
- [ ] Average total cost
solution: Rent on the building is paid even at zero output.
:::
