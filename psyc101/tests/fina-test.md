::: problem id=t1 type=choice
To find out whether a new therapy **causes** improvement, researchers should:
- [ ] survey people who chose the therapy
- [x] randomly assign people to the therapy or a control group
- [ ] interview one successful client
solution: Only an experiment with random assignment shows cause and effect.
:::

::: problem id=t2 type=choice
Pushing a painful memory out of conscious awareness is the defence mechanism of:
- [x] repression
- [ ] projection
- [ ] sublimation
solution: Repression keeps the memory unconscious.
:::

::: problem id=t3 type=numeric answer="75"
Learning a list took 20 minutes. Relearning it later takes 5 minutes. What are the savings, in percent?
solution: $(20 - 5)/20 = 15/20 = 75\%$.
:::

::: problem id=t4 type=choice
A 5-year-old thinks a tall, thin glass holds more juice than a short, wide one with the same amount. In Piaget's terms, the child lacks:
- [x] conservation
- [ ] object permanence
- [ ] abstract reasoning
solution: Preoperational children judge amount by appearance.
:::

::: problem id=t5 type=choice
Feeling afraid **because** you notice your heart racing is the view of the:
- [x] James-Lange theory
- [ ] Cannon-Bard theory
- [ ] two-factor theory
solution: In James-Lange, bodily reaction comes first.
:::

::: problem id=t6 type=choice
Someone high in **agreeableness** is likely to be:
- [x] kind and cooperative
- [ ] organised and careful
- [ ] anxious and moody
solution: Agreeableness: warm, trusting, helpful.
:::

::: problem id=t7 type=choice
In Milgram's studies, obedience dropped sharply when:
- [x] the experimenter gave orders by phone instead of in person
- [ ] the shocks were labelled higher
- [ ] the learner was in another room
solution: A present, close authority drives obedience. (The learner being out of sight actually made obedience easier.)
:::

::: problem id=t8 type=choice
Exposure therapy for a fear of flying is an example of:
- [ ] psychodynamic therapy
- [x] behaviour therapy
- [ ] biomedical therapy
solution: It uses learning principles to replace fear.
:::
