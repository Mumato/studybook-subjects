::: problem id=t1 type=choice
Wilhelm Wundt's 1879 laboratory is important because it:
- [x] marked the start of psychology as a separate experimental science
- [ ] introduced psychoanalysis
- [ ] began behaviourism
solution: Wundt's lab is the traditional birth of scientific psychology.
:::

::: problem id=t2 type=choice
Which correlation shows the weakest relationship?
- [ ] $-0.70$
- [ ] $+0.55$
- [x] $+0.05$
- [ ] $-0.95$
solution: 0.05 is closest to zero, so the relationship is almost nonexistent.
:::

::: problem id=t3 type=numeric answer="95"
IQ scores have a mean of 100 and an SD of 15. About what percent of people score between 70 and 130?
solution: 70 and 130 are 2 SD from the mean: about 95%.
:::

::: problem id=t4 type=choice
The "fight or flight" response is produced by the:
- [x] sympathetic nervous system
- [ ] parasympathetic nervous system
- [ ] somatic nervous system
solution: It speeds the heart and prepares the body for action.
:::

::: problem id=t5 type=choice
The part of the brain most important for forming new long-term memories is the:
- [ ] amygdala
- [x] hippocampus
- [ ] cerebellum
- [ ] medulla
solution: Damage to the hippocampus blocks new long-term memories.
:::

::: problem id=t6 type=numeric answer="8"
The JND for brightness is 8% of the starting brightness. A lamp gives 100 units of light. By how many units must it brighten to be just noticeable?
solution: $8\% \times 100 = 8$ units.
:::

::: problem id=t7 type=choice
A rat gets food after the first lever press every 2 minutes. This schedule is:
- [ ] fixed-ratio
- [ ] variable-ratio
- [x] fixed-interval
- [ ] variable-interval
solution: The reward depends on time passing (a fixed amount), not on the number of presses.
:::

::: problem id=t8 type=choice
Children in Bandura's study imitated an adult attacking a doll. This shows:
- [ ] classical conditioning
- [x] observational learning
- [ ] insight learning
solution: They learned by watching a model.
:::
