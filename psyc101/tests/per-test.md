::: problem id=t1 type=choice
According to Freud, the ego's main job is to:
- [x] balance the id's urges, the superego's rules and reality
- [ ] seek pleasure immediately
- [ ] enforce moral rules
solution: The ego is the realistic mediator.
:::

::: problem id=t2 type=choice
Someone who can't remember a traumatic event because it has been pushed out of awareness is, in Freud's terms, using:
- [x] repression
- [ ] projection
- [ ] sublimation
solution: Repression keeps painful material unconscious.
:::

::: problem id=t3 type=choice
Turning aggressive urges into a career as a surgeon is, in Freud's terms:
- [ ] displacement
- [x] sublimation
- [ ] regression
solution: Sublimation channels urges into socially valued activity.
:::

::: problem id=t4 type=choice
Rogers believed healthy growth needs:
- [x] unconditional positive regard
- [ ] strict punishment
- [ ] a strong superego
solution: Acceptance without conditions.
:::

::: problem id=t5 type=choice
"If I work hard, I can pass" reflects:
- [x] an internal locus of control
- [ ] an external locus of control
- [ ] the collective unconscious
solution: Believing your actions shape outcomes.
:::

::: problem id=t6 type=choice
Which is **not** one of the Big Five traits?
- [ ] openness
- [ ] agreeableness
- [x] intelligence
- [ ] neuroticism
solution: OCEAN: openness, conscientiousness, extraversion, agreeableness, neuroticism.
:::

::: problem id=t7 type=choice
The MMPI is a:
- [x] self-report personality inventory
- [ ] projective test
- [ ] intelligence test
solution: Hundreds of true/false items, scored objectively.
:::

::: problem id=t8 type=choice
Identical twins raised apart often have similar personalities. This supports:
- [x] a genetic influence on personality
- [ ] Freud's theory of the id
- [ ] the idea that environment is all that matters
solution: Similarity despite different homes points to genes, though not genes alone.
:::
