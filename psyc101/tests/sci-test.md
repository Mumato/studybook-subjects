title: Psychology as a science test
---
::: problem id=t1 type=choice
Psychology is best defined as the scientific study of:
- [ ] the brain only
- [x] behaviour and mental processes
- [ ] mental illness
- [ ] dreams and the unconscious
solution: It covers both what we do (behaviour) and what goes on in the mind.
:::

::: problem id=t2 type=choice
Which early school asked what the mind is **for**, influenced by Darwin's ideas?
- [ ] structuralism
- [x] functionalism
- [ ] behaviourism
- [ ] humanism
solution: William James's functionalism studied the purpose of mental processes.
:::

::: problem id=t3 type=choice
A researcher wants to know whether a new reading program **causes** better reading scores. She should use:
- [ ] a survey of teachers
- [ ] a correlational study
- [x] an experiment with random assignment
- [ ] a case study of one child
solution: Only an experiment can show cause and effect.
:::

::: problem id=t4 type=text answers="independent variable;independent;iv;the independent variable"
In that experiment, which variable is the reading program (program or no program)? Type the name of this kind of variable.
solution: It's what the researcher changes: the independent variable.
:::

::: problem id=t5 type=choice
Ice-cream sales and drownings rise together in summer. The best explanation is:
- [ ] ice cream causes drowning
- [ ] drowning causes ice-cream sales
- [x] a third variable, hot weather, increases both
solution: A classic case of correlation without causation.
:::

::: problem id=t6 type=numeric answer="7"
What is the mean of 3, 5, 7, 9, 11?
solution: $(3+5+7+9+11)/5 = 35/5 = 7$.
:::

::: problem id=t7 type=numeric answer="6"
What is the median of 10, 2, 6, 8, 4?
solution: Sorted: 2, 4, 6, 8, 10. The middle score is 6.
:::

::: problem id=t8 type=choice
Before taking part, participants are told what the study involves and agree to it. This is:
- [x] informed consent
- [ ] debriefing
- [ ] a double-blind procedure
- [ ] confidentiality
solution: Consent comes first, with enough information to make a real choice.
:::
