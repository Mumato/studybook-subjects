---
::: problem id=t1 type=choice
In the Atkinson-Shiffrin model, information moves from sensory memory to short-term memory through:
- [x] attention
- [ ] rehearsal
- [ ] retrieval
solution: What we pay attention to enters short-term memory; the rest fades from sensory memory.
:::

::: problem id=t2 type=numeric answer="4"
The letters NBCCNNBBCMTV, grouped as TV channel names (NBC, CNN, BBC, MTV), make how many chunks?
solution: Four chunks of three letters each.
:::

::: problem id=t3 type=choice
Knowing how to swim is stored as:
- [ ] episodic memory
- [ ] semantic memory
- [x] procedural memory
solution: Skills are implicit, procedural memories.
:::

::: problem id=t4 type=numeric answer="80"
Learning a list took 30 minutes. Relearning it later takes 6 minutes. What are the savings, in percent?
solution: $(30 - 6)/30 = 24/30 = 80\%$.
:::

::: problem id=t5 type=choice
You remember the last few items in a list well because they're still in short-term memory. This is the:
- [ ] primacy effect
- [x] recency effect
- [ ] spacing effect
solution: Recency: the latest items haven't faded yet.
:::

::: problem id=t6 type=choice
Learning a new locker combination makes you forget last year's. This is:
- [ ] proactive interference
- [x] retroactive interference
- [ ] encoding failure
solution: New learning disrupts old memory.
:::

::: problem id=t7 type=choice
A head injury erases memories from the months before the accident. This is:
- [ ] anterograde amnesia
- [x] retrograde amnesia
- [ ] the misinformation effect
solution: Retrograde amnesia goes back in time; anterograde is about new memories.
:::

::: problem id=t8 type=choice
Loftus's car-crash studies showed that:
- [x] the wording of a question can change what people remember
- [ ] memories are stored exactly like recordings
- [ ] eyewitnesses are always accurate when confident
solution: "Smashed" led to higher speed estimates and false memories of broken glass.
:::
