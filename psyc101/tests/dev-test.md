::: problem id=t1 type=choice
A child insists that a flattened ball of clay has less clay than before. In Piaget's terms, the child hasn't mastered:
- [x] conservation
- [ ] object permanence
- [ ] assimilation
solution: Conservation is understood in the concrete operational stage.
:::

::: problem id=t2 type=choice
Piaget's sensorimotor stage covers roughly:
- [x] birth to age 2
- [ ] ages 2-7
- [ ] ages 7-11
- [ ] age 11 and up
solution: Babies learn through senses and actions.
:::

::: problem id=t3 type=choice
A newborn turns toward a touch on the cheek. This is the:
- [x] rooting reflex
- [ ] Moro reflex
- [ ] grasping reflex
solution: Rooting helps the baby find the nipple to feed.
:::

::: problem id=t4 type=choice
Which attachment style shows distress at separation and quick comfort at reunion?
- [x] secure
- [ ] avoidant
- [ ] resistant
- [ ] disorganised
solution: The parent is a secure base.
:::

::: problem id=t5 type=choice
Parents with few rules who give their child whatever they want are:
- [ ] authoritative
- [ ] authoritarian
- [x] permissive
solution: Warm but undemanding.
:::

::: problem id=t6 type=choice
A young adult struggling to form close relationships is facing Erikson's stage of:
- [x] intimacy vs isolation
- [ ] trust vs mistrust
- [ ] integrity vs despair
solution: Intimacy vs isolation is the young adult stage.
:::

::: problem id=t7 type=choice
With age, which tends to stay steady or improve?
- [ ] processing speed
- [ ] fluid intelligence
- [x] vocabulary (crystallised intelligence)
solution: Knowledge keeps growing even as speed slows.
:::

::: problem id=t8 type=numeric answer="11"
A child enters Piaget's concrete operational stage at about 7 and stays in it for about 4 years. At about what age do formal operations begin?
solution: $7 + 4 = 11$.
:::
