title: Disorders and treatment test
---
::: problem id=t1 type=choice
The manual most clinicians in North America use to diagnose psychological disorders is the:
- [x] DSM-5
- [ ] MMPI
- [ ] TAT
solution: The Diagnostic and Statistical Manual of Mental Disorders.
:::

::: problem id=t2 type=choice
Constant, uncontrollable worry about many everyday things for months fits:
- [x] generalised anxiety disorder
- [ ] specific phobia
- [ ] bipolar disorder
solution: The worry isn't tied to one object or situation.
:::

::: problem id=t3 type=choice
Repeatedly checking that the stove is off, dozens of times, to relieve anxiety, is a:
- [ ] delusion
- [x] compulsion
- [ ] hallucination
solution: A ritual performed to ease an obsession.
:::

::: problem id=t4 type=choice
Bipolar disorder involves:
- [ ] depression only
- [x] episodes of depression and mania
- [ ] hallucinations only
solution: Mood swings between depressive and manic episodes.
:::

::: problem id=t5 type=choice
Which is a positive symptom of schizophrenia?
- [x] hallucinations
- [ ] flat emotion
- [ ] lack of motivation
solution: Positive symptoms add experiences that aren't normally there.
:::

::: problem id=t6 type=choice
Which therapy focuses on changing distorted thoughts and behaviours?
- [ ] psychoanalysis
- [x] cognitive-behavioural therapy
- [ ] client-centred therapy
solution: CBT.
:::

::: problem id=t7 type=choice
Systematic desensitisation is most often used to treat:
- [x] phobias
- [ ] schizophrenia
- [ ] antisocial personality disorder
solution: Step-by-step exposure while relaxed.
:::

::: problem id=t8 type=choice
SSRIs are mainly used to treat:
- [x] depression and anxiety
- [ ] schizophrenia
- [ ] dementia
solution: They block the reuptake of serotonin.
:::
