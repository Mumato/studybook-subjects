::: problem id=t1 type=choice
A mental shortcut that's fast but can lead to errors is a:
- [ ] algorithm
- [x] heuristic
- [ ] prototype
solution: Heuristics trade accuracy for speed.
:::

::: problem id=t2 type=choice
Judging how common something is by how easily examples come to mind is the:
- [x] availability heuristic
- [ ] confirmation bias
- [ ] anchoring effect
solution: Memorable events seem more frequent than they really are.
:::

::: problem id=t3 type=choice
Someone fails to solve a problem because they keep using a method that worked before. This is:
- [ ] functional fixedness
- [x] mental set
- [ ] hindsight bias
solution: A mental set is sticking with old approaches.
:::

::: problem id=t4 type=numeric answer="4"
How many morphemes are in "unbelievably" (un-, believe, -able, -ly)?
solution: Four: un-, believe, -able, -ly.
:::

::: problem id=t5 type=choice
A child saying "I goed to the park" is:
- [x] overgeneralising a grammar rule
- [ ] babbling
- [ ] using telegraphic speech
solution: The child applies the regular "-ed" rule to an irregular verb.
:::

::: problem id=t6 type=numeric answer="85"
IQ has a mean of 100 and an SD of 15. What IQ is 1 standard deviation below the mean?
solution: $100 - 15 = 85$.
:::

::: problem id=t7 type=choice
A test measures what it claims to measure. It is:
- [ ] reliable
- [x] valid
- [ ] standardised
solution: Validity is about measuring the right thing.
:::

::: problem id=t8 type=choice
Spearman's g refers to:
- [x] a general intelligence underlying many abilities
- [ ] a gene for intelligence
- [ ] musical intelligence
solution: People who do well on one kind of mental test tend to do well on others; Spearman called the shared factor g.
:::
