::: problem id=t1 type=choice
A cat runs to the kitchen when it hears the can opener, because the sound has been paired with food. The can opener sound is the:
- [ ] unconditioned stimulus
- [x] conditioned stimulus
- [ ] unconditioned response
solution: The sound became meaningful only through pairing with food.
:::

::: problem id=t2 type=choice
A conditioned response fading when the CS is repeatedly presented without the US is:
- [x] extinction
- [ ] generalisation
- [ ] shaping
solution: Extinction weakens the learned link.
:::

::: problem id=t3 type=choice
You clean your room to stop your parents nagging, and the nagging stops. Your cleaning is maintained by:
- [ ] positive reinforcement
- [x] negative reinforcement
- [ ] positive punishment
solution: An unpleasant thing (nagging) is removed, so the behaviour increases.
:::

::: problem id=t4 type=choice
Getting a speeding ticket (a fine to pay) is meant to work as:
- [x] positive punishment
- [ ] negative punishment
- [ ] negative reinforcement
solution: An unpleasant consequence is added to reduce the behaviour. (Losing your licence would be negative punishment.)
:::

::: problem id=t5 type=choice
Which schedule makes behaviour most resistant to extinction?
- [ ] continuous reinforcement
- [ ] fixed-ratio
- [x] variable-ratio
solution: When rewards are unpredictable, it takes a long time to notice they've stopped.
:::

::: problem id=t6 type=numeric answer="4"
A coffee shop gives a free coffee after every 10 coffees bought (fixed-ratio 10). How many free coffees does someone earn for buying 47?
solution: $47 / 10 = 4.7$, so 4 free coffees.
:::

::: problem id=t7 type=choice
Learning to cook a dish by watching a video is:
- [x] observational learning
- [ ] classical conditioning
- [ ] latent learning
solution: Learning from a model, even on a screen, is observational learning.
:::

::: problem id=t8 type=choice
Tolman's rats that learned a maze without any reward showed:
- [ ] insight learning
- [x] latent learning
- [ ] spontaneous recovery
solution: The learning stayed hidden until a reward gave a reason to show it.
:::
