::: problem id=t1 type=choice
Assuming a quiet classmate is unfriendly, without considering that she might be shy or new, is the:
- [x] fundamental attribution error
- [ ] self-serving bias
- [ ] mere-exposure effect
solution: Overemphasising personality and ignoring the situation.
:::

::: problem id=t2 type=choice
Changing a belief to match something you've already done reduces:
- [ ] social loafing
- [x] cognitive dissonance
- [ ] in-group bias
solution: The clash between action and belief is uncomfortable, so the belief shifts.
:::

::: problem id=t3 type=choice
In Asch's experiments, participants sometimes gave wrong answers about line lengths because of:
- [x] conformity to the group
- [ ] obedience to authority
- [ ] poor eyesight
solution: They went along with a unanimous group.
:::

::: problem id=t4 type=numeric answer="65"
About what percent of Milgram's participants obeyed all the way to 450 volts?
solution: About 65%.
:::

::: problem id=t5 type=choice
People clap less loudly each when in a large group than when alone. This is:
- [ ] social facilitation
- [x] social loafing
- [ ] groupthink
solution: Individual effort drops when it's hidden in a group.
:::

::: problem id=t6 type=choice
A negative attitude toward people because of their group is:
- [ ] a stereotype
- [x] prejudice
- [ ] discrimination
solution: Prejudice is the attitude.
:::

::: problem id=t7 type=choice
The more witnesses there are to an emergency, the less likely any one of them is to help. This is the:
- [x] bystander effect
- [ ] foot-in-the-door effect
- [ ] mere-exposure effect
solution: Responsibility is diffused across the crowd.
:::

::: problem id=t8 type=choice
Which is a superordinate goal?
- [ ] winning a game against the other team
- [x] two rival groups working together to fix their town's broken water supply
- [ ] each group raising money for itself
solution: A shared goal that needs both groups.
:::
