::: problem id=t1 type=choice
Which part of a neuron carries the signal away from the cell body?
- [ ] dendrite
- [x] axon
- [ ] synapse
- [ ] receptor
solution: The axon carries the action potential to the terminals.
:::

::: problem id=t2 type=choice
Neurons communicate across the synapse using:
- [ ] hormones
- [x] neurotransmitters
- [ ] myelin
- [ ] blood cells
solution: Neurotransmitters cross the gap and bind to receptors.
:::

::: problem id=t3 type=choice
The neurotransmitter most linked with reward and motivation is:
- [x] dopamine
- [ ] acetylcholine
- [ ] GABA
- [ ] glutamate
solution: Dopamine pathways are central to reward and learning from rewards.
:::

::: problem id=t4 type=choice
"Fight or flight" is triggered by the:
- [ ] parasympathetic nervous system
- [x] sympathetic nervous system
- [ ] somatic nervous system
- [ ] cerebellum
solution: The sympathetic branch arouses the body for action.
:::

::: problem id=t5 type=text answers="occipital;occipital lobe;the occipital lobe"
Which lobe of the brain processes vision?
solution: The occipital lobe, at the back.
:::

::: problem id=t6 type=choice
Phineas Gage's change in personality after his injury pointed to the role of the:
- [x] frontal lobe
- [ ] occipital lobe
- [ ] cerebellum
- [ ] medulla
solution: The rod passed through his frontal lobes.
:::

::: problem id=t7 type=choice
Damage to the medulla is especially dangerous because it controls:
- [ ] vision
- [x] breathing and heartbeat
- [ ] memory
- [ ] language
solution: The medulla runs basic life-support functions.
:::

::: problem id=t8 type=choice
The structure that connects the brain's two hemispheres is the:
- [ ] hippocampus
- [ ] thalamus
- [x] corpus callosum
- [ ] amygdala
solution: It's a thick band of nerve fibres. Cutting it ("split brain") stops the halves sharing information directly.
:::
