::: problem id=t1 type=choice
Turning light into neural signals in the retina is an example of:
- [x] transduction
- [ ] adaptation
- [ ] perception
- [ ] perceptual set
solution: Transduction converts physical energy into nerve signals.
:::

::: problem id=t2 type=numeric answer="15"
The JND for loudness is 10% of the starting loudness. A sound measures 150 units. How many units must it rise to be just noticeable?
solution: $10\% \times 150 = 15$ units.
:::

::: problem id=t3 type=choice
According to the gate-control theory, why does rubbing a stubbed toe ease the pain?
- [ ] It repairs the tissue faster.
- [x] Touch signals from the rubbing help close a "gate" in the spinal cord that pain signals must pass through.
- [ ] It numbs the pain receptors permanently.
solution: Non-painful input competes with pain signals in the spinal cord, as Melzack and Wall proposed.
:::

::: problem id=t4 type=choice
Which receptors let you see colour and fine detail?
- [ ] rods
- [x] cones
- [ ] hair cells
solution: Cones are concentrated in the fovea.
:::

::: problem id=t5 type=choice
Loudness depends mainly on a sound wave's:
- [ ] frequency
- [x] amplitude
- [ ] wavelength
solution: Bigger amplitude, louder sound.
:::

::: problem id=t6 type=choice
Parallel road edges appear to meet in the distance. This monocular cue is:
- [x] linear perspective
- [ ] retinal disparity
- [ ] convergence
solution: Linear perspective works even with one eye closed.
:::

::: problem id=t7 type=choice
We see a person walking toward us as the same size, even as their image grows. This is:
- [ ] figure-ground
- [x] perceptual constancy
- [ ] similarity
solution: Size constancy, one kind of perceptual constancy.
:::

::: problem id=t8 type=choice
A red afterimage appears after staring at green. This supports:
- [ ] trichromatic theory
- [x] opponent-process theory
- [ ] Weber's law
solution: Red and green are an opponent pair.
:::
