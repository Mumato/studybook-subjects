::: problem id=t1 type=choice
The body's roughly 24-hour cycle of sleep and wakefulness is the:
- [x] circadian rhythm
- [ ] REM cycle
- [ ] activation-synthesis cycle
solution: It's set mostly by light and dark.
:::

::: problem id=t2 type=numeric answer="6"
How many 90-minute sleep cycles are there in 9 hours of sleep?
solution: $9 \times 60 = 540$ minutes; $540 / 90 = 6$.
:::

::: problem id=t3 type=choice
Deep, slow-wave sleep (N3) happens mostly:
- [x] early in the night
- [ ] late in the night
- [ ] only during naps
solution: Later cycles have more REM and less N3.
:::

::: problem id=t4 type=choice
A person who suddenly falls asleep during the day, even mid-conversation, may have:
- [ ] insomnia
- [x] narcolepsy
- [ ] sleep apnea
solution: Narcolepsy causes sudden sleep attacks, sometimes straight into REM.
:::

::: problem id=t5 type=choice
Opioids such as morphine are:
- [x] depressants that relieve pain
- [ ] stimulants
- [ ] hallucinogens
solution: They slow the nervous system and act on the body's pain-relief (endorphin) system.
:::

::: problem id=t6 type=choice
Caffeine and cocaine are both:
- [ ] depressants
- [x] stimulants
- [ ] hallucinogens
solution: Both increase nervous system activity, though cocaine is far stronger and more addictive.
:::

::: problem id=t7 type=choice
Needing more of a drug to get the same effect is called:
- [x] tolerance
- [ ] withdrawal
- [ ] suggestibility
solution: Tolerance develops with repeated use.
:::

::: problem id=t8 type=choice
Freud believed dreams:
- [ ] are random brain activity
- [x] express hidden wishes in disguised form
- [ ] help store new memories
solution: For Freud, dreams were "the royal road to the unconscious".
:::
