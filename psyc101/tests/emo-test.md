---
::: problem id=t1 type=choice
Performing best at a moderate level of arousal is described by the:
- [x] Yerkes-Dodson law
- [ ] James-Lange theory
- [ ] general adaptation syndrome
solution: Performance follows an inverted U with arousal.
:::

::: problem id=t2 type=choice
Someone who paints only to sell paintings is driven mainly by:
- [ ] intrinsic motivation
- [x] extrinsic motivation
- [ ] self-actualisation
solution: The reward comes from outside the activity.
:::

::: problem id=t3 type=choice
In Maslow's hierarchy, the need for friendship and belonging comes right above:
- [x] safety needs
- [ ] esteem needs
- [ ] self-actualisation
solution: Physiological, safety, then love and belonging.
:::

::: problem id=t4 type=choice
Schachter and Singer's two-factor theory says emotion depends on:
- [x] physical arousal and how we label it
- [ ] the facial expression only
- [ ] the thalamus alone
solution: Arousal plus a cognitive label.
:::

::: problem id=t5 type=choice
Basic emotional expressions such as fear and happiness are:
- [ ] different in every culture
- [x] recognised across cultures
- [ ] only learned in adulthood
solution: Ekman's cross-cultural research showed broad recognition.
:::

::: problem id=t6 type=numeric answer="70"
Marriage scores 50 and moving house scores 20 on the stress rating scale. What is the total for someone who does both in a year?
solution: $50 + 20 = 70$.
:::

::: problem id=t7 type=choice
The stage of Selye's model where the body first reacts with fight or flight is:
- [x] alarm
- [ ] resistance
- [ ] exhaustion
solution: The alarm stage is the initial shock response.
:::

::: problem id=t8 type=choice
Talking to a friend to feel better about a stressful situation is:
- [ ] problem-focused coping
- [x] emotion-focused coping
- [ ] drive reduction
solution: It eases the feelings; social support also protects health.
:::
