::: problem id=t1 type=choice
A researcher randomly assigns people to sleep 4 or 8 hours, then measures their reaction time. Reaction time is the:
- [ ] independent variable
- [x] dependent variable
- [ ] control group
- [ ] confound
solution: It's what's measured. Hours of sleep is the independent variable.
:::

::: problem id=t2 type=numeric answer="12"
What is the median of 15, 9, 12, 20, 4?
solution: Sorted: 4, 9, 12, 15, 20. The middle score is 12.
:::

::: problem id=t3 type=choice
The neurotransmitter that acts as the brain's main "brake", calming activity, is:
- [ ] dopamine
- [x] GABA
- [ ] glutamate
- [ ] acetylcholine
solution: GABA is the main inhibitory neurotransmitter.
:::

::: problem id=t4 type=choice
Damage to Wernicke's area most likely causes trouble with:
- [ ] producing fluent speech
- [x] understanding language
- [ ] seeing colours
- [ ] balance
solution: Wernicke's area, in the temporal lobe, is key for comprehension.
:::

::: problem id=t5 type=choice
You can still find your friend's face in a crowd at dusk, but colours look washed out. Which receptors are mostly in use?
- [x] rods
- [ ] cones
- [ ] hair cells
solution: In dim light, rods take over, and they don't see colour.
:::

::: problem id=t6 type=choice
Most vivid dreaming happens during:
- [ ] N1 sleep
- [ ] N3 sleep
- [x] REM sleep
solution: REM sleep brings the most vivid dreams, with the body's muscles paralysed.
:::

::: problem id=t7 type=choice
A student studies to avoid a parent's lecture, and the lecture doesn't come. The studying is strengthened by:
- [ ] positive reinforcement
- [x] negative reinforcement
- [ ] positive punishment
- [ ] negative punishment
solution: Avoiding something unpleasant reinforces the behaviour.
:::

::: problem id=t8 type=choice
A dog afraid of one vet's white coat starts fearing all people in white coats. This is:
- [x] generalisation
- [ ] discrimination
- [ ] extinction
- [ ] latent learning
solution: The fear spreads to similar stimuli.
:::
