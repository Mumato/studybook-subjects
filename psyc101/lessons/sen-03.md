title: Perception
---
Your eyes deliver a flat, upside-down, constantly shifting image. Your brain turns it into a stable 3D world of objects. Illusions show how it does that, by revealing when its shortcuts go wrong. (OpenStax Psychology 2e ch. 5)

::: rule
- **Gestalt** psychologists showed that we perceive whole patterns: **figure-ground** (an object stands out from its background), **proximity** (close things group together), **similarity** (alike things group together), **closure** (we fill in gaps), **continuity** (we see smooth, continuous lines).
- **Depth cues:** **binocular** cues need both eyes (**retinal disparity**: each eye sees a slightly different view). **Monocular** cues work with one eye: relative size, interposition (overlap), linear perspective (parallel lines meet in the distance), texture gradient.
- **Perceptual constancy:** we see a door as rectangular and a friend as the same size, even as the image on the retina changes.
- **Perceptual set:** expectations shape what we perceive.
:::

::: example
Railway tracks seem to meet at the horizon. That's **linear perspective**, a monocular depth cue: painters use it to make a flat canvas look deep.
:::

::: problem id=p1 type=choice
In the left picture, the dots are seen as three columns of pairs. Which Gestalt principle is at work?
![](assets/sen-gestalt.3x.png)
- [x] proximity
- [ ] similarity
- [ ] closure
solution: Dots that are close together get grouped.
:::

::: problem id=p2 type=choice
You see a circle even though a small gap breaks its outline. This is:
- [ ] proximity
- [x] closure
- [ ] figure-ground
solution: The brain fills in gaps to see complete shapes.
:::

::: problem id=p3 type=choice
Which depth cue needs **two** eyes?
- [ ] linear perspective
- [ ] relative size
- [x] retinal disparity
- [ ] interposition
solution: Each eye sees a slightly different image; the brain uses the difference to judge depth.
:::

::: problem id=p4 type=choice
A car parked behind a tree is partly hidden, so you know the tree is closer. This cue is:
- [x] interposition (overlap)
- [ ] texture gradient
- [ ] retinal disparity
solution: Whatever blocks the view of something else must be in front of it.
:::

::: problem id=p5 type=choice
As your friend walks away, the image on your retina shrinks, but you don't think they're shrinking. This is:
- [ ] sensory adaptation
- [x] size constancy
- [ ] closure
solution: Perceptual constancy keeps the world stable despite changing images.
:::

::: problem id=p6 type=choice creative=true
Lines A and B are exactly the same length, yet A looks longer. What's the best explanation?
![](assets/sen-muller.3x.png)
- [ ] Our eyes measure length badly in general.
- [x] The fins act like depth cues: A's outward fins resemble the far corner of a room, B's like a near corner, and the brain "corrects" A to be bigger.
- [ ] A is drawn with thicker lines.
solution: This is the Müller-Lyer illusion. People raised with few straight-edged buildings are less fooled by it, which suggests experience shapes how we use these cues.
:::

::: problem id=p7 type=choice
Told that a blurry picture shows a duck, people see a duck; told it's a rabbit, they see a rabbit. This shows:
- [x] perceptual set
- [ ] sensory adaptation
- [ ] retinal disparity
solution: Expectations steer how we interpret ambiguous input: top-down processing.
:::
