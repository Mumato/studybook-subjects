title: Thinking and problem solving
---
We solve problems and make decisions all day, mostly with quick mental shortcuts. They usually work, but they also lead to predictable mistakes. (OpenStax Psychology 2e ch. 7)

::: rule
- **Concepts** group similar things; a **prototype** is the best example of a concept (a robin is a more "birdy" bird than a penguin).
- Problem-solving strategies: an **algorithm** is a step-by-step method that guarantees an answer (but can be slow); a **heuristic** is a mental shortcut (fast but can fail).
- Obstacles: **functional fixedness** (seeing objects only in their usual use) and **mental set** (sticking with a method that worked before).
- Biases: **confirmation bias** (looking for evidence that supports what we already believe), the **availability heuristic** (judging how likely something is by how easily examples come to mind), **hindsight bias** ("I knew it all along"), the **anchoring** effect (relying too much on the first number heard).
:::

::: example
After seeing news of a plane crash, many people feel flying is more dangerous than driving, though driving is far riskier per kilometre. Dramatic crashes come to mind easily, so they seem common: the **availability heuristic**.
:::

::: problem id=p1 type=choice
Trying every possible combination to open a 3-digit lock is:
- [x] an algorithm
- [ ] a heuristic
- [ ] functional fixedness
solution: It's slow, but guaranteed to work eventually.
:::

::: problem id=p2 type=choice
You need a screwdriver and don't think to use a coin, because coins are "for paying". This is:
- [ ] confirmation bias
- [x] functional fixedness
- [ ] the availability heuristic
solution: You're stuck on the coin's usual function.
:::

::: problem id=p3 type=choice
Someone who believes a diet works only reads success stories and ignores studies showing it doesn't. This is:
- [x] confirmation bias
- [ ] hindsight bias
- [ ] anchoring
solution: Seeking out confirming evidence and ignoring the rest.
:::

::: problem id=p4 type=choice
After a game, fans say "I knew we'd lose", though before it they expected to win. This is:
- [ ] anchoring
- [x] hindsight bias
- [ ] mental set
solution: Once we know the outcome, it seems like it was obvious all along.
:::

::: problem id=p5 type=choice
A seller first asks 1000 dollars for a used bike, then "drops" to 600; you feel it's a bargain, though similar bikes sell for 400. This is the:
- [x] anchoring effect
- [ ] availability heuristic
- [ ] confirmation bias
solution: The first number heard sets the anchor for what seems reasonable.
:::

::: problem id=p6 type=text answers="prototype;a prototype"
What is the most typical example of a category called (like a robin for "bird")?
solution: A prototype.
:::

::: problem id=p7 type=choice
People overestimate deaths from shark attacks, which make headlines, and underestimate deaths from common diseases. This shows the:
- [ ] anchoring effect
- [x] availability heuristic
- [ ] functional fixedness
solution: Vivid, memorable events seem more frequent than they are.
:::
