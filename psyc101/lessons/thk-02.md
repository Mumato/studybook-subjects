title: Language
---
Language lets us turn a handful of sounds into an endless number of meanings. Children pick it up with astonishing speed, which has long puzzled psychologists. (OpenStax Psychology 2e ch. 7)

::: rule
- Building blocks: **phonemes** (the smallest sound units, like the "b" in *bat*), **morphemes** (the smallest units of meaning, like *un-*, *happy*, *-ness*), **syntax** (rules for ordering words) and **semantics** (meaning).
- Development: babbling (around 4-6 months), first words (around 12 months), two-word "telegraphic" speech (around 2 years), then rapid growth. Errors like "goed" show children learn **rules**, not just copy.
- **Skinner** said language is learned by reinforcement and imitation; **Chomsky** argued the brain has an inborn capacity for grammar. There seems to be a **sensitive period**: learning a language is much easier early in life.
- The **linguistic relativity** (Whorf) idea says language shapes thought. Strong versions are not supported, but language can influence some aspects of perception and memory.
:::

::: example
The word *unhappiness* has three **morphemes**: *un-* (not), *happy*, and *-ness* (a state of). Each carries meaning. The word *bat* has one morpheme but three **phonemes**: b, a, t.
:::

::: problem id=p1 type=numeric answer="3"
How many morphemes are in the word "replayed" (re-, play, -ed)?
solution: Three: re- (again), play, -ed (past tense).
:::

::: problem id=p2 type=choice
The smallest unit of sound in a language is a:
- [x] phoneme
- [ ] morpheme
- [ ] syntax rule
solution: Phonemes are sounds; morphemes carry meaning.
:::

::: problem id=p3 type=choice
A 3-year-old says "I runned home" and "two mouses". This shows the child is:
- [ ] copying adults exactly
- [x] applying grammar rules, even where English breaks them
- [ ] falling behind in language
solution: Overgeneralising the "-ed" and "-s" rules shows children learn rules. They never heard adults say "runned".
:::

::: problem id=p4 type=choice
Which theorist argued that humans are born with a built-in capacity for grammar?
- [ ] B. F. Skinner
- [x] Noam Chomsky
- [ ] Sigmund Freud
solution: Chomsky's view contrasts with Skinner's learning-based explanation.
:::

::: problem id=p5 type=text answers="syntax;grammar"
What do we call the rules for putting words in order to make sentences?
solution: Syntax.
:::

::: problem id=p6 type=choice
Speech like "want cookie" or "daddy go", at around age 2, is called:
- [ ] babbling
- [x] telegraphic speech
- [ ] overgeneralisation
solution: Like an old telegram, it keeps the key words and drops the rest.
:::

::: problem id=p7 type=choice
Adults who move to a new country usually learn its language with an accent, while young children often sound native. This supports the idea of a:
- [x] sensitive period for language
- [ ] linguistic relativity
- [ ] functional fixedness
solution: Language learning is easiest early in life, though adults can still learn a lot.
:::
