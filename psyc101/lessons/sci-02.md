title: Research methods
---
How do psychologists know what they claim? Each research method answers a different kind of question, and only one can show what *causes* what. (OpenStax Psychology 2e ch. 2)

::: rule
- **Descriptive** methods describe behaviour: **case studies** (one person in depth), **naturalistic observation** (watching in real settings) and **surveys** (asking many people).
- **Correlational** research measures how two variables move together. The **correlation coefficient** $r$ runs from $-1$ to $+1$: the sign gives the direction, the size (closer to 1) gives the strength. **Correlation does not prove causation.**
- An **experiment** shows cause and effect: the researcher changes the **independent variable** (IV), measures the **dependent variable** (DV), and uses **random assignment** to put people into an **experimental group** and a **control group**.
- A **double-blind** study keeps both participants and researchers unaware of who got the real treatment, so expectations can't bias the result.
:::

::: example
Does caffeine improve memory? Researchers randomly assign 100 students: half get caffeine, half get a **placebo** (an identical pill with no caffeine). Then everyone takes a memory test.
- IV: caffeine or not. DV: memory score.
- Random assignment makes the groups alike in every other way, so a difference in scores can be put down to the caffeine.
:::

::: problem id=p1 type=choice
Which method can show that one variable **causes** a change in another?
- [ ] a case study
- [ ] a survey
- [ ] a correlational study
- [x] an experiment
solution: Only an experiment manipulates one variable and controls the rest.
:::

::: problem id=p2 type=text answers="independent variable;independent;iv;the independent variable"
In the caffeine study, "caffeine or placebo" is the variable the researcher changes. What is that kind of variable called?
solution: The independent variable is the one the experimenter manipulates.
:::

::: problem id=p3 type=text answers="dependent variable;dependent;dv;the dependent variable"
The memory score is what the researcher measures to see the effect. What is that kind of variable called?
solution: The dependent variable "depends" on the independent variable.
:::

::: problem id=p4 type=choice
Which correlation is the **strongest**?
- [ ] $+0.40$
- [x] $-0.85$
- [ ] $+0.10$
- [ ] $0$
solution: Strength is the size, ignoring the sign: 0.85 is closest to 1. The minus only says that as one goes up, the other goes down.
:::

::: problem id=p5 type=choice
In the picture, which plot shows a **negative** correlation?
![](assets/psy-corr.3x.png)
- [ ] the left one
- [x] the middle one
- [ ] the right one
solution: In the middle plot, as one variable rises the other falls.
:::

::: problem id=p6 type=choice
Why do researchers use **random assignment**?
- [ ] so the sample represents the whole population
- [x] so the groups are alike at the start, and any difference later is due to the independent variable
- [ ] so participants don't know the hypothesis
solution: Random assignment spreads differences (age, sleep, ability) evenly across groups. Random *sampling* is a different idea: choosing who is in the study at all.
:::

::: problem id=p7 type=choice
In a double-blind drug study:
- [x] neither the participants nor the researchers giving the pills know who gets the real drug
- [ ] the participants are blindfolded
- [ ] only the participants don't know
solution: Keeping both "blind" stops expectations (theirs and the researchers') from shaping the results.
:::

::: problem id=p8 type=choice creative=true
A study finds that students who sit in the front row get higher grades. Can we conclude that sitting in front *causes* better grades?
- [ ] Yes, the correlation proves it.
- [x] No: it's a correlation. Keen students may choose the front row and also study more, so a third factor could explain both.
- [ ] Yes, if the correlation is above 0.5.
solution: To test the causal claim you would need an experiment: randomly assign students to seats and compare grades.
:::
