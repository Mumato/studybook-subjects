title: Neurons and neurotransmitters
---
Every thought, feeling and movement starts as signals passed between nerve cells, or **neurons**. Your brain has about 86 billion of them, each talking to thousands of others. (OpenStax Psychology 2e ch. 3)

::: rule
- A neuron's **dendrites** receive signals, the **cell body** (soma) adds them up, and the **axon** carries the signal away to the **axon terminals**. A fatty **myelin sheath** speeds the signal along the axon.
- At rest, the inside of a neuron is negative, about **−70 mV** (the **resting potential**). If incoming signals push it past the **threshold**, it fires an **action potential**: an electrical impulse that travels down the axon. Firing is **all-or-none**: a neuron either fires fully or not at all.
- At the **synapse**, the tiny gap between neurons, the terminals release **neurotransmitters** that fit **receptors** on the next neuron. Leftover neurotransmitter is taken back up (**reuptake**).
:::

![](assets/bio-neuron.3x.png)

::: example
Some key neurotransmitters:
- **Acetylcholine:** muscle movement, memory.
- **Dopamine:** reward, motivation, movement (lost in Parkinson's disease).
- **Serotonin:** mood, sleep, appetite (many antidepressants block its reuptake).
- **GABA:** the main "brake": it calms neural activity. **Glutamate:** the main "accelerator".
- **Endorphins:** the body's natural painkillers.
:::

::: problem id=p1 type=choice
Which part of a neuron receives messages from other neurons?
![](assets/bio-neuron.3x.png)
- [x] dendrites
- [ ] axon
- [ ] myelin sheath
- [ ] axon terminals
solution: Dendrites branch out like antennas to receive signals.
:::

::: problem id=p2 type=numeric answer="-70"
What is a neuron's typical resting potential, in millivolts?
solution: About −70 mV: the inside is negative compared with the outside.
:::

::: problem id=p3 type=choice
A stronger stimulus makes a neuron:
- [ ] fire a bigger action potential
- [x] fire more often, since each action potential is the same size (all-or-none)
- [ ] stop firing
solution: Action potentials are all-or-none, so intensity is signalled by firing rate and by how many neurons fire.
:::

::: problem id=p4 type=text answers="myelin;myelin sheath;the myelin sheath"
What is the fatty layer that insulates many axons and speeds up the signal?
solution: The myelin sheath. In multiple sclerosis it is damaged, and signals slow down.
:::

::: problem id=p5 type=choice
The gap between one neuron and the next is called the:
![](assets/bio-synapse.3x.png)
- [ ] axon
- [x] synapse
- [ ] dendrite
- [ ] receptor
solution: Neurotransmitters cross the synapse to reach receptors on the next neuron.
:::

::: problem id=p6 type=choice
Parkinson's disease, with its tremors and slow movement, involves the loss of neurons that make:
- [ ] serotonin
- [x] dopamine
- [ ] endorphins
- [ ] GABA
solution: Dopamine-producing neurons in the midbrain die, which disrupts movement control.
:::

::: problem id=p7 type=choice
Many antidepressants (SSRIs) work by blocking the **reuptake** of serotonin. This leaves:
- [x] more serotonin in the synapse, acting longer
- [ ] less serotonin in the synapse
- [ ] no change at the synapse
solution: Blocking reuptake keeps the neurotransmitter in the synapse.
:::
