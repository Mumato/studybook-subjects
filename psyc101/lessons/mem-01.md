title: How memory is organised
---
Memory isn't one thing. Information flows through stages that hold it for different lengths of time, and long-term memory has several separate kinds. (OpenStax Psychology 2e ch. 8)

::: rule
- Memory needs **encoding** (getting information in), **storage** (keeping it) and **retrieval** (getting it back out).
- The **Atkinson-Shiffrin model**: **sensory memory** holds a brief copy of everything (images about half a second, sounds a few seconds); what we pay **attention** to enters **short-term memory**, which holds about **7 ± 2** items for about 20 seconds unless **rehearsed**; **encoding** moves it into **long-term memory**, which is practically unlimited.
- **Chunking** groups items into meaningful units, so short-term memory holds more. **Working memory** is short-term memory as an active workspace.
- Long-term memory is **explicit** (declarative: things you can state) or **implicit** (shown in what you do). Explicit memory is **episodic** (personal events) or **semantic** (facts). Implicit memory includes **procedural** memory (skills like riding a bike) and **priming**.
:::

::: example
Remembering **FBICIAUSANBA** as 12 letters is hard. As four chunks (**FBI, CIA, USA, NBA**) it's easy: the same letters, but only 4 items in short-term memory.
:::

::: problem id=p1 type=numeric answer="9"
According to George Miller, short-term memory holds "7 plus or minus 2" items. What is the upper end of that range?
solution: $7 + 2 = 9$ items.
:::

::: problem id=p2 type=numeric answer="3"
A 10-digit phone number written as 555-867-5309 is grouped into how many chunks?
solution: Three chunks: 555, 867 and 5309.
:::

::: problem id=p3 type=choice
Without rehearsal, information in short-term memory fades in about:
- [ ] half a second
- [x] 20 seconds
- [ ] a day
- [ ] a year
solution: About 20 seconds, unless you keep repeating it or encode it into long-term memory.
:::

::: problem id=p4 type=choice
Remembering your tenth birthday party is an example of:
- [x] episodic memory
- [ ] semantic memory
- [ ] procedural memory
solution: Episodic memory stores personal experiences tied to a time and place.
:::

::: problem id=p5 type=choice
Knowing that Paris is the capital of France is:
- [ ] episodic memory
- [x] semantic memory
- [ ] procedural memory
solution: Semantic memory holds general facts, without remembering when you learned them.
:::

::: problem id=p6 type=choice
You can type quickly without thinking about where each key is, but can't easily say where the letter J is. That skill is:
- [ ] explicit memory
- [x] implicit (procedural) memory
- [ ] sensory memory
solution: Procedural memories show in performance, not in what you can describe.
:::

::: problem id=p7 type=text answers="chunking"
Grouping separate items into larger meaningful units to remember more is called what?
solution: Chunking.
:::
