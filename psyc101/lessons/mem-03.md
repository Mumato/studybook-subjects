title: Forgetting and false memories
---
Memory isn't a video recording. We forget quickly, old and new memories get in each other's way, and each time we remember, we rebuild the memory and can change it. (OpenStax Psychology 2e ch. 8)

::: rule
- **Ebbinghaus's forgetting curve:** most forgetting happens soon after learning, then levels off.
- Why we forget: **encoding failure** (it never got in), **decay**, and **interference**. **Proactive** interference: old learning disrupts new. **Retroactive** interference: new learning disrupts old.
- **Amnesia:** **anterograde** amnesia is being unable to form **new** memories; **retrograde** amnesia is losing **old** ones.
- Memories are **reconstructed**. The **misinformation effect**: misleading information after an event can change the memory of it. Vivid **false memories** can be created, so confidence doesn't prove accuracy.
:::

![](assets/mem-forget.3x.png)

::: example
Elizabeth **Loftus** showed people a film of a car crash, then asked how fast the cars were going when they "**smashed**" or "**hit**" each other. The "smashed" group guessed higher speeds, and a week later were more than twice as likely to "remember" broken glass, though there was none in the film.
:::

::: problem id=p1 type=choice
According to the forgetting curve, when does most forgetting happen?
![](assets/mem-forget.3x.png)
- [x] soon after learning
- [ ] steadily, at the same rate every day
- [ ] after about a month
solution: Memory drops sharply at first and then levels off. Reviewing soon after learning slows the drop.
:::

::: problem id=p2 type=choice
After switching to a new phone, you keep typing your old passcode. This is:
- [x] proactive interference
- [ ] retroactive interference
- [ ] encoding failure
solution: Old learning (the old code) interferes with new learning.
:::

::: problem id=p3 type=choice
After learning Spanish, you find it harder to recall the French you studied years ago. This is:
- [ ] proactive interference
- [x] retroactive interference
- [ ] anterograde amnesia
solution: New learning (Spanish) interferes with old memories (French).
:::

::: problem id=p4 type=choice
After brain surgery, patient H.M. could remember his childhood but couldn't form new lasting memories. He had:
- [x] anterograde amnesia
- [ ] retrograde amnesia
- [ ] the misinformation effect
solution: His hippocampus was removed; he lost the ability to form new long-term memories.
:::

::: problem id=p5 type=choice
You can't remember the colour of the "STOP" letters on a stop sign, though you've seen thousands. Most likely this is:
- [ ] decay
- [x] encoding failure
- [ ] retroactive interference
solution: You never paid attention to that detail, so it was never stored.
:::

::: problem id=p6 type=text answers="misinformation effect;the misinformation effect;misinformation"
Misleading questions after an event change people's memory of it. What is this called?
solution: The misinformation effect, shown by Loftus.
:::

::: problem id=p7 type=choice creative=true
An eyewitness is completely confident that she remembers the robber's face. A jury should:
- [ ] trust her fully, since confidence means accuracy
- [x] be cautious: confident memories can still be wrong, especially after suggestive questions or a long delay
- [ ] ignore all eyewitness evidence
solution: Many people later cleared by DNA evidence had been convicted on confident eyewitness testimony. Careful procedures (no leading questions, fair line-ups) make eyewitness memory more reliable.
:::
