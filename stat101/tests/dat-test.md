::: problem id=t1 type=choice
A poll of 1,000 adults finds 52% approve of the mayor. The 52% is:
- [ ] a parameter
- [x] a statistic
- [ ] a population
- [ ] a variable
solution: It describes the sample of 1,000.
:::

::: problem id=t2 type=choice
Which variable is **quantitative and continuous**?
- [ ] Number of pets
- [x] Body temperature
- [ ] Blood type
- [ ] Country of birth
solution: Temperature is measured on a continuous scale. Pets are counted (discrete); the other two are categorical.
:::

::: problem id=t3 type=choice
A teacher numbers a class list and picks every 5th name after a random start. This is a:
- [ ] stratified sample
- [ ] cluster sample
- [x] systematic sample
- [ ] convenience sample
solution: A random start, then every $k$-th: systematic.
:::

::: problem id=t4 type=numeric answer="40"
A list has 2,400 customers. A systematic sample of 60 should take every how many customers?
solution: $k = 2400 / 60 = 40$.
:::

::: problem id=t5 type=choice
A survey is mailed to 2,000 homes; only 300 reply. The biggest concern is:
- [x] nonresponse bias
- [ ] a leading question
- [ ] a placebo effect
- [ ] confounding
solution: The 300 who replied may differ from the 1,700 who didn't.
:::

::: problem id=t6 type=choice
Which study can show that a new teaching method **causes** higher scores?
- [ ] Comparing schools that chose the method with schools that didn't
- [x] Randomly assigning classes to the new or old method
- [ ] Asking teachers which method they prefer
- [ ] Surveying students about their scores
solution: Only random assignment makes the groups alike apart from the method.
:::

::: problem id=t7 type=choice
Ice cream sales and drownings rise and fall together. A likely confounding variable is:
- [ ] the price of ice cream
- [x] hot weather
- [ ] the number of shops
- [ ] the flavour of ice cream
solution: Hot weather increases both ice cream sales and swimming.
:::

::: problem id=t8 type=numeric answer="12"
A company has 300 managers and 1,700 other staff. A stratified sample of 80 takes each group in proportion to its size. How many managers are in it?
solution: Managers are $300 / 2000 = 0.15$ of staff, and $0.15 \times 80 = 12$.
:::
