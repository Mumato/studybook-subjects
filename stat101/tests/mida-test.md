::: problem id=t1 type=numeric answer="10"
Find the mean of 8, 12, 15, 9, 6.

::: problem id=t2 type=numeric answer="8"
Find the median of 3, 9, 4, 7, 12, 10.
solution: Sorted: 3, 4, 7, 9, 10, 12. $(7 + 9)/2 = 8$.
:::

::: problem id=t3 type=choice
A hospital randomly picks 20 patients from each of its 6 wards. This is a:
- [ ] cluster sample
- [x] stratified sample
- [ ] systematic sample
- [ ] convenience sample
solution: A random sample from **every** group: stratified.
:::

::: problem id=t4 type=numeric answer="0.7"
$P(A) = 0.4$, $P(B) = 0.5$, $P(A \text{ and } B) = 0.2$. Find $P(A \text{ or } B)$.
solution: $0.4 + 0.5 - 0.2 = 0.7$.
:::

::: problem id=t5 type=numeric answer="0.2344" tolerance=0.001
Toss a fair coin 6 times. What is the probability of exactly 2 heads? (4 decimals)
solution: $\binom{6}{2}(0.5)^6 = 15/64 = 0.2344$.
:::

::: problem id=t6 type=numeric answer="1.7"
X = 1, 2, 3 with probabilities 0.5, 0.3, 0.2. Find $E(X)$.
solution: $0.5 + 0.6 + 0.6 = 1.7$.
:::

::: problem id=t7 type=numeric answer="0.0808"
X is normal with $\mu = 60$, $\sigma = 5$. Given $\Phi(1.4) = 0.9192$, find $P(X > 67)$.
solution: $z = 7/5 = 1.4$. $1 - 0.9192 = 0.0808$.
:::

::: problem id=t8 type=numeric answer="-1.25"
Data has mean 50 and SD 4. What is the z-score of 45?
solution: $(45 - 50)/4 = -1.25$.
:::
