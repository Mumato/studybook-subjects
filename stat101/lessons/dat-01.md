title: Populations, samples and variables
---
Statistics starts with a question about a group, and data collected to answer it. First, name the pieces. (OpenStax ch. 1)

::: rule
- The **population** is the whole group you want to know about. A **sample** is the part you actually measure.
- A **parameter** is a number that describes the population (usually unknown). A **statistic** describes the sample.
- A **variable** is what you record for each individual. **Categorical** (qualitative) variables put individuals in groups: eye colour, major. **Quantitative** variables are numbers you can average: height, income.
- Quantitative variables are **discrete** (counts: 0, 1, 2, ...) or **continuous** (measurements that can take any value in a range).
:::

::: example
A college surveys 200 of its 9,000 students and finds that 34% work part-time.
- Population: all 9,000 students. Sample: the 200 surveyed.
- 34% is a **statistic** (it describes the sample). The true share of all 9,000 is the **parameter**.
- "Works part-time (yes/no)" is a categorical variable.
:::

::: problem id=p1 type=choice
A researcher weighs 50 apples from an orchard of 20,000 trees. The 50 apples are:
- [ ] the population
- [x] the sample
- [ ] a parameter
- [ ] a variable
solution: They are the part that was actually measured.
:::

::: problem id=p2 type=choice
The average weight of **all** apples in the orchard is:
- [x] a parameter
- [ ] a statistic
- [ ] a sample
- [ ] a categorical variable
solution: It describes the whole population, so it's a parameter. It's usually unknown.
:::

::: problem id=p3 type=choice
Which variable is **categorical**?
- [ ] Number of siblings
- [ ] Time to run 100 m
- [x] Favourite sport
- [ ] Monthly rent
solution: Favourite sport puts people in groups. The others are numbers.
:::

::: problem id=p4 type=choice
"Number of text messages sent yesterday" is:
- [x] quantitative and discrete
- [ ] quantitative and continuous
- [ ] categorical
solution: It's a count: 0, 1, 2, ... with no values in between.
:::

::: problem id=p5 type=choice
"Time spent waiting for a bus" is:
- [ ] quantitative and discrete
- [x] quantitative and continuous
- [ ] categorical
solution: Time is measured and can take any value in a range.
:::

::: problem id=p6 type=choice
Postal codes are made of digits in some countries. As a variable, a postal code is:
- [x] categorical, because averaging them means nothing
- [ ] quantitative, because it's a number
- [ ] continuous
solution: A number that only labels a group is categorical. The "average postal code" has no meaning.
:::

::: problem id=p7 type=numeric answer="40"
In a sample of 250 voters, 100 support a new transit plan. What percent of the sample supports it?
solution: $100 / 250 = 0.40 = 40\%$. This is a statistic.
:::
