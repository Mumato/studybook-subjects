title: Confidence intervals for a proportion
---
Polls say "52%, plus or minus 3 points, 19 times out of 20". That's a 95% confidence interval for a proportion. (OpenStax ch. 8)

::: rule
$$\hat{p} \pm z^* \sqrt{\frac{\hat{p}(1 - \hat{p})}{n}}$$
- Use it when there are at least 10 successes and 10 failures in the sample.
- Sample size for a margin $E$: $n = \left(\frac{z^*}{E}\right)^2 \hat{p}(1 - \hat{p})$, rounded **up**. With no earlier estimate, use $\hat{p} = 0.5$ (the safest, largest $n$).
:::

::: example
520 of 1,000 voters favour a candidate: $\hat{p} = 0.52$.
SE $= \sqrt{0.52 \times 0.48/1000} = 0.0158$. 95% margin: $1.96 \times 0.0158 = 0.031$.
Interval: $0.52 \pm 0.031$, about 49% to 55%.
:::

::: problem id=p1 type=numeric answer="0.33"
132 of 400 students surveyed walk to school. What is $\hat{p}$?
solution: $132/400 = 0.33$.
:::

::: problem id=p2 type=numeric answer="0.0229" tolerance=0.0005
$\hat{p} = 0.3$ and $n = 400$. What is the standard error? (4 decimals)
solution: $\sqrt{0.3 \times 0.7/400} = \sqrt{0.000525} = 0.0229$.
:::

::: problem id=p3 type=numeric answer="0.0449" tolerance=0.001
Same sample ($\hat{p} = 0.3$, $n = 400$). What is the 95% margin of error? (4 decimals)
solution: $1.96 \times 0.0229 = 0.0449$.
:::

::: problem id=p4 type=numeric answer="1068"
A pollster wants a 95% margin of error of 0.03 and has no earlier estimate. How many people should be sampled?
solution: $n = (1.96/0.03)^2 \times 0.25 = 1067.1$; round up to 1068.
:::

::: problem id=p5 type=numeric answer="601"
Same, but a margin of 0.04. How many people?
solution: $(1.96/0.04)^2 \times 0.25 = 600.25$; round up to 601.
:::

::: problem id=p6 type=numeric answer="246"
An earlier study found 20% of drivers text while driving. How many drivers should be sampled for a 95% margin of 0.05?
solution: $(1.96/0.05)^2 \times 0.2 \times 0.8 = 245.9$; round up to 246.
:::

::: problem id=p7 type=choice creative=true
A 95% interval for a candidate's support is 0.46 to 0.54. Can you say the candidate has majority support?
- [ ] Yes: the whole interval is above 0.45
- [x] No: the interval includes values below 0.5 as well as above
- [ ] Yes: 0.54 is above 0.5
solution: The data fits both a majority and a minority. You'd need a bigger sample to tell.
:::
