id: ci-02
title: The t distribution
---
In real life you rarely know $\sigma$. Using the sample's $s$ instead adds uncertainty, so the interval uses a slightly wider distribution: Student's **t**. (OpenStax ch. 8)

::: rule
When $\sigma$ is unknown:
$$\bar{x} \pm t^* \frac{s}{\sqrt{n}}, \quad \text{degrees of freedom } df = n - 1$$
- $t$ curves are bell-shaped like $Z$ but with fatter tails, so $t^*$ is bigger than $z^*$.
- As $df$ grows, $t$ gets closer to $Z$.
- Needs a random sample, and a roughly normal population or a large $n$.
:::

::: example
16 light bulbs last $\bar{x} = 50$ days with $s = 8$. For 95% with $df = 15$, $t^* = 2.131$.
$E = 2.131 \times 8/\sqrt{16} = 2.131 \times 2 = 4.262$. Interval: $50 \pm 4.262$, from 45.74 to 54.26.
:::

::: problem id=p1 type=numeric answer="24"
A sample has 25 values. How many degrees of freedom does its t interval use?
solution: $df = n - 1 = 24$.
:::

::: problem id=p2 type=numeric answer="4.128" tolerance=0.01
$n = 25$, $s = 10$. With $t^* = 2.064$ (95%, df 24), what is the margin of error? (3 decimals)
solution: $2.064 \times 10/5 = 4.128$.
:::

::: problem id=p3 type=numeric answer="3"
$s = 12$ and $n = 16$. What is the standard error $s/\sqrt{n}$?
solution: $12/4 = 3$.
:::

::: problem id=p4 type=numeric answer="16.781" tolerance=0.01
$n = 10$, $\bar{x} = 20$, $s = 4.5$. With $t^* = 2.262$ (95%, df 9), find the **lower** end of the interval. (3 decimals)
solution: SE $= 4.5/\sqrt{10} = 1.423$. $E = 2.262 \times 1.423 = 3.219$. Lower end $= 20 - 3.219 = 16.781$.
:::

::: problem id=p5 type=numeric answer="98.809" tolerance=0.01
36 people have mean body temperature 98.2°F with $s = 1.8$. With $t^* = 2.030$ (95%, df 35), find the **upper** end. (3 decimals)
solution: SE $= 1.8/6 = 0.3$. $E = 2.030 \times 0.3 = 0.609$. Upper end $= 98.809$.
:::

::: problem id=p6 type=choice
Why is $t^*$ bigger than $z^*$ for the same confidence?
- [x] Estimating $\sigma$ with $s$ adds uncertainty, so the interval must be wider
- [ ] The t distribution has a bigger mean
- [ ] Samples are always small
solution: $s$ itself varies from sample to sample. Fatter tails account for that.
:::

::: problem id=p7 type=choice
For 95% confidence, which $df$ gives the $t^*$ closest to 1.96?
- [ ] 5
- [ ] 10
- [ ] 20
- [x] 200
solution: With more degrees of freedom, $t$ approaches $Z$.
:::
