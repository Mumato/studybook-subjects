title: Debt, equity and leverage
---
A firm's **capital structure** is its mix of debt and equity. Borrowing (leverage) changes who gets what, and how risky equity is. (Berk ch. 16.1)

::: rule
- An **unlevered** firm has no debt; a **levered** firm has some.
- Debtholders are paid first (a fixed amount); shareholders get what's left.
- So leverage makes equity **riskier**: its gains and losses are both magnified. Shareholders then demand a **higher expected return**.
- In **perfect capital markets** (no taxes, no costs of distress, no fees) the **total value of the firm doesn't change** with leverage: it only changes how the cash flows are split.
:::

::: example
A project costs \$800 and next year is worth \$1,400 or \$900 (equally likely): expected \$1,150. At $r_U = 15\%$ it's worth $1150 / 1.15 = 1000$.
Financed with \$500 of debt at 5%, equity gets $1400 - 525 = 875$ or $900 - 525 = 375$: expected \$625 on \$500, a 25% expected return instead of 15%.
:::

::: problem id=p1 type=numeric answer="1000" tolerance=0.5
An unlevered firm's cash flow next year is expected to be \$1,150. With $r_U = 15\%$, what is it worth today?
solution: $1150 / 1.15 = 1000$.
:::

::: problem id=p2 type=numeric answer="500" tolerance=0.5
In perfect markets, that firm borrows \$500. What is its equity now worth?
solution: Total value stays \$1,000; debt is \$500, so equity is $1000 - 500 = 500$.
:::

::: problem id=p3 type=numeric answer="25" tolerance=0.01
The levered shareholders expect \$625 next year on their \$500. What is their expected return? Type the percent.
solution: $625 / 500 - 1 = 25\%$.
:::

::: problem id=p4 type=numeric answer="-25" tolerance=0.01
In the bad state the firm is worth \$900 and the debt is owed \$525. What return do the levered shareholders get? Type the percent (negative for a loss).
solution: Equity gets $900 - 525 = 375$: $375 / 500 - 1 = -25\%$. Unlevered shareholders would have lost only 10%.
:::

::: problem id=p5 type=choice
Adding debt to a firm's capital structure makes its equity:
- [x] riskier, with a higher expected return
- [ ] safer, with a lower expected return
- [ ] riskier, with the same expected return
solution: Leverage magnifies equity's ups and downs, and investors demand more return for that risk.
:::

::: problem id=p6 type=choice
In perfect capital markets, borrowing to buy back shares:
- [ ] raises the firm's total value
- [ ] lowers the firm's total value
- [x] leaves the firm's total value unchanged
solution: The firm's cash flows don't change; only their split between lenders and shareholders does.
:::
