::: problem id=t1 type=choice
\$3,000 next year, growing 2% a year forever, at 8% is worth:
- [ ] \$37,500
- [x] \$50,000
- [ ] \$30,000
- [ ] \$51,000
solution: $3000 / (0.08 - 0.02) = 50000$.
:::

::: problem id=t2 type=choice
A project costs \$1,000 and returns \$1,200 in one year; the cost of capital is 15%. Which is true?
- [x] NPV = \$43.48 and IRR = 20%: accept
- [ ] NPV = \$200 and IRR = 20%: accept
- [ ] NPV = −\$43.48: reject
- [ ] IRR = 15%: indifferent
solution: $-1000 + 1200/1.15 = 43.48$; IRR $= 1200/1000 - 1 = 20\% > 15\%$.
:::

::: problem id=t3 type=choice
A firm is 70% equity (12%) and 30% debt (5%), tax rate 25%. Its WACC is:
- [ ] 9.90%
- [x] 9.53%
- [ ] 8.50%
- [ ] 10.13%
solution: $0.7 \times 12 + 0.3 \times 5 \times 0.75 = 8.4 + 1.125 = 9.525\%$.
:::

::: problem id=t4 type=choice
An unlevered firm worth \$500M adds \$200M of permanent debt; tax rate 26%. Ignoring distress costs, it's worth:
- [ ] \$500M
- [ ] \$700M
- [x] \$552M
- [ ] \$448M
solution: $500 + 0.26 \times 200 = 552$ million.
:::

::: problem id=t5 type=choice
A stock is at \$60 just before going ex-dividend on a \$2 dividend. In perfect markets the ex-dividend price is:
- [x] \$58
- [ ] \$60
- [ ] \$62
- [ ] \$30
solution: $60 - 2 = 58$.
:::

::: problem id=t6 type=choice
Shares trade at \$24; holders can buy one new share at \$18 for every 5 held. The theoretical ex-rights price is:
- [ ] \$21
- [x] \$23
- [ ] \$22.80
- [ ] \$18
solution: $(5 \times 24 + 18) / 6 = 23$.
:::

::: problem id=t7 type=choice
You paid \$2.50 for a call with a \$45 strike. The stock ends at \$51. Your profit is:
- [ ] \$6.00
- [x] \$3.50
- [ ] \$8.50
- [ ] −\$2.50
solution: Payoff $51 - 45 = 6$; profit $6 - 2.50 = 3.50$.
:::

::: problem id=t8 type=choice
A target worth \$300M on its own would cost \$360M; synergies are worth \$50M. The acquirer should:
- [ ] buy: synergies are positive
- [x] not buy: NPV is −\$10M
- [ ] buy: NPV is +\$50M
solution: Premium \$60M exceeds synergies of \$50M: $NPV = 50 - 60 = -10$.
:::
