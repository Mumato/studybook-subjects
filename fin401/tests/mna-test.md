::: problem id=t1 type=numeric answer="25" tolerance=0.01
A target trades at \$32 before a bid of \$40 a share. What is the premium? Type the percent.
solution: $(40 - 32) / 32 = 25\%$.
:::

::: problem id=t2 type=choice
A target worth \$900M alone is bought for \$1,050M; synergies are worth \$200M. The acquirer's NPV is:
- [ ] \$200M
- [ ] \$150M
- [x] \$50M
- [ ] −\$150M
solution: Premium paid \$150M; $200 - 150 = 50$ million.
:::

::: problem id=t3 type=choice
Which is the strongest economic reason for a merger?
- [ ] diversifying the firm's risk
- [ ] increasing earnings per share
- [x] cost savings from combining operations
- [ ] making the managers' firm larger
solution: Only real synergies create value.
:::

::: problem id=t4 type=numeric answer="0.75" tolerance=0.001
An acquirer's shares trade at \$48. It offers \$36 per target share, paid in its own shares. What is the exchange ratio?
solution: $36 / 48 = 0.75$.
:::

::: problem id=t5 type=choice
Which is **not** a takeover defence?
- [ ] poison pill
- [ ] staggered board
- [x] toehold
- [ ] white knight
solution: A toehold is a raider's tactic: buying shares before bidding.
:::

::: problem id=t6 type=choice
On average, who gains the most from acquisitions?
- [x] target shareholders
- [ ] acquirer shareholders
- [ ] bondholders of the acquirer
solution: Targets receive the takeover premium.
:::
