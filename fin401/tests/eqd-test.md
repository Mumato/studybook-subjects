::: problem id=t1 type=choice
A VC invests \$3 million for 20% of a start-up. The post-money valuation is:
- [ ] \$12 million
- [x] \$15 million
- [ ] \$3.6 million
- [ ] \$60 million
solution: $3 / 0.20 = 15$ million (pre-money \$12M).
:::

::: problem id=t2 type=numeric answer="15" tolerance=0.01
An IPO is priced at \$16 and closes its first day at \$18.40. What is the first-day return? Type the percent.
solution: $(18.40 - 16) / 16 = 15\%$.
:::

::: problem id=t3 type=choice
Shares trade at \$40. Holders can buy one new share at \$32 for every 3 they own. The theoretical ex-rights price is:
- [ ] \$36
- [x] \$38
- [ ] \$32
- [ ] \$40
solution: $(3 \times 40 + 32) / 4 = 38$.
:::

::: problem id=t4 type=choice
IPO underpricing means:
- [x] the offer price tends to be below the first-day trading price
- [ ] IPO shares are sold above their true value
- [ ] underwriters charge too little
solution: Buyers at the offer price usually gain on the first day.
:::

::: problem id=t5 type=choice
Which is an example of private debt?
- [ ] a debenture sold to the public
- [x] a bank term loan
- [ ] a government bond
solution: Bank loans and private placements aren't traded publicly.
:::

::: problem id=t6 type=choice
Investors require a higher yield on callable bonds because:
- [x] the issuer will call them when rates fall, cutting investors' returns
- [ ] callable bonds are always junior
- [ ] calls happen only in bankruptcy
solution: The call option belongs to the issuer, who uses it against investors' interests.
:::
