::: problem id=t1 type=choice
What is \$1,200 a year for 8 years (first payment in one year) worth today at 6%?
- [x] \$7,451.75
- [ ] \$7,898.86
- [ ] \$9,600.00
- [ ] \$5,988.16
solution: $\frac{1200}{0.06}(1 - 1.06^{-8}) = 7451.75$. (\$7,898.86 treats it as an annuity due.)
:::

::: problem id=t2 type=choice
A 10-year bond (\$1,000 face) pays a 5% coupon semi-annually; its yield is 6% (APR, semi-annual). Its price is closest to:
- [ ] \$926.40
- [x] \$925.61
- [ ] \$1,000.00
- [ ] \$1,077.95
solution: \$25 for 20 half-years at 3%: $\frac{25}{0.03}(1 - 1.03^{-20}) + 1000 \times 1.03^{-20} = 925.61$. (\$926.40 uses annual payments.)
:::

::: problem id=t3 type=choice
A firm just paid a \$1.80 dividend. Dividends grow 4% a year and $r_E = 10\%$. The share price is:
- [ ] \$30.00
- [x] \$31.20
- [ ] \$18.72
- [ ] \$45.00
solution: $Div_1 = 1.80 \times 1.04 = 1.872$; $1.872 / 0.06 = 31.20$. (\$30 forgets to grow the dividend.)
:::

::: problem id=t4 type=choice
A project costs \$5,000 and pays \$1,500, \$2,000 and \$2,500 over the next three years. At 10% you should:
- [ ] accept it: it returns \$6,000 for \$5,000
- [x] reject it: its NPV is about −\$105
- [ ] accept it: its NPV is about +\$105
solution: $-5000 + \frac{1500}{1.1} + \frac{2000}{1.1^2} + \frac{2500}{1.1^3} = -105.18$.
:::

::: problem id=t5 type=choice
Equity is worth \$400M (cost 11%) and debt \$100M (cost 6%); tax rate 26%. The WACC is closest to:
- [ ] 10.00%
- [x] 9.69%
- [ ] 8.50%
- [ ] 11.00%
solution: $0.8 \times 11 + 0.2 \times 6 \times 0.74 = 9.69\%$. (10.00% ignores the tax shield.)
:::

::: problem id=t6 type=choice
With no taxes, $r_U = 10\%$, $r_D = 4\%$ and $D/E = 0.25$. The cost of levered equity is:
- [ ] 10.0%
- [x] 11.5%
- [ ] 12.5%
- [ ] 8.5%
solution: $10 + 0.25 \times (10 - 4) = 11.5\%$.
:::

::: problem id=t7 type=choice
A firm adds \$300M of permanent debt and has a 25% tax rate. The interest tax shields add about how much value?
- [ ] \$300M
- [ ] \$225M
- [x] \$75M
- [ ] nothing, by MM
solution: $T_c D = 0.25 \times 300 = 75$ million.
:::

::: problem id=t8 type=choice
A stock pays a \$3 dividend and investors' effective dividend tax rate is 20%. On the ex-dividend date the price should drop by about:
- [ ] \$3.00
- [x] \$2.40
- [ ] \$0.60
- [ ] nothing
solution: $3 \times (1 - 0.20) = 2.40$.
:::
