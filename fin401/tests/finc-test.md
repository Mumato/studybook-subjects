::: problem id=t1 type=choice
A \$10,000 loan at 12% APR (compounded monthly) is repaid monthly over 2 years. The payment is closest to:
- [x] \$470.73
- [ ] \$416.67
- [ ] \$516.67
- [ ] \$591.70
solution: 1% a month for 24 months: $\frac{10000 \times 0.01}{1 - 1.01^{-24}} = 470.73$.
:::

::: problem id=t2 type=choice
With a fixed capital budget and many positive-NPV projects, the best way to choose is by:
- [ ] shortest payback
- [ ] highest IRR
- [x] highest profitability index
- [ ] largest initial investment
solution: The PI is NPV per dollar of the scarce budget.
:::

::: problem id=t3 type=choice
Comparable firms are 70% equity (beta 1.3) and 30% debt (beta 0.15). The risk-free rate is 3.5% and the market risk premium 5.5%. The project's cost of capital is closest to:
- [x] 8.75%
- [ ] 10.65%
- [ ] 9.00%
- [ ] 5.25%
solution: $\beta_U = 0.7 \times 1.3 + 0.3 \times 0.15 = 0.955$; $3.5 + 0.955 \times 5.5 = 8.75\%$. (10.65% uses the equity beta.)
:::

::: problem id=t4 type=choice
A firm has \$50M of debt at 7% and a 26% tax rate. Its yearly interest tax shield is:
- [ ] \$3.50M
- [x] \$0.91M
- [ ] \$13.0M
- [ ] \$2.59M
solution: Interest \$3.5M; $0.26 \times 3.5 = 0.91$ million.
:::

::: problem id=t5 type=choice
Dividends are taxed at 33% and capital gains at 13%. The effective dividend tax rate is closest to:
- [ ] 20.00%
- [x] 22.99%
- [ ] 33.00%
- [ ] 46.00%
solution: $(0.33 - 0.13) / 0.87 = 22.99\%$.
:::

::: problem id=t6 type=choice
A target's shares trade at \$25 before a bid of \$31. The takeover premium is:
- [ ] 6%
- [ ] 19.4%
- [x] 24%
- [ ] 31%
solution: $(31 - 25) / 25 = 24\%$.
:::

::: problem id=t7 type=choice
A \$1,000 bond converts into 32 shares; the stock is at \$35 at maturity. The holder should:
- [x] convert: the shares are worth \$1,120
- [ ] take the \$1,000 face value
- [ ] it makes no difference
solution: Conversion value $32 \times 35 = 1120 > 1000$. (Conversion price $= 1000/32 = 31.25 < 35$.)
:::

::: problem id=t8 type=choice
A VC invests \$5 million for 40% of a start-up. The pre-money valuation is:
- [ ] \$12.5 million
- [x] \$7.5 million
- [ ] \$2 million
- [ ] \$5 million
solution: Post-money $= 5 / 0.4 = 12.5$; pre-money $= 12.5 - 5 = 7.5$ million.
:::
