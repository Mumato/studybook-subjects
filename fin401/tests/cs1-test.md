::: problem id=t1 type=choice
In perfect capital markets, the value of a levered firm is:
- [ ] higher than the unlevered firm's
- [x] the same as the unlevered firm's
- [ ] lower than the unlevered firm's
solution: MM Proposition I: $V_L = V_U$.
:::

::: problem id=t2 type=choice
$r_U = 11\%$, $r_D = 5\%$, debt \$30M, equity \$70M, no taxes. The cost of levered equity is closest to:
- [ ] 11.0%
- [ ] 12.0%
- [x] 13.6%
- [ ] 15.0%
solution: $11 + \frac{30}{70}(11 - 5) = 11 + 2.57 = 13.57\%$.
:::

::: problem id=t3 type=numeric answer="11" tolerance=0.01
For the same firm, what is the WACC (no taxes)? Type the percent.
solution: With no taxes the WACC equals $r_U = 11\%$.
:::

::: problem id=t4 type=choice
As a firm adds debt (no taxes), its equity holders' expected return:
- [x] rises
- [ ] falls
- [ ] stays the same
solution: MM II: $r_E$ rises with $D/E$, because equity gets riskier.
:::

::: problem id=t5 type=numeric answer="20" tolerance=0.01
An unlevered firm has 10 million shares at \$20. In perfect markets it borrows \$50M to buy back shares. What is the share price afterwards?
solution: Value stays \$200M; equity $= 150$M; 2.5 million shares bought back at \$20, 7.5 million left: $150 / 7.5 = 20$.
:::

::: problem id=t6 type=choice
Which is **not** an assumption of perfect capital markets?
- [ ] no taxes
- [ ] no transaction or bankruptcy costs
- [x] firms can't borrow
- [ ] financing doesn't change the firm's cash flows from investment
solution: Firms (and investors) can borrow in perfect markets; MM is about what borrowing changes.
:::
