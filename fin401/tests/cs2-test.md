::: problem id=t1 type=choice
An unlevered firm is worth \$600M. It adds \$150M of permanent debt; the tax rate is 27%. Ignoring distress costs, the firm is now worth:
- [ ] \$600.0M
- [x] \$640.5M
- [ ] \$750.0M
- [ ] \$559.5M
solution: $600 + 0.27 \times 150 = 640.5$ million.
:::

::: problem id=t2 type=numeric answer="2.7" tolerance=0.01
A firm pays \$10M of interest a year and has a 27% tax rate. What is the yearly interest tax shield, in millions?
solution: $0.27 \times 10 = 2.7$ million.
:::

::: problem id=t3 type=choice
The trade-off theory says the value of a levered firm is:
- [ ] $V_U + T_c D$
- [x] $V_U$ + PV(tax shields) − PV(distress costs)
- [ ] $V_U$ − PV(tax shields)
- [ ] the same as $V_U$
solution: Tax shields add value; expected distress costs take it away.
:::

::: problem id=t4 type=choice
Which is an example of debt overhang?
- [ ] a healthy firm borrowing to buy back shares
- [x] a distressed firm refusing a positive-NPV project because lenders would get most of the gain
- [ ] a firm investing in a very risky project
solution: Debt overhang is under-investment caused by existing debt.
:::

::: problem id=t5 type=choice
According to the pecking order, a profitable firm with plenty of retained earnings that needs funds will most likely:
- [x] use its retained earnings
- [ ] issue new shares
- [ ] issue long-term debt
solution: Internal funds come first: no issuing costs and no negative signal.
:::

::: problem id=t6 type=choice
With corporate taxes, a firm announces a permanent debt-financed share buyback. Its share price should:
- [x] rise by the PV of the tax shield per share
- [ ] fall, because the firm is riskier
- [ ] not change, by MM
solution: The tax shield adds $T_c D$ to firm value, and current shareholders capture it at the announcement.
:::

::: problem id=t7 type=choice
Which firm faces the highest indirect costs of financial distress?
- [ ] a firm selling oil to large refiners
- [x] an airline whose customers worry about future flights
- [ ] a firm owning apartment buildings
solution: Customers avoid buying long-term services from a firm they fear will fail.
:::
