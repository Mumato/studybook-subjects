::: problem id=t1 type=choice
A firm is 65% equity (13%) and 35% debt (7%); its tax rate is 27%. Its WACC is closest to:
- [ ] 10.90%
- [x] 10.24%
- [ ] 9.10%
- [ ] 11.50%
solution: $0.65 \times 13 + 0.35 \times 7 \times 0.73 = 8.45 + 1.79 = 10.24\%$. (10.90% forgets the tax shield.)
:::

::: problem id=t2 type=numeric answer="10.95" tolerance=0.01
The risk-free rate is 2.5%, beta 1.3 and the market risk premium 6.5%. What is the cost of equity? Type the percent.
solution: $2.5 + 1.3 \times 6.5 = 10.95\%$.
:::

::: problem id=t3 type=choice
Why is the cost of debt taken after tax in the WACC?
- [ ] lenders pay tax on interest
- [x] interest payments are tax-deductible for the firm
- [ ] debt is less risky than equity
solution: Each dollar of interest lowers the firm's taxes, so debt effectively costs $r_D(1 - T_c)$.
:::

::: problem id=t4 type=choice
A firm has 10 million shares at \$40 and bonds with a book value of \$300M trading at 90% of face. The equity weight in its WACC is:
- [ ] 57.1%
- [x] 59.7%
- [ ] 40.3%
- [ ] 50%
solution: $E = 400$, $D = 0.9 \times 300 = 270$: $400 / 670 = 59.7\%$.
:::

::: problem id=t5 type=numeric answer="6" tolerance=0.01
A preferred share pays \$3 a year and trades at \$50. What is the cost of preferred? Type the percent.
solution: $3 / 50 = 6\%$.
:::

::: problem id=t6 type=choice
A firm's equity beta is 1.4; it is 50% debt (beta 0.2). Its asset beta is:
- [ ] 1.4
- [x] 0.8
- [ ] 1.6
- [ ] 0.7
solution: $0.5 \times 1.4 + 0.5 \times 0.2 = 0.8$.
:::

::: problem id=t7 type=choice
A project is much safer than the firm's typical project. Using the firm's WACC to value it would:
- [x] undervalue the project
- [ ] overvalue the project
- [ ] value it correctly
solution: The WACC is too high a rate for a safer project, so its cash flows get discounted too much.
:::
