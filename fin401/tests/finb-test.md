::: problem id=t1 type=choice
A 3-year bond (\$1,000 face) pays a 6% annual coupon and yields 4%. Its price is closest to:
- [ ] \$1,000.00
- [x] \$1,055.50
- [ ] \$946.54
- [ ] \$1,180.00
solution: $\frac{60}{0.04}(1 - 1.04^{-3}) + 1000 \times 1.04^{-3} = 1055.50$: a premium, since the coupon beats the yield.
:::

::: problem id=t2 type=choice
A stock costs \$32, its next dividend is \$1.60 and dividends grow 5%. Its cost of equity is:
- [ ] 5%
- [x] 10%
- [ ] 10.25%
- [ ] 15%
solution: $1.60 / 32 + 5\% = 5\% + 5\% = 10\%$.
:::

::: problem id=t3 type=choice
A \$120,000 asset: CCA rate 20%, tax 25%, cost of capital 8%, half-year rule. The PV of its CCA tax shield is closest to:
- [ ] \$21,429
- [x] \$20,635
- [ ] \$30,000
- [ ] \$24,000
solution: $\frac{120000 \times 0.2 \times 0.25}{0.28} \times \frac{1.04}{1.08} = 20634.92$.
:::

::: problem id=t4 type=choice
No taxes: $r_U = 9\%$, $r_D = 5\%$, $D/E = 0.5$. The cost of levered equity is:
- [ ] 9%
- [x] 11%
- [ ] 7%
- [ ] 13%
solution: $9 + 0.5 \times (9 - 5) = 11\%$.
:::

::: problem id=t5 type=choice
Spot is 1.36 CAD/USD; 1-year rates are 3.5% in Canada and 4.5% in the US. The 1-year forward rate (CAD/USD) is closest to:
- [x] 1.3470
- [ ] 1.3731
- [ ] 1.3600
- [ ] 1.4076
solution: $1.36 \times 1.035 / 1.045 = 1.3470$.
:::

::: problem id=t6 type=choice
You are **short** one futures contract on 1,000 units at \$80. It settles at \$83 the next day. Your cash flow that day is:
- [ ] +\$3,000
- [x] −\$3,000
- [ ] +\$83,000
- [ ] \$0
solution: The short loses when the price rises: $-1000 \times 3 = -3000$.
:::

::: problem id=t7 type=choice
A stock is at \$30; a 1-year European call with a \$30 strike costs \$3; $r_f = 5\%$. The matching put is worth about:
- [ ] \$3.00
- [x] \$1.57
- [ ] \$4.43
- [ ] \$0.00
solution: $P = 3 - 30 + 30/1.05 = 1.57$.
:::

::: problem id=t8 type=choice
A family owns 60% of firm A, which owns 30% of firm B. The family's share of B's cash flows is:
- [ ] 30%
- [ ] 60%
- [x] 18%
- [ ] 90%
solution: $0.6 \times 0.3 = 18\%$.
:::
