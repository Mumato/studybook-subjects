title: Hiragana: the N and H rows
---
Halfway through the basic hiragana! This lesson adds the N and H rows, including one sound English doesn't quite have.

::: rule
- The N row: !say[な] **na**, !say[に] **ni**, !say[ぬ] **nu**, !say[ね] **ne**, !say[の] **no**.
- The H row: !say[は] **ha**, !say[ひ] **hi**, !say[ふ] **fu**, !say[へ] **he**, !say[ほ] **ho**.
- ふ is softer than English "f": blow gently through slightly open lips, between an "h" and an "f". Typing `fu` or `hu` both work.
- Coming soon: when は and へ are used as **particles** (grammar words), they're read **wa** and **e**.
:::

![](assets/hir-nh.3x.png)

::: example
- !say[ねこ] = ne + ko = **neko**, "cat"
- !say[いぬ] = i + nu = **inu**, "dog"
- !say[はな] = ha + na = **hana**, "flower" (also "nose")
- !say[ほし] = ho + shi = **hoshi**, "star"
:::

::: problem id=p1 type=text answers="nu"
Type the reading: ぬ
solution: ぬ is **nu**.
Hear it: !say[ぬ]
:::

::: problem id=p2 type=text answers="fu;hu"
Type the reading: ふ
solution: ふ is **fu**, a soft "f".
Hear it: !say[ふ]
:::

::: problem id=p3 type=text answers="neko"
Read this word: ねこ
solution: ね (ne) + こ (ko) = **neko**, "cat".
Hear it: !say[ねこ]
:::

::: problem id=p4 type=text answers="hoshi;hosi"
Read this word: ほし
solution: ほ (ho) + し (shi) = **hoshi**, "star".
Hear it: !say[ほし]
:::

::: problem id=p5 type=choice
Which hiragana is **ho**?
- [ ] は
- [x] ほ
- [ ] け
solution: ほ (ho) is は (ha) with an extra horizontal line on top.
Hear it: !say[ほ]
:::

::: problem id=p6 type=choice
What does いぬ mean?
- [x] dog
- [ ] cat
- [ ] star
solution: いぬ (inu) is "dog"; ねこ (neko) is "cat".
:::

::: problem id=p7 type=choice
Which spells **hana** (flower)?
- [x] はな
- [ ] ほな
- [ ] はね
solution: は (ha) + な (na).
Hear it: !say[はな]
:::

::: problem id=p8 type=text answers="ふね"
Listen: !listen[ふね]
Type the word you hear (romaji turns into hiragana).
hint: Two syllables: an H-row sound with "u", then an N-row sound with "e".
solution: ふね (fune), "ship".
:::
