---
id: num-03
title: Telling the time
---
Time is number + a counter word: じ for o'clock and ふん for minutes. A few numbers change their sound, so listen carefully.

::: rule
- **O'clock** is number + じ: !say[いちじ] (1:00), !say[にじ] (2:00). Three are irregular: !say[よじ] (4:00), !say[しちじ] (7:00), !say[くじ] (9:00).
- **Minutes**: ふん or ぷん. !say[いっぷん] (1), !say[にふん] (2), !say[さんぷん] (3), !say[よんぷん] (4), !say[ごふん] (5), !say[ろっぷん] (6), !say[ななふん] (7), !say[はっぷん] (8), !say[きゅうふん] (9), !say[じゅっぷん] (10). Tens follow 10: にじゅっぷん (20), さんじゅうごふん (35).
- **Half past** is はん: !say[さんじはん] (3:30).
- **a.m. / p.m.** come first: !say[ごぜん くじ] (9 a.m.), !say[ごご ろくじ] (6 p.m.).
- Asking: !say[いま なんじ ですか。] *What time is it now?* Answer: !say[m|にじ じゅっぷん です。] *It's 2:10.*
:::

::: example
Making plans:

- A: !say[じゅぎょうは なんじ ですか。] *What time is class?*
- B: !say[m|ごぜん じゅうじはん です。] *It's at 10:30 a.m.*

Note the order: ごぜん (a.m.) → じゅうじ (10 o'clock) → はん (half).
:::

::: problem id=p1 type=text answers="よじ"
Type 4 o'clock in Japanese.
hint: Not よんじ.
solution: よじ (yoji).
Hear it: !say[よじ]
:::

::: problem id=p2 type=text answers="くじ"
Type 9 o'clock in Japanese.
hint: Not きゅうじ.
solution: くじ (kuji).
Hear it: !say[くじ]
:::

::: problem id=p3 type=choice
How do you say 7:30?
- [x] しちじはん
- [ ] ななじはん
- [ ] しちじさんじゅう
solution: 7 o'clock is しちじ, half past is はん. (しちじさんじゅっぷん is possible but はん is what people say.)
Hear it: !say[しちじはん]
:::

::: problem id=p4 type=text answers="ろっぷん"
Type "6 minutes".
hint: roppun
solution: ろっぷん (roppun).
Hear it: !say[ろっぷん]
:::

::: problem id=p5 type=choice
ごご さんじ means:
- [ ] 3 a.m.
- [x] 3 p.m.
- [ ] 3 minutes
solution: ごご is p.m., さんじ is 3 o'clock.
Hear it: !say[ごご さんじ]
:::

::: problem id=p6 type=text answers="いまなんじですか"
Type "What time is it now?"
hint: ima nanji desu ka
solution: いま なんじ ですか。
Hear it: !say[いま なんじ ですか。]
:::

::: problem id=p7 type=choice
Listen: !listen[m|いま ごぜん はちじ じゅっぷん です。]
What time is it?
- [x] 8:10 a.m.
- [ ] 8:10 p.m.
- [ ] 10:08 a.m.
solution: ごぜん (a.m.) はちじ (8:00) じゅっぷん (10 minutes): 8:10 a.m.
:::

::: problem id=p8 type=choice
Listen: !listen[ごご よじはん]
What time did you hear?
- [ ] 4:30 a.m.
- [x] 4:30 p.m.
- [ ] 9:30 p.m.
solution: ごご (p.m.) よじ (4:00) はん (half): 4:30 p.m.
:::
