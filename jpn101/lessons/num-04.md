id: num-04
title: This book, that place, whose: この, ここ, だれの
---
You know これ, それ, あれ (this one, that one). Japanese has a whole family of these **ko-so-a-do** words: the same four sounds make "this/that/that over there/which" for things, places and more.

::: rule
- **Before a noun**: !say[この ほん] (this book, near me), !say[その ほん] (that book, near you), !say[あの ほん] (that book over there), !say[どの ほん] (which book?). この/その/あの/どの always need a noun after them; これ/それ/あれ/どれ stand alone.
- **Places**: !say[ここ] (here), !say[そこ] (there, near you), !say[あそこ] (over there), !say[どこ] (where?): !say[トイレは どこですか。] *Where is the toilet?* !say[あそこです。] *Over there.*
- **Whose**: !say[だれの] + noun: !say[これは だれの かさですか。] *Whose umbrella is this?* Answer with a name + の: !say[わたしのです。] *It's mine.* (の can stand for the noun.)
- The pattern: **ko** = near me, **so** = near you, **a** = far from both, **do** = question.
:::

::: example
At a lost-and-found:

- A: !say[すみません、あの かばんは だれのですか。] *Excuse me, whose is that bag over there?*
- B: !say[m|やまださんのです。] *It's Yamada's.*
- A: !say[じゃあ、この かさは？] *Then, this umbrella?*
- B: !say[m|それは わたしのです。どこに ありましたか。] *That's mine. Where was it?*
- A: !say[ここです。] *Here.*
:::

::: problem id=p1 type=choice
"This book" is:
- [x] この ほん
- [ ] これ ほん
- [ ] この ほんは これ
solution: この + noun. これ stands alone ("this one").
Hear it: !say[この ほん]
:::

::: problem id=p2 type=choice
The clerk is holding a bag. You point and ask "How much is that bag?":
- [ ] この かばんは いくらですか。
- [x] その かばんは いくらですか。
- [ ] あの かばんは いくらですか。
solution: It's near the listener: その.
Hear it: !say[その かばんは いくらですか。]
:::

::: problem id=p3 type=text answers="トイレはどこですか"
Type "Where is the toilet?"
hint: toire wa doko desu ka
solution: トイレは どこですか。
Hear it: !say[トイレは どこですか。]
:::

::: problem id=p4 type=text answers="これはだれのかさですか"
Type "Whose umbrella is this?"
hint: kore wa dare no kasa desu ka
solution: これは だれの かさですか。
Hear it: !say[これは だれの かさですか。]
:::

::: problem id=p5 type=choice
"It's mine" is:
- [x] わたしのです。
- [ ] わたしです。
- [ ] わたしのかさの です。
solution: わたしの (mine): の stands in for the noun.
Hear it: !say[わたしのです。]
:::

::: problem id=p6 type=choice
Which is wrong?
- [ ] どの えいがを みますか。
- [x] どれ えいがを みますか。
- [ ] どれを みますか。
solution: どれ stands alone; before a noun use どの.
:::

::: problem id=p7 type=choice
Listen: !listen[m|ぎんこうは あそこです。]
Where is the bank?
- [ ] right here
- [ ] near the listener
- [x] over there
solution: あそこ: over there, away from both speakers.
:::

::: problem id=p8 type=choice
Listen: !listen[この とけいは あにのです。]
Whose watch is it?
- [ ] the speaker's
- [x] the speaker's older brother's
- [ ] the teacher's
solution: あにの: my older brother's.
:::
