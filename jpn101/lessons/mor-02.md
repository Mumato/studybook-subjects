---
id: mor-02
title: I want to: ～たい, and because: ～から
---
Two patterns that let you talk about wishes and reasons: "I want to go to Japan, because I like anime."

::: rule
- **Want to do**: drop ます, add **たいです**: いきます → !say[いきたいです] (I want to go), たべます → !say[たべたいです] (I want to eat).
- **Don't want to**: **たくないです**: !say[はたらきたくないです] *I don't want to work.*
- Ask what someone wants: !say[なにを したいですか。] *What do you want to do?* (In polite talk, asking a superior about their wishes directly can sound pushy: use it with friends and classmates.)
- **Because**: reason + **から**, then the result: !say[あついですから、まどを あけます。] *It's hot, so I'll open the window.*
- Answering **why** (!say[どうして]): !say[どうして にほんごを べんきょうしますか。] *Why do you study Japanese?* → !say[アニメが すきですから。] *Because I like anime.*
:::

::: example
- A: !say[なつやすみに なにを したいですか。] *What do you want to do in the summer holidays?*
- B: !say[m|にほんに いきたいです。ほっかいどうの うみが みたいです。] *I want to go to Japan. I want to see the sea in Hokkaido.*
- A: !say[どうして ほっかいどう ですか。] *Why Hokkaido?*
- B: !say[m|すずしいですから。] *Because it's cool.*

With たい, the thing wanted can take が instead of を: うみ**が** みたいです.
:::

::: problem id=p1 type=text answers="のみたいです"
Type "I want to drink." (from のみます)
hint: nomitai desu
solution: のみたいです: のみ + たいです.
Hear it: !say[のみたいです]
:::

::: problem id=p2 type=text answers="いきたくないです"
Type "I don't want to go."
hint: ikitakunai desu
solution: いきたくないです.
Hear it: !say[いきたくないです]
:::

::: problem id=p3 type=choice
みたいです means:
- [x] I want to see/watch.
- [ ] I saw.
- [ ] Let's watch.
solution: み (from みます) + たいです.
Hear it: !say[みたいです]
:::

::: problem id=p4 type=choice
Put the reason first: "I'll go home, because I'm tired" (つかれました = I'm tired).
- [x] つかれましたから、うちに かえります。
- [ ] うちに かえりますから、つかれました。
- [ ] つかれましたまで、うちに かえります。
solution: Reason + から, then what happens: つかれましたから、かえります.
Hear it: !say[つかれましたから、うちに かえります。]
:::

::: problem id=p5 type=text answers="どうしてですか"
Type "Why?" (politely)
hint: doushite desu ka
solution: どうしてですか。
Hear it: !say[どうしてですか。]
:::

::: problem id=p6 type=choice
How do you answer "why" with "because it's cheap" (やすい)?
- [ ] やすいですまで。
- [x] やすいですから。
- [ ] やすいたいです。
solution: reason + から: やすいですから.
Hear it: !say[やすいですから。]
:::

::: problem id=p7 type=choice
Listen: !listen[m|あしたは しけんが ありますから、こんばんは べんきょうしたいです。]
Why does the speaker want to study tonight?
- [x] There's an exam tomorrow.
- [ ] They like studying at night.
- [ ] They studied last night.
solution: あしたは しけんが ありますから: "because there's an exam tomorrow".
:::

::: problem id=p8 type=open
Say one thing you want to do this year, and why.
!speak[my wish and reason]
solution: For example: にほんに いきたいです。にほんの りょうりが すきですから。
:::
