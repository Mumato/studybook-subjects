id: gre-02
title: Introducing yourself: は, です, の and か
---
Your first real sentences! With one pattern and three small words you can say who you are, ask questions, and talk about where you belong.

::: rule
- **X は Y です** means "X is Y". は (the topic particle, read **wa**) marks what you're talking about; です (desu) ends a polite sentence.
- To say "is not", replace です with **じゃないです** (or the more formal じゃありません).
- Add **か** at the end to make a question: がくせいですか。 "Are you a student?" Answer はい (yes) or いいえ (no).
- **の** links two nouns like "'s" or "of": わたしの なまえ "my name", だいがくの がくせい "a university student".
- Nationality: country + じん: にほんじん (Japanese person). People are addressed by name + さん; Japanese rarely say あなた ("you").
:::

::: example
Meeting someone for the first time:

はじめまして。わたしは たなか です。{日本|にほん}じん です。だいがくの いちねんせい です。よろしく おねがいします。

*Nice to meet you. I'm Tanaka. I'm Japanese. I'm a first-year university student. Pleased to meet you.*

(Small text above a kanji, like the にほん over 日本, is **furigana**: it shows how to read the kanji.)
:::

::: problem id=p1 type=text answers="わたしはがくせいです;がくせいです"
Type "I am a student." in Japanese. (がくせい = student)
hint: watashi wa gakusei desu
solution: わたしは がくせいです。 The particle は is typed *wa* or *ha*; both work.
:::

::: problem id=p2 type=text answers="がくせいですか;あなたはがくせいですか"
Type the question "Are you a student?" (you can leave out "you").
hint: Add ka to the end of a sentence.
solution: がくせいですか。 Leaving out "you" is natural in Japanese.
:::

::: problem id=p3 type=choice
How do you say "I am not a teacher"?
- [ ] せんせいです
- [x] せんせいじゃないです
- [ ] せんせいですか
solution: Replace です with じゃないです.
:::

::: problem id=p4 type=choice
What does わたしの なまえ mean?
- [x] my name
- [ ] I am a name
- [ ] your name
solution: の links the nouns: わたし (I) + の + なまえ (name) = "my name".
:::

::: problem id=p5 type=text answers="にほんじん"
Type "a Japanese person".
hint: Japan is にほん; add じん.
solution: にほんじん (nihonjin).
:::

::: problem id=p6 type=choice
Someone asks がくせいですか。 You are a student. How do you answer?
- [x] はい、がくせいです。
- [ ] いいえ、がくせいです。
- [ ] はい、がくせいじゃないです。
solution: はい (yes) and then repeat the statement.
:::

::: problem id=p7 type=choice
What is the small text above the kanji in {日本|にほん}?
- [ ] a translation into English
- [x] furigana: the reading of the kanji in hiragana
- [ ] the stroke order
solution: Furigana help learners (and children) read kanji they don't know yet.
:::

::: problem id=p8 type=choice creative=true
In English you'd ask a classmate "Are *you* a student?" Why would a Japanese speaker usually say たなかさんは がくせいですか instead of using あなた ("you")?
- [ ] あなた is a rude swear word.
- [x] Using the person's name with さん is the natural, polite way; あなた can sound distant or overly direct, and is often how wives address husbands.
- [ ] Japanese has no word for "you".
solution: Japanese often leaves "you" out altogether, or uses the person's name, title (せんせい) or role. あなた exists, but is used much less than "you" in English.
:::
