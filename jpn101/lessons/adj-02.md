---
id: adj-02
title: Past adjectives, すき and きらい
---
To describe yesterday's trip or last night's dinner, adjectives need a past tense. You'll also learn to say what you like and dislike.

::: rule
- **い-adjectives, past**: drop い, add **かったです**: !say[たのしかったです] (it was fun). Past negative: **くなかったです**: !say[たのしくなかったです] (it wasn't fun).
- **な-adjectives, past**: add **でした**: !say[しずかでした] (it was quiet). Past negative: **じゃなかったです**: !say[しずかじゃなかったです].
- いい (good) again uses よ: !say[よかったです] (it was good).
- **Likes**: !say[すしが すきです] *I like sushi.* **Dislikes**: !say[やさいが きらいです] *I dislike vegetables.* The thing liked takes **が**, not を.
- **だいすき** is "love", **あまり すきじゃないです** is "don't really like".
- Asking: !say[どんな おんがくが すきですか。] *What kind of music do you like?*
:::

::: example
After a trip:

- A: !say[りょこうは どうでしたか。] *How was your trip?*
- B: !say[m|とても たのしかったです。てんきも よかったです。でも、ホテルは あまり きれいじゃなかったです。] *It was a lot of fun. The weather was good too. But the hotel wasn't very clean.*
:::

::: problem id=p1 type=text answers="おいしかったです"
Type "It was tasty." (from おいしい)
hint: oishikatta desu
solution: おいしかったです (oishikatta desu).
Hear it: !say[おいしかったです]
:::

::: problem id=p2 type=text answers="ひまでした"
Type "I was free." (from ひま)
hint: hima deshita
solution: ひまでした: な-adjectives take でした.
Hear it: !say[ひまでした]
:::

::: problem id=p3 type=choice
How do you say "It was good"?
- [ ] いかったです
- [x] よかったです
- [ ] いいでした
solution: いい → よかったです.
Hear it: !say[よかったです]
:::

::: problem id=p4 type=choice
"The test wasn't difficult" (むずかしい) is:
- [x] むずかしくなかったです
- [ ] むずかしいじゃなかったです
- [ ] むずかしかったです
solution: い-adjective past negative: drop い + くなかったです.
Hear it: !say[むずかしくなかったです]
:::

::: problem id=p5 type=choice
Fill in: ねこ ＿ すきです。 (I like cats.)
- [ ] を
- [x] が
- [ ] で
solution: With すき and きらい, the liked thing takes が.
Hear it: !say[ねこが すきです]
:::

::: problem id=p6 type=text answers="どんなおんがくがすきですか"
Type "What kind of music do you like?"
hint: donna ongaku ga suki desu ka
solution: どんな おんがくが すきですか。
Hear it: !say[どんな おんがくが すきですか。]
:::

::: problem id=p7 type=choice
Listen: !listen[m|わたしは にくが だいすきです。でも、さかなは あまり すきじゃないです。]
What doesn't the speaker really like?
- [ ] meat
- [x] fish
- [ ] vegetables
solution: にくが だいすきです (I love meat). さかなは あまり すきじゃないです (I don't really like fish).
:::

::: problem id=p8 type=open
Say how your last weekend was, with one い-adjective and one な-adjective in the past tense.
!speak[my weekend]
solution: For example: しゅうまつは とても たのしかったです。こうえんは しずかでした。
:::
