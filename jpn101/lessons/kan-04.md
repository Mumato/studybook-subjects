id: kan-04
title: Kanji: position, family and people
---
These kanji let you write the position words and family words from the last two parts. Several are simple pictures: 上 and 下 point up and down from a line, 子 is a child with arms out, and 女 is a kneeling woman.

::: rule
- Position: !say[うえ] **上** up, on; !say[した] **下** down, under; !say[ひだり] **左** left; !say[みぎ] **右** right; !say[まえ] **前** in front, before; !say[うしろ] **後** behind, after; !say[そと] **外** outside.
- Family and people: !say[ちち] **父** father; !say[はは] **母** mother; !say[おとこ] **男** man; !say[おんな] **女** woman; !say[こ] **子** child.
- Compounds you know: **女の子** !say[おんなのこ] girl, **男の人** !say[おとこのひと] man, **外国人** !say[がいこくじん] foreigner, **午前** !say[ごぜん] a.m. and **午後** !say[ごご] p.m. (**午** is noon).
- Okurigana again: **上** alone is うえ, but in compounds it can be じょう: you'll meet those readings in JPN102. For now, learn the word readings shown here.
- 前 also means "before" in time: {三時|さんじ}の{前|まえ} *before 3 o'clock*.
:::

::: example
A note on a classroom door:

{午後|ごご}の クラスは {上|うえ}の {教室|きょうしつ}です。{父|ちち}{母|はは}の {方|かた}は {右|みぎ}の へやへ どうぞ。

*The afternoon class is in the classroom upstairs. Parents, please go to the room on the right.*

!say[ごごの クラスは うえの きょうしつです。ふぼの かたは みぎの へやへ どうぞ。]

父母 together is read **ふぼ**, "parents": compounds often use the Chinese-style readings.
:::

::: problem id=p1 type=choice
What does 下 mean?
- [ ] up
- [x] down, under
- [ ] behind
solution: 下 (した) points down from the line: under.
Hear it: !say[した]
:::

::: problem id=p4 type=choice
Which kanji is "mother"?
- [ ] 父
- [x] 母
- [ ] 毎
solution: 母 (はは). 父 is father; 毎 (every) looks similar but has a different top.
Hear it: !say[はは]
:::

::: problem id=p5 type=choice
午後 means:
- [ ] a.m.
- [x] p.m.
- [ ] noon
solution: 午後 (ごご): after noon, p.m. 午前 (ごぜん) is a.m.
Hear it: !say[ごご]
:::

::: problem id=p6 type=text answers="がいこくじん"
Type the reading of 外国人.
hint: gaikokujin
solution: がいこくじん, a foreigner: 外 (outside) 国 (country) 人 (person).
Hear it: !say[がいこくじん]
:::

::: problem id=p7 type=choice

- [ ] 外

:::
