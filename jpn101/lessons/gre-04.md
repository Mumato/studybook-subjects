id: gre-04
title: Reading: introductions on a class board
---
University language courses always include reading practice: short texts using what you've learned. Here are three students' introductions from a class message board. Read each one, listen to it, then answer the questions.

::: rule
How to read a Japanese passage:
- **Read it twice.** First for the general idea, then for details.
- **Find the topic** (the word before は) and the **verb at the end** of each sentence: that's the skeleton.
- **Don't stop at unknown words.** Guess from context, then check.
- **Listen** with ▶ and follow the text: it trains your eyes and ears together.
:::

::: example
Three introductions:

はじめまして。わたしは たなか ゆき です。にほんじん です。だいがくの いちねんせい です。せんこうは けいざい です。どうぞ よろしく。

!say[はじめまして。わたしは たなか ゆき です。にほんじん です。だいがくの いちねんせい です。せんこうは けいざい です。どうぞ よろしく。]

はじめまして。キム です。かんこくじん です。にねんせい です。せんこうは にほんご です。よろしく おねがいします。

!say[m|はじめまして。キム です。かんこくじん です。にねんせい です。せんこうは にほんご です。よろしく おねがいします。]

はじめまして。マリア です。メキシコじん です。だいがくいんせい です。せんこうは びじゅつ です。よろしく！

!say[はじめまして。マリア です。メキシコじん です。だいがくいんせい です。せんこうは びじゅつ です。よろしく！]

New words: せんこう major, けいざい economics, かんこく Korea, だいがくいんせい graduate student, びじゅつ art.
:::

::: problem id=p1 type=choice
What does Tanaka study?
- [x] economics
- [ ] Japanese
- [ ] art
solution: せんこうは けいざい です: her major is economics.
:::

::: problem id=p2 type=choice
Where is Kim from?
- [ ] Japan
- [x] Korea
- [ ] Mexico
solution: かんこくじん です: Korean.
:::

::: problem id=p3 type=choice
Who is a graduate student?
- [ ] Tanaka
- [ ] Kim
- [x] Maria
solution: マリア: だいがくいんせい です.
:::

::: problem id=p4 type=choice
What year is Kim in?
- [ ] first year
- [x] second year
- [ ] fourth year
solution: にねんせい: second-year student.
:::

::: problem id=p5 type=choice
Which introduction is the most casual?
- [ ] Tanaka's
- [ ] Kim's
- [x] Maria's
solution: Maria ends with just よろしく！, the short casual form. Kim's よろしく おねがいします is the most polite.
:::

::: problem id=p6 type=text answers="にほんご"
Type Kim's major in Japanese.
hint: nihongo
solution: にほんご.
Hear it: !say[にほんご]
:::

::: problem id=p7 type=open
Now write your own introduction for the board, in the same style (name, nationality, year, major, closing phrase), and say it aloud.
!speak[my board introduction]
solution: For example: はじめまして。（name） です。（nationality）じん です。いちねんせい です。せんこうは （major） です。よろしく おねがいします。 Majors: すうがく (math), れきし (history), コンピューター (computer science), ぶんがく (literature).
:::
