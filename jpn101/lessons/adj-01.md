---
id: adj-01
title: い-adjectives and な-adjectives
---
Japanese adjectives come in two types, named after how they end. They behave differently in the negative, so knowing the type matters.

::: rule
- **い-adjectives** end in い: !say[おおきい] (big), !say[ちいさい] (small), !say[たかい] (expensive, tall), !say[やすい] (cheap), !say[おいしい] (tasty), !say[おもしろい] (interesting), !say[むずかしい] (difficult), !say[あたらしい] (new).
- **な-adjectives** need な before a noun: !say[しずか] (quiet), !say[きれい] (pretty, clean), !say[げんき] (lively, well), !say[ゆうめい] (famous), !say[すき] (liked), !say[ひま] (free, not busy). きれい ends in い but is a な-adjective: learn it as an exception.
- **Before a noun**: い-adj as is, な-adj + な: !say[たかい とけい] (an expensive watch), !say[しずかな まち] (a quiet town).
- **Is**: !say[たかいです], !say[しずかです].
- **Is not**: い-adj: drop い, add **くないです**: !say[たかくないです]. な-adj: add **じゃないです**: !say[しずかじゃないです].
- One irregular: いい (good) → !say[よくないです] (not good).
- **とても** (very) strengthens an adjective: !say[とても おいしいです].
:::

::: example
Talking about your town:

- A: !say[たなかさんの まちは どんな まち ですか。] *Tanaka, what kind of town is yours?*
- B: !say[m|ちいさい まち です。とても しずかです。でも、あまり ゆうめいじゃないです。] *It's a small town. It's very quiet. But it's not very famous.*
:::

::: problem id=p1 type=text answers="やすくないです"
Type "It's not cheap." (from やすい)
hint: Drop い, add kunai desu.
solution: やすくないです (yasukunai desu).
Hear it: !say[やすくないです]
:::

::: problem id=p2 type=text answers="ひまじゃないです"
Type "I'm not free." (from ひま, a な-adjective)
hint: hima ja nai desu
solution: ひまじゃないです: な-adjectives take じゃないです.
Hear it: !say[ひまじゃないです]
:::

::: problem id=p3 type=choice
Which is correct for "a quiet room"?
- [ ] しずか へや
- [x] しずかな へや
- [ ] しずかい へや
solution: A な-adjective takes な before a noun: しずかな へや.
Hear it: !say[しずかな へや]
:::

::: problem id=p4 type=choice
"It's not pretty" (きれい) is:
- [ ] きれくないです
- [x] きれいじゃないです
- [ ] きれいくないです
solution: きれい is a な-adjective despite the final い, so it takes じゃないです.
Hear it: !say[きれいじゃないです]
:::

::: problem id=p5 type=choice
How do you say "It's not good"?
- [ ] いくないです
- [x] よくないです
- [ ] いいじゃないです
solution: いい is irregular: its negative is よくないです.
Hear it: !say[よくないです]
:::

::: problem id=p6 type=choice
Which is an い-adjective?
- [x] むずかしい
- [ ] げんき
- [ ] ゆうめい
solution: むずかしい (difficult) is an い-adjective. げんき and ゆうめい are な-adjectives.
:::

::: problem id=p7 type=choice
Listen: !listen[m|この レストランは とても おいしいです。でも、たかいです。]
What does the speaker say about the restaurant?
- [x] The food is very tasty, but it's expensive.
- [ ] It's cheap and tasty.
- [ ] It's not tasty, and it's expensive.
solution: とても おいしいです (very tasty). でも、たかいです (but expensive).
:::

::: problem id=p8 type=choice creative=true
Why might Japanese have two kinds of adjectives?
- [x] な-adjectives are mostly noun-like words (many from Chinese, like ゆうめい) that need a linking word, while い-adjectives are native words that work like verbs and change their own endings.
- [ ] な-adjectives are only used for people.
- [ ] It is random which ending a word has.
solution: い-adjectives behave like verbs (they change form: たかくない, たかかった). な-adjectives behave like nouns (they use です, じゃない, でした). Many な-adjectives came from Chinese.
:::
