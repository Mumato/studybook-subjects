title: Kanji: numbers and 円
---
**Kanji** are characters borrowed from Chinese. Each one carries a meaning, and most have two kinds of reading: an **on-reading** (from Chinese, used in compounds) and a **kun-reading** (native Japanese). The number kanji are the perfect place to start: you already know their readings.

::: rule
- !say[いち] **一** one, !say[に] **二** two, !say[さん] **三** three: one, two and three lines.
- !say[よん] **四** four, !say[ご] **五** five, !say[ろく] **六** six, !say[なな] **七** seven, !say[はち] **八** eight, !say[きゅう] **九** nine, !say[じゅう] **十** ten.
- !say[ひゃく] **百** hundred, !say[せん] **千** thousand, !say[まん] **万** ten thousand.
- !say[えん] **円** yen (and "circle").
- Numbers build exactly as in speech: **三十五** = さんじゅうご (35), **二千円** = にせんえん (¥2,000), **一万** = いちまん. Sound changes stay: **三百** is さんびゃく.
- Japanese text uses kanji numbers in vertical writing and on menus and signs; everyday horizontal text often uses 1, 2, 3.
- Stroke order rules: **top to bottom**, **left to right**, and horizontal before vertical when they cross (十: the bar first).
:::

::: example
A price tag at a temple shop:

**お守り　八百円**

おまもり　はっぴゃくえん: *Charm, ¥800.* 八 (8) + 百 (100) = 八百, read はっぴゃく.
:::

::: problem id=p1 type=numeric answer="7"
What number is 七?
solution: 七 is なな (or しち), seven: 7.
Hear it: !say[なな]
:::

::: problem id=p2 type=numeric answer="40"
What number is 四十?
solution: 四 (4) × 十 (10) = 40, よんじゅう.
Hear it: !say[よんじゅう]
:::

::: problem id=p3 type=numeric answer="600"
What number is 六百?
solution: 六 (6) × 百 (100) = 600, read ろっぴゃく.
Hear it: !say[ろっぴゃく]
:::

::: problem id=p4 type=text answers="さんぜんえん"
Type the reading of 三千円.
hint: The sound changes: sanzen.
solution: さんぜんえん (sanzen en), ¥3,000.
Hear it: !say[さんぜんえん]
:::

::: problem id=p5 type=choice
Which is 9?
- [ ] 六
- [x] 九
- [ ] 八
solution: 九 is nine (きゅう). 六 is six, 八 is eight.
Hear it: !say[きゅう]
:::

::: problem id=p6 type=numeric answer="15000"
How many yen is 一万五千円?
solution: 一万 (10,000) + 五千 (5,000) = ¥15,000.
Hear it: !say[いちまんごせんえん]
:::

::: problem id=p7 type=choice
How is 円 read in prices?
- [x] えん
- [ ] まる
- [ ] よん
solution: In prices 円 is えん. (Its other meaning, "circle", is read まる in some words.)
Hear it: !say[えん]
:::

::: problem id=p8 type=choice creative=true
English speakers often notice that "yen" and 円 (えん) don't sound the same. Where might "yen" have come from?
- [x] Older romanizations: early Western visitors wrote the sound as "yen", following a pronunciation of the time and older spelling habits.
- [ ] It's a different, unrelated word.
- [ ] "Yen" is the Chinese reading.
solution: "Yen" comes from older spellings used by Westerners in the 1800s. In modern Japanese the word is simply えん. (Chinese reads the character as *yuán*.)
:::

::: problem id=p9 type=draw answer="三"

solution: 三 has 3 strokes. Three horizontal strokes, top to bottom; the bottom one is the longest.
:::

::: problem id=p10 type=draw answer="十"

::: problem id=p11 type=draw answer="円"
Write 円 **yen**.
solution: 円 has 4 strokes. The left side, the top and right side in one stroke, the short vertical in the middle, then the bar across the bottom of the box.
:::
