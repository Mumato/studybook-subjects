---
id: plc-02
title: Counting things and people
---
In Japanese you don't just say "three apples": you add a **counter** that fits the kind of thing. Most counters use the numbers you know, with a few sound changes, and there's a general-purpose set for when you're not sure.

::: rule
- **General things** (～つ, up to 10): !say[ひとつ], !say[ふたつ], !say[みっつ], !say[よっつ], !say[いつつ], !say[むっつ], !say[ななつ], !say[やっつ], !say[ここのつ], !say[とお]. "How many?" is !say[いくつ].
- **People** (～人): !say[ひとり] (1), !say[ふたり] (2), then regular: !say[さんにん], !say[よにん] (4, not よんにん), !say[ごにん]. "How many people?" !say[なんにん].
- **Long, thin things** (pens, bottles, umbrellas: ～本): !say[いっぽん], !say[にほん], !say[さんぼん], !say[よんほん], !say[ろっぽん], !say[はっぽん], !say[じゅっぽん]. Ask with !say[なんぼん].
- **Flat things** (paper, tickets, shirts: ～枚): !say[いちまい], !say[にまい], !say[さんまい]: no sound changes.
- **Word order**: thing を number+counter verb: !say[りんごを みっつ ください。] *Three apples, please.* !say[がくせいが ふたり います。] *There are two students.*
:::

::: example
At a café counter:

- Clerk: !say[m|なんめいさま ですか。] *How many people?* (a polite なんにん)
- You: !say[ふたりです。] *Two.*
- You: !say[コーヒーを ふたつと、ケーキを ひとつ ください。] *Two coffees and one cake, please.*
:::

::: problem id=p1 type=text answers="みっつ"
Type "three (things)" with the general counter.
hint: mittsu
solution: みっつ (mittsu).
Hear it: !say[みっつ]
:::

::: problem id=p2 type=choice
How do you say "two people"?
- [ ] ににん
- [x] ふたり
- [ ] ふたつ
solution: 1 and 2 people are irregular: ひとり, ふたり.
Hear it: !say[ふたり]
:::

::: problem id=p3 type=choice
Which counter for pencils?
- [ ] ～まい
- [x] ～ほん
- [ ] ～にん
solution: Pencils are long and thin: ～本 (ほん/ぼん/ぽん).
:::

::: problem id=p4 type=text answers="さんぼん"
Type "three (bottles)".
hint: The sound changes: sanbon.
solution: さんぼん (sanbon).
Hear it: !say[さんぼん]
:::

::: problem id=p5 type=text answers="きっぷをにまいください"
Type "Two tickets, please." (ticket = きっぷ)
hint: kippu o nimai kudasai
solution: きっぷを にまい ください。 Tickets are flat: ～まい.
Hear it: !say[きっぷを にまい ください。]
:::

::: problem id=p6 type=choice
How do you say "four people"?
- [ ] よんにん
- [x] よにん
- [ ] しにん
solution: よにん (yonin) is the exception.
Hear it: !say[よにん]
:::

::: problem id=p7 type=numeric answer="6"
Listen: !listen[m|りんごを むっつ ください。]
How many apples does the speaker want?
solution: むっつ is six: 6.
:::

::: problem id=p8 type=choice
Listen: !listen[m|クラスに がくせいが ななにん います。]
How many students are in the class?
- [ ] 5
- [x] 7
- [ ] 17
solution: ななにん: seven people.
:::
