title: Hiragana: the S and T rows
---
Two more rows, and two surprises: a couple of characters don't follow the pattern you'd expect.

::: rule
- The S row: !say[さ] **sa**, !say[し] **shi**, !say[す] **su**, !say[せ] **se**, !say[そ] **so**.
- The T row: !say[た] **ta**, !say[ち] **chi**, !say[つ] **tsu**, !say[て] **te**, !say[と] **to**.
- Watch the exceptions: し is **shi** (not "si"), ち is **chi** (not "ti"), つ is **tsu** (not "tu").
- When typing, both spellings work: `shi` or `si`, `chi` or `ti`, `tsu` or `tu`.
:::

![](assets/hir-st.3x.png)

::: example
- !say[すし] = su + shi = **sushi**
- !say[たこ] = ta + ko = **tako**, "octopus"
- !say[くつ] = ku + tsu = **kutsu**, "shoes"
- !say[とけい] = to + ke + i = **tokei**, "clock, watch"
:::

::: problem id=p1 type=text answers="shi;si"
Type the reading: し
solution: し is **shi**.
Hear it: !say[し]
:::

::: problem id=p2 type=text answers="chi;ti"
Type the reading: ち
solution: ち is **chi**.
Hear it: !say[ち]
:::

::: problem id=p3 type=text answers="tsu;tu"
Type the reading: つ
solution: つ is **tsu**: say "ts" as in *cats*, then "u".
Hear it: !say[つ]
:::

::: problem id=p4 type=text answers="sushi;susi"
Read this word: すし
solution: す (su) + し (shi) = **sushi**.
Hear it: !say[すし]
:::

::: problem id=p5 type=text answers="tokei"
Read this word: とけい
solution: と (to) + け (ke) + い (i) = **tokei**, "clock".
Hear it: !say[とけい]
:::

::: problem id=p6 type=choice
These two look alike. Which one is **sa**?
![](assets/hir-lookalike.3x.png)
- [x] さ
- [ ] ち
solution: さ is **sa**; ち (**chi**) is its mirror image, curving the other way.
Hear it: !say[さ]
:::

::: problem id=p7 type=choice
What does くつ mean?
- [ ] octopus
- [x] shoes
- [ ] clock
solution: くつ (kutsu) means "shoes".
:::

::: problem id=p8 type=choice
Listen: !listen[たこ]
Which word did you hear?
- [ ] たけ
- [x] たこ
- [ ] とこ
solution: You heard たこ (tako), "octopus".
:::

::: problem id=p9 type=draw answer="さ"
Write !say[さ] **sa**.
solution: さ has 3 strokes. The bar, then the stroke down through it, then the curve at the bottom (some fonts join the last two).
:::

::: problem id=p10 type=draw answer="し"
Write !say[し] **shi**.
solution: し has 1 stroke: straight down, then curve up to the right.
:::

::: problem id=p11 type=draw answer="つ"
Write !say[つ] **tsu**.
solution: つ has 1 stroke: across and over, curving down to the left.
:::
