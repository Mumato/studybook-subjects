---
id: kat-02
title: Katakana: the second half, long sounds and small ッ
---
The rest of the katakana chart, plus the marks that make loanwords work: the long bar ー, small ッ, and the dakuten dots you already know from hiragana.

::: rule
- The H row: !say[ハ] **ha**, !say[ヒ] **hi**, !say[フ] **fu**, !say[ヘ] **he**, !say[ホ] **ho**.
- The M row: !say[マ] **ma**, !say[ミ] **mi**, !say[ム] **mu**, !say[メ] **me**, !say[モ] **mo**.
- Y, R and W: !say[ヤ] **ya**, !say[ユ] **yu**, !say[ヨ] **yo**; !say[ラ] **ra**, !say[リ] **ri**, !say[ル] **ru**, !say[レ] **re**, !say[ロ] **ro**; !say[ワ] **wa**; !say[ン] **n**.
- Dakuten and handakuten work as in hiragana: !say[ガ] **ga**, !say[ザ] **za**, !say[ダ] **da**, !say[バ] **ba**, !say[パ] **pa**. Combinations too: !say[キャ] **kya**, !say[シュ] **shu**, !say[チョ] **cho**.
- **ー** makes a vowel long, and is used instead of the extra vowel letter: !say[コーヒー] *koohii* (coffee). Type it with a hyphen: `ko-hi-`.
- **Small ッ** doubles the next consonant, just like っ: !say[ベッド] *beddo* (bed), !say[カップ] *kappu* (cup).
- More look-alikes: **ク ku / ケ ke / タ ta**, **ウ u / ワ wa / フ fu**, **ノ no / メ me / ヌ nu**, **ル ru / レ re**.
:::

::: example
A café menu:

!say[コーヒー] coffee · !say[ジュース] juice · !say[ミルク] milk · !say[サンドイッチ] sandwich · !say[ハンバーガー] hamburger

Notice ジュース: ジ + small ュ makes **ju**, and the ー stretches it. サンドイッチ has a small ッ before チ: *sandoicchi*.
:::

::: problem id=p1 type=text answers="コーヒー"
Type "coffee" in katakana.
hint: ko-hi-
solution: コーヒー (koohii): both vowels are long.
Hear it: !say[コーヒー]
:::

::: problem id=p2 type=choice
What does ミルク mean?
- [x] milk
- [ ] mirror
- [ ] mill
solution: ミ mi + ル ru + ク ku: *miruku*, milk.
Hear it: !say[ミルク]
:::

::: problem id=p3 type=text answers="beddo"
Type the reading of ベッド in romaji.
hint: The small ッ doubles the next consonant.
solution: *beddo* (bed).
Hear it: !say[ベッド]
:::

::: problem id=p4 type=choice
Which is "juice"?
- [ ] ジユス
- [x] ジュース
- [ ] シュース
solution: Small ュ makes ジ into **ju**, ー makes it long, and the dakuten makes it voiced (ju, not shu).
Hear it: !say[ジュース]
:::

::: problem id=p5 type=text answers="ハンバーガー"
Type "hamburger" in katakana.
hint: ha-n-ba-ga
solution: ハンバーガー (hanbaagaa).
Hear it: !say[ハンバーガー]
:::

::: problem id=p6 type=choice
Which character is **wa**?
- [ ] ウ
- [x] ワ
- [ ] フ
solution: ワ (wa). ウ (u) has an extra short stroke on top; フ (fu) has no left side.
Hear it: !say[ワ]
:::

::: problem id=p7 type=choice
Listen: !listen[カップ]
Which word did you hear?
- [ ] カプ
- [x] カップ
- [ ] カープ
solution: You heard カップ (kappu, cup): the small ッ is a short pause before プ.
:::

::: problem id=p8 type=choice creative=true
ビル is short for "building" and パソコン for "personal computer". What does this tell you about loanwords in Japanese?
- [x] They often get shortened and become Japanese words in their own right, so they don't always match the English.
- [ ] They are spelled letter by letter from English.
- [ ] Japanese speakers misremember English words.
solution: Long loanwords are often clipped: パーソナル・コンピューター → パソコン, エアコンディショナー → エアコン. Some even have new meanings, so learn them as Japanese words.
:::

::: problem id=p9 type=draw answer="ク"
Write !say[ク] **ku**.
solution: ク has 2 strokes. The short stroke from the top, then the bent stroke across and down to the left.
:::

::: problem id=p10 type=draw answer="ワ"
Write !say[ワ] **wa**.
solution: ワ has 2 strokes. The short stroke down on the left, then the stroke across and down, curving left.
:::

::: problem id=p11 type=draw answer="ル"
Write !say[ル] **ru**.
solution: ル has 2 strokes. The left stroke curving down, then the right stroke down with a flick up to the right.
:::
