title: Sounding natural: ね, よ, ～ごろ and how long
---
Two tiny sentence endings make your Japanese sound natural instead of textbook: **ね** and **よ**. You'll also learn to say "around 3 o'clock" and "for two hours".

::: rule
- **ね** at the end asks for agreement, like "isn't it?" or "right?": !say[いい てんきですね。] *Nice weather, isn't it?* Answer: !say[そうですね。] *It is.*
- **よ** tells the listener something new, like "you know" or "I'm telling you": !say[あの みせは やすいですよ。] *That shop is cheap, you know.*
- Rule of thumb: ね when you both know it, よ when only you know it. Don't overuse よ with superiors: it can sound pushy.
- **About, around (a time)**: time + **ごろ**: !say[しちじごろ おきます。] *I get up around seven.*
- **How long**: hours **じかん**, minutes **ふん/ぷん**: !say[にじかん べんきょうしました。] *I studied for two hours.* !say[さんじゅっぷん あるきます。] *I walk for thirty minutes.* Asking: !say[なんじかん ですか。]
- Durations take no particle: にじかん べんきょうします (not にじかんに).
:::

::: example
Waiting for a train:

- A: !say[さむいですね。] *It's cold, isn't it?*
- B: !say[m|そうですね。でんしゃは じゅうじごろ きますよ。] *Isn't it. The train comes around ten, you know.*
- A: !say[とうきょうまで なんじかん ですか。] *How many hours to Tokyo?*
- B: !say[m|にじかんぐらい です。] *About two hours.* (ぐらい = about, for amounts.)
:::

::: problem id=p1 type=choice
You and a friend are looking at a beautiful view. You say:
- [x] きれいですね。
- [ ] きれいですよ。
- [ ] きれいですか。
solution: You both see it: ね (isn't it?).
Hear it: !say[きれいですね。]
:::

::: problem id=p2 type=choice
Your friend doesn't know the café is closed today. You tell them:
- [ ] きょうは やすみですね。
- [x] きょうは やすみですよ。
- [ ] きょうは やすみですか。
solution: New information for the listener: よ.
Hear it: !say[きょうは やすみですよ。]
:::

::: problem id=p3 type=text answers="くじごろねます"
Type "I go to bed around nine."
hint: kuji goro nemasu
solution: くじごろ ねます。
Hear it: !say[くじごろ ねます。]
:::

::: problem id=p4 type=text answers="さんじかんべんきょうしました"
Type "I studied for three hours."
hint: sanjikan benkyou shimashita
solution: さんじかん べんきょうしました。
Hear it: !say[さんじかん べんきょうしました。]
:::

::: problem id=p5 type=choice
How do you ask "How many hours?"
- [x] なんじかん ですか。
- [ ] なんじ ですか。
- [ ] なんじごろ ですか。
solution: なんじかん: how many hours. なんじ is "what time".
Hear it: !say[なんじかん ですか。]
:::

::: problem id=p6 type=choice
Which is correct for "I walk for twenty minutes"?
- [x] にじゅっぷん あるきます。
- [ ] にじゅっぷんに あるきます。
- [ ] にじゅっぷんを あるきます。
solution: Durations take no particle.
Hear it: !say[にじゅっぷん あるきます。]
:::

::: problem id=p7 type=choice
Listen: !listen[m|まいにち いちじかん ジョギングします。]
How long does the speaker jog every day?
- [ ] until one o'clock
- [x] for one hour
- [ ] around one o'clock
solution: いちじかん: for one hour.
:::

::: problem id=p8 type=choice creative=true
A learner ends every sentence with よ: ペンを かして くださいよ, いきますよ. Why might that sound odd to Japanese ears?
- [x] よ insists the listener should know something; using it all the time sounds pushy or lecturing, especially in requests.
- [ ] よ is only for women.
- [ ] よ is rude in all situations.
solution: Sentence endings carry attitude. よ is great for useful information, but overusing it makes you sound like you're correcting people.
:::
