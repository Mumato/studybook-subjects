id: num-02
title: Shopping: prices, これ・それ・あれ and ください
---
Prices in Japan run into the thousands of yen, so you need hundreds, thousands and ten-thousands, plus a few words to point at things and ask for them.

::: rule
- **Hundreds** (ひゃく) and **thousands** (せん) combine like the tens, with a few sound changes: !say[さんびゃく] (300), !say[ろっぴゃく] (600), !say[はっぴゃく] (800); !say[さんぜん] (3,000), !say[はっせん] (8,000). 100 and 1,000 are just ひゃく and せん, no いち.
- **10,000** is !say[いちまん]: Japanese counts in units of ten thousand. 20,000 is にまん, 50,000 is ごまん.
- Yen is **えん**: !say[せんごひゃくえん] (¥1,500).
- **これ** (this one, near me), **それ** (that one, near you), **あれ** (that one over there), **どれ** (which one?).
- Asking the price: !say[これは いくら ですか。] *How much is this?*
- Buying: **noun + を ください**: !say[それを ください。] *That one, please.* (を is read **o**.)
:::

::: example
At a shop:

- Customer: !say[すみません、あれは いくら ですか。] *Excuse me, how much is that one over there?*
- Clerk: !say[m|あれは にせんはっぴゃくえん です。] *That one is 2,800 yen.*
- Customer: !say[じゃあ、あれを ください。] *Then I'll take that one, please.*
:::

::: problem id=p1 type=numeric answer="300"
What number is さんびゃく?
solution: さん (3) × ひゃく (100), with ひゃく changing to びゃく: 300.
Hear it: !say[さんびゃく]
:::

::: problem id=p2 type=text answers="ろっぴゃく"
Type 600 in Japanese.
hint: It changes sound: roppyaku.
solution: ろっぴゃく (roppyaku), not ろくひゃく.
Hear it: !say[ろっぴゃく]
:::

::: problem id=p3 type=numeric answer="8000"
What number is はっせん?
solution: はち (8) × せん (1,000) becomes はっせん: 8,000.
Hear it: !say[はっせん]
:::

::: problem id=p4 type=numeric answer="35000"
How many yen is さんまんごせんえん?
solution: さんまん (30,000) + ごせん (5,000) = ¥35,000.
Hear it: !say[さんまんごせんえん]
:::

::: problem id=p5 type=choice
The clerk is holding a pen. You want it. What do you say?
- [ ] これを ください。
- [x] それを ください。
- [ ] あれを ください。
solution: The pen is near the listener (the clerk), so it's それ.
Hear it: !say[それを ください。]
:::

::: problem id=p6 type=text answers="これはいくらですか"
Type "How much is this?"
hint: kore wa ikura desu ka
solution: これは いくら ですか。
Hear it: !say[これは いくら ですか。]
:::

::: problem id=p7 type=numeric answer="1980"
Listen: !listen[m|それは せんきゅうひゃくはちじゅうえん です。]
How many yen does it cost?
solution: せん (1,000) + きゅうひゃく (900) + はちじゅう (80) = ¥1,980.
:::

::: problem id=p8 type=choice creative=true
Why does Japanese say 10,000 as いちまん instead of "ten thousand"?
- [x] Japanese (like Chinese) groups big numbers in fours: まん is 10,000 and おく is 100,000,000, so a million is ひゃくまん, "a hundred ten-thousands".
- [ ] Japanese has no word for "thousand".
- [ ] It is a shop-only word for prices.
solution: English groups digits in threes (thousand, million), Japanese in fours (まん, おく). So 1,000,000 = ひゃくまん. Shifting the comma in your head (100,0000) helps.
:::
