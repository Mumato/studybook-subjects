title: Hiragana: M, Y, R, W and ん
---
The last basic rows. After this lesson you can read every one of the 46 basic hiragana.

::: rule
- The M row: !say[ま] **ma**, !say[み] **mi**, !say[む] **mu**, !say[め] **me**, !say[も] **mo**.
- The Y row has only three: !say[や] **ya**, !say[ゆ] **yu**, !say[よ] **yo**.
- The R row: !say[ら] **ra**, !say[り] **ri**, !say[る] **ru**, !say[れ] **re**, !say[ろ] **ro**. The Japanese "r" is a light tap of the tongue, between English r, l and d.
- The W row: !say[わ] **wa**, and !say[を] **o** (used only as a grammar particle; type `wo`).
- !say[ん] **n** is the only consonant that stands alone. When typing, use `nn` before a vowel or at the end if needed: `hon` or `honn` both give ほん.
:::

![](assets/hir-mw.3x.png)

::: example
- !say[やま] = **yama**, "mountain"
- !say[わたし] = **watashi**, "I, me"
- !say[ほん] = **hon**, "book"
- !say[せんせい] = **sensei**, "teacher"
:::

::: problem id=p3 type=text answers="yama"
Read this word: やま
solution: や (ya) + ま (ma) = **yama**, "mountain".
Hear it: !say[やま]
:::

::: problem id=p4 type=text answers="watashi;watasi"
Read this word: わたし
solution: わ (wa) + た (ta) + し (shi) = **watashi**, "I".
Hear it: !say[わたし]
:::

::: problem id=p5 type=text answers="sensei"
Read this word: せんせい
solution: せ (se) + ん (n) + せ (se) + い (i) = **sensei**, "teacher".
Hear it: !say[せんせい]
:::

::: problem id=p6 type=choice
These pairs look alike. Which is **me**?
![](assets/hir-lookalike.3x.png)
- [ ] ぬ
- [x] め
solution: め is **me**; ぬ (**nu**) has an extra loop at the end.
Hear it: !say[め]
:::

::: problem id=p8 type=text answers="よる"
Listen: !listen[よる]
Type the word you hear.
solution: よる (yoru), "night".
:::

::: problem id=p7 type=choice
Which one is **re**?
- [ ] ね
- [x] れ
- [ ] わ
solution: れ (re) ends with an outward flick; ね (ne) ends with a loop; わ (wa) ends with a round curve.
Hear it: !say[れ]
:::
