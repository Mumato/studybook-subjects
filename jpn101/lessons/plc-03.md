---
id: plc-03
title: Months, dates and birthdays
---
Months are easy: number + がつ. Days of the month are the trickiest numbers in first-year Japanese, because the first ten use old Japanese words. Learn them as a song: everyone does.

::: rule
- **Months**: number + がつ: !say[いちがつ] (January), !say[にがつ] (February) and so on. Three special readings: !say[しがつ] (April), !say[しちがつ] (July), !say[くがつ] (September).
- **Days 1 to 10** are special: !say[ついたち] (1st), !say[ふつか] (2nd), !say[みっか] (3rd), !say[よっか] (4th), !say[いつか] (5th), !say[むいか] (6th), !say[なのか] (7th), !say[ようか] (8th), !say[ここのか] (9th), !say[とおか] (10th).
- **From 11** it's number + にち: !say[じゅういちにち] (11th), !say[にじゅうごにち] (25th). Exceptions: !say[じゅうよっか] (14th), !say[はつか] (20th), !say[にじゅうよっか] (24th), and 19th/29th use く: !say[じゅうくにち].
- Order: month, then day: !say[しがつ ついたち] (April 1st).
- Asking: !say[たんじょうびは いつ ですか。] *When's your birthday?* !say[きょうは なんがつ なんにち ですか。] *What's the date today?*
:::

::: example
- A: !say[たんじょうびは いつ ですか。] *When's your birthday?*
- B: !say[m|くがつ はつか です。] *September 20th.*
- A: !say[あ、らいしゅう ですね！] *Oh, that's next week!*
:::

::: problem id=p1 type=text answers="しがつ"
Type "April".
hint: Not よんがつ.
solution: しがつ (shigatsu).
Hear it: !say[しがつ]
:::

::: problem id=p2 type=text answers="ついたち"
Type "the 1st" (day of the month).
hint: tsuitachi
solution: ついたち.
Hear it: !say[ついたち]
:::

::: problem id=p3 type=choice
Which is the 20th?
- [ ] にじゅうにち
- [x] はつか
- [ ] ふつか
solution: The 20th is はつか. ふつか is the 2nd.
Hear it: !say[はつか]
:::

::: problem id=p4 type=numeric answer="8"
Which day of the month is ようか?
solution: ようか is the 8th.
Hear it: !say[ようか]
:::

::: problem id=p5 type=choice
How do you say July 7th (the star festival, Tanabata)?
- [x] しちがつ なのか
- [ ] ななつき なのか
- [ ] しちがつ ななにち
solution: July is しちがつ, the 7th is なのか.
Hear it: !say[しちがつ なのか]
:::

::: problem id=p6 type=text answers="たんじょうびはいつですか"
Type "When's your birthday?"
hint: tanjoubi wa itsu desu ka
solution: たんじょうびは いつ ですか。
Hear it: !say[たんじょうびは いつ ですか。]
:::

::: problem id=p7 type=choice
Listen: !listen[m|わたしの たんじょうびは じゅうにがつ みっか です。]
When is the speaker's birthday?
- [x] December 3rd
- [ ] February 3rd
- [ ] December 30th
solution: じゅうにがつ (December) みっか (3rd).
:::

::: problem id=p8 type=open
Say your own birthday, and today's date.
!speak[my birthday and today's date]
solution: For example: わたしの たんじょうびは ごがつ とおか です。きょうは じゅういちがつ にじゅうごにち です。
:::
