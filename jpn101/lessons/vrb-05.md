---
id: vrb-05
title: Reading: a day in my life
---
A university student's diary entry, using the verbs, particles and time words from this part. Read it for the order of events, then answer the questions.

::: rule
Reading tips for a diary:
- **Time words come first** in each sentence (あさ, ごご, じゅうにじに): use them to follow the order of the day.
- **Particles tell you the roles**: を (what), で (where it happens), に (to where / at what time).
- **Past or not?** Check the verb ending: ました and ませんでした are past.
:::

::: example
Ken's diary, Monday:

きょうは しちじに おきました。あさごはんは たべませんでした。はちじはんに うちを でて、でんしゃで だいがくに いきました。

ごぜんは としょかんで にほんごを べんきょうしました。じゅうにじに ともだちと しょくどうで ひるごはんを たべました。ごごは クラスが ふたつ ありました。

よる、うちで テレビを みました。それから しゅくだいを しました。じゅういちじに ねました。たいへんな いちにち でした。

!say[m|きょうは しちじに おきました。あさごはんは たべませんでした。はちじはんに うちを でて、でんしゃで だいがくに いきました。ごぜんは としょかんで にほんごを べんきょうしました。じゅうにじに ともだちと しょくどうで ひるごはんを たべました。ごごは クラスが ふたつ ありました。よる、うちで テレビを みました。それから しゅくだいを しました。じゅういちじに ねました。たいへんな いちにち でした。]

New words: でる leave (でて = leaving, and), しょくどう cafeteria, いちにち a day, たいへん tough.
:::

::: problem id=p1 type=numeric answer="7"
What time did Ken get up? (just the hour)
solution: しちじに おきました: at 7.
:::

::: problem id=p2 type=choice
Did Ken eat breakfast?
- [ ] Yes, at home.
- [x] No, he didn't.
- [ ] Yes, at the cafeteria.
solution: あさごはんは たべませんでした: he didn't eat breakfast.
:::

::: problem id=p3 type=choice
How did Ken get to university?
- [ ] by bus
- [x] by train
- [ ] on foot
solution: でんしゃで: by train.
:::

::: problem id=p4 type=choice
Where did Ken study Japanese?
- [x] at the library
- [ ] at home
- [ ] in class
solution: としょかんで にほんごを べんきょうしました.
:::

::: problem id=p5 type=choice
What did Ken do at 12?
- [ ] went home
- [x] had lunch with a friend at the cafeteria
- [ ] went to class
solution: じゅうにじに ともだちと しょくどうで ひるごはんを たべました.
:::

::: problem id=p6 type=numeric answer="2"
How many classes did Ken have in the afternoon?
solution: クラスが ふたつ ありました: two (2).
:::

::: problem id=p7 type=choice
What did Ken do last?
- [ ] watched TV
- [ ] did homework
- [x] went to bed at 11
solution: The order: TV, then homework (それから), then bed at 11.
:::

Write and say three sentences about your own day yesterday, with times.
