title: Hiragana: the vowels and the K row
---
Japanese is written with three scripts working together: **hiragana**, **katakana** and **kanji**. Every word can be written in hiragana, so it's the first thing every learner masters. Each hiragana character is one syllable.

::: rule
The five vowels come first, and every other row is a consonant plus these vowels.
- あ **a** (as in *father*), い **i** (as in *machine*), う **u** (as in *food*, lips relaxed), え **e** (as in *met*), お **o** (as in *bold*).
- The K row: か **ka**, き **ki**, く **ku**, け **ke**, こ **ko**.
- Japanese vowels are short and pure: no "ay-ee" glide like English *day*.
:::

::: example
Put syllables together to read words:
- あか = a + ka = **aka**, "red"
- いえ = i + e = **ie**, "house"
- かお = ka + o = **kao**, "face"
- こえ = ko + e = **koe**, "voice"

Tip: き looks like a **key**, and く is a beak going "**ku**ku".
:::

::: problem id=p1 type=text answers="ka"
Type the reading of this hiragana in romaji: か
solution: か is **ka**.
:::

::: problem id=p2 type=text answers="i"
Type the reading: い
solution: い is **i**: two short strokes, like two eels side by side.
:::

::: problem id=p3 type=text answers="ke"
Type the reading: け
solution: け is **ke**.
:::

::: problem id=p4 type=choice
Which hiragana is **o**?
- [ ] あ
- [x] お
- [ ] こ
solution: お is **o**. It looks like あ (a), but its first stroke is a short dash, not a long line.
:::

::: problem id=p5 type=text answers="aka"
Read this word and type it in romaji: あか
solution: あ (a) + か (ka) = **aka**, which means "red".
:::

::: problem id=p6 type=text answers="kao"
Read this word: かお
solution: か (ka) + お (o) = **kao**, "face".
:::

::: problem id=p7 type=choice
What does いえ mean?
- [x] house
- [ ] red
- [ ] voice
solution: いえ (ie) means "house".
:::

::: problem id=p8 type=choice
Which spells **kaki** (persimmon)?
- [x] かき
- [ ] かけ
- [ ] きか
solution: か (ka) + き (ki).
:::
