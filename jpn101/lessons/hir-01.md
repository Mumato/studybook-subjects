title: Hiragana: the vowels and the K row
---
Japanese is written with three scripts working together: **hiragana**, **katakana** and **kanji**. Every word can be written in hiragana, so it's the first thing every learner masters. Each hiragana character is one syllable.

::: rule
The five vowels come first, and every other row is a consonant plus these vowels.
- !say[あ] **a** (as in *father*), !say[い] **i** (as in *machine*), !say[う] **u** (as in *food*, lips relaxed), !say[え] **e** (as in *met*), !say[お] **o** (as in *bold*).
- The K row: !say[か] **ka**, !say[き] **ki**, !say[く] **ku**, !say[け] **ke**, !say[こ] **ko**.
- Japanese vowels are short and pure: no "ay-ee" glide like English *day*.
:::

![](assets/hir-ak.3x.png)

::: example
Put syllables together to read words:
- !say[あか] = a + ka = **aka**, "red"
- !say[いえ] = i + e = **ie**, "house"
- !say[かお] = ka + o = **kao**, "face"
- !say[こえ] = ko + e = **koe**, "voice"

Click ▶ to hear a word.

Tip: き looks like a **key**, and く is a beak going "**ku**ku".
:::

::: problem id=p1 type=text answers="ka"
Type the reading of this hiragana in romaji: か
solution: か is **ka**.
Hear it: !say[か]
:::

::: problem id=p2 type=text answers="i"
Type the reading: い
solution: い is **i**: two short strokes, like two eels side by side.
Hear it: !say[い]
:::

::: problem id=p3 type=text answers="ke"
Type the reading: け
solution: け is **ke**.
Hear it: !say[け]
:::

::: problem id=p4 type=choice
Which hiragana is **o**?
- [ ] あ
- [x] お
- [ ] こ
solution: お is **o**. It looks like あ (a), but its first stroke is a short dash, not a long line.
Hear it: !say[お]
:::

::: problem id=p5 type=text answers="aka"
Read this word and type it in romaji: あか
solution: あ (a) + か (ka) = **aka**, which means "red".
:::

::: problem id=p6 type=text answers="kao"
Read this word: かお
solution: か (ka) + お (o) = **kao**, "face".
Hear it: !say[かお]
:::

::: problem id=p7 type=choice
Listen: !listen[いえ]
Which word did you hear?
- [x] いえ
- [ ] いけ
- [ ] えい
solution: You heard いえ (ie), "house". いけ (ike) is "pond"; えい (ei) has the vowels the other way round.
:::

::: problem id=p8 type=choice
Which spells **kaki** (persimmon)?
- [x] かき
- [ ] かけ
- [ ] きか
solution: か (ka) + き (ki).
Hear it: !say[かき]
:::

::: rule
**Writing practice.** Draw each character in the square with the mouse: hold the button down for each stroke and let go between strokes. Then click **Check**.
- **▶ Strokes** shows the stroke order, numbered. Watch it once before you start.
- Order and direction matter: Japanese strokes go from top to bottom and left to right, and the check tells you which stroke to fix.
- **← Undo** takes back your last stroke, **✕ Clear** starts again. Size and position in the square don't matter.
:::

::: problem id=p9 type=draw answer="あ"
Write !say[あ] **a**.
solution: あ has 3 strokes. Start with the short bar, then the long stroke down, then the loop that curls round and ends low on the right.
:::

::: problem id=p10 type=draw answer="い"
Write !say[い] **i**.
solution: い has 2 strokes. Two short strokes, left then right. The left one is longer and ends with a little hook up.
:::

::: problem id=p11 type=draw answer="か"
Write !say[か] **ka**.
solution: か has 3 strokes. The 'hooked seven' first, then the long stroke through it, then the little tick on the right.
:::
