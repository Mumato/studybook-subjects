---
id: num-01
title: Numbers from 0 to 100
---
Japanese numbers are wonderfully regular: learn 1 to 10 and you can count to 99 just by combining them.

::: rule
- 1 to 10: !say[いち] **ichi**, !say[に] **ni**, !say[さん] **san**, !say[よん] **yon** (or し), !say[ご] **go**, !say[ろく] **roku**, !say[なな] **nana** (or しち), !say[はち] **hachi**, !say[きゅう] **kyuu** (or く), !say[じゅう] **juu**. Zero is !say[ゼロ] **zero** or !say[れい] **rei**.
- 4, 7 and 9 have two readings. Use **よん, なな, きゅう** when counting and saying numbers; し and く sound like "death" and "suffering", so they're avoided.
- **Tens**: number × じゅう. !say[にじゅう] (20), !say[さんじゅう] (30), !say[よんじゅう] (40), !say[きゅうじゅう] (90).
- **11 to 99**: tens + ones. !say[じゅういち] (11), !say[にじゅうご] (25), !say[ななじゅうはち] (78).
- 100 is !say[ひゃく] **hyaku**.
- Phone numbers are read digit by digit with **の** between the groups: 03-1234 → !say[ゼロさんの いちにさんよん].
:::

::: example
Asking someone's phone number:

- A: !say[でんわばんごうは なんばん ですか。] *What's your phone number?*
- B: !say[m|ゼロきゅうゼロの ごろくななはちの にさんよんご です。] *090-5678-2345.*

なんばん means "what number". With phone numbers, に (2) and ご (5) are often stretched to にい and ごう so they're heard clearly.
:::

::: problem id=p1 type=numeric answer="15"
What number is じゅうご?
solution: じゅう (10) + ご (5) = 15.
Hear it: !say[じゅうご]
:::

::: problem id=p2 type=numeric answer="42"
What number is よんじゅうに?
solution: よん (4) × じゅう (10) + に (2) = 42.
Hear it: !say[よんじゅうに]
:::

::: problem id=p3 type=text answers="にじゅうはち"
Type 28 in Japanese.
hint: ni-juu-hachi
solution: にじゅうはち (nijuuhachi): 2 tens, then 8.
Hear it: !say[にじゅうはち]
:::

::: problem id=p4 type=text answers="きゅうじゅうなな;きゅうじゅうしち"
Type 97 in Japanese.
hint: Use kyuu for 9.
solution: きゅうじゅうなな (kyuujuunana). きゅうじゅうしち is also correct.
Hear it: !say[きゅうじゅうなな]
:::

::: problem id=p5 type=choice
Which reading of 4 do you use to say "40"?
- [x] よんじゅう
- [ ] しじゅう
- [ ] よじゅう
solution: よんじゅう is the everyday form. しじゅう exists but sounds old-fashioned, and is avoided because し sounds like "death".
Hear it: !say[よんじゅう]
:::

::: problem id=p6 type=numeric answer="63"
Listen: !listen[ろくじゅうさん]
Type the number you heard.
solution: ろくじゅうさん: 6 tens and 3, so 63.
:::

::: problem id=p7 type=numeric answer="100"
What number is ひゃく?
solution: ひゃく is 100.
Hear it: !say[ひゃく]
:::

::: problem id=p8 type=choice
Listen: !listen[m|でんわばんごうは ゼロさんの ななごの いちはち です。]
Which phone number did you hear?
- [x] 03-75-18
- [ ] 03-57-81
- [ ] 08-75-18
solution: ゼロさん (03) の ななご (75) の いちはち (18).
:::
