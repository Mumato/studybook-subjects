title: Kanji: people, school and nature
---
Many simple kanji started as pictures: 山 is three peaks, 川 is flowing water, 人 is a person walking. Combine them and you can write words from your first lessons, like 先生 and 学生.

::: rule
- Pictures: !say[やま] **山** mountain, !say[かわ] **川** river, !say[ひと] **人** person, !say[くち] **口** mouth, !say[き] **木** tree, !say[た] **田** rice field.
- Size and place: !say[おおきい] **大**きい big, !say[ちいさい] **小**さい small, !say[なか] **中** inside, middle.
- School words: **学生** !say[がくせい] student, **先生** !say[せんせい] teacher, **大学** !say[だいがく] university, **日本** !say[にほん] Japan.
- **人** after a country is **じん**: !say[にほんじん] 日本人 (a Japanese person). Alone it's ひと.
- **Okurigana**: kana after a kanji that complete the word: 大**きい**, 小**さい**. The kanji holds the meaning, the kana the ending.
- Many Japanese names are made of these: 山田 (やまだ, "mountain field"), 中川 (なかがわ, "middle river"), 田中 (たなか).
:::

::: example
Back to your first self-introduction, now in kanji:

{私|わたし}は {田中|たなか}です。{日本人|にほんじん}です。{大学|だいがく}の {学生|がくせい}です。

!say[わたしは たなか です。にほんじん です。だいがくの がくせい です。]

Kanji make sentences shorter and easier to read quickly, because each word stands out.
:::

::: problem id=p4 type=choice
How is 人 read in アメリカ人?
- [ ] ひと
- [x] じん
- [ ] にん
solution: After a country, 人 is じん: アメリカじん, an American.
Hear it: !say[アメリカじん]

::: problem id=p5 type=choice
Which is "small"?
- [ ] 大きい
- [x] 小さい
- [ ] 中
solution: 小さい (ちいさい) is small; 大きい (おおきい) is big; 中 (なか) is inside.
Hear it: !say[ちいさい]
:::

::: problem id=p6 type=text answers="やまだ"
Type the reading of the family name 山田.
hint: mountain + field: yama + da
solution: やまだ. 田 is た, but it softens to だ after やま.
Hear it: !say[やまだ]
:::

::: problem id=p7 type=choice
In 大きい, what are the kana きい called?
- [ ] furigana
- [x] okurigana
- [ ] katakana
solution: Okurigana are kana after a kanji that complete the word. Furigana are the small reading aids above kanji.
:::

::: problem id=p8 type=choice
Listen: !listen[m|わたしの せんせいは にほんじん です。]
Who is Japanese?
- [x] the speaker's teacher
- [ ] the speaker
- [ ] the speaker's student
solution: わたしの せんせい (my teacher) は にほんじん です: "My teacher is Japanese." In kanji: 私の先生は日本人です。
:::

::: problem id=p10 type=draw answer="山"
Write 山 **mountain**.
solution: 山 has 3 strokes. The centre stroke first, then the left side with the bottom in one stroke, then the right side.
:::

::: problem id=p11 type=draw answer="川"
Write 川 **river**.
solution: 川 has 3 strokes. Left to right: the curving left stroke, the short middle one, then the long right one.
:::

::: problem id=p9 type=draw answer="人"
Write 人 **person**.
solution: 人 has 2 strokes. The left sweep first, then the right stroke, which starts partway down the first.
:::

::: problem id=p12 type=draw answer="口"
Write 口 **mouth**.
solution: 口 has 3 strokes. The left side, then the top and right side in one stroke, then the bottom.
