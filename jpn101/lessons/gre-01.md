id: gre-01
title: Everyday greetings
---
Greetings are the first thing you'll use, and Japanese has a set phrase for almost every everyday moment. Politeness matters: the longer form is usually the polite one.

::: rule
- !say[おはようございます]: good morning (polite; with friends just おはよう)
- !say[こんにちは]: hello, good afternoon (the final は is read **wa**: *konnichiwa*)
- !say[こんばんは]: good evening (*konbanwa*)
- !say[さようなら]: goodbye (for longer partings; with friends, じゃあね)
- !say[ありがとうございます]: thank you (polite)
- !say[すみません]: excuse me / I'm sorry
- !say[いただきます]: before eating; !say[ごちそうさまでした]: after eating
- !say[おやすみなさい]: good night (before bed)
:::

::: example
Morning at school:
- Student: せんせい、おはようございます。 *Good morning, teacher.*
- Teacher: おはようございます。

Bumping into someone: すみません！ The same word gets a waiter's attention in a restaurant.
:::

::: problem id=p1 type=choice
You meet your teacher at 8 a.m. What do you say?
- [x] おはようございます
- [ ] こんばんは
- [ ] おやすみなさい
solution: おはようございます is the polite "good morning".
:::

::: problem id=p2 type=text answers="ありがとうございます"
Type "thank you" (polite) in Japanese. (Type romaji; it turns into hiragana.)
hint: arigatou gozaimasu
solution: ありがとうございます (arigatou gozaimasu).
:::

::: problem id=p3 type=text answers="こんばんは"
Type "good evening" in Japanese.
hint: konbanwa
solution: こんばんは. The last character is は, but it's read **wa**, so typing *konbanwa* is fine.
:::

::: problem id=p4 type=choice
Why is the は at the end of こんにちは read "wa"?
- [ ] It's a spelling mistake that stuck.
- [x] こんにちは began as a phrase with the particle は ("today is..."), and the particle は is read "wa".
- [ ] は is always read "wa".
solution: Only the particle は is read "wa"; in words like はな (hana) it's still "ha".
:::

::: problem id=p5 type=choice
What do you say just before you start eating?
- [ ] ごちそうさまでした
- [x] いただきます
- [ ] すみません
solution: いただきます before the meal; ごちそうさまでした after it.
:::

::: problem id=p6 type=choice
You step on someone's foot on a crowded train. What do you say?
- [ ] こんにちは
- [x] すみません
- [ ] ありがとうございます
solution: すみません is "excuse me" and "sorry".
:::

::: problem id=p8 type=choice
Listen: !listen[こんばんは]
When would you say what you heard?
- [ ] in the morning
- [ ] at lunchtime
- [x] in the evening
solution: You heard こんばんは (konbanwa), "good evening".
:::

::: problem id=p7 type=text answers="おやすみなさい"
Type "good night" (said before going to bed).
hint: oyasuminasai
solution: おやすみなさい (oyasumi nasai).
:::
