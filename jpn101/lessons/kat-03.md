---
id: kat-03
title: Katakana: new sounds and your name
---
Some English sounds don't exist in Japanese, so katakana combines letters with small ァ ィ ゥ ェ ォ to make them. With these you can write almost any foreign word, including your own name.

::: rule
- **f** sounds: !say[ファ] **fa**, !say[フィ] **fi**, !say[フェ] **fe**, !say[フォ] **fo**, as in !say[フォーク] (fork).
- **ti** and **di**: !say[ティ] **ti**, !say[ディ] **di**, as in !say[パーティー] (party). Type `ti` and `di`: the book reads them as ティ and ディ when the answer needs it. (On a real Japanese keyboard, `ti` gives チ, so there you type `thi` and `dhi`.)
- **w** sounds: !say[ウィ] **wi**, !say[ウェ] **we**, as in !say[ウェブ] (web).
- **v** sounds: !say[ヴァ] **va** and friends exist, but most words use B instead: !say[バイオリン] (violin) is more common than ヴァイオリン.
- **Your name in katakana**: write it by **sound**, not spelling. Split it into Japanese syllables, add vowels after stray consonants (usually **u**, or **o** after t and d), and use ー for long vowels. "Mike" → !say[マイク], "Emma" → !say[エマ], "David" → !say[デイビッド].
- The dot **・** separates first and last names: !say[ジョン・スミス].
:::

::: example
Introducing yourself with a foreign name:

!say[はじめまして。わたしは エマ・ブラウン です。]

*Nice to meet you. I'm Emma Brown.* "Brown" becomes ブラウン: bu-ra-u-n. The final n is ン, and the "br" cluster gets a vowel: ブ.
:::

::: problem id=p1 type=text answers="フォーク"
Type "fork" in katakana.
hint: fo-ku
solution: フォーク (fooku): フ + small ォ makes **fo**.
Hear it: !say[フォーク]
:::

::: problem id=p2 type=text answers="パーティー"
Type "party" in katakana.
hint: pa-ti-
solution: パーティー (paatii). `ti` or `thi` both give ティ here.
Hear it: !say[パーティー]
:::

::: problem id=p3 type=choice
What is ウェブ?
- [x] web
- [ ] wave
- [ ] weave
solution: ウ + small ェ makes **we**: *webu*, web.
Hear it: !say[ウェブ]
:::

::: problem id=p4 type=choice
How is the name "Mike" written in katakana?
- [ ] ミケ
- [x] マイク
- [ ] ミク
solution: By sound: "my-k" → マイ + ク (the k gets a u). ミケ is how it's *spelled*, not how it sounds.
Hear it: !say[マイク]
:::

::: problem id=p5 type=choice
"Ben" in katakana is:
- [x] ベン
- [ ] ベヌ
- [ ] ベンヌ
solution: A final n is ン: ベン.
Hear it: !say[ベン]
:::

::: problem id=p6 type=text answers="アメリカ"
Type "America" in katakana.
hint: a-me-ri-ka
solution: アメリカ (amerika). Add じん for an American: アメリカじん.
Hear it: !say[アメリカ]
:::

::: problem id=p7 type=choice
Listen: !listen[m|わたしは デイビッド です。アメリカじん です。]
Where is the speaker from?
- [x] America
- [ ] Britain
- [ ] Japan
solution: He says: わたしは デイビッド です。アメリカじん です。 "I'm David. I'm American."
:::

::: problem id=p8 type=open
Write your own name in katakana, the way it **sounds**, and say it in a self-introduction.
!speak[my name in katakana]
solution: For example: "Sarah" → セーラ or サラ, "Alex" → アレックス, "Chris" → クリス. There's often more than one acceptable spelling: Japanese people with your name may spell it differently. Then: はじめまして。わたしは （your name） です。
:::
