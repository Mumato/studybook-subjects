---
id: hir-05
title: Hiragana: voiced sounds, combinations and long sounds
---
With a few small marks and small characters, the 46 basic hiragana spell every sound in Japanese.

::: rule
- **Dakuten** ゛ (two dots) makes a sound **voiced**: か→!say[が] **ga**, さ→!say[ざ] **za**, た→!say[だ] **da**, は→!say[ば] **ba**. **Handakuten** ゜ (a small circle) turns は→!say[ぱ] **pa**.
- A small ゃ, ゅ or ょ after an **i**-column character makes one syllable: き+ゃ = !say[きゃ] **kya**, し+ゅ = !say[しゅ] **shu**, ち+ょ = !say[ちょ] **cho**.
- A small っ doubles the next consonant with a tiny pause: !say[きって] **kitte** (stamp).
- **Long vowels** hold the sound twice as long, and change the meaning: !say[おばさん] **obasan** (aunt) vs !say[おばあさん] **obaasan** (grandmother). Long o is usually written おう: !say[がっこう] **gakkou** (school).
:::

::: example
- !say[ぶた] = **buta**, "pig"
- !say[きょう] = **kyou**, "today"
- !say[がっこう] = **gakkou**, "school"
- !say[おばさん] (aunt) vs !say[おばあさん] (grandmother)
- びょういん = **byouin**, "hospital", but びよういん = **biyouin**, "beauty salon"! The small ょ matters.
:::

::: problem id=p1 type=text answers="ga"
Type the reading: が
solution: か (ka) + dakuten = が **ga**.
Hear it: !say[が]
:::

::: problem id=p2 type=text answers="pa"
Type the reading: ぱ
solution: は (ha) + handakuten = ぱ **pa**.
Hear it: !say[ぱ]
:::

::: problem id=p3 type=text answers="buta"
Read this word: ぶた
solution: ぶ (bu) + た (ta) = **buta**, "pig".
Hear it: !say[ぶた]
:::

::: problem id=p4 type=text answers="kyou;kyoo"
Read this word: きょう
solution: きょ (kyo) + う (long o) = **kyou**, "today".
Hear it: !say[きょう]
:::

::: problem id=p5 type=text answers="gakkou;gakkoo"
Read this word: がっこう
solution: が (ga) + っ (doubles the k) + こう (kou) = **gakkou**, "school".
Hear it: !say[がっこう]
:::

::: problem id=p6 type=choice
What does the small っ in きって do?
- [ ] makes the word plural
- [x] doubles the next consonant, with a short pause: ki-tte
- [ ] adds a "tsu" sound
solution: A small っ isn't pronounced as "tsu"; it holds the next consonant for a beat.
:::

::: problem id=p7 type=choice
Listen: !listen[びょういん]
Which word did you hear?
- [x] びょういん (hospital)
- [ ] びよういん (beauty salon)
solution: びょういん (byouin) is a hospital; びよういん (biyouin), with a full-size よ, is a beauty salon.
:::

::: problem id=p8 type=choice creative=true
おばさん and おばあさん differ only by one あ. What does that tell you about Japanese pronunciation?
- [ ] Nothing: the extra あ is silent.
- [x] Vowel length changes meaning, so long vowels must be held about twice as long.
- [ ] The second word is just a polite version.
solution: おばさん is "aunt" (or a middle-aged woman), おばあさん is "grandmother". Holding vowels for the right length is as important as getting the sound right.
:::

::: problem id=p9 type=draw answer="が"
Write !say[が] **ga**.
solution: が has 5 strokes. Write か first, then the two dakuten dots at the top right.
:::
