---
id: vrb-03
title: The past: ました and ませんでした
---
To talk about yesterday, change the ending: ます becomes **ました**, and ません becomes **ませんでした**. Add how often you do things and you can describe your whole week.

::: rule
- **Past**: ます → **ました**: !say[たべました] (ate), !say[いきました] (went).
- **Past negative**: ません → **ませんでした**: !say[たべませんでした] (didn't eat).
- Time words: !say[きのう] (yesterday), !say[きょう] (today), !say[あした] (tomorrow), !say[せんしゅう] (last week), !say[こんしゅう] (this week), !say[らいしゅう] (next week).
- How often: !say[いつも] (always), !say[よく] (often), !say[ときどき] (sometimes) go with a positive verb; !say[あまり] (not much) and !say[ぜんぜん] (not at all) go with a **negative** verb: !say[ぜんぜん みません] *I never watch it.*
- Past questions: !say[きのう なにを しましたか。] *What did you do yesterday?*
:::

::: example
Monday morning:

- A: !say[しゅうまつ なにを しましたか。] *What did you do at the weekend?*
- B: !say[m|ともだちと えいがを みました。でも、しゅくだいは しませんでした。] *I watched a movie with a friend. But I didn't do my homework.*

The は in しゅくだい**は** replaces を to contrast: "homework, I didn't do".
:::

::: problem id=p1 type=text answers="のみました"
Type "I drank."
hint: nomimashita
solution: のみました (nomimashita).
Hear it: !say[のみました]
:::

::: problem id=p2 type=text answers="いきませんでした"
Type "I didn't go."
hint: ikimasen deshita
solution: いきませんでした (ikimasen deshita).
Hear it: !say[いきませんでした]
:::

::: problem id=p3 type=choice
きのう テレビを みませんでした means:
- [ ] I'll watch TV tomorrow.
- [ ] I watched TV yesterday.
- [x] I didn't watch TV yesterday.
solution: きのう (yesterday) + みませんでした (didn't watch).
Hear it: !say[きのう テレビを みませんでした]
:::

::: problem id=p4 type=choice
Which word fits? ＿ さかなを たべません。 (I don't eat fish much.)
- [ ] よく
- [x] あまり
- [ ] いつも
solution: あまり goes with a negative verb: "not much".
Hear it: !say[あまり さかなを たべません]
:::

::: problem id=p5 type=choice
Which sentence is wrong?
- [ ] ときどき りょうりを します。
- [x] ぜんぜん りょうりを します。
- [ ] ぜんぜん りょうりを しません。
solution: ぜんぜん (not at all) needs a negative verb: ぜんぜん しません.
:::

::: problem id=p6 type=text answers="なにをしましたか"
Type "What did you do?"
hint: nani o shimashita ka
solution: なにを しましたか。
Hear it: !say[なにを しましたか。]
:::

::: problem id=p7 type=choice
Listen: !listen[m|せんしゅう きょうとに いきました。おてらを みました。]
When did the speaker go to Kyoto?
- [x] last week
- [ ] this week
- [ ] next week
solution: せんしゅう (last week) and いきました (went). "Last week I went to Kyoto and saw temples."
:::

::: problem id=p8 type=open
Say three things you did yesterday, using ました, and one thing you didn't do, using ませんでした.
!speak[my yesterday]
solution: For example: きのう だいがくに いきました。としょかんで べんきょうしました。うちで ばんごはんを たべました。テレビは みませんでした。
:::
