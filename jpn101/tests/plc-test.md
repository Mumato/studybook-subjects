::: problem id=t1 type=choice
Fill in: きょうしつに せんせいが ＿。 (The teacher is in the classroom.)
- [ ] あります
- [x] います
- [ ] です
solution: A teacher is a person: います.
Hear it: !say[きょうしつに せんせいが います。]
:::

::: problem id=t2 type=choice

Hear it: !say[うちの うしろ]
