::: problem id=t1 type=numeric answer="800"
What number is 八百?
solution: 八 (8) × 百 (100) = 800, はっぴゃく.
Hear it: !say[はっぴゃく]
:::

::: problem id=t2 type=numeric answer="2500"
How many yen is 二千五百円?
solution: 二千 (2,000) + 五百 (500) = ¥2,500.
Hear it: !say[にせんごひゃくえん]
:::

::: problem id=t3 type=choice
Which day is 土曜日?
- [ ] Sunday
- [ ] Thursday
- [x] Saturday
solution: 土 (earth) 曜日: どようび, Saturday.
Hear it: !say[どようび]
:::

::: problem id=t4 type=text answers="げつようび"
Type the reading of 月曜日.
hint: getsuyoubi
solution: げつようび, Monday.
Hear it: !say[げつようび]
:::

::: problem id=t5 type=choice
What does 母 mean?
- [ ] father
- [x] mother
- [ ] child
solution: 母 (はは): mother. 父 is father, 子 is child.
Hear it: !say[はは]
:::

::: problem id=t6 type=text answers="たべたいです"
Type the reading of 食べたいです.
hint: tabetai desu
solution: たべたいです, "I want to eat": 食 keeps its reading た when the ending changes.
Hear it: !say[たべたいです]
:::

::: problem id=t7 type=choice
How is 日 read in 日本?
- [x] に
- [ ] にち
- [ ] ひ
solution: 日本 is にほん: 日 is に here.
Hear it: !say[にほん]
:::

::: problem id=t8 type=choice
Listen: !listen[m|いま よじはん です。]
Which is the time you heard, in kanji?
- [ ] 四時
- [x] 四時半
- [ ] 九時半
solution: よじはん: 四時半, 4:30.
:::
