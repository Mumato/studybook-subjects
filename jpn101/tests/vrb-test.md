::: problem id=t1 type=text answers="よみません"
Type "I don't read." (from よみます)
hint: yomimasen
solution: よみません (yomimasen).
Hear it: !say[よみません]
:::

::: problem id=t2 type=choice
Fill in: うち ＿ ばんごはんを たべます。 (I eat dinner at home.)
- [ ] を
- [x] で
- [ ] に
solution: Home is where the action happens: で.
Hear it: !say[うちで ばんごはんを たべます]
:::

::: problem id=t3 type=choice
Fill in: ごご にじ ＿ えきに いきます。 (I'll go to the station at 2 p.m.)
- [x] に
- [ ] で
- [ ] を
solution: A clock time takes に.
Hear it: !say[ごご にじに えきに いきます]
:::

::: problem id=t4 type=text answers="みませんでした"
Type "I didn't watch."
hint: mimasen deshita
solution: みませんでした (mimasen deshita).
Hear it: !say[みませんでした]
:::

::: problem id=t5 type=choice
Which needs a negative verb?
- [ ] よく
- [ ] ときどき
- [x] ぜんぜん
solution: ぜんぜん (not at all) goes with a negative verb.
:::

::: problem id=t6 type=text answers="たべましょう"
Type "Let's eat."
hint: tabemashou
solution: たべましょう (tabemashou).
Hear it: !say[たべましょう]
:::

::: problem id=t7 type=choice
Listen: !listen[m|きのう としょかんで にほんごを べんきょうしました。]
What did the speaker do yesterday?
- [x] studied Japanese at the library
- [ ] read Japanese books at home
- [ ] will study Japanese at the library
solution: きのう (yesterday) としょかんで (at the library) にほんごを べんきょうしました (studied Japanese).
:::

::: problem id=t8 type=choice
Listen: !listen[こんばん いっしょに ばんごはんを たべませんか。]
What is the speaker doing?
- [ ] saying they won't eat dinner
- [x] inviting you to dinner tonight
- [ ] asking what you ate last night
solution: たべませんか is an invitation: "Would you like to have dinner together tonight?"
:::
