::: problem id=t1 type=numeric answer="76"
What number is ななじゅうろく?
solution: なな (7) × じゅう + ろく (6) = 76.
Hear it: !say[ななじゅうろく]
:::

:::

::: problem id=t3 type=numeric answer="12000"
How many yen is いちまんにせんえん?
solution: いちまん (10,000) + にせん (2,000) = ¥12,000.
Hear it: !say[いちまんにせんえん]
:::
