::: problem id=t1 type=text answers="たかくないです"
Type "It's not expensive." (from たかい)
hint: takakunai desu
solution: たかくないです.
Hear it: !say[たかくないです]
:::

::: problem id=t2 type=choice
"A famous person" is:
- [x] ゆうめいな ひと
- [ ] ゆうめい ひと
- [ ] ゆうめいい ひと
solution: ゆうめい is a な-adjective: ゆうめいな ひと.
Hear it: !say[ゆうめいな ひと]
:::

::: problem id=t3 type=choice
"It wasn't quiet" (しずか) is:
- [ ] しずかくなかったです
- [x] しずかじゃなかったです
- [ ] しずかでしたじゃない
solution: な-adjective past negative: じゃなかったです.
Hear it: !say[しずかじゃなかったです]
:::

::: problem id=t4 type=text answers="たのしかったです"
Type "It was fun." (from たのしい)
hint: tanoshikatta desu
solution: たのしかったです.
Hear it: !say[たのしかったです]
:::

::: problem id=t5 type=choice
Which is a な-adjective, even though it ends in い?
- [ ] おおきい
- [x] きれい
- [ ] ちいさい
solution: きれい is a な-adjective: きれいな, きれいじゃないです.
:::

::: problem id=t6 type=choice
Fill in: わたしは スポーツ ＿ きらいです。
- [x] が
- [ ] を
- [ ] に
solution: きらい (dislike) takes が.
Hear it: !say[わたしは スポーツが きらいです]
:::
