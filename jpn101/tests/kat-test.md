::: problem id=t1 type=choice
Which is **tsu**?
- [ ] シ
- [x] ツ
- [ ] ソ
solution: ツ: dots on top, the stroke sweeps down. シ is shi, ソ is so.
Hear it: !say[ツ]
:::

::: problem id=t2 type=text answers="タクシー"
Type "taxi" in katakana.
hint: ta-ku-shi-
solution: タクシー (takushii).
Hear it: !say[タクシー]
:::

::: problem id=t3 type=choice
What does ジュース mean?
- [x] juice
- [ ] juicer
- [ ] use
solution: ジュ (ju) + ー + ス: *juusu*, juice.
Hear it: !say[ジュース]
:::

::: problem id=t4 type=text answers="kappu"
Type the reading of カップ in romaji.
solution: *kappu* (cup): small ッ doubles the p.
Hear it: !say[カップ]
:::

::: problem id=t5 type=choice
Listen: !listen[ハンバーガー]
What did you hear?
- [x] hamburger
- [ ] handbag
- [ ] hamster
solution: ハンバーガー (hanbaagaa).
:::

::: problem id=t6 type=choice
Which is the best katakana for the name "Lisa"?
- [x] リサ
- [ ] リザ
- [ ] ライサ
solution: By sound: li-sa → リサ. Japanese has no separate l, so l and r both use the R row.
Hear it: !say[リサ]
:::

::: problem id=t7 type=text answers="パーティー"
Type "party" in katakana.
hint: Type thi for ティ.
solution: パーティー (paatii).
Hear it: !say[パーティー]
:::

::: problem id=t8 type=choice
Which word is written in katakana because it is a loanword?
- [ ] すし
- [x] テレビ (TV)
- [ ] せんせい
solution: テレビ comes from "television". すし and せんせい are Japanese words, written in hiragana (or kanji).
Hear it: !say[テレビ]
:::
