::: problem id=t3 type=text answers="fu;hu"

:::

::: problem id=t4 type=text answers="sakura"
Read this word: さくら (cherry blossom)
solution: さ (sa) + く (ku) + ら (ra) = **sakura**.
Hear it: !say[さくら]
:::

::: problem id=t5 type=text answers="kitte"
Read this word: きって (stamp)
solution: The small っ doubles the t: **kitte**.
Hear it: !say[きって]
:::

::: problem id=t6 type=choice
Which is **nu**?
- [x] ぬ
- [ ] め
- [ ] ね
solution: ぬ (nu) has the loop at the end; め (me) doesn't.
Hear it: !say[ぬ]
:::

::: problem id=t7 type=text answers="おちゃ"
Listen: !listen[おちゃ]
Type the word you hear.
solution: おちゃ (ocha), "green tea": お + ちゃ (with a small ゃ).
:::

::: problem id=t8 type=choice
Adding two small dots (dakuten) to さ gives:
- [x] ざ (za)
- [ ] ぱ (pa)
- [ ] さ unchanged
solution: Dakuten voices the sound: s becomes z.
Hear it: !say[ざ]
:::
