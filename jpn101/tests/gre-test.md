::: problem id=t1 type=choice
What do you say at 7 p.m. when you meet a friend's parents?
- [ ] おはようございます
- [x] こんばんは
- [ ] おやすみなさい
solution: こんばんは is "good evening".
:::

::: problem id=t2 type=text answers="こんにちは"
Type "hello" (the daytime greeting).
hint: konnichiwa
solution: こんにちは, read *konnichiwa*.
:::

::: problem id=t3 type=choice
Which do you say after finishing a meal?
- [x] ごちそうさまでした
- [ ] いただきます
- [ ] はじめまして
solution: ごちそうさまでした thanks the people who prepared the meal.
:::

::: problem id=t4 type=text answers="はじめまして"
Type the phrase you say when meeting someone for the very first time.
hint: hajimemashite
solution: はじめまして (hajimemashite), "nice to meet you".
:::

::: problem id=t5 type=text answers="わたしはせんせいです;せんせいです"
Type "I am a teacher."
hint: watashi wa sensei desu
solution: わたしは せんせいです。
:::

::: problem id=t6 type=choice
Listen: !listen[m|がくせいですか。]
What did you hear?
- [ ] a statement: "I'm a student."
- [x] a question: "Are you a student?"
- [ ] a denial: "I'm not a student."
solution: がくせいですか。 The か at the end makes it a question.
:::

::: problem id=t7 type=choice
だいがくの がくせい means:
- [x] a university student
- [ ] the university is a student
- [ ] a student's university
solution: の links them: だいがく (university) の がくせい (student).
:::

::: problem id=t8 type=choice
How is the particle は in わたしは read?
- [ ] ha
- [x] wa
- [ ] ba
solution: As a particle, は is read "wa".
:::
