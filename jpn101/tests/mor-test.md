::: problem id=t1 type=choice
Fill in: タクシー ＿ かえります。 (I'll go home by taxi.)
- [x] で
- [ ] を
- [ ] も
solution: で marks the means.
Hear it: !say[タクシーで かえります。]
:::

::: problem id=t2 type=choice
"I like cats too" (replacing が):
- [ ] ねこが も すきです。
- [x] ねこも すきです。
- [ ] ねこと すきです。
solution: も replaces が: ねこも すきです.
Hear it: !say[ねこも すきです。]
:::

::: problem id=t3 type=text answers="じゅうじからごじまで"
Type "from 10 to 5" (o'clock).
hint: juuji kara goji made
solution: じゅうじから ごじまで.
Hear it: !say[じゅうじから ごじまで]
:::

::: problem id=t4 type=text answers="たべたいです"
Type "I want to eat."
hint: tabetai desu
solution: たべたいです.
Hear it: !say[たべたいです]
:::

::: problem id=t5 type=choice
どうして きませんでしたか。 The best answer is:
- [x] あたまが いたかったですから。
- [ ] あたまが いたかったです まで。
- [ ] きたいです。
solution: Answer "why" with reason + から: "Because I had a headache." (いたい means painful; いたかった is its past.)
Hear it: !say[あたまが いたかったですから。]
:::

::: problem id=t6 type=choice
Your **own** older sister, to a teacher:
- [x] あね
- [ ] おねえさん
- [ ] いもうと
solution: Humble word for your own family: あね.
Hear it: !say[あね]
:::

::: problem id=t7 type=choice
Listen: !listen[m|ともだちと バスで うみに いきたいです。]
How does the speaker want to go to the sea?
- [ ] alone, by train
- [x] with a friend, by bus
- [ ] with family, by car
solution: ともだちと (with a friend) バスで (by bus).
:::

::: problem id=t8 type=choice
Listen: !listen[あには にじゅうにさい です。せが たかいです。]
What do you learn about the older brother?
- [x] He's 22 and tall.
- [ ] He's 12 and tall.
- [ ] He's 22 and short.
solution: にじゅうにさい (22) and せが たかい (tall).
:::
